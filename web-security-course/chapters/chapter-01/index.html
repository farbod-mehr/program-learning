📖 عنوان کامل فصل: مبانی امنیت وب و نقشه راه CEH — بنیادی‌ترین فصل دوره که کل مسیر پیش روی شما را روشن می‌کند.

🎓 سطح دشواری: مبتدی (بدون نیاز به دانش پیشین امنیت). تنها پیش‌نیاز، آشنایی ابتدایی با HTML و یک زبان بک‌اند (ترجیحاً Python/Django) و مفهوم HTTP است.

⏱ زمان مطالعه: ۹۰ تا ۱۲۰ دقیقه (شامل راه‌اندازی آزمایشگاه و انجام کارگاه).

🎯 اهداف کلان این فصل:
  1. درک مدل CIA به‌عنوان ستون فقرات هر بحث امنیتی و توانایی تحلیل هر حادثه بر اساس آن.
  2. آشنایی کامل با Cyber Kill Chain و هفت مرحله‌ای که هر حمله واقعی طی می‌کند.
  3. شناخت OWASP Top 10 (2021) به‌عنوان نقشه راه استاندارد آسیب‌پذیری‌های وب.
  4. تمایز روشن بین هکرهای کلاه‌سفید/خاکستری/سیاه و درک مسئولیت حقوقی هر نقش.
  5. راه‌اندازی اولین آزمایشگاه امنیتی شخصی با VMware + Kali + Django.
📚 خروجی قابل اندازه‌گیری (پس از این فصل):
  • می‌توانید هر آسیب‌پذیری را در یکی از سه ضلع CIA جای دهید.
  • می‌توانید هفت فاز Kill Chain را روی یک حمله واقعی (مثل Equifax 2017) نقشه کنید.
  • آزمایشگاه ایزوله با ۲ ماشین مجازی راه‌اندازی کرده و IPها را تنظیم کرده‌اید.
  • می‌دانید چه کاری قانونی و چه کاری جرم است (بر اساس قانون ایران).
  • یک نقشه راه شخصی ۶ ماهه برای ورود به امنیت وب نوشته‌اید.
⚠️ هشدار اخلاقی و قانونی (بسیار مهم): تمام تکنیک‌های این دوره فقط در آزمایشگاه ایزوله و روی سیستم‌هایی که مالک آن‌ها هستید یا مجوز کتبی (Written Authorization) دارید، مجاز است. در ایران، مطابق قانون جرایم رایانه‌ای مصوب ۱۳۸۸ (مواد ۱ تا ۸)، دسترسی غیرمجاز به سیستم‌های رایانه‌ای جرم کیفری محسوب شده و مجازات آن از حبس ۹۱ روز تا ۱ سال شروع و در موارد تشدیدشده به حبس ۵ تا ۱۵ سال می‌رسد. یادگیری امنیت، یادگیری مسئولیت‌پذیری است.

۴. مقدمه و اهمیت موضوع (چرا این حمله خطرناک است؟)

📖 داستان واقعی — Equifax (۲۰۱۷): یکی از سه آژانس اعتبارسنجی بزرگ آمریکا، در یک بازه ۷۶ روزه (از ۱۳ می تا ۲۹ جولای ۲۰۱۷) توسط مهاجمان ناشناس نفوذ کرد. ریشه حمله یک آسیب‌پذیری Apache Struts (CVE-2017-5638) بود که پچ آن ۲ ماه قبل منتشر شده بود ولی اعمال نشده بود. نتیجه فاجعه‌بار:

  • افشای اطلاعات ۱۴۷ میلیون کاربر (نام، شماره تأمین اجتماعی، تاریخ تولد، شماره گواهینامه)
  • جریمه ۵۷۵ تا ۷۰۰ میلیون دلاری
  • استعفای مدیرعامل، CIO و CSO
  • هزینه کل تخمینی: حدود ۱.۷ میلیارد دلار

و همه این‌ها از یک پچ اعمال‌نشده شروع شد. درس: در امنیت، «نگهداری» به‌اندازه «طراحی» مهم است.

تهدید: متوسط
💰 Cybercriminal

با انگیزه مالی؛ باج‌گیری، فروش داده، کلاهبرداری.

تهدید: بالا

🕵️ APT

تهدید: بحرانی
5.4 — مدل‌های ذهنی ضروری:
  • Defense in Depth (دفاع لایه‌ای): هیچ لایه‌ای تنها کافی نیست؛ ترکیب چند لایه (WAF + کد امن + پایش + آموزش کاربر).
  • Least Privilege (کمترین امتیاز): هر کاربر و سرویس فقط حداقل دسترسی لازم را داشته باشد.
  • Fail Securely: اگر سیستم شکست خورد، امن شکست بخورد (مثلاً اگر WAF خراب شد، ترافیک بسته شود نه عبور کند).
  • Trust but Verify: حتی به کاربران داخلی هم بدون تأیید اعتماد نکنید (Zero Trust).
  • Attack Surface (سطح حمله): هر ورودی/سرویس/API جدید، سطح حمله را گسترش می‌دهد.

۶. زنجیره کشتار سایبری (Cyber Kill Chain)

قبل از یادگیری هر حمله خاص، باید بدانید هر حمله واقعی چه مراحلی دارد. مدل Cyber Kill Chain که توسط Lockheed Martin در ۲۰۱۱ معرفی شد، هفت مرحله دارد. هر مرحله فرصتی برای دفاع است.

مرحله ۱: Reconnaissance    →  شناسایی و جمع‌آوری اطلاعات
مرحله ۲: Weaponization     →  ساخت ابزار حمله
مرحله ۳: Delivery          →  تحویل (ایمیل، وب، USB)
مرحله ۴: Exploitation      →  بهره‌جویی از آسیب‌پذیری
مرحله ۵: Installation      →  نصب backdoor
مرحله ۶: Command & Control →  ارتباط با مهاجم
مرحله ۷: Actions on Obj.   →  عملیات اصلی (سرقت/تخریب)
تحلیل گام‌به‌گام — با مثال Equifax 2017:
⚔️ نقشه‌برداری یک حمله واقعی:
  1. Reconnaissance: مهاجم سایت Equifax را بررسی می‌کند، زیردامنه‌ها را با subfinder پیدا می‌کند، تکنولوژی‌ها را با Wappalyzer شناسایی می‌کند → Apache Struts شناسایی می‌شود.
  2. Weaponization: مهاجم PoC عمومی CVE-2017-5638 را از GitHub برمی‌دارد و برای هدف تجهیز می‌کند (رشته OGNL مخرب در هدر Content-Type).
  3. Delivery: درخواست HTTP مخرب به endpoint آسیب‌پذیر ارسال می‌شود: 
    POST /struts/upload.action HTTP/1.1
Host: vulnerable.equifax.com
Content-Type: %{(#_='multipart/form-data').(#_memberAccess=@@DEFAULT_MEMBER_ACCESS)...
}
  4. Exploitation: Struts هدر را تفسیر می‌کند و کد Java مخرب اجرا می‌شود → RCE (اجرای کد از راه دور).
  5. Installation: مهاجم Web Shell نصب می‌کند تا دسترسی پایدار داشته باشد.
  6. Command & Control: از طریق Web Shell با سرور مهاجم (C2) ارتباط برقرار می‌کند.
  7. Actions on Objective: به‌مدت ۷۶ روز به دیتابیس دسترسی دارد، ۱۴۷ میلیون رکورد استخراج می‌کند.
💡 درس کلیدی: Equifax می‌توانست در حداقل ۳ مرحله جلوی حمله را بگیرد:
  • مرحله ۱: شناسایی آسیب‌پذیری → پچ به‌موقع
  • مرحله ۴: WAF قواعد Struts RCE → بلاک درخواست
  • مرحله ۷: پایش خروج داده (DLP) → شناسایی استخراج ۱۴۷M رکورد
این یعنی: «دفاع لایه‌ای» واقعیت دارد و هر لایه، یک فرصت نجات است.

مرحله ۱: ساخت شبکه Host-Only در VMware
  1. VMware Workstation → Edit → Virtual Network Editor
  2. Add Network → انتخاب VMnet1 → Type: Host-Only
  3. تنظیم Subnet IP: 192.168.56.0 و Mask: 255.255.255.0
  4. تیک Connect a host virtual adapter to this network را بزنید
  5. تیک Use local DHCP service را بردارید (IP استاتیک می‌خواهیم)
مرحله ۲: تنظیم IP استاتیک در Kali

در ترمینال Kali (با کاربر root یا sudo):

# ۱) پیدا کردن نام اینترفیس
ip link show
# معمولاً eth0 یا ens33

# ۲) تنظیم IP استاتیک
sudo ip addr add 192.168.56.10/24 dev eth0
sudo ip link set eth0 up

# ۳) تست اولیه
ip addr show eth0
# باید 192.168.56.10 را ببینید

# ۴) برای دائمی شدن: ویرایش /etc/network/interfaces
sudo nano /etc/network/interfaces
# اضافه کنید:
# auto eth0
# iface eth0 inet static
#     address 192.168.56.10
#     netmask 255.255.255.0
مرحله ۳: تنظیم IP استاتیک در Windows
  1. Control Panel → Network and Sharing Center → Change adapter settings
  2. راست‌کلیک روی آداپتر VMware (VMnet1) → Properties
  3. Internet Protocol Version 4 (TCP/IPv4) → Properties
  4. Use the following IP address:
    • IP: 192.168.56.20
    • Subnet: 255.255.255.0
    • Gateway: خالی
  5. OK → OK

def search(request):

    products = Product.objects.filter(name__icontains=q)   # ایمن به‌صورت پیش‌فرض
    return render(request, 'products.html', {'products': products})

# ✅ اگر مجبور به SQL خام هستید:
cursor.execute("SELECT * FROM products WHERE name LIKE %s", [f"%{q}%"])  # پارامتری

server {

    # هدرهای امنیتی

}

۹. اخلاق حرفه‌ای و قانون (بحرانی‌ترین بخش)

🚨 قانون طلایی (حفظ کنید): «هرگز، تحت هیچ شرایطی، بدون مجوز کتبی مکتوب به سیستم‌هایی که مالک آن‌ها نیستید، حمله نکنید. حتی برای «کمک» یا «نمایش آسیب‌پذیری». نیت خوب، جرم را توجیه نمی‌کند.»
۹.۱ — چارچوب قانونی ایران (قانون جرایم رایانه‌ای ۱۳۸۸):
مادهموضوعمجازات

ℹ️ نکته حقوقی: حتی تلاش ناموفق برای نفوذ هم جرم است. «فقط چک کردم ببینم باز است» دفاع حقوقی معتبری نیست. مرجع رسمی: https://rc.majlis.ir/fa/law/show/791050
۹.۲ — تفاوت سه کلاه (در امنیت):
⚪ هکر کلاه‌سفید (Ethical Hacker)
  • مجوز کتبی دارد (Scope of Work)
  • در محدوده تعریف‌شده کار می‌کند
  • گزارش مسئولانه ارائه می‌دهد
  • از قوانین پیروی می‌کند (NDA)
  • مثال: پنتستر شرکت‌ها، Bug Bounty Hunter در محدوده
⚫ هکر کلاه‌سیاه (Black Hat)
  • بدون مجوز وارد می‌شود
  • با انگیزه مالی/انتقام
  • داده می‌فروشد یا تخریب می‌کند
  • ردپا پاک می‌کند
  • مثال: باج‌گیرها، خرابکاران

⚫⚪ هکر کلاه‌خاکستری: بدون مجوز وارد می‌شود ولی گزارش می‌دهد (مثلاً آسیب‌پذیری را پیدا می‌کند و به شرکت اطلاع می‌دهد). این کار همچنان غیرقانونی است — هرچند بعضی شرکت‌ها به‌عنوان Bug Bounty با محدودیت‌های مشخص اجازه می‌دهند.

۹.۳ — چک‌لیست «قبل از هر تست» (Scope of Work):
  • مجوز کتبی امضاشده از مالک سیستم
  • لیست دقیق دارایی‌های مجاز (IP/Domain/API)
  • بازه زمانی مشخص تست (مثلاً ۳ روز)
  • تکنیک‌های ممنوع (مثلاً DoS ممنوع)
  • مخاطب اضطراری (اگر سایت از کار افتاد)
  • توافق محرمانگی (NDA)
  • روش انتقال یافته‌ها (Encrypted)
  • تعهد به گزارش مسئولانه (Responsible Disclosure)
⚠️ دام‌های رایج مبتدیان (پرهیز کنید):
  • ❌ «آزمایش» روی سایت دانشگاه/شرکت «برای درس» بدون مجوز
  • ❌ اسکن کردن IPهای عمومی برای «کنجکاوی»
  • ❌ اعلام آسیب‌پذیری سایت شرکتی در توییتر/لینکدین برای «شهرت»
  • ❌ استفاده از ابزارهای خودکار روی دامنه دیگران حتی بدون intention
  • ❌ اشتراک‌گذاری PoC که اطلاعات حساس قربانی دارد
حتی در این موارد، IP شما در لاگ‌ها ثبت می‌شود و قابل پیگرد است.

تفاوت CEH با OSCP چیست؟ کدام بهتر است؟

CEH (Certified Ethical Hacker) = تئوری‌محور، پوشش گسترده، ورودی صنعت. OSCP (Offensive Security Certified Professional) = عملی، ۲۴ ساعت آزمون عملی، معتبرترین گواهی پنتست. توصیه: اول CEH برای پایه‌ریزی، بعد از ۶-۱۲ ماه تمرین، OSCP.

چرا حمله من در DVWA کار نمی‌کند؟

چک‌لیست:

۴. اگر sqlmap استفاده می‌کنید، --cookie و --data لازم است

آیا Nmap بدون مجوز، جرم است؟

چون تمام فصل‌های بعدی، «کاربرد» همین مفاهیم پایه هستند. اگر مدل CIA و Kill Chain را درونی کنید، به‌جای «حفظ کردن ۵۰ حمله»، «فهمیدن ۵۰ نمونه از ۷ الگو» را تجربه می‌کنید. این تفاوت بین یک اسکریپت‌کیدی و یک مهندس امنیت است.

📎 پل به فصل بعد: در فصل ۲، آزمایشگاه را کامل می‌کنیم و اولین ابزارهای reconnaissance را اجرا می‌کنیم: Nmap، Gobuster، Subfinder، Wappalyzer. خواهید دید چطور یک مهاجم حرفه‌ای، قبل از هر حمله، ۸۰٪ اطلاعات هدف را از منابع عمومی جمع می‌کند.

۱۲. خودارزیابی و آزمونک

⭐ چک‌لیست خودارزیابی (صادق باشید):
  • می‌توانم هر آسیب‌پذیری را در یکی از اضلاع CIA دسته‌بندی کنم.
  • می‌توانم هفت مرحله Kill Chain را به‌ترتیب نام ببرم و برای هر کدام یک مثال بزنم.
  • می‌دانم تفاوت Vulnerability، Threat و Risk چیست.
  • آزمایشگاه Kali + Windows دارم و پینگ بین دو طرف کار می‌کند.
  • سرور Django روی هدف اجرا می‌شود و از Kali قابل دسترسی است.
  • می‌دانم تفاوت سه کلاه (سفید، خاکستری، سیاه) در چیست.
  • می‌دانم حداقل سه ماده از قانون جرایم رایانه‌ای ۱۳۸۸ ایران.
  • یک فایل گزارش lab-report.md از راه‌اندازی آزمایشگاه تهیه کرده‌ام.
📝 آزمونک فصل (۵ سؤال، بدون نگاه به متن بالا):
۱. کدام گزینه، نماد نقض «محرمانگی» (Confidentiality) است؟
  • الف) تغییر رمز کاربر توسط مهاجم
  • ب) استخراج دیتابیس کاربران با SQL Injection
  • ج) حمله DDoS و از کار انداختن سایت
  • د) شکست بکاپ و از دست رفتن داده
۲. در Cyber Kill Chain، کدام مرحله «ساخت ابزار حمله» را توصیف می‌کند؟
  • الف) Reconnaissance
  • ب) Weaponization
  • ج) Delivery
  • د) Exploitation
۳. کدام CVE مربوط به Apache Struts بود که به نفوذ Equifax در ۲۰۱۷ منجر شد؟
  • الف) CVE-2017-5638
  • ب) CVE-2021-44228
  • ج) CVE-2014-0160
  • د) CVE-2019-0708
۴. طبق قانون جرایم رایانه‌ای ایران، حداقل مجازات «دسترسی غیرمجاز به داده‌های محرمانه» چیست؟
  • الف) تذکر کتبی
  • ب) حبس ۹۱ روز تا ۱ سال + جزای نقدی
  • ج) فقط جزای نقدی
  • د) حبس ۵ تا ۱۵ سال
۵. کدام گزینه «لایه اول دفاعی» در مدل Defense in Depth وب است؟
  • الف) WAF
  • ب) آموزش کاربر
  • ج) کد امن (Secure Coding)
  • د) SIEM
✅ نمایش پاسخ‌های صحیح

۱. ب — استخراج دیتابیس با SQLi = دسترسی غیرمجاز به داده = نقض محرمانگی.

۲. ب — Weaponization دقیقاً مرحله «ساخت/تجهیز ابزار حمله» است.

۳. الف — CVE-2017-5638 (Apache Struts2 RCE) عامل نفوذ Equifax بود.

۴. ب — ماده ۱ قانون جرایم رایانه‌ای: حبس ۹۱ روز تا ۱ سال + جزای نقدی.

۵. ج — کد امن (Secure Coding) آخرین سنگر است؛ اگر WAF رد شود، کد باید ایمن باشد.

۱۳. پروژه هفتگی (تمرین مستقل)

🏆 پروژه هفتگی: «گزارش تحلیلی یک نقض امنیتی واقعی»

هدف: یکی از پنج رخداد زیر را انتخاب کنید، تحقیق کنید، و بر اساس مدل‌های CIA و Kill Chain تحلیل کنید.

ساختار گزارش (حداقل ۳ صفحه، حداکثر ۶ صفحه):

  5. ریشه فنی: دقیقاً چه آسیب‌پذیری/ضعفی؟ CVE (اگر دارد)

🎯 گام بعدی (فصل ۲):

در فصل ۲، آزمایشگاه را تکمیل می‌کنیم و وارد فاز Reconnaissance می‌شویم:

  • 🔍 Passive Recon: جستجو در Google Dorks، Shodan، Censys، Wayback Machine
