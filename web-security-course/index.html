جمع‌آوری اطلاعات (Reconnaissance)

اولین فاز تست نفوذ — کشف کامل هدف از منابع عمومی و تعاملی. با اطلاعات دقیق، حمله هدفمند می‌شود.

  • Passive vs Active Recon — تفاوت بحرانی
  • OSINT با Google Dorks، Shodan، Censys
  • DNS Enumeration — زیردامنه‌ها و رکوردها
  • Nmap — پادشاه اسکن پورت با NSE Scripts
  • Gobuster و FFUF برای کشف مسیرها
  • WhatWeb و Wappalyzer برای Fingerprinting

شناسایی و اسکن وب

فصل ۶

SQL Injection — نفوذ در دیتابیس

پادشاه آسیب‌پذیری‌ها — استخراج کامل دیتابیس از یک فیلد ورودی ساده.

  • Union-based SQLi — استخراج داده در یک درخواست
  • Boolean-based Blind — حمله کور با سؤال بله/خیر
  • Time-based Blind — حمله با تأخیر زمانی
  • Error-based — استخراج از پیام‌های خطا
  • Out-of-Band SQLi — سرقت داده از طریق DNS
  • تسلط کامل بر sqlmap + Bypass WAF
⏱ ۱۳۰ دقیقه 🎓 متوسط 🛠 sqlmap + Burp
⚡
فصل ۷

XSS — تزریق اسکریپت سمت کلاینت

سرقت نشست کاربران و اجرای کد در مرورگر آن‌ها — پرتکرارترین حمله وب.

  • Reflected XSS — تزریق در URL
  • Stored XSS — کد مخرب در دیتابیس
  • DOM-based XSS — حمله در سمت مرورگر
  • BeEF Framework — کنترل مرورگر قربانی
  • CSP Bypass و تکنیک‌های دور زدن فیلتر
⏱ ۱۲۰ دقیقه 🎓 متوسط 🛠 BeEF + Burp
🎭
فصل ۸

CSRF — جعل درخواست بین‌سایتی

وادار کردن قربانی احراز هویت‌شده به انجام کار ناخواسته — بدون دزدیدن رمز.

  • ساخت صفحه حمله برای تغییر رمز/ایمیل
  • SameSite Cookie Bypass
  • CSRF Token Flaws و Reuse
  • Referer/Origin Check Bypass
  • XSS + CSRF Chains (زنجیره حمله)
⏱ ۱۰۰ دقیقه 🎓 متوسط 🛠 Burp + HTML
🚪
فصل ۹

IDOR و شکست کنترل دسترسی

ساده‌ترین و پردرآمدترین آسیب‌پذیری Bug Bounty — تغییر یک عدد در URL.

  • Horizontal Privilege Escalation (کاربر به کاربر)
  • Vertical Privilege Escalation (کاربر به ادمین)
  • BOLA (Broken Object Level Authorization)
  • Mass Assignment — تغییر فیلدهای مخفی
  • Directory Traversal و Path Bypass
⏱ ۱۰۰ دقیقه 🎓 متوسط 🛠 Burp Intruder

فصل ۱۰

آپلود فایل ناامن و Web Shell

از یک فرم آپلود ساده تا دسترسی کامل به سرور با Reverse Shell.

  • Bypass Extension Filters (.php, .phtml, .php5)
  • Bypass MIME Type Check
  • Polyglot Files (تصویر + کد PHP)
  • Web Shell (PHP, JSP, ASPX)
  • Reverse Shell با netcat و powershell
⏱ ۱۲۵ دقیقه 🎓 پیشرفته 🛠 Burp + netcat

فصل ۱۱

Command Injection و RCE

خطرناک‌ترین کلاس آسیب‌پذیری — اجرای دستور مستقیم روی سرور هدف.

  • OS Command Injection — اجرای دستور سیستم
  • Blind Command Injection (با تأخیر و OAST)
  • Filter Bypass (space, pipe, semicolon)
  • Reverse Shell با bash, python, powershell
  • Privilege Escalation اولیه روی سرور
⏱ ۱۲۰ دقیقه 🎓 پیشرفته 🛠 Burp + nc + python
🌐
فصل ۱۲

SSRF — جعل درخواست سمت سرور

عبور از دیوار آتش از داخل — قلب حمله به سرویس‌های ابری (AWS, GCP).

  • کشف سرویس‌های داخلی (Internal Network Scan)
  • Cloud Metadata Attacks (169.254.169.254)
  • Bypass Blocklist (hex, decimal, DNS rebinding)
  • SSRF via URL parsers و redirects
  • ترکیب SSRF با سایر حملات (chained)
⏱ ۱۱۰ دقیقه 🎓 پیشرفته 🛠 Burp + curl
📄
فصل ۱۳

XXE — حمله به پردازش XML

خواندن فایل‌های سرور و SSRF از طریق پردازش XML — آسیب‌پذیری فراموش‌شده اما خطرناک.

  • XML External Entity — خواندن فایل‌های حساس
  • SSRF via XXE — حمله به شبکه داخلی
  • Blind XXE — با Out-of-Band Interaction
  • Billion Laughs — حمله DoS
  • XXE in SOAP, SAML, DOCX, SVG
⏱ ۱۱۰ دقیقه 🎓 پیشرفته 🛠 Burp + XXE Payloads

  • Insecure Deserialization (Java, PHP, Python)
