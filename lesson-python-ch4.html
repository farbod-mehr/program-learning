مقدمه و انگیزه‌بخشی

در دنیای واقعی، هر روز با تصمیم‌گیری‌های مختلف روبرو هستیم: «اگر باران بیاید، چتر برمی‌دارم» یا «اگر گرسنه باشم، غذا می‌خورم». در برنامه‌نویسی هم همین‌طور است. ساختارهای شرطی به برنامه اجازه می‌دهند بر اساس شرایط مختلف، تصمیم‌گیری کند و مسیرهای مختلفی را طی کند.

در این فصل با همه‌ی ابزارهای تصمیم‌گیری در پایتون آشنا می‌شوید: از if و else ساده گرفته تا elif، match-case و عملگر شرطی (Ternary). همچنین با مفهوم Falsy و Truthy آشنا می‌شوید که یکی از مفاهیم کلیدی در شرط‌های پایتون است.

تسلط بر ساختارهای شرطی، یکی از مهم‌ترین مهارت‌های هر برنامه‌نویسی است. با این فصل، می‌توانید برنامه‌هایی بنویسید که هوشمندانه رفتار کنند و به ورودی‌های کاربر پاسخ مناسب بدهند.

۴.۱ دستور if و else

ساده‌ترین ساختار شرطی است. اگر شرط True باشد، بلوک کد اجرا می‌شود. else زمانی اجرا می‌شود که شرط False باشد.

  • در پایتون، تورفتگی (Indentation) برای مشخص کردن بلوک کد استفاده می‌شود.
  • از : در انتهای خط شرط استفاده کنید.
# if ساده
age = 18
if age >= 18:
    print("شما بزرگسال هستید.")

# if/else
temperature = 30
if temperature > 25:
    print("هوا گرم است")
else:
    print("هوا خنک است")

# شرط با ورودی
score = int(input("امتیاز خود را وارد کنید: "))
if score >= 50:
    print("قبول شدید")
else:
    print("رد شدید")

# تورفتگی مهم است!
if True:
    print("این خط اجرا می‌شود")
    print("این خط هم اجرا می‌شود")
print("این خط همیشه اجرا می‌شود")
نکته در پایتون، تورفتگی (Indentation) بسیار مهم است. معمولاً از ۴ فاصله (Space) یا یک Tab برای تورفتگی استفاده می‌شود. عدم رعایت تورفتگی باعث خطای IndentationError می‌شود.
✏ تمرین یک برنامه بنویسید که عددی را از کاربر دریافت کند و با if/else مشخص کند که عدد زوج است یا فرد.

۴.۲ دستور elif (چندین شرط)

وقتی بیش از دو حالت داریم، از elif (مخفف else if) استفاده می‌کنیم. این ساختار به شما اجازه می‌دهد چندین شرط را پشت سر هم بررسی کنید.

# سیستم نمره‌دهی
score = int(input("نمره را وارد کنید: "))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"نمره: {score} → {grade}")

# وضعیت آب و هوا
temp = int(input("دمای امروز را وارد کنید: "))

if temp > 35:
    status = "بسیار گرم"
elif temp > 25:
    status = "گرم"
elif temp > 15:
    status = "معتدل"
elif temp > 5:
    status = "خنک"
else:
    status = "سرد"

print(f"وضعیت آب و هوا: {status}")
نکته طلایی ترتیب شرط‌ها در elif مهم است. پایتون از بالا به پایین شرط‌ها را بررسی می‌کند و به محض پیدا کردن شرط True، بقیه را نادیده می‌گیرد. شرط‌های خاص‌تر را بالاتر قرار دهید.
✏ تمرین یک برنامه بنویسید که سن کاربر را دریافت کند و بر اساس آن، گروه سنی را مشخص کند: زیر ۱۲ سال (کودک)، ۱۲ تا ۱۷ (نوجوان)، ۱۸ تا ۶۴ (بزرگسال)، ۶۵ به بالا (سالمند).

۴.۳ match-case (Python 3.10+)

match-case یک ساختار شرطی جدید در پایتون ۳.۱۰ است که مشابه switch در زبان‌های دیگر عمل می‌کند. برای مقایسه‌ی یک مقدار با چندین الگو استفاده می‌شود.

# مثال ساده: روزهای هفته
day = 3

match day:
    case 1:
        name = "شنبه"
    case 2:
        name = "یکشنبه"
    case 3:
        name = "دوشنبه"
    case 4:
        name = "سه‌شنبه"
    case 5:
        name = "چهارشنبه"
    case 6:
        name = "پنجشنبه"
    case 7:
        name = "جمعه"
    case _:
        name = "روز نامعتبر"

print(f"روز شماره {day}: {name}")  # روز شماره 3: دوشنبه

# match-case با مقادیر مختلف
command = "start"

match command:
    case "start":
        print("شروع برنامه")
    case "stop":
        print("توقف برنامه")
    case "restart":
        print("راه‌اندازی مجدد")
    case _:
        print("دستور نامعتبر")

# match-case با چند مقدار
number = 5

match number:
    case 0:
        print("صفر")
    case 1 | 2 | 3:
        print("یک تا سه")
    case 4 | 5 | 6:
        print("چهار تا شش")
    case _:
        print("بیشتر از شش")
نکته match-case از Python 3.10 به بعد در دسترس است. اگر از نسخه‌های قدیمی‌تر استفاده می‌کنید، از if/elif/else استفاده کنید. case _ مانند default در switch عمل می‌کند.
✏ تمرین با استفاده از match-case یک برنامه بنویسید که نام ماه (به انگلیسی) را دریافت کند و تعداد روزهای آن ماه را چاپ کند. (استفاده از | برای ترکیب چند مقدار).

۴.۴ عملگر شرطی (Ternary Operator)

عملگر شرطی (Ternary) یک روش کوتاه برای نوشتن if/else ساده است.

ساختار: مقدار_درست if شرط else مقدار_نادرست

# Ternary ساده
age = 20
status = "بزرگسال" if age >= 18 else "نوجوان"
print(status)  # "بزرگسال"

# مثال دیگر
score = 85
result = "قبول" if score >= 60 else "رد"
print(result)  # "قبول"

# استفاده در چاپ
x = 10
y = 20
print("x بزرگتر است" if x > y else "y بزرگتر است")  # y بزرگتر است

# Ternary تو در تو (توصیه نمی‌شود)
num = 0
result = "مثبت" if num > 0 else ("منفی" if num < 0 else "صفر")
print(result)  # صفر
نکته طلایی از Ternary فقط برای شرط‌های ساده و کوتاه استفاده کنید. برای شرط‌های پیچیده، از if/elif/else استفاده کنید تا کد خوانا باشد. از Ternary تو در تو خودداری کنید.
✏ تمرین با استفاده از Ternary، یک متغیر is_even تعریف کنید که اگر عددی زوج بود True و اگر فرد بود False برگرداند.

۴.۵ مفهوم Falsy و Truthy در پایتون

در پایتون، هر مقدار می‌تواند در یک شرط به صورت True (معادل Truthy) یا False (معادل Falsy) رفتار کند.

مقادیر Falsy در پایتون:

مقدارتوضیح
Noneمقدار خالی
Falseمقدار بولی False
0عدد صفر
0.0عدد اعشاری صفر
""رشته خالی
[]لیست خالی
{}دیکشنری خالی
()تاپل خالی
set()مجموعه خالی

همه‌ی مقادیر دیگر Truthy هستند.

# Falsy values
if False:
    print("اجرا نمی‌شود")

if 0:
    print("اجرا نمی‌شود")

if "":
    print("اجرا نمی‌شود")

if []:
    print("اجرا نمی‌شود")

if None:
    print("اجرا نمی‌شود")

# Truthy values
if True:
    print("اجرا می‌شود")

if 1:
    print("اجرا می‌شود")

if "سلام":
    print("اجرا می‌شود")

if [1, 2]:
    print("اجرا می‌شود")

if {"key": "value"}:
    print("اجرا می‌شود")

# استفاده عملی: بررسی وجود داده
user_input = input("ورودی: ")
if user_input:  # اگر رشته خالی نباشد
    print(f"شما وارد کردید: {user_input}")
else:
    print("ورودی خالی است")

# بررسی لیست
items = []
if items:  # اگر لیست خالی نباشد
    print("آیتم‌ها وجود دارند")
else:
    print("لیست خالی است")
نکته این ویژگی در پایتون بسیار قدرتمند است و به شما اجازه می‌دهد شرط‌ها را به‌صورت مختصر بنویسید. مثلاً if name: به معنای «اگر نام وجود دارد» است.
✏ تمرین یک لیست از چند عنصر تعریف کنید و با if بررسی کنید که آیا لیست خالی است یا نه. سپس با استفاده از Truthy/Falsy، یک برنامه بنویسید که یک رشته را از کاربر دریافت کند و اگر خالی بود پیام «ورودی خالی» نمایش دهد.

۴.۶ شرط‌های تو در تو (Nested Conditions)

گاهی اوقات نیاز داریم شرطی را داخل شرط دیگری قرار دهیم. به این کار شرط تو در تو (Nested) می‌گویند.

# بررسی احراز هویت
username = "admin"
password = "12345"

if username == "admin":
    if password == "12345":
        print("ورود موفق")
    else:
        print("رمز عبور اشتباه است")
else:
    print("نام کاربری اشتباه است")

# مثال: بررسی وام
age = 25
income = 6000000  # درآمد ماهانه
credit_score = 720

if age >= 18:
    if income >= 5000000:
        if credit_score >= 700:
            print("✔ وام تایید شد")
        else:
            print("✘ امتیاز اعتباری پایین است")
    else:
        print("✘ درآمد کافی نیست")
else:
    print("✘ سن کافی نیست")

# بهتر: ترکیب شرط‌ها با and
if age >= 18 and income >= 5000000 and credit_score >= 700:
    print("✔ وام تایید شد")
else:
    print("✘ شرایط را ندارید")
نکته طلایی شرط‌های تو در تو را تا حد ممکن ساده کنید. اگر بیش از ۲-۳ سطح تو در تو دارید، بهتر است از and یا or برای ترکیب شرط‌ها استفاده کنید یا کد را با توابع جداگانه بازنویسی کنید تا خوانایی افزایش یابد.
✏ تمرین یک برنامه بنویسید که وضعیت یک کاربر را بررسی کند: اگر کاربر وارد شده باشد (logged_in = True) و ادمین باشد (is_admin = True) «خوش آمدید ادمین» را چاپ کند. اگر وارد شده باشد ولی ادمین نباشد، «خوش آمدید کاربر» را چاپ کند. در غیر این صورت «لطفاً وارد شوید» را چاپ کند.

  3. با if/elif/else سطح امتیاز را مشخص کنید: ۹۰ تا ۱۰۰ عالی، ۷۰ تا ۸۹ خوب، ۵۰ تا ۶۹ متوسط، کمتر از ۵۰ ضعیف.

چالش کدنویسی: یک برنامه بنویسید که:

  • از کاربر یک عدد دریافت کند
  • با if/elif/else بررسی کند که عدد مثبت، منفی یا صفر است
  • با match-case بررسی کند که عدد در کدام بازه است (۱-۱۰، ۱۱-۲۰، ۲۱-۳۰ و ...)
  • با Ternary Operator مشخص کند که عدد زوج است یا فرد
  • با شرط‌های تو در تو بررسی کند که آیا عدد بخش‌پذیر بر ۳ و ۵ است

جمع‌بندی و خلاصه

نکات طلایی if و else برای تصمیم‌گیری‌های ساده. elif برای بررسی چندین شرط. match-case (Python 3.10+) برای مقایسه‌ی یک مقدار با چندین الگو. Ternary Operator (... if ... else ...) برای شرط‌های کوتاه و ساده. Falsy: None, False, 0, 0.0, '', [], {}, (), set(). همه‌ی مقادیر دیگر Truthy هستند. از شرط‌های تو در تو با احتیاط استفاده کنید و تا حد ممکن از and/or استفاده کنید. تورفتگی در پایتون ضروری است و مشخص‌کننده‌ی بلوک‌های کد است.

برگه تقلب

# if/elif/else
if condition:
    # code
elif condition2:
    # code
else:
    # code

# match-case (Python 3.10+)
match value:
    case 1:
        # code
    case 2 | 3:
        # code
    case _:
        # code

# Ternary
result = value_if_true if condition else value_if_false

# Truthy/Falsy
if value:  # اگر value Truthy باشد
    print("True")

واژه‌نامه تخصصی

  • Conditional (شرطی): ساختاری که بر اساس یک شرط تصمیم‌گیری می‌کند.
  • if: دستور شرطی پایه.
  • else: بخشی که در صورت False بودن شرط اجرا می‌شود.
  • elif: ترکیبی از else و if برای بررسی شرط‌های اضافی.
  • match-case: ساختار شرطی برای مقایسه‌ی الگو (Python 3.10+).
  • Ternary Operator: عملگر شرطی سه‌تایی.
  • Truthy: مقداری که در شرط معادل True است.
  • Falsy: مقداری که در شرط معادل False است.
  • Indentation: فاصله‌ی ابتدای خط برای مشخص کردن بلوک کد.
  • Nested Condition: شرطی که داخل شرط دیگری قرار دارد.

خطاهای رایج و عیب‌یابی

اشتباه فراموش کردن : در انتهای خط (if, elif, else, match).
راه‌حل: همیشه از : بعد از شرط استفاده کنید.
اشتباه استفاده از = (انتساب) به‌جای == (مقایسه) در شرط‌ها.
راه‌حل: برای مقایسه از == استفاده کنید. if x == 5: درست است.
اشتباه فراموش کردن تورفتگی که باعث خطای IndentationError می‌شود.
راه‌حل: از ۴ فاصله برای تورفتگی استفاده کنید و همیشه یکنواخت باشید.
اشتباه استفاده از match بدون case.
راه‌حل: case همیشه باید بعد از match بیاید.
اشتباه فراموش کردن case _ در match-case که باعث می‌شود مقادیر پیش‌بینی‌نشده مدیریت نشوند.
راه‌حل: همیشه یک case _ برای مقدار پیش‌فرض قرار دهید.

پروژه نهایی فصل ۴

عنوان پروژه: ساخت یک سیستم تشخیص وضعیت آب و هوا

شرح: یک برنامه بنویسید که با دریافت اطلاعات از کاربر، وضعیت آب و هوا را تحلیل کند:

  • از کاربر دمای فعلی را دریافت کند.
  • از کاربر وضعیت بارش (باران، برف، آفتابی، ابری) را دریافت کند.
  • از کاربر سرعت باد را دریافت کند.
  • با if/elif/else بر اساس دما، یک توصیه‌ی لباس (سبک، معمولی، گرم، بسیار گرم) ارائه دهد.
  • با match-case بر اساس وضعیت بارش، یک توصیه‌ی فعالیت (پیاده‌روی، بمان در خانه، ورزش indoor) ارائه دهد.
  • با Ternary Operator مشخص کند که آیا هوا برای سفر مناسب است (دمای بین ۱۵ تا ۳۰ و بدون باران).
  • با شرط‌های تو در تو بررسی کند که آیا شرایط خطرناک (باد شدید و باران) وجود دارد.
  • با استفاده از Truthy/Falsy، بررسی کند که آیا کاربر داده‌های معتبر وارد کرده است (مثلاً دما معتبر و بارش از لیست مجاز).
  • همه‌ی نتایج را به صورت یک گزارش کامل با f-string نمایش دهد.

چالش بیشتر یک سیستم پیشنهاد سفر بر اساس آب و هوا اضافه کنید (با match-case). با and و or شرط‌های پیچیده‌تری برای تشخیص شرایط اضطراری بسازید. از ifهای تو در تو برای تحلیل دقیق‌تر (مثل ترکیب دما و بارش) استفاده کنید.
