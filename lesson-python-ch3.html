مقدمه و انگیزه‌بخشی

در فصل قبل با متغیرها و انواع داده آشنا شدید. حالا وقت آن است که با عملگرها آشنا شوید. عملگرها به شما اجازه می‌دهند روی داده‌ها عملیات انجام دهید: جمع و تفریق، مقایسه، ترکیب شرط‌ها و خیلی چیزهای دیگر. بدون عملگرها، برنامه‌نویسی عملاً غیرممکن است.

در این فصل با همه‌ی عملگرهای اصلی پایتون آشنا می‌شوید: عملگرهای حسابی برای محاسبات ریاضی، عملگرهای مقایسه‌ای برای مقایسه‌ی مقادیر، عملگرهای منطقی برای ترکیب شرط‌ها، عملگرهای انتساب برای تغییر متغیرها، عملگرهای هویتی برای مقایسه‌ی هویت اشیاء و عملگرهای عضویت برای بررسی وجود یک عنصر در یک مجموعه.

تسلط بر عملگرها، کلید اصلی نوشتن برنامه‌های کاربردی است. با این فصل، می‌توانید برنامه‌هایی بنویسید که محاسبات، مقایسه‌ها و تصمیم‌گیری‌های پیچیده را انجام دهند.

۳.۱ عملگرهای حسابی (Arithmetic Operators)

عملگرهای حسابی برای انجام محاسبات ریاضی استفاده می‌شوند.

عملگرناممثالنتیجه
+جمع5 + 38
-تفریق10 - 46
*ضرب6 * 742
/تقسیم اعشاری15 / 43.75
//تقسیم صحیح15 // 43
%باقی‌مانده15 % 43
**توان2 ** 532
# جمع
print(5 + 3)        # 8

# تفریق
print(10 - 4)       # 6

# ضرب
print(6 * 7)        # 42

# تقسیم اعشاری
print(15 / 4)       # 3.75

# تقسیم صحیح
print(15 // 4)      # 3

# باقی‌مانده
print(15 % 4)       # 3

# توان
print(2 ** 5)       # 32

# ترکیب عملگرها
result = (10 + 5) * 2 - 4
print(result)       # 26

# کار با متغیرها
a = 10
b = 3
print(a + b)        # 13
print(a / b)        # 3.333...
print(a // b)       # 3
print(a % b)        # 1
نکته عملگر / همیشه یک عدد اعشاری (float) برمی‌گرداند، حتی اگر نتیجه‌ی تقسیم دقیق باشد (مثل 4 / 2 = 2.0). برای تقسیم صحیح از // استفاده کنید.
✏ تمرین یک برنامه بنویسید که شعاع یک دایره را از کاربر دریافت کند و محیط و مساحت آن را محاسبه کند. (فرمول‌ها: محیط = 2 * π * r، مساحت = π * r²). از pi = 3.14159 استفاده کنید.

۳.۲ عملگرهای مقایسه‌ای (Comparison Operators)

عملگرهای مقایسه‌ای دو مقدار را مقایسه می‌کنند و یک مقدار بولی (True یا False) برمی‌گردانند.

عملگرناممثالنتیجه
==برابری5 == 5True
!=نابرابری5 != 3True
>بزرگ‌تر8 > 5True
<کوچک‌تر3 < 5True
>=بزرگ‌تر یا مساوی5 >= 3True
<=کوچک‌تر یا مساوی5 <= 5True
x = 10
y = 20

print(x == y)       # False
print(x != y)       # True
print(x > y)        # False
print(x < y)        # True
print(x >= 10)      # True
print(y <= 20)      # True

# مقایسه‌ی رشته‌ها (بر اساس ترتیب حروف)
print("apple" == "apple")       # True
print("apple" != "orange")      # True
print("banana" > "apple")       # True (b > a)

# ترکیب با متغیرها
age = 18
is_adult = age >= 18
print(is_adult)     # True
نکته طلایی از == برای مقایسه‌ی برابری استفاده کنید. = عملگر انتساب است و برای مقداردهی استفاده می‌شود. اشتباه گرفتن این دو یکی از رایج‌ترین خطاهاست!
✏ تمرین یک برنامه بنویسید که دو عدد از کاربر دریافت کند و با عملگرهای مقایسه‌ای مشخص کند که آیا عدد اول بزرگ‌تر، کوچک‌تر یا مساوی عدد دوم است.

۳.۳ عملگرهای منطقی (Logical Operators)

عملگرهای منطقی برای ترکیب شرط‌ها و ایجاد منطق پیچیده استفاده می‌شوند.

عملگرتوضیحمثالنتیجه
andهر دو شرط باید True باشندTrue and TrueTrue
orحداقل یکی از شرط‌ها True باشدTrue or FalseTrue
notبرعکس کردن مقدار بولیnot TrueFalse
# and - هر دو شرط باید True باشد
age = 25
has_license = True
can_drive = age >= 18 and has_license
print(can_drive)        # True

# or - حداقل یکی از شرط‌ها True باشد
is_weekend = True
is_holiday = False
can_rest = is_weekend or is_holiday
print(can_rest)         # True

# not - برعکس کردن
is_raining = False
is_sunny = not is_raining
print(is_sunny)         # True

# ترکیب چند عملگر منطقی
score = 85
is_passed = score >= 60 and score <= 100
print(is_passed)        # True

# عملگرهای منطقی با مقادیر Truthy/Falsy
name = "Ali"
if name:                # نام نباید خالی باشد
    print("نام وجود دارد")  # خروجی: "نام وجود دارد"

# عملگرهای منطقی در رشته‌ها
user_input = ""
if not user_input:
    print("ورودی خالی است")
نکته عملگرهای منطقی در پایتون هم‌چین (Short-circuit) هستند. یعنی اگر نتیجه‌ی عبارت از اول مشخص باشد، بقیه‌ی عبارت بررسی نمی‌شود.
✏ تمرین یک برنامه بنویسید که سن و وضعیت تحصیلی کاربر را دریافت کند و مشخص کند که آیا او واجد شرایط دریافت وام تحصیلی است یا نه (شرط: سن بین ۱۸ تا ۳۰ و دانشجو بودن).

۳.۴ عملگرهای انتساب (Assignment Operators)

عملگرهای انتساب برای مقداردهی و تغییر متغیرها استفاده می‌شوند.

عملگرمعادلنام
=x = 10مقداردهی ساده
+=x += 5 → x = x + 5افزایش
-=x -= 3 → x = x - 3کاهش
*=x *= 2 → x = x * 2ضرب
/=x /= 4 → x = x / 4تقسیم
//=x //= 3 → x = x // 3تقسیم صحیح
%=x %= 5 → x = x % 5باقی‌مانده
**=x **= 2 → x = x ** 2توان
# مقداردهی اولیه
x = 10
print(x)        # 10

# افزایش
x += 5
print(x)        # 15

# کاهش
x -= 3
print(x)        # 12

# ضرب
x *= 2
print(x)        # 24

# تقسیم
x /= 4
print(x)        # 6.0

# تقسیم صحیح
x //= 2
print(x)        # 3.0

# باقی‌مانده
x %= 2
print(x)        # 1.0

# توان
x **= 3
print(x)        # 1.0

# مثال عملی: شمارنده
counter = 0
counter += 1    # 1
counter += 1    # 2
counter += 1    # 3
print(counter)  # 3
نکته طلایی عملگرهای انتساب ترکیبی کد را کوتاه‌تر و خواناتر می‌کنند. به‌جای x = x + 1 از x += 1 استفاده کنید.
✏ تمرین یک برنامه بنویسید که یک متغیر total را با مقدار 0 داشته باشد. سپس از کاربر ۵ عدد دریافت کند و آن‌ها را با += به total اضافه کند. در نهایت مجموع را چاپ کند.

۳.۵ عملگرهای هویتی (Identity Operators)

عملگرهای هویتی برای بررسی اینکه آیا دو متغیر به همان شیء (Object) در حافظه اشاره می‌کنند یا نه، استفاده می‌شوند.

  • is: اگر دو متغیر به یک شیء اشاره کنند، True است.
  • is not: اگر دو متغیر به اشیاء متفاوتی اشاره کنند، True است.
# اعداد صحیح کوچک (cached)
a = 10
b = 10
print(a is b)       # True (هر دو به یک شیء در حافظه اشاره می‌کنند)

# رشته‌ها (cached)
x = "hello"
y = "hello"
print(x is y)       # True

# لیست‌ها
list1 = [1, 2, 3]
list2 = [1, 2, 3]
print(list1 is list2)       # False (اشاره به اشیاء متفاوت)
print(list1 == list2)       # True (مقادیر برابر هستند)

# is not
print(list1 is not list2)   # True

# بررسی None
value = None
if value is None:
    print("مقدار None است")
نکته برای مقایسه‌ی مقادیر از == استفاده کنید. برای بررسی اینکه آیا دو متغیر به یک شیء اشاره می‌کنند، از is استفاده کنید. معمولاً برای بررسی None از is استفاده می‌شود.
✏ تمرین یک لیست بسازید و آن را به متغیر دیگری اختصاص دهید. با is بررسی کنید که آیا هر دو به یک شیء اشاره می‌کنند یا خیر. سپس با == مقادیر را مقایسه کنید.

۳.۶ عملگرهای عضویت (Membership Operators)

عملگرهای عضویت برای بررسی وجود یک عنصر در یک مجموعه (لیست، رشته، تاپل، دیکشنری و ...) استفاده می‌شوند.

  • in: اگر عنصر در مجموعه وجود داشته باشد، True است.
  • not in: اگر عنصر در مجموعه وجود نداشته باشد، True است.
# لیست
fruits = ["apple", "banana", "orange"]
print("banana" in fruits)       # True
print("grape" in fruits)        # False
print("grape" not in fruits)    # True

# رشته
text = "Hello, World!"
print("World" in text)          # True
print("Python" in text)         # False

# دیکشنری (بررسی کلیدها)
person = {"name": "Ali", "age": 25}
print("name" in person)         # True (کلید وجود دارد)
print("Ali" in person)          # False (مقدار بررسی نمی‌شود)

# استفاده در حلقه
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    print(num, end=" ")         # 1 2 3 4 5
نکته طلایی عملگرهای عضویت برای بررسی وجود یک عنصر در لیست‌ها، رشته‌ها و دیکشنری‌ها بسیار مفید هستند. در حلقه‌ها نیز برای پیمایش عناصر استفاده می‌شوند.
✏ تمرین یک برنامه بنویسید که از کاربر یک حرف دریافت کند و با عملگر in بررسی کند که آیا آن حرف در یک رشته‌ی از پیش تعریف شده (مثل "python") وجود دارد یا نه.

۳.۷ اولویت عملگرها (Operator Precedence)

در عبارات پیچیده، عملگرها بر اساس اولویت اجرا می‌شوند. ترتیب اولویت از بالا به پایین:

اولویتعملگرهاتوضیح
۱()پرانتز (بالاترین اولویت)
۲**توان
۳-xمنفی یکانی
۴*, /, //, %ضرب، تقسیم، تقسیم صحیح، باقی‌مانده
۵+, -جمع و تفریق
۶==, !=, <, >, <=, >=مقایسه‌ای
۷is, is notهویتی
۸in, not inعضویت
۹not, and, orمنطقی (به ترتیب)
# اولویت عملگرها
result = 10 + 5 * 2
print(result)       # 20 (ضرب اولویت دارد)

# با پرانتز اولویت را تغییر می‌دهیم
result = (10 + 5) * 2
print(result)       # 30

# ترکیب عملگرها
a = 5
b = 10
c = 3
result = a + b * c - 2 ** 3
# 2**3 = 8 (توان)
# b * c = 30 (ضرب)
# 5 + 30 - 8 = 27 (جمع و تفریق)
print(result)       # 27

# منطقی با مقایسه‌ای
x = 10
y = 20
z = 30
is_true = x < y and y < z     # True and True = True
print(is_true)      # True

# استفاده از پرانتز برای خوانایی
# is_valid = (age >= 18) and (has_license or is_learner)
نکته برای خوانایی بیشتر و جلوگیری از اشتباه، همیشه از پرانتز برای مشخص کردن اولویت در عبارات پیچیده استفاده کنید.
✏ تمرین عبارت زیر را بدون اجرا، مقدار آن را حدس بزنید. سپس با پایتون محاسبه کنید و نتیجه را بررسی کنید. 
result = 8 + 2 * 3 ** 2 - 4 / 2

کارگاه عملی

گام‌به‌گام: ساخت یک ماشین حساب پیشرفته با عملگرها

  1. یک فایل calculator_operators.py ایجاد کنید.
  2. از کاربر دو عدد و یک عملگر (+, -, *, /, //, %, **) دریافت کنید.
  3. با استفاده از عملگرهای حسابی، عملیات مورد نظر را انجام دهید.
  4. نتیجه را با f-string نمایش دهید.
  5. با عملگرهای مقایسه‌ای بررسی کنید که آیا نتیجه مثبت است یا منفی.
  6. با عملگرهای منطقی بررسی کنید که آیا هر دو عدد زوج هستند یا خیر.
  7. با عملگرهای عضویت بررسی کنید که آیا عملگر مورد نظر در لیست عملگرهای مجاز وجود دارد.

چالش نهایی: یک برنامه بنویسید که:

  • سه عدد از کاربر دریافت کند
  • با عملگرهای مقایسه‌ای بزرگ‌ترین عدد را پیدا کند (بدون استفاده از ()max)
  • با عملگرهای منطقی بررسی کند که آیا سه عدد تشکیل یک مثلث می‌دهند یا نه
  • با عملگرهای هویتی بررسی کند که آیا دو عدد اول به یک شیء اشاره می‌کنند (با استفاده از اعداد کوچک)

پرسش‌ها و تمرینات

سوالات تشریحی:

  1. تفاوت بین عملگرهای / و // چیست؟
  2. == و is چه تفاوتی دارند؟
  3. عملگرهای and و or چگونه کار می‌کنند و چه تفاوتی دارند؟
  4. چرا باید از عملگرهای انتساب ترکیبی (مثل +=) استفاده کنیم؟
  5. عملگرهای عضویت چه کاربردی دارند؟

سوالات چهارگزینه‌ای:

  1. خروجی 15 / 4 چیست؟
    الف) 3.75   ب) 3   ج) 4   د) 0.3
  2. خروجی 10 % 6 چیست؟
    الف) 4   ب) 1.66   ج) 1   د) 6
  3. کدام یک از موارد زیر برای بررسی برابری دو مقدار استفاده می‌شود؟
    الف) =   ب) ==   ج) ===   د) !=

تمرین عملی: یک برنامه بنویسید که:

  • از کاربر دو عدد دریافت کند
  • با عملگرهای حسابی همه‌ی عملیات (جمع، تفریق، ضرب، تقسیم، تقسیم صحیح، باقی‌مانده، توان) را محاسبه و نمایش دهد
  • با عملگرهای مقایسه‌ای مشخص کند که آیا دو عدد با هم برابرند، اولی بزرگ‌تر است یا دومی
  • با عملگرهای منطقی بررسی کند که آیا هر دو عدد مثبت هستند یا خیر
  • با عملگرهای عضویت بررسی کند که آیا عدد اول در یک بازه (مثلاً ۱ تا ۱۰۰) قرار دارد

جمع‌بندی و خلاصه

نکات طلایی عملگرهای حسابی: +, -, *, /, //, %, **. عملگرهای مقایسه‌ای: ==, !=, <, >, <=, >=. عملگرهای منطقی: and, or, not. عملگرهای انتساب: =, +=, -=, *=, /=, //=, %=, **=. عملگرهای هویتی: is, is not (مقایسه‌ی اشیاء). عملگرهای عضویت: in, not in (بررسی وجود عنصر). اولویت عملگرها: با پرانتز اولویت را کنترل کنید.

برگه تقلب

# حسابی
5 + 3   # 8
5 - 3   # 2
5 * 3   # 15
5 / 3   # 1.666
5 // 3  # 1
5 % 3   # 2
5 ** 3  # 125

# مقایسه‌ای

5 != 3  # True
5 > 3   # True
5 < 8   # True

# منطقی

True or False   # True
not True        # False

# انتساب

# هویتی
x is y
x is not y

# عضویت
"a" in "apple"      # True
"x" not in "apple"  # True

واژه‌نامه تخصصی

  • Operator (عملگر): نمادی که یک عملیات را روی یک یا چند مقدار انجام می‌دهد.
  • Arithmetic Operator: عملگرهای ریاضی برای محاسبات.
  • Comparison Operator: عملگر برای مقایسه‌ی دو مقدار.
  • Logical Operator: عملگر برای ترکیب شرط‌ها.
  • Assignment Operator: عملگر برای مقداردهی به متغیرها.
  • Identity Operator: عملگر برای مقایسه‌ی هویت اشیاء.
  • Membership Operator: عملگر برای بررسی وجود یک عنصر در مجموعه.
  • Precedence (اولویت): ترتیب اجرای عملگرها در یک عبارت.
  • Short-circuit: توقف ارزیابی عبارت در زمانی که نتیجه مشخص است.

اشتباه فراموش کردن پرانتز در شرط‌های پیچیده با and, or, not.
راه‌حل: از پرانتز برای شفافیت بیشتر استفاده کنید.

راه‌حل: برای مقادیر از == و برای هویت اشیاء از is استفاده کنید.
اشتباه فراموش کردن پرانتز در عبارات با عملگرهای مختلف که باعث محاسبه‌ی اشتباه می‌شود.
راه‌حل: با پرانتز اولویت را مشخص کنید.
اشتباه استفاده از in روی دیکشنری بدون در نظر گرفتن اینکه فقط کلیدها را بررسی می‌کند.

عنوان پروژه: ساخت یک تحلیل‌گر عددی پیشرفته

شرح: یک برنامه بنویسید که یک عدد از کاربر دریافت کند و تحلیل‌های زیر را روی آن انجام دهد:

  • با عملگرهای حسابی: جذر، مربع، مکعب و فاکتوریل (با حلقه) عدد را محاسبه کند.
  • با عملگرهای مقایسه‌ای: مشخص کند که عدد مثبت است، منفی است یا صفر.
  • با عملگرهای منطقی: بررسی کند که آیا عدد بین ۰ تا ۱۰۰ است و آیا زوج است یا خیر.
  • با عملگرهای عضویت: بررسی کند که آیا عدد در یک لیست از اعداد اول (مثل [2, 3, 5, 7, 11, 13]) وجود دارد.
  • با عملگرهای هویتی: یک متغیر دیگر با همان مقدار تعریف کند و بررسی کند که آیا به یک شیء اشاره می‌کنند.
  • با عملگرهای انتساب: عدد را به‌طور متوالی تغییر دهد (مثلاً ۵ بار به آن ۲ اضافه کند).
  • همه‌ی نتایج را با f-string به‌صورت زیبا نمایش دهد.
