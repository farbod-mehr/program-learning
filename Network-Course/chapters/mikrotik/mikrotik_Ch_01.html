📘 بدنه‌ی آموزشی

۱.۱ RouterOS و RouterBOARD

MikroTik یک شرکت لتونیایی است که دو محصول اصلی دارد:

  • RouterOS: سیستم‌عامل شبکه مبتنی بر Linux — روی سخت‌افزار MikroTik، VPS، Cloud یا ماشین مجازی اجرا می‌شود
  • RouterBOARD: سخت‌افزارهای MikroTik (روتر، سوئیچ، Access Point) که RouterOS روی آن‌ها نصب است

کاربردهای اصلی RouterOS:

  • روتر اصلی شبکه (Routing، NAT، Firewall)
  • Access Point Wireless
  • Hotspot و User Manager
  • VPN Server/Client
  • Queue و Traffic Shaping
  • Bandwidth Management
  • MPLS و BGP برای ISPها
💡 نکته
RouterOS هم روی سخت‌افزار MikroTik نصب می‌شود و هم روی PC یا سرور (x86)، VM (CHR - Cloud Hosted Router) و Cloud (AWS، Azure، GCP).

[admin@MikroTik] /ip/address> ..

# مشاهده Help
[admin@MikroTik] > ?
[admin@MikroTik] > /ip ?

# Autocomplete با Tab
[admin@MikroTik] > /ip addr
! → /ip address

# History
[admin@MikroTik] > /history
[admin@MikroTik] > /history print

# دستورات مفید
[admin@MikroTik] > /system resource print
[admin@MikroTik] > /system identity print
[admin@MikroTik] > /system clock print
[admin@MikroTik] > /system package print
[admin@MikroTik] > /system routerboard print
[admin@MikroTik] > /export

ساختار دستور در RouterOS:

/path action item=value

مثال:
/ip address add address=192.168.1.1/24 interface=ether2

path = /ip address
action = add
item = address
value = 192.168.1.1/24

۱.۵ پیکربندی اولیه — IP، Gateway، NAT

# ===== گام ۱: تنظیم Hostname =====
[admin@MikroTik] > /system identity set name=MyRouter

# ===== گام ۲: تنظیم IP روی LAN =====
[admin@MikroTik] > /ip address add \
    address=192.168.88.1/24 \
    interface=ether2 \
    comment="LAN"

# ===== گام ۳: دریافت IP از ISP روی WAN =====
# اگر ISP با DHCP IP می‌دهد:
[admin@MikroTik] > /ip dhcp-client add \
    interface=ether1 \
    disabled=no \
    comment="WAN DHCP"

# اگر ISP IP Static می‌دهد:
[admin@MikroTik] > /ip address add \
    address=203.0.113.2/24 \
    interface=ether1 \
    comment="WAN Static"

# ===== گام ۴: Default Route =====
# اگر از DHCP استفاده می‌کنی، خودکار اضافه می‌شود.
# اگر Static:
[admin@MikroTik] > /ip route add \
    dst-address=0.0.0.0/0 \
    gateway=203.0.113.1

# ===== گام ۵: NAT Masquerade برای خروج به اینترنت =====
[admin@MikroTik] > /ip firewall nat add \
    chain=srcnat \
    out-interface=ether1 \
    action=masquerade \
    comment="NAT to Internet"

# ===== گام ۶: DNS Server =====
[admin@MikroTik] > /ip dns set \
    servers=8.8.8.8,1.1.1.1 \
    allow-remote-requests=yes

# ===== بررسی =====
[admin@MikroTik] > /ip address print
[admin@MikroTik] > /ip route print
[admin@MikroTik] > /ip firewall nat print
[admin@MikroTik] > /ip dns print

۱.۶ راه‌اندازی DHCP Server

# ===== گام ۱: تعریف Pool =====
[admin@MikroTik] > /ip pool add \
    name=dhcp_pool \
    ranges=192.168.88.10-192.168.88.254

# ===== گام ۲: DHCP Network =====
[admin@MikroTik] > /ip dhcp-server network add \
    address=192.168.88.0/24 \
    gateway=192.168.88.1 \
    dns-server=192.168.88.1 \
    comment="LAN Network"

# ===== گام ۳: DHCP Server =====
[admin@MikroTik] > /ip dhcp-server add \
    name=dhcp_lan \
    interface=ether2 \
    address-pool=dhcp_pool \
    lease-time=1d \
    disabled=no

# ===== بررسی =====
[admin@MikroTik] > /ip dhcp-server print
[admin@MikroTik] > /ip dhcp-server lease print
[admin@MikroTik] > /ip dhcp-server lease print detail

۱.۷ Winbox — نصب و کار با آن

Winbox محبوب‌ترین ابزار مدیریت MikroTik است — یک برنامه ویندوزی که از mikrotik.com/download قابل دانلود است.

مزایای Winbox:

  • محیط گرافیکی کامل و سریع
  • اتصال با MAC Address (حتی بدون IP)
  • Safe Mode برای پیکربندی امن
  • پشتیبانی از Drag & Drop در Firewall Rules
  • Torch و Traffic Monitor داخلی
  • نصب از طریق Wine در Linux/Mac

حالت‌های مهم در Winbox:

  • Safe Mode: تغییرات بعد از Logout برگردانده می‌شوند اگر تأیید نکنی — برای پیکربندی‌های حساس
  • Advanced Mode: نمایش تمام گزینه‌ها (حتی پارامترهای پیشرفته)
  • Simple Mode: فقط گزینه‌های پایه
⚠️ امنیت Winbox
Winbox روی پورت TCP/8291 کار می‌کند. حتماً:
  • پورت را به IP مدیریتی محدود کن
  • سرویس را روی WAN غیرفعال کن
  • از Winbox نسخه 3.30+ استفاده کن (پچ CVE-2018-14847)

۱.۸ Webfig و Quickset

Webfig: رابط وب RouterOS — از مرورگر در آدرس http://192.168.88.1 قابل دسترسی است.

مزایا:

  • نیاز به نصب ندارد
  • قابل استفاده از هر سیستمی
  • مشابه Winbox ولی کندتر

Quickset: صفحه‌ی راه‌اندازی سریع — برای تنظیمات پایه: انتخاب حالت (Router، Bridge، AP، CPE)، WAN، LAN، Wireless.

# فعال‌سازی Webfig
[admin@MikroTik] > /ip service set www disabled=no port=80
[admin@MikroTik] > /ip service set www-ssl disabled=no port=443
[admin@MikroTik] > /ip service print

# ===== سرویس‌های مهم =====
[admin@MikroTik] > /ip service print
# خروجی:
# NAME      PORT   ADDRESS
# telnet    23
# ftp       21
# www       80
# ssh       22
# www-ssl   443
# api       8728
# winbox    8291
# api-ssl   8729

# ===== امن‌سازی سرویس‌ها =====
# غیرفعال‌سازی سرویس‌های بی‌استفاده
[admin@MikroTik] > /ip service disable telnet,ftp,www,api

# محدود کردن دسترسی به IP مشخص
[admin@MikroTik] > /ip service set winbox address=192.168.88.0/24
[admin@MikroTik] > /ip service set ssh address=192.168.88.0/24

۱.۱۰ ارتقاء RouterOS

# ===== روش ۱: از طریق CLI =====
[admin@MikroTik] > /system package update check-for-updates
[admin@MikroTik] > /system package update download
[admin@MikroTik] > /system reboot
# یا اگر Update Channel را ست کردی:
[admin@MikroTik] > /system package update set channel=stable

# ===== روش ۲: از طریق فایل =====
# فایل .npk را از mikrotik.com دانلود کن
# آپلود به Files
# Reboot

# ===== روش ۳: از طریق Winbox =====
# System → Packages → Check For Updates

# ===== تنظیم Update Channel =====
[admin@MikroTik] > /system package update set channel=long-term
# گزینه‌ها: stable (پیش‌فرض)، long-term، testing، development

# بررسی نسخه فعلی
[admin@MikroTik] > /system resource print
# خروجی: version, build-time, factory-software

# آپدیت RouterBOOT Firmware (جدا از RouterOS)
[admin@MikroTik] > /system routerboard print
[admin@MikroTik] > /system routerboard upgrade
[admin@MikroTik] > /system reboot
🏆 نکته‌ی طلایی
برای شبکه‌های Production، از long-term استفاده کن — پایدارتر و تست‌شده. از testing و development پرهیز کن.

۱.۱۱ Backup و Restore

# ===== دو نوع Backup در RouterOS =====

# ۱. Binary Backup (.backup)
# کامل + سریع + قابل Restore فقط روی همان مدل دستگاه
[admin@MikroTik] > /system backup save name=router-backup

# ۲. Export Config (.rsc)
# متنی + قابل ویرایش + قابل Restore روی هر دستگاهی
[admin@MikroTik] > /export file=router-config

# Export فقط بخش خاص
[admin@MikroTik] > /ip firewall export file=firewall-rules
[admin@MikroTik] > /ip address export

# ===== Restore =====

# از Binary Backup
[admin@MikroTik] > /system backup load name=router-backup

# از Export File
[admin@MikroTik] > /import file-name=router-config.rsc

# ===== انتقال به سرور خارجی =====
# با FTP
[admin@MikroTik] > /tool fetch address=192.168.1.100 \
    src-path=router-backup.backup \
    dst-path=/router-backup.backup \
    user=admin password=pass mode=ftp upload=yes

# با Email (برای بکاپ خودکار)
[admin@MikroTik] > /tool e-mail set \
    server=smtp.gmail.com port=587 \
    from=myrouter@gmail.com \
    user=myrouter@gmail.com password=app-password \
    tls=yes

[admin@MikroTik] > /system backup save name=backup
[admin@MikroTik] > /tool e-mail send \
    to=admin@company.ir \
    subject="Backup $(date)" \
    body="Daily backup" \
    file=backup.backup

۱.۱۲ Factory Reset

# ===== روش‌های Factory Reset =====

# ۱. از CLI
[admin@MikroTik] > /system reset-configuration
# سوال می‌پرسد: Dangerous! Reset anyway? [y/N] → y
# سوال: Keep default configuration? [y/N]
#   y = پیکربندی پیش‌فرض می‌ماند (IP 192.168.88.1)
#   n = پیکربندی خالی می‌شود

# ۲. با حذف تمام Config اما نگه‌داشتن Userها
[admin@MikroTik] > /system reset-configuration keep-users=yes

# ۳. بدون Backup خودکار
[admin@MikroTik] > /system reset-configuration no-defaults=yes skip-backup=yes

# ۴. از طریق Winbox
# System → Reset Configuration

# ۵. با دکمه‌ی Reset سخت‌افزاری
# دکمه Reset را نگه دار و برق را وصل کن
# LED شروع به چشمک زدن می‌کند → رها کن
# یا 10 ثانیه نگه دار برای Factory Default

# ۶. با Netinstall (اگر RouterOS بالا نمی‌آید)
# → در بخش بعدی توضیح داده شده
⚠️ هشدار
قبل از Factory Reset، حتماً:
  • Backup بگیر (/system backup save)
  • Export پیکربندی بگیر (/export)
  • لایسنس را ذخیره کن

۱.۱۳ مدیریت کاربران و گروه‌ها

[admin@MikroTik] > /user set admin password=StrongP@ss2024

[admin@MikroTik] > /user add \

# ===== سیاست‌های موجود =====
# local, telnet, ssh, ftp, reboot, read, write, policy, test,

# ===== مشاهده Active Sessions =====
[admin@MikroTik] > /user active print
[admin@MikroTik] > /user active print detail

# ===== قطع Session =====
[admin@MikroTik] > /user active remove 0

۱.۱۴ Netinstall — نصب مجدد RouterOS

Netinstall ابزار رسمی MikroTik برای نصب مجدد RouterOS روی دستگاه است — وقتی که RouterOS خراب شده یا نیاز به پاک‌سازی کامل داری.

پیش‌نیازها:

  • یک کامپیوتر با Windows یا Linux
  • نرم‌افزار Netinstall (از mikrotik.com)
  • فایل .npk RouterOS
  • اتصال Ethernet مستقیم بین PC و MikroTik
# ===== مراحل Netinstall =====

# ۱. Netinstall را اجرا کن (Run as Administrator)
# ۲. از منوی Net booting → Netinstall Server
# ۳. Client IP: 192.168.88.2 ، Server IP: 192.168.88.3
# ۴. فایل .npk را در Netinstall انتخاب کن
# ۵. روی کامپیوتر، IP دستی مثل 192.168.88.2/24 بده
# ۶. MikroTik را با دکمه Reset روشن کن
#    - دکمه Reset را نگه دار
#    - برق را وصل کن
#    - LED چشمک می‌زند → رها کن
# ۷. دستگاه در Netinstall ظاهر می‌شود → انتخاب و Install

# ===== بعد از نصب =====
# دستگاه با پیکربندی خالی بالا می‌آید
# با MAC-Winbox یا از Console وصل شو
💡 نکته
Netinstall تمام پیکربندی، لایسنس (در بعضی مدل‌ها) و فایل‌ها را پاک می‌کند. آخرین راه‌حل قبل از تعویض سخت‌افزار است.

🎨 نکات کلیدی این فصل

💡 نکته‌ی کاربردی
همیشه بعد از هر تغییر مهم، /export بگیر و در محل امن ذخیره کن. فایل RSC قابل ویرایش است و روی هر دستگاهی Restore می‌شود.
⚠️ امنیت
رمز admin خالی، بزرگ‌ترین حفره‌ی امنیتی MikroTik است. متأسفانه هزاران دستگاه در اینترنت قربانی حمله‌ی Hajime و Mirai شده‌اند به دلیل همین سهل‌انگاری.
🏆 نکته‌ی طلایی
در Production، همیشه Safe Mode در Winbox را قبل از تغییرات Firewall یا IP استفاده کن — اگر اشتباهی رخ داد و خودت را از دستگاه بیرون انداختی، Safe Mode بعد از Logout همه‌ی تغییرات را برمی‌گرداند.
ℹ️ اطلاعات بیشتر
در فصل ۲ با Static Route، Default Route و Route Flags آشنا می‌شوی.
🔮 دیدگاه پیشرفته
در MTCINE و MTCRE با BGP، OSPF و MPLS در RouterOS کار می‌کنی.

🛠️ کارگاه عملی گام‌به‌گام

  1. RouterOS را روی VM (CHR) یا سخت‌افزار RouterBOARD راه‌اندازی کن
  2. با Winbox وصل شو (MAC یا IP پیش‌فرض 192.168.88.1)
  3. رمز admin را عوض کن به یک رمز قوی
  4. Hostname را تنظیم کن
  5. WAN را با DHCP Client روی ether1 پیکربندی کن
  6. LAN را با IP 192.168.88.1/24 روی ether2 پیکربندی کن
  7. DHCP Server را با Pool مناسب راه‌اندازی کن
  8. NAT Masquerade را روی ether1 فعال کن
  9. DNS Server را تنظیم کن
  10. از یک PC در شبکه LAN، IP بگیر و به اینترنت ping بزن
  11. سرویس‌های بی‌استفاده را غیرفعال کن (Telnet، FTP، www)
  12. دسترسی Winbox و SSH را به IP مدیریتی محدود کن
  13. NTP Client را برای زمان‌بندی دقیق راه‌اندازی کن
  14. از کل پیکربندی /export بگیر و از /system backup هم فایل ذخیره کن

🚫 خطاهای رایج و رفع‌اشکال

  • Winbox وصل نمی‌شود: پورت 8291 باز، IP درست، یا با MAC-Telnet تست کن.
  • IP پیش‌فرض 192.168.88.1 کار نمی‌کند: ممکن است Factory Reset شده باشد. با MAC-Winbox وصل شو.
  • DHCP IP نمی‌دهد: Network، Pool و Server را جداگانه چک کن — هر سه باید هماهنگ باشند.
  • بدون NAT، اینترنت کار نمی‌کند: از بیرون به داخل ممکن است کار کند ولی به بیرون نه — NAT Masquerade را چک کن.
  • DNS کار نمی‌کند: allow-remote-requests=yes و DNS Server روی DHCP Network ست شود.
  • بعد از Update، دستگاه بوت نمی‌شود: از Channel long-term استفاده کن یا با Netinstall برگردان.
  • لایسنس Trial تمام شد: بعد از ۲۴ ساعت، اگر لایسنس نداری، برخی سرویس‌ها قطع می‌شوند.
  • Backup روی دستگاه دیگر Restore نمی‌شود: Binary Backup به مدل/نسخه گره خورده — از /export استفاده کن.
  • بعد از تغییر IP خودت را از دستگاه بیرون انداختی: از MAC-Winbox یا Console وارد شو.
  • سرویس www خاموش شد و Webfig باز نمی‌شود: با Winbox روشنش کن یا از SSH استفاده کن.
  • Netinstall دستگاه را نمی‌بیند: Firewall ویندوز، IP اشتباه، یا دکمه Reset را دیر رها کردی.
  • بعد از Factory Reset، رمز admin خالی است: بلافاصله رمز قوی بگذار — خطر امنیتی جدی.

🎯 پروژه‌ی پایانی فصل

یک روتر MikroTik کامل برای یک دفتر کوچک راه‌اندازی کن:

  • سخت‌افزار: RouterBOARD یا CHR روی VM
  • WAN: DHCP Client روی ether1 (شبیه‌سازی ISP)
  • LAN: ether2 با IP 192.168.10.1/24
  • DHCP Server: Pool 192.168.10.10-200، Lease 1d
  • DNS: با allow-remote-requests و DNS سرورهای عمومی
  • NAT Masquerade: روی ether1
  • NTP Client: همگام با pool.ntp.org و Timezone تهران
  • User: admin با رمز قوی + کاربر Operator با دسترسی read
  • امنیت: غیرفعال کردن سرویس‌های Telnet، FTP، www
  • محدودیت: Winbox و SSH فقط از Subnet مدیریتی
  • Backup خودکار: روزانه ساعت ۳ بامداد با Email
  • مستندسازی کامل با Export و دیاگرام شبکه
🏆 چالش اضافه
  • یک Script بنویس که وقتی اینترنت قطع شد، یک Email هشدار بفرستد.
  • با Netwatch، پایش یک سرور مهم (مثلاً 8.8.8.8) راه‌اندازی کن.
  • با Scheduler، هر روز Config را Export کن و در FTP سرور ذخیره کن.
  • یک Firewall Rule بساز که فقط اجازه Ping از LAN بدهد و بقیه را Block کند.

📋 جمع‌بندی و برگه‌تقب

  • RouterOS: سیستم‌عامل شبکه MikroTik — روی RouterBOARD، VM، Cloud
  • IP پیش‌فرض: 192.168.88.1/24 — User admin با رمز خالی (حتماً عوض کن)
  • Winbox: TCP/8291، اتصال MAC یا IP، Safe Mode، Advanced Mode
  • Webfig: HTTP/80 یا HTTPS/443
  • SSH: TCP/22 — امن، اسکریپت‌پذیر
  • MAC-Telnet: L2، بدون IP — برای شرایط اضطراری
  • NAT Masquerade: chain=srcnat، out-interface=WAN، action=masquerade
  • DHCP Server: Pool + Network + Server (هر سه لازم است)
  • DNS: allow-remote-requests=yes برای راه‌اندازی DNS Server محلی
  • Backup: Binary (.backup) مخصوص همان مدل — Export (.rsc) قابل انتقال
  • Factory Reset: /system reset-configuration یا دکمه Reset
  • Netinstall: نصب مجدد RouterOS — آخرین راه‌حل
  • لایسنس: Level 1 (Free 24h) تا Level 6 (Full ISP)
  • Channel: long-term برای Production
  • امنیت: غیرفعال کردن سرویس‌های ناامن، محدود کردن دسترسی به IP مدیریتی
  • NTP Client: با pool.ntp.org و Timezone Asia/Tehran
