پیش‌نیازها

  • آشنایی اولیه با کامپیوتر و سیستم‌عامل (Windows، macOS یا Linux)
  • توانایی نصب نرم‌افزار روی سیستم
  • یک ویرایشگر کد (VS Code توصیه می‌شود)
  • هیچ دانش قبلی از برنامه‌نویسی لازم نیست؛ همه‌چیز از صفر آموزش داده می‌شود

اهداف آموزشی

پس از پایان این فصل، شما قادر خواهید بود:

  • تشریح کنید که پایتون چیست و چه کاربردهایی دارد
  • پایتون را روی سیستم‌عامل خود نصب کنید
  • محیط توسعه (VS Code) را برای برنامه‌نویسی پایتون راه‌اندازی کنید
  • اولین برنامه‌ی پایتون را با ()print بنویسید
  • از محیط تعاملی (REPL) و اجرای اسکریپت استفاده کنید
  • مفهوم pip و نصب پکیج‌ها را درک کنید
  • با محیط‌های مجازی (venv) آشنا شوید

مقدمه و انگیزه‌بخشی

پایتون یکی از محبوب‌ترین زبان‌های برنامه‌نویسی جهان است. از توسعه‌ی وب (با Django و Flask) تا دیتا ساینس (با Pandas و NumPy)، از اتومیشن و اسکریپت‌نویسی تا هوش مصنوعی و یادگیری ماشین — پایتون در همه‌جا حضور دارد. اما چه چیزی پایتون را این‌قدر خاص می‌کند؟

  • سادگی و خوانایی: کد پایتون شبیه به زبان انگلیسی است و یادگیری آن بسیار آسان است.
  • جامعه‌ی بزرگ و پشتیبانی عالی: هزاران کتابخانه و فریمورک آماده برای هر نیازی.
  • همه‌کاره بودن: از وب تا دسکتاپ، از دیتا ساینس تا اتومیشن.
  • بازار کار عالی: تقاضای بالا برای توسعه‌دهندگان پایتون در سراسر جهان.

در این فصل، با مبانی پایتون آشنا می‌شوید: تاریخچه، نصب، راه‌اندازی محیط توسعه و نوشتن اولین برنامه. این فصل پایه‌ی تمام مباحث بعدی است.

۱.۱ پایتون چیست و چه کاربردهایی دارد؟

پایتون (Python) یک زبان برنامه‌نویسی سطح‌بالا، تفسیری و همه‌کاره است که توسط خودو فان روسوم در سال ۱۹۹۱ ایجاد شد. فلسفه‌ی اصلی پایتون «خوانایی کد» است.

کاربردهای اصلی پایتون:

  • توسعه‌ی وب: Django، Flask، FastAPI
  • دیتا ساینس و تحلیل داده: Pandas، NumPy، Matplotlib
  • یادگیری ماشین و هوش مصنوعی: TensorFlow، PyTorch، Scikit-learn
  • اتومیشن و اسکریپت‌نویسی: تسک‌های تکراری، Web Scraping
  • توسعه‌ی دسکتاپ: Tkinter، PyQt
  • توسعه‌ی بازی: Pygame
  • علوم و مهندسی: محاسبات علمی، شبیه‌سازی
نکته نام «پایتون» از گروه کمدی Monty Python گرفته شده است، نه از مار پایتون! این نام نشان‌دهنده‌ی رویکرد شوخ‌طبعانه‌ی خالق آن است.

۱.۲ تاریخچه و تکامل پایتون (Python 1.x تا Python 3.x)

پایتون در سال ۱۹۹۱ منتشر شد و از آن زمان تاکنون نسخه‌های مختلفی از آن منتشر شده است:

  • Python 1.0 (۱۹۹۴): اولین نسخه‌ی رسمی.
  • Python 2.0 (۲۰۰۰): اضافه شدن List Comprehensions و Garbage Collector.
  • Python 2.7 (۲۰۱۰): آخرین نسخه‌ی Python 2 (پشتیبانی تا ۲۰۲۰).
  • Python 3.0 (۲۰۰۸): تغییرات بزرگ و ناسازگار با نسخه‌ی ۲ (مانند print تابعی).
  • Python 3.6 (۲۰۱۶): اضافه شدن f-strings و نوع‌دهی.
  • Python 3.8 (۲۰۱۹): Assignment Expressions (:=).
  • Python 3.10 (۲۰۲۱): match-case (Structural Pattern Matching).
  • Python 3.12 (۲۰۲۳): بهبود عملکرد و ویژگی‌های جدید.
نکته طلایی امروزه Python 3 استاندارد اصلی است و Python 2 به‌طور رسمی منسوخ شده است. همیشه از Python 3 استفاده کنید.

۱.۳ نصب پایتون روی Windows، macOS و Linux

ویندوز:

  1. به سایت python.org بروید.
  2. آخرین نسخه‌ی Python 3 را دانلود کنید.
  3. در نصب، گزینه‌ی «Add Python to PATH» را فعال کنید.
  4. نصب را کامل کنید.

macOS:

  1. از python.org نصب‌کننده را دانلود کنید.
  2. یا با Homebrew: brew install python

Linux (Ubuntu/Debian):

  1. sudo apt update
  2. sudo apt install python3 python3-pip

بررسی نصب و اجرای REPL

# بررسی نصب
python3 --version
# خروجی: Python 3.12.0 (یا نسخه‌ی نصب‌شده)

# اجرای محیط تعاملی (REPL)
python3
# خروجی: Python 3.12.0 ... Type "help", ... >>>
✏ تمرین پایتون را روی سیستم خود نصب کنید و با python3 --version نسخه‌ی نصب‌شده را بررسی کنید.

۱.۴ راه‌اندازی VS Code و نصب افزونه‌ی Python

VS Code یکی از بهترین ویرایشگرهای کد برای پایتون است. مراحل راه‌اندازی:

  1. VS Code را از code.visualstudio.com دانلود و نصب کنید.
  2. برنامه را باز کنید و به بخش Extensions (Ctrl+Shift+X) بروید.
  3. افزونه‌ی Python (توسط Microsoft) را نصب کنید.
  4. برای تست، یک فایل جدید با پسوند py. ایجاد کنید.

hello.py

print("سلام دنیا!")

# اجرا در ترمینال
python3 hello.py

خروجی: سلام دنیا!

نکته VS Code به‌طور خودکار پیشنهادهای کد، اشکال‌زدایی و اجرای مستقیم اسکریپت‌ها را فراهم می‌کند. از کلید F5 برای اجرا استفاده کنید.
✏ تمرین VS Code را نصب کنید، افزونه‌ی Python را اضافه کنید و یک فایل test.py با print("Hello") ایجاد کنید و اجرا کنید.

۱.۵ اولین برنامه: ()print و محیط تعاملی (REPL)

ساده‌ترین برنامه‌ی پایتون، چاپ یک پیام با ()print است. دو روش برای اجرای کد پایتون وجود دارد:

  • محیط تعاملی (REPL): تایپ کد به‌صورت خط‌به‌خط و دیدن نتیجه‌ی فوری.
  • اسکریپت (فایل .py): نوشتن کد در فایل و اجرای کامل آن.

محیط تعاملی (REPL)

>>> print("سلام دنیا!")
سلام دنیا!
>>> 2 + 3
5
>>> name = "علی"
>>> print("سلام", name)
سلام علی

اسکریپت (فایل hello.py)

print("این یک برنامه‌ی پایتون است")
print(10 + 20)
print("نام من:", "رضا")

خروجی اسکریپت: این یک برنامه‌ی پایتون است ، 30 ، نام من: رضا

نکته طلایی محیط تعاملی (REPL) برای تست سریع کدها و یادگیری مفاهیم جدید بسیار عالی است. از آن به‌عنوان یک «دفترچه‌ی آزمایشی» استفاده کنید.
✏ تمرین در محیط تعاملی پایتون، سه پیام مختلف با ()print چاپ کنید. سپس یک فایل first.py ایجاد کنید و دو خط کد در آن بنویسید و اجرا کنید.

۱.۶ آشنایی با pip و نصب پکیج‌ها

pip مدیر بسته‌های پایتون است و برای نصب کتابخانه‌های شخص ثالث استفاده می‌شود.

  • نصب یک پکیج: pip install package_name
  • حذف یک پکیج: pip uninstall package_name
  • نمایش پکیج‌های نصب‌شده: pip list
# نصب پکیج محبوب requests
pip install requests

# نصب یک نسخه‌ی خاص
pip install requests==2.28.1

# آپگرید یک پکیج
pip install --upgrade requests

# نصب از روی فایل requirements.txt
pip install -r requirements.txt
نکته پکیج‌های نصب‌شده با pip در سراسر سیستم نصب می‌شوند. برای جلوگیری از تداخل، از محیط‌های مجازی استفاده کنید (بخش بعدی).
✏ تمرین با استفاده از pip پکیج‌های requests و numpy را نصب کنید. سپس با pip list آن‌ها را ببینید.

۱.۷ محیط‌های مجازی (venv) و اهمیت آن‌ها

محیط مجازی (Virtual Environment) یک فضای ایزوله برای پروژه‌های پایتون است. هر پروژه می‌تواند پکیج‌های مخصوص خود را داشته باشد بدون اینکه با پروژه‌های دیگر تداخل کند.

  • ایجاد محیط مجازی: python3 -m venv venv
  • فعال‌سازی در Windows: venv\Scripts\activate
  • فعال‌سازی در macOS/Linux: source venv/bin/activate
  • خروج از محیط: deactivate
# ایجاد محیط مجازی
python3 -m venv myenv

# فعال‌سازی (Linux/macOS)
source myenv/bin/activate

# نصب پکیج در محیط مجازی
pip install flask

# ذخیره‌سازی وابستگی‌ها
pip freeze > requirements.txt

# خروج
deactivate
نکته طلایی همیشه برای هر پروژه‌ی پایتونی یک محیط مجازی ایجاد کنید. این کار باعث می‌شود پروژه‌ها از هم مستقل باشند و از مشکلات نسخه‌های مختلف جلوگیری شود.
✏ تمرین یک محیط مجازی به نام myproject ایجاد کنید، آن را فعال کنید، پکیج flask را نصب کنید و وابستگی‌ها را در فایل requirements.txt ذخیره کنید.

کارگاه عملی

گام‌به‌گام: ساخت اولین برنامه‌ی تعاملی با پایتون

  1. یک پوشه به نام project_first ایجاد کنید.
  2. در آن پوشه، یک محیط مجازی با python3 -m venv venv بسازید.
  3. محیط را فعال کنید و فایل app.py ایجاد کنید.
  4. در app.py کد زیر را بنویسید: 
    name = input("نام خود را وارد کنید: ")
print("سلام", name, "! به دنیای پایتون خوش آمدید.")
  5. برنامه را با python3 app.py اجرا کنید.
  6. با pip freeze > requirements.txt وابستگی‌ها را ذخیره کنید.

چالش کدنویسی: یک برنامه بنویسید که:

  • از کاربر دو عدد (با ()input) دریافت کند.
  • مجموع، تفریق، ضرب و تقسیم آن‌ها را محاسبه کند.
  • نتایج را با ()print نمایش دهد.

پرسش‌ها و تمرینات

سوالات تشریحی:

  2. تفاوت بین Python 2 و Python 3 چیست و چرا باید از Python 3 استفاده کنیم؟
  3. pip چیست و چه کاربردی دارد؟
  4. محیط مجازی (venv) چه مزیتی دارد و چرا باید از آن استفاده کنیم؟
  5. تفاوت بین محیط تعاملی (REPL) و اجرای اسکریپت چیست؟

سوالات چهارگزینه‌ای:

  1. کدام دستور برای نصب یک پکیج در پایتون استفاده می‌شود؟
    الف) python install   ب) pip install   ج) package install   د) install pip
  2. برای ایجاد یک محیط مجازی از کدام دستور استفاده می‌شود؟
    الف) python -m virtual venv   ب) python3 -m venv   ج) venv create   د) python venv
  3. خالق پایتون چه کسی است؟
    الف) Guido van Rossum   ب) Brendan Eich   ج) Linus Torvalds   د) Tim Berners-Lee

تمرین عملی: یک پروژه‌ی جدید با محیط مجازی ایجاد کنید و یک برنامه بنویسید که:

  • نام، سن و شهر کاربر را دریافت کند.
  • یک پیام خوش‌آمدگویی با تمام اطلاعات نمایش دهد.
  • از پکیج requests برای دریافت اطلاعات از یک API ساده استفاده کند (اختیاری).

جمع‌بندی و خلاصه

نکات طلایی پایتون یک زبان ساده، خوانا و همه‌کاره است. از Python 3 استفاده کنید؛ Python 2 منسوخ شده است. VS Code با افزونه‌ی Python بهترین ابزار برای توسعه است. ()print برای چاپ و ()input برای دریافت ورودی استفاده می‌شود. pip مدیر بسته‌ها و venv محیط‌های مجازی است. همیشه از محیط مجازی برای ایزوله کردن پروژه‌ها استفاده کنید.

برگه تقلب

# چاپ
print("Hello")

# ورودی
name = input("نام: ")

# محیط مجازی
python3 -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows

# pip
pip install package_name
pip freeze > requirements.txt
pip install -r requirements.txt

واژه‌نامه تخصصی

  • pip: مدیر بسته‌های پایتون.
  • venv: محیط مجازی برای ایزوله کردن پروژه‌ها.
  • VS Code: ویرایشگر کد محبوب برای توسعه‌ی پایتون.
  • ()print: تابع برای چاپ خروجی.
  • ()input: تابع برای دریافت ورودی از کاربر.
  • requirements.txt: فایل لیست وابستگی‌های پروژه.

خطاهای رایج و عیب‌یابی

اشتباه فراموش کردن افزودن پایتون به PATH در هنگام نصب (ویندوز).
راه‌حل: در نصب، گزینه‌ی «Add Python to PATH» را فعال کنید یا به‌صورت دستی PATH را تنظیم کنید.
اشتباه استفاده از python به‌جای python3 در سیستم‌هایی که Python 2 نصب دارند.
راه‌حل: همیشه از python3 استفاده کنید تا مطمئن باشید Python 3 اجرا می‌شود.
اشتباه فراموش کردن فعال‌سازی محیط مجازی قبل از نصب پکیج‌ها.
راه‌حل: قبل از نصب هر پکیج، محیط مجازی را فعال کنید.
اشتباه نصب پکیج‌ها با pip بدون محیط مجازی که باعث می‌شود پکیج‌ها در سیستم نصب شوند.
راه‌حل: همیشه در پروژه‌های جدید یک محیط مجازی ایجاد کنید و پکیج‌ها را در آن نصب کنید.

پروژه نهایی فصل ۱

عنوان پروژه: ساخت یک دفترچه‌ی یادداشت ساده با پایتون

شرح: یک برنامه‌ی خط فرمان بسازید که بتواند یادداشت‌ها را ذخیره و نمایش دهد.

  • از کاربر با ()input بپرسید که می‌خواهد یادداشت جدید بنویسد یا یادداشت‌ها را ببیند.
  • یادداشت‌ها را در یک فایل متنی (با ()open) ذخیره کنید.
  • با ()print یادداشت‌ها را نمایش دهید.
  • از یک حلقه‌ی while برای ادامه‌ی برنامه تا زمانی که کاربر «خروج» را انتخاب کند استفاده کنید.
  • برای این پروژه یک محیط مجازی ایجاد کنید و یک فایل requirements.txt برای وابستگی‌ها (در صورت نیاز) ایجاد کنید.
  • کد خود را در VS Code بنویسید و با python3 اجرا کنید.
