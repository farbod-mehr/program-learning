Topic 101: معماری سیستم (System Architecture)

101.1 تعیین و پیکربندی تنظیمات سخت‌افزاری

شناسایی سخت‌افزار:

  • lspci: نمایش دستگاه‌های متصل به باس PCI (کارت گرافیک، شبکه، صدا)
  • lsusb: نمایش دستگاه‌های USB
  • lsmod: لیست ماژول‌های کرنل بارگذاری‌شده
  • modprobe: بارگذاری/حذف ماژول‌های کرنل (modprobe -r برای حذف)
  • lshw: نمایش کامل سخت‌افزار
  • /proc/: فایل‌سیستم مجازی حاوی اطلاعات سخت‌افزاری (مانند /proc/cpuinfo, /proc/meminfo)
  • /sys/: اطلاعات کرنل و دستگاه‌ها
  • /dev/: فایل‌های دستگاه (مانند /dev/sda, /dev/null)

مدیریت ماژول‌های کرنل:

lsmod | grep snd        # بررسی ماژول صدا
modprobe snd_hda_intel  # بارگذاری ماژول
modprobe -r snd_hda_intel # حذف ماژول

101.2 بوت کردن سیستم (Boot the System)

فرآیند بوت:

  1. BIOS/UEFI: POST (تست سخت‌افزار) و انتخاب دستگاه بوت
  2. MBR/GPT: خواندن بوت‌لودر
  3. GRUB2: بارگذاری کرنل و initrd
  4. Kernel: راه‌اندازی سخت‌افزار و mount کردن root filesystem
  5. init/systemd: اولین فرآیند (PID 1)

GRUB2 - دستورات کلیدی:

grub2-install /dev/sda              # نصب GRUB روی MBR (BIOS)
grub2-mkconfig -o /boot/grub2/grub.cfg  # تولید فایل پیکربندی (BIOS)
grub2-mkconfig -o /boot/efi/EFI/centos/grub.cfg  # برای UEFI

فایل‌های مهم GRUB2:

  • /boot/grub2/grub.cfg: فایل پیکربندی اصلی (به‌صورت خودکار تولید می‌شود)
  • /etc/default/grub: تنظیمات کاربر (مثل GRUB_TIMEOUT)
  • /etc/grub.d/: اسکریپت‌های تولید grub.cfg

بازیابی GRUB:

# بوت از رسانه نجات
chroot /mnt/sysroot
grub2-install /dev/sda
grub2-mkconfig -o /boot/grub2/grub.cfg

101.3 تغییر Runlevelها / اهداف بوت

Systemd (سیستم‌های مدرن):

  • poweroff.target: خاموش کردن
  • rescue.target: تک‌کاربره (نیازمند رمز root)
  • multi-user.target: چندکاربره با شبکه
  • graphical.target: چندکاربره با محیط گرافیکی
  • reboot.target: ری‌استارت
systemctl get-default                    # مشاهده هدف پیش‌فرض
systemctl set-default multi-user.target  # تنظیم هدف پیش‌فرض
systemctl isolate rescue.target          # تغییر به هدف rescue
systemctl list-units --type=target       # لیست اهداف

Topic 102: نصب لینوکس و مدیریت بسته‌ها

102.1 طراحی چیدمان هارد دیسک

پارتیشن‌بندی:

  • /boot: ۵۰۰MB تا ۱GB (فایل‌های بوت)
  • /: ۱۵-۲۰GB (سیستم‌عامل)
  • swap: ۲-۴GB یا بیشتر (حافظه مجازی)
  • /home: فضای باقی‌مانده (داده‌های کاربران)
fdisk -l              # لیست دیسک‌ها و پارتیشن‌ها
fdisk /dev/sda        # ویرایش پارتیشن‌ها (MBR)
gdisk /dev/sda        # ویرایش پارتیشن‌ها (GPT)
parted /dev/sda       # ابزار پیشرفته پارتیشن‌بندی

102.2 نصب بوت منیجر

GRUB2 (بوت‌لودر استاندارد لینوکس):

  • نصب روی MBR (BIOS): grub2-install /dev/sda
  • نصب روی ESP (UEFI): grub2-install --target=x86_64-efi --efi-directory=/boot/efi
  • تولید پیکربندی: grub2-mkconfig -o /boot/grub2/grub.cfg

فایل‌های پیکربندی: /etc/default/grub (تنظیمات ساده مثل timeout و kernel params)، /etc/grub.d/ (اسکریپت‌های تولیدکننده).

102.3 مدیریت کتابخانه‌های اشتراکی

کتابخانه‌های اشتراکی (*.so) کد مشترک بین برنامه‌ها هستند. مکان‌های استاندارد: /lib, /usr/lib.

ldd /bin/ls              # نمایش کتابخانه‌های مورد نیاز ls
ldconfig -p              # لیست کتابخانه‌های کش‌شده

ldconfig برای به‌روزرسانی کش کتابخانه‌ها استفاده می‌شود و /etc/ld.so.conf مسیرهای جستجوی کتابخانه را نگه می‌دارد.

102.4 مدیریت بسته Debian (apt, dpkg)

dpkg (سطح پایین):

dpkg -i package.deb       # نصب بسته
dpkg -r package            # حذف بسته
dpkg -l                   # لیست بسته‌های نصب‌شده
dpkg -L package           # لیست فایل‌های یک بسته
dpkg -S /path/to/file     # پیدا کردن بسته مالک یک فایل

apt (سطح بالا - مدیریت وابستگی‌ها):

apt update                # به‌روزرسانی لیست بسته‌ها
apt upgrade               # ارتقاء بسته‌ها
apt install package       # نصب بسته
apt remove package        # حذف بسته (بدون تنظیمات)
apt purge package         # حذف کامل (با تنظیمات)
apt autoremove            # حذف وابستگی‌های بی‌استفاده
apt search keyword        # جستجو
apt-cache show package    # اطلاعات بسته

فایل‌های مهم: /etc/apt/sources.list (مخازن اصلی)، /etc/apt/sources.list.d/ (مخازن اضافی)، /etc/apt/trusted.gpg.d/ (کلیدهای GPG).

102.5 مدیریت بسته RPM (rpm, yum, dnf, zypper)

rpm (سطح پایین):

rpm -ivh package.rpm      # نصب
rpm -e package            # حذف
rpm -qa                   # لیست همه بسته‌ها
rpm -ql package           # لیست فایل‌های بسته
rpm -qf /path/to/file     # بسته مالک فایل
rpm -qp --requires pkg.rpm # وابستگی‌های یک فایل rpm

yum/dnf (سطح بالا):

yum install package       # نصب
yum remove package        # حذف
yum update                # به‌روزرسانی
yum search keyword        # جستجو
yum info package          # اطلاعات
dnf install package       # جایگزین مدرن yum

zypper (openSUSE):

zypper install package
zypper remove package
zypper search keyword

فایل‌های مهم: /etc/yum.conf (پیکربندی yum)، /etc/yum.repos.d/ (فایل‌های مخزن).

102.6 لینوکس به‌عنوان مهمان مجازی‌سازی

  • VM (Virtual Machine): ماشین مجازی کامل
  • Container: جداسازی سبک‌تر (Docker, LXC)
  • IaaS Cloud: زیرساخت ابری (AWS, Azure)
  • cloud-init: ابزار پیکربندی اولیه در ابر

تغییرات لازم در کلون:

  • SSH host keys: باید تولید مجدد شوند (ssh-keygen -A)
  • machine-id: باید پاک شود (/etc/machine-id, /var/lib/dbus/machine-id)
  • hostname: باید تغییر کند

Topic 103: دستورات GNU و یونیکس

103.1 کار در خط فرمان

Bash و محیط:

echo $PATH              # نمایش متغیر PATH
export EDITOR=vim       # تعریف متغیر محیطی
env                     # نمایش همه متغیرها
set                     # نمایش متغیرهای شل
unset VAR               # حذف متغیر
history                 # تاریخچه دستورات
!100                    # اجرای دستور 100 از تاریخچه
!!                      # اجرای دستور قبلی
Ctrl+R                  # جستجو در تاریخچه

راهنما:

man ls                  # راهنمای دستور
ls --help               # کمک سریع
type ls                 # نوع دستور (alias, builtin, file)
which ls                # مسیر اجرایی

103.2 پردازش جریان‌های متنی با فیلترها

cat file.txt            # نمایش فایل
cut -d: -f1 /etc/passwd # برش ستون 1 با جداکننده :
sort file.txt           # مرتب‌سازی
uniq                    # حذف خطوط تکراری (نیاز به sort)
head -n 10 file         # 10 خط اول
tail -n 10 file         # 10 خط آخر
tail -f file            # دنبال کردن زنده
wc -l file              # شمارش خطوط
tr 'a-z' 'A-Z'          # تبدیل حروف
sed 's/old/new/g'       # جایگزینی
grep pattern file       # جستجو

103.3 مدیریت پایه فایل

cp source dest          # کپی
cp -r dir1 dir2         # کپی بازگشتی
mv source dest          # انتقال/تغییر نام
rm file                 # حذف
rm -r dir               # حذف بازگشتی
mkdir -p /a/b/c         # ساخت مسیر تو در تو
rmdir dir               # حذف پوشه خالی
touch file              # ایجاد فایل خالی/به‌روزرسانی timestamp
find / -name "*.conf"   # جستجو
find / -size +10M       # فایل‌های بزرگ‌تر از 10MB
tar -czvf archive.tar.gz dir/  # فشرده‌سازی
tar -xzvf archive.tar.gz       # استخراج

103.4 جریان‌ها، لوله‌ها و تغییر مسیرها

command > file          # stdout به فایل (بازنویسی)
command >> file         # stdout به فایل (افزودن)
command 2> error.txt    # stderr به فایل
command &> all.txt      # stdout و stderr
command | grep pattern  # لوله (pipe)
tee file                # نوشتن در فایل + نمایش
xargs                   # تبدیل ورودی به آرگومان

103.5 ایجاد، نظارت و از بین بردن فرآیندها

command &               # اجرا در پس‌زمینه
jobs                    # لیست jobها
fg %1                   # آوردن job 1 به پیش‌زمینه
bg %1                   # فرستادن job 1 به پس‌زمینه
Ctrl+Z                  # توقف موقت
ps aux                  # همه فرآیندها
ps -ef                  # فرمت دیگر
top                     # نمایش زنده
htop                    # نسخه بهتر top
pgrep sshd              # پیدا کردن PID با نام
pkill sshd              # کشتن با نام
kill -9 PID             # کشتن اجباری
killall process         # کشتن همه با نام
nohup command &         # اجرا پس از logout
screen / tmux           # جلسات پایدار

103.6 تغییر اولویت اجرای فرآیند

nice -n 10 command      # اجرا با nice بالاتر (اولویت کمتر)
renice -n 5 -p PID      # تغییر nice فرآیند در حال اجرا
# مقادیر nice: -20 (بالاترین اولویت) تا 19 (پایین‌ترین)

103.7 جستجوی فایل‌های متنی با عبارات باقاعده

grep '^root' /etc/passwd    # شروع با root
grep 'bash$' /etc/passwd    # پایان با bash
grep '[0-9]' file           # شامل عدد
grep 'a.*b' file            # a و b با هر چیزی بینشان
grep -E 'pattern1|pattern2' # چند الگو

103.8 ویرایش پایه فایل با vi

حالت‌های vi:

  • Normal: ناوبری (h j k l, w, b, gg, G)
  • Insert: تایپ (i, a, o, O)
  • Command: دستورات (:w, :q, :wq, :q!, :set nu)

جستجو و جایگزینی:

/pattern        # جستجو به جلو
?pattern        # جستجو به عقب
n               # بعدی
N               # قبلی
:%s/old/new/g   # جایگزینی همه

Topic 104: دستگاه‌ها، فایل‌سیستم‌ها و FHS

104.1 ایجاد پارتیشن‌ها و فایل‌سیستم‌ها

fdisk /dev/sdb          # ایجاد پارتیشن (MBR)
gdisk /dev/sdb          # ایجاد پارتیشن (GPT)
mkfs.ext4 /dev/sdb1     # ساخت فایل‌سیستم ext4
mkfs.xfs /dev/sdb1      # ساخت فایل‌سیستم XFS
mkswap /dev/sdb2        # ساخت swap
blkid                   # نمایش UUID و نوع فایل‌سیستم

104.2 حفظ یکپارچگی فایل‌سیستم‌ها

fsck /dev/sdb1          # بررسی و تعمیر
fsck -y /dev/sdb1       # پاسخ خودکار بله
e2fsck -f /dev/sdb1     # بررسی اجباری ext

104.3 کنترل Mount و Unmount

mount /dev/sdb1 /mnt/data          # mount دستی
umount /mnt/data                   # unmount
mount -a                           # mount همه از fstab
mount -t ext4 /dev/sdb1 /mnt       # تعیین نوع
mount -o ro /dev/sdb1 /mnt         # فقط خواندنی

/etc/fstab - مثال:

UUID=xxxx-xxxx / ext4 defaults 0 1
UUID=yyyy-yyyy /home ext4 defaults 0 2
UUID=zzzz-zzzz none swap sw 0 0

104.4 مدیریت سهمیه دیسک

quotacheck -cug /home          # ایجاد فایل‌های سهمیه
quotaon /home                  # فعال‌سازی
edquota -u username            # ویرایش سهمیه کاربر
repquota /home                 # گزارش

104.5 مدیریت مجوزها و مالکیت

مجوزهای پایه: r (4) خواندن، w (2) نوشتن، x (1) اجرا.

chmod 755 file          # rwxr-xr-x
chmod u+x file          # افزودن اجرا برای مالک
chown user:group file   # تغییر مالک و گروه
chgrp group file        # تغییر گروه
umask 022               # مجوز پیش‌فرض فایل‌های جدید

مجوزهای ویژه:

  • SUID (chmod u+s): اجرا با مجوز مالک فایل (مثال: /usr/bin/passwd)
  • SGID (chmod g+s): روی فایل‌ها اجرا با گروه مالک؛ روی دایرکتوری‌ها فایل‌های جدید گروه دایرکتوری را به ارث می‌برند
  • Sticky Bit (chmod +t): فقط مالک می‌تواند فایل را حذف کند (مثال: /tmp)
-rwsr-xr-x  # SUID
-rwxr-sr-x  # SGID
drwxrwxrwt  # Sticky

104.6 لینک‌های سخت و نمادین

ln file1 file2          # لینک سخت (Hard Link)
ln -s /path/to/file link # لینک نمادین (Symbolic/Soft Link)
ls -li                  # نمایش inode (لینک‌های سخت inode یکسان دارند)
ls -l                   # لینک نمادین با -> نمایش داده می‌شود

تفاوت‌ها: Hard Link فقط روی همان فایل‌سیستم است، inode یکسان دارد و اگر فایل اصلی حذف شود لینک باقی می‌ماند. Soft Link می‌تواند به هر جایی اشاره کند و اگر فایل اصلی حذف شود لینک شکسته می‌شود.

Topic 105: شل و اسکریپت‌نویسی

105.1 سفارشی‌سازی محیط شل

فایل‌های startup:

  • /etc/profile: برای همه کاربران (login shell)
  • ~/.bash_profile یا ~/.profile: برای کاربر (login shell)
  • ~/.bashrc: برای shell غیر-login تعاملی
  • /etc/bashrc یا /etc/bash.bashrc: system-wide
# در ~/.bashrc
export PATH=$PATH:/home/user/bin
alias ll='ls -la'
alias grep='grep --color=auto'

105.2 نوشتن اسکریپت‌های ساده

Shebang:

#!/bin/bash

متغیرها:

name="Ali"
echo "Hello $name"
echo "Hello ${name}"

شرط‌ها:

if [ $age -gt 18 ]; then
    echo "Adult"
elif [ $age -gt 12 ]; then
    echo "Teen"
else
    echo "Child"
fi

حلقه‌ها:

for i in {1..5}; do
    echo "Number $i"
done

while [ $count -lt 10 ]; do
    echo $count
    ((count++))
done

Command Substitution:

current_date=$(date +%Y-%m-%d)
files=$(ls *.txt)

شرط‌های تست: -eq, -ne, -lt, -gt (مقایسه عددی)، -z, -n (خالی/غیرخالی بودن رشته)، -f, -d (وجود فایل/دایرکتوری).

Topic 106: رابط‌های کاربری و دسکتاپ

106.1 نصب و پیکربندی X11

مفاهیم X11:

  • X Server: مدیریت نمایش و ورودی
  • X Client: برنامه‌های گرافیکی
  • Display Manager: صفحه ورود (GDM, LightDM)
  • Window Manager: مدیریت پنجره‌ها (Mutter, KWin)

فایل پیکربندی: /etc/X11/xorg.conf (پیکربندی اصلی، کمتر استفاده می‌شود)، /etc/X11/xorg.conf.d/ (قطعات پیکربندی).

Xorg -configure         # تولید فایل پیکربندی
startx                  # شروع X از خط فرمان
xrandr                  # مدیریت نمایشگرها

106.2 دسکتاپ‌های گرافیکی

محیط‌های دسکتاپ: GNOME (مدرن، پیش‌فرض Fedora/Ubuntu)، KDE Plasma (قابل تنظیم، ویندوزمانند)، XFCE (سبک و سریع)، MATE (ادامه GNOME 2)، Cinnamon (شبیه ویندوز، Linux Mint).

دسترسی از راه دور: VNC (پروتکل دسکتاپ از راه دور)، RDP (پروتکل مایکروسافت)، X11 Forwarding (ssh -X user@host).

106.3 دسترسی‌پذیری

Screen Reader (صفحه‌خوان — Orca)، Screen Magnifier (بزرگ‌نمایی)، On-Screen Keyboard (کیبورد مجازی)، High Contrast Themes (تم‌های کنتراست بالا).

Topic 107: وظایف مدیریتی

107.1 مدیریت کاربران و گروه‌ها

useradd -m -s /bin/bash ali     # ایجاد کاربر با home
useradd -m -G sudo,developers ali # با گروه‌های اضافی
usermod -aG sudo ali            # افزودن به گروه
usermod -L ali                  # قفل کردن
usermod -U ali                  # باز کردن
userdel -r ali                  # حذف با home
passwd ali                      # تغییر رمز

groupadd developers
groupdel developers
groupmod -n newname oldname

chage -l ali                    # اطلاعات انقضای رمز
chage -M 90 ali                 # حداکثر 90 روز
chage -E 2026-12-31 ali         # تاریخ انقضا

فایل‌های مهم: /etc/passwd (اطلاعات کاربر: UID, GID, shell)، /etc/shadow (رمزهای هش‌شده)، /etc/group (گروه‌ها)، /etc/skel/ (فایل‌های پیش‌فرض home).

107.2 خودکارسازی وظایف

Cron:

crontab -e              # ویرایش cron کاربر
crontab -l              # لیست
crontab -r              # حذف

# فرمت: دقیقه ساعت روز ماه روزهفته دستور
0 2 * * * /backup.sh    # هر روز 2 بامداد
*/5 * * * * /check.sh   # هر 5 دقیقه

دایرکتوری‌های cron: /etc/cron.d/ (فایل‌های cron سفارشی)، /etc/cron.daily/, /etc/cron.hourly/, /etc/cron.weekly/, /etc/cron.monthly/ (اسکریپت‌های دوره‌ای).

at:

echo "/backup.sh" | at 02:00
atq                     # لیست کارهای at
atrm 1                  # حذف کار 1

Systemd Timers:

systemctl list-timers
systemd-run --on-calendar="*-*-* 02:00:00" /backup.sh

107.3 بومی‌سازی و بین‌المللی‌سازی

locale                  # نمایش locale فعلی
locale -a               # لیست localeهای موجود
localectl status        # وضعیت
localectl set-locale LANG=en_US.UTF-8
localectl set-keymap us

timedatectl                              # وضعیت زمان
timedatectl list-timezones               # لیست مناطق زمانی
timedatectl set-timezone Asia/Tehran     # تنظیم منطقه
timedatectl set-time "2026-01-01 12:00:00"

متغیرها: LANG (زبان اصلی)، LC_ALL (override همه)، LC_TIME (فرمت تاریخ/زمان)، LC_MESSAGES (زبان پیام‌ها)، TZ (منطقه زمانی).

نکته LANG=C در اسکریپت‌ها خروجی استاندارد انگلیسی برای پردازش قابل‌پیش‌بینی ایجاد می‌کند.

108.2 ثبت لاگ سیستم

rsyslog: /etc/rsyslog.conf (پیکربندی)، فرمت facility.priority action، مثال: authpriv.* /var/log/secure.

Facilities: auth, authpriv, cron, daemon, kern, mail, user. Priorities: debug, info, notice, warning, err, crit, alert, emerg.

systemd journal:

journalctl                              # همه لاگ‌ها
journalctl -u sshd                      # لاگ سرویس
journalctl --since "1 hour ago"         # بازه زمانی
journalctl -p err                       # فقط خطاها
journalctl -b                           # از بوت فعلی
journalctl --disk-usage                 # فضای مصرفی
journalctl --vacuum-time=7d             # حذف قدیمی‌تر از 7 روز

logrotate: /etc/logrotate.conf (پیکربندی اصلی)، /etc/logrotate.d/ (پیکربندی هر سرویس).

110.3 ایمن‌سازی داده‌ها با رمزنگاری

GPG:

gpg --gen-key                           # تولید کلید

gpg --decrypt file.gpg                  # رمزگشایی
gpg --sign file                         # امضا
gpg --verify file.sig                   # تأیید

SSH:

ssh-keygen -t ed25519                   # تولید کلید

ssh user@host                           # اتصال

فایل‌های SSH: ~/.ssh/id_ed25519 (کلید خصوصی)، ~/.ssh/id_ed25519.pub (کلید عمومی)، ~/.ssh/authorized_keys (کلیدهای مجاز سرور)، /etc/ssh/sshd_config (پیکربندی سرور).
