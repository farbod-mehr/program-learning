🔭 چشم‌انداز فصل: اهداف و جایگاه

در فصل‌های قبلی یاد گرفتیم چطور مقادیر را در متغیرها ذخیره کنیم. اما یک برنامه‌ی واقعی فقط مقادیر را نگه نمی‌دارد — روی آن‌ها کار می‌کند: جمع و تفریق می‌کند، دو مقدار را با هم مقایسه می‌کند، شرط‌های منطقی می‌سازد. ابزارهایی که این کارها را انجام می‌دهند، عملگر نام دارند.

این فصل، جعبه‌ابزار شما را کامل می‌کند. بدون عملگرها، کد شما فقط یک سری اعداد و متن است که هیچ‌کاری انجام نمی‌دهد. با عملگرها، برنامه‌ی شما واقعاً «فکر» می‌کند: می‌تواند حساب کند، تصمیم بگیرد و منطق واقعی داشته باشد.

در پایان این فصل، شما می‌توانید:

  • با اعداد، چهار عمل اصلی (جمع، تفریق، ضرب، تقسیم) و چند عمل دیگر انجام دهید.
  • دو مقدار را با هم مقایسه کنید و بفهمید برابرند، بزرگ‌ترند یا کوچک‌تر.
  • با and، or، not شرط‌های منطقی بسازید.
  • مقدار یک متغیر را با عملگرهای ترکیبی مثل += به‌طور خلاصه به‌روزرسانی کنید.
  • بدانید پایتون به ترتیب، کدام عملگر را اول محاسبه می‌کند.
  • با پرانتز، اولویت‌ها را کنترل کنید تا خروجی همان‌طور باشد که می‌خواهید.
📌 نکته مهم این فصل، پیش‌نیاز مستقیم فصل ۵ (شرط و تصمیم‌گیری) است. بدون درک عملگرهای مقایسه‌ای و منطقی، فصل ۵ معنی ندارد. پس این فصل را جدی بگیرید و هر مثال را خودتان تایپ و اجرا کنید.

🤔 سوالات محرک ذهنی

قبل از خواندن آموزش، چند لحظه به این سوال‌ها فکر کنید:

🤔 چرا پایتون دو نوع تقسیم دارد؟ (/ و //)

چون گاهی می‌خواهید نتیجه با اعشار باشد (مثلاً ۷ ÷ ۲ = ۳.۵)، و گاهی فقط عدد صحیح کار می‌کند (مثلاً «چند بار عدد ۲ داخل ۷ جا می‌شود؟» → ۳ بار). با / جواب اعشاری می‌گیرید، با // جواب صحیح و بریده‌شده. فصل‌های بعدی می‌بینید که هرکدام جای خودشان را دارند.

🤔 تفاوت = و == چیست؟ یکسان به‌نظر می‌رسند!

این یکی از مهم‌ترین تفاوت‌هاست. = یک علامت انتساب است: «این مقدار را داخل متغیر بریز». == یک علامت مقایسه است: «آیا این دو مقدار برابرند؟» و جواب بله/خیر می‌دهد. مثال: x = 5 یعنی «۵ را در x بگذار»، ولی x == 5 یعنی «آیا x برابر ۵ است؟».

🤔 چرا باید اولویت عملگرها را بدانم؟ مگر ریاضی فرق دارد؟

اصول همان اصول ریاضی دبستان است، اما پایتون چند عملگر دارد که در ریاضی معمولی نیستند (مثل % و **). اگر ترتیب را ندانید، خروجی اشتباه می‌گیرید. مثلاً 2 + 3 * 4 در پایتون می‌شود 14 نه 20، چون ضرب اول محاسبه می‌شود. اگر می‌خواهید اول جمع انجام شود، باید پرانتز بگذارید: (2 + 3) * 4.

📖 آموزش گام‌به‌گام: عملگرها

۱) عملگر چیست؟ — ابزار انجام کار روی مقادیر

یک عملگر، نمادی است که روی یک یا چند مقدار کار انجام می‌دهد و یک نتیجه تولید می‌کند. مقادیری که روی آن‌ها کار می‌شود، عملوند نام دارند.

مثال ساده:

مثال سادهPython
2 + 3
# ↑  ↑
# عملوند  عملگر  عملوند
# نتیجه: 5

ترکیب عملگرها و عملوندها، یک عبارت (expression) می‌سازد. هر عبارت، یک مقدار تولید می‌کند که می‌توانید آن را در متغیر ذخیره کنید یا مستقیماً چاپ کنید:

expression_demo.pyPython
# مستقیماً چاپ
print(2 + 3)

# یا در متغیر ذخیره
result = 2 + 3
print(result)

۲) عملگرهای حسابی — ابزار کار با اعداد

پایتون ۷ عملگر حسابی دارد. بعضی را از ریاضی می‌شناسید، بعضی را نه:

الف) جمع، تفریق، ضرب، تقسیم — آشنایان قدیمی

basic_arithmetic.pyPython
print(10 + 3)    # 13 — جمع
print(10 - 3)    # 7  — تفریق
print(10 * 3)    # 30 — ضرب
print(10 / 3)    # 3.3333... — تقسیم (همیشه اعشاری)

نکته‌ی مهم: عملگر / در پایتون ۳ همیشه خروجی اعشاری می‌دهد، حتی اگر جواب صحیح باشد:

تقسیم با /Python
print(10 / 2)    # 5.0  (نه 5!)
print(type(10 / 2))   # <class 'float'>

ب) تقسیم صحیح — عملگر //

اگر می‌خواهید نتیجه‌ی تقسیم، عدد صحیح باشد (اعشارش حذف شود)، از // استفاده کنید:

floor_division.pyPython
print(10 // 3)   # 3 (نه 3.33)
print(10 // 2)   # 5 (صحیح، نه 5.0)
print(17 // 5)   # 3
print(7 // 2)    # 3
💡 کاربرد واقعی فرض کنید ۱۷ سیب دارید و می‌خواهید در جعبه‌های ۵ تایی بچینید. چند جعبه‌ی کامل پر می‌شود؟ 17 // 5 = ۳ جعبه. این نوع محاسبه در برنامه‌نویسی بسیار رایج است.

ج) باقیمانده — عملگر %

عملگر % باقیمانده‌ی تقسیم را به شما می‌دهد:

modulo.pyPython
print(10 % 3)    # 1 (چون 10 = 3 × 3 + 1)
print(10 % 5)    # 0 (چون 10 = 5 × 2 + 0)
print(17 % 5)    # 2 (چون 17 = 5 × 3 + 2)

کاربردش چیست؟ برای تشخیص زوج و فرد، بررسی بخش‌پذیری، و خیلی از محاسبات چرخه‌ای:

even_odd.pyPython
num = 8
print(num % 2)    # 0 → زوج

num = 7
print(num % 2)    # 1 → فرد

اگر عدد % 2 صفر باشد، عدد زوج است. اگر ۱ باشد، فرد است. این ترفند را در فصل ۵ به‌کار می‌بریم.

د) توان — عملگر **

برای محاسبه‌ی توان (مثلاً ۲ به قوّت ۳) از ** استفاده می‌کنیم:

power.pyPython
print(2 ** 3)    # 8  (2 × 2 × 2)
print(5 ** 2)    # 25 (5 × 5)
print(2 ** 10)   # 1024
print(9 ** 0.5)  # 3.0 (جذر ۹)

۳) عملگرهای مقایسه‌ای — بله/خیر

عملگرهای مقایسه‌ای دو مقدار را با هم مقایسه می‌کنند و همیشه یک مقدار True یا False برمی‌گردانند:

comparison.pyPython
print(5 == 5)    # True   — برابر (دوتا علامت مساوی!)
print(5 != 3)    # True   — نابرابر
print(10 > 3)    # True   — بزرگ‌تر
print(10 < 3)    # False  — کوچک‌تر
print(10 >= 10)  # True   — بزرگ‌تر یا مساوی
print(10 <= 5)   # False  — کوچک‌تر یا مساوی
⚠️ دام بزرگ = برای انتساب است (ذخیره مقدار در متغیر)، اما == برای مقایسه. اگر اشتباهاً بنویسید if x = 5 به‌جای if x == 5، پایتون خطای SyntaxError می‌دهد. این اشتباه در مبتدیان بسیار رایج است.

مقایسه فقط بین اعداد نیست — متن‌ها را هم می‌توانید مقایسه کنید:

str_comparison.pyPython
print("سلام" == "سلام")     # True
print("سلام" == "خوبی")      # False
print("a" < "b")             # True (بر اساس ترتیب الفبا)
print("apple" < "banana")    # True

۴) عملگرهای منطقی — ترکیب شرط‌ها

گاهی می‌خواهید چند شرط را با هم ترکیب کنید. پایتون سه عملگر منطقی دارد:

  • and — درست است اگر هر دو شرط درست باشند.
  • or — درست است اگر حداقل یکی از شرط‌ها درست باشد.
  • not — مقدار را برعکس می‌کند.

عملگر and

and_demo.pyPython
age = 20
has_license = True

print(age >= 18 and has_license)   # True (هر دو شرط درست)
print(age >= 18 and age < 30)      # True
print(age >= 18 and age < 18)      # False (چون یکی غلط است)

عملگر or

or_demo.pyPython
is_weekend = True
is_holiday = False

print(is_weekend or is_holiday)    # True (چون weekend درست است)
print(False or False)              # False
print(False or True)               # True

عملگر not

not_demo.pyPython
is_raining = False
print(not is_raining)   # True (چون باران نمی‌بارد)

is_sunny = True
print(not is_sunny)     # False

ترکیب عملگرهای منطقی

logical_combined.pyPython
age = 25
has_id = True
is_banned = False

# شرط‌های ترکیبی
can_enter = age >= 18 and has_id and not is_banned
print(can_enter)   # True

# با پرانتز، خواناتر می‌شود
can_enter = (age >= 18) and has_id and (not is_banned)
print(can_enter)   # True
💡 نکته طلایی حتی وقتی نیازی نیست، از پرانتز استفاده کنید تا نیت کد شما برای خواننده واضح باشد. پرانتزهای اضافی ضرری ندارند اما باعث می‌شوند کد خوانا شود.

۵) عملگرهای انتساب ترکیبی — کوتاه‌نویسی

فرض کنید می‌خواهید مقدار score را ۵ واحد زیاد کنید. راه معمولی:

normal_way.pyPython
score = 10
score = score + 5
print(score)   # 15

پایتون یک راه کوتاه‌تر دارد: عملگر انتساب ترکیبی +=:

short_way.pyPython
score = 10
score += 5     # معادل: score = score + 5
print(score)   # 15

score -= 3     # معادل: score = score - 3
print(score)   # 12

score *= 2     # معادل: score = score * 2
print(score)   # 24

score //= 5    # معادل: score = score // 5
print(score)   # 4

همه‌ی عملگرهای حسابی این نسخه‌ی ترکیبی دارند: +=، -=، *=، /=، //=، %=، **=.

۶) اولویت عملگرها — چه چیزی اول حساب می‌شود؟

وقتی یک عبارت چند عملگر دارد، پایتون با ترتیب مشخصی آن‌ها را محاسبه می‌کند. این ترتیب، از ریاضی دبستان آشناست:

  1. پرانتز () — همیشه اول.
  2. توان ** — بعد از پرانتز.
  3. ضرب، تقسیم، تقسیم صحیح، باقیمانده * / // % — از چپ به راست.
  4. جمع و تفریق + - — از چپ به راست.
  5. مقایسه == != > < >= <= — بعد از حساب.
  6. منطقی not — قبل از and و or.
  7. منطقی and — قبل از or.
  8. منطقی or — آخر از همه.

چند مثال برای درک بهتر:

precedence.pyPython
# ضرب قبل از جمع
print(2 + 3 * 4)          # 14 (نه 20)

# با پرانتز، ترتیب را عوض می‌کنیم
print((2 + 3) * 4)        # 20

# توان قبل از ضرب
print(2 * 3 ** 2)         # 18 (چون 3² = 9، بعد × 2)

# تقسیم و ضرب از چپ به راست
print(20 / 4 * 2)         # 10.0 (نه 2.5، چون 20/4 اول، بعد × 2)

# مقایسه بعد از حساب
print(2 + 3 > 4)          # True (چون 5 > 4)

# not قبل از and
print(not True and False) # False (چون (not True) = False، و False and False = False)

# and قبل از or
print(True or False and False)  # True (چون and اول: False and False = False، بعد True or False = True)
💡 نکته طلایی اگر شک دارید، پرانتز بگذارید. پرانتز نه فقط ترتیب را مشخص می‌کند، بلکه کد شما را برای خواننده هم واضح‌تر می‌کند. تجربه نشان می‌دهد که حرفه‌ای‌ها بیشتر از مبتدی‌ها از پرانتز استفاده می‌کنند، نه کمتر.

۷) کاربرد واقعی: ترکیب همه‌چیز

بیایید همه‌ی این عملگرها را در یک برنامه‌ی واقعی به کار بگیریم. برنامه‌ای که وضعیت یک فروشگاه را بررسی می‌کند:

store_status.pyPython
# فرض کنید اطلاعات زیر از کاربر یا سیستم گرفته شده
stock = 50               # موجودی انبار
sold = 12                # تعداد فروش رفته
price_per_item = 25000   # قیمت هر کالا
is_weekend = True
is_holiday = False

# محاسبات با عملگرهای حسابی
remaining = stock - sold                    # موجودی باقیمانده
revenue = sold * price_per_item             # درآمد کل
cartons = stock // 10                       # چند کارتن ده‌تایی پر می‌شود
leftover = stock % 10                       # چند تا باقی می‌ماند

# مقایسه‌ها
needs_restock = remaining < 20              # نیاز به تأمین مجدد؟
is_popular = sold > 10                      # پرفروش بوده؟

# منطق ترکیبی
is_busy_day = is_weekend or is_holiday      # روز شلوغ؟
all_good = (remaining >= 0) and (revenue > 0)

# نمایش
print("=" * 40)
print("گزارش فروشگاه")
print("=" * 40)
print("موجودی باقیمانده :", remaining)
print("درآمد کل        :", revenue)
print("کارتن‌های پر     :", cartons)
print("کالای باقیمانده :", leftover)
print()
print("نیاز به تأمین مجدد؟", needs_restock)
print("پرفروش؟           ", is_popular)
print("روز شلوغ؟         ", is_busy_day)
print("همه‌چیز خوب؟      ", all_good)
print("=" * 40)

💻 مثال عملی

یک برنامه‌ی ساده که از کاربر دو عدد می‌گیرد و همه‌ی عملگرها را روی آن‌ها نمایش می‌دهد:

calculator.py — ماشین‌حساب همه‌کارهPython
# ماشین‌حساب — تمرین همه‌ی عملگرها

print("=" * 40)
print("        ماشین‌حساب ساده")
print("=" * 40)
print()

# دریافت دو عدد
a_text = input("عدد اول را وارد کنید: ")
b_text = input("عدد دوم را وارد کنید: ")

a = float(a_text)
b = float(b_text)

# محاسبات با عملگرهای حسابی
sum_result = a + b
diff = a - b
product = a * b
quotient = a / b
floor_div = a // b
remainder = a % b
power = a ** b

# مقایسه‌ها
equal = (a == b)
greater = (a > b)

# منطق ترکیبی
is_both_positive = (a > 0) and (b > 0)
is_any_zero = (a == 0) or (b == 0)

# نمایش نتایج
print()
print("-" * 40)
print("  نتایج محاسبات:")
print(f"    {a} + {b} = {sum_result}")
print(f"    {a} - {b} = {diff}")
print(f"    {a} × {b} = {product}")
print(f"    {a} ÷ {b} = {quotient}")
print(f"    {a} // {b} = {floor_div}")
print(f"    {a} % {b} = {remainder}")
print(f"    {a} ** {b} = {power}")
print("-" * 40)
print("  مقایسه:")

🛠️ کارگاه عملی

یک برنامه‌ی «محاسبه‌گر فاکتور رستوران» بسازید که همه‌ی عملگرها را در خود داشته باشد:

  1. فایل جدیدی به نام restaurant_bill.py در پوشه‌ی پروژه بسازید.
  2. از کاربر بخواهید قیمت سه غذا را وارد کند. با float() به عدد تبدیل کنید.
  3. جمع کل سه غذا را در متغیر subtotal ذخیره کنید.
  4. مالیات ۹٪ را محاسبه کنید (ضرب در ۰.۰۹) و در tax بگذارید.
  5. مبلغ نهایی را در total بگذارید.
  6. تعداد نفرات را از کاربر بپرسید و در people بگذارید (با int()).
  7. سهم هر نفر را با تقسیم total / people حساب کنید.
  8. بررسی کنید که آیا سهم هر نفر از ۱۰۰۰۰۰ تومان بیشتر است؟ (نتیجه را در متغیر is_expensive ذخیره کنید.)
  9. بررسی کنید که آیا تعداد نفرات بیشتر از ۳ و مبلغ نهایی بیشتر از ۵۰۰۰۰۰ است؟ (نتیجه را در group_discount_eligible بگذارید.)
  10. همه‌چیز را در قالب یک فاکتور زیبا چاپ کنید.
  11. یک خط اضافه کنید که چاپ کند: «پرداخت به عهده‌ی شماست؟» — جواب فقط وقتی True باشد که هم سهم شما بالا باشد و هم گروه واجد شرایط تخفیف باشد. از and استفاده کنید.

راهنما: به ترتیب عملگرها دقت کنید. مثلاً a * 0.09 + b اول ضرب و بعد جمع می‌شود. اگر می‌خواهید ترتیب دیگری باشد، از پرانتز استفاده کنید.

🐞 خطاهای رایج و رفع آن‌ها

این خطاها را در تمرین‌ها زیاد می‌بینید. هر کدام را خوب بشناسید:

❌ SyntaxError: invalid syntax (وقتی از = به‌جای == استفاده می‌کنید)

معنی: پایتون انتظار دارد در این محل مقایسه انجام شود، اما شما انتساب نوشته‌اید.

علت: نوشته‌اید if x = 5: یا (x = 5).

راه‌حل: برای مقایسه، همیشه از == استفاده کنید. برای انتساب، از =. این دو، متفاوتند و اشتباه‌گرفتنشان خطای رایجی است.

❌ TypeError: unsupported operand type(s) for +: 'int' and 'str'

معنی: «نمی‌توانم عدد و متن را با هم جمع کنم».

علت: کدی مثل "سن: " + 25 یا age + " سال" نوشته‌اید.

راه‌حل: با str() عدد را به متن تبدیل کنید، یا از print("سن:", 25) با کاما استفاده کنید. این دام در فصل ۳ مطرح شد.

❌ ZeroDivisionError: division by zero

معنی: «نمی‌توان بر صفر تقسیم کرد».

علت: کدی مثل 10 / 0 یا x // 0 یا 10 % 0 نوشته‌اید.

راه‌حل: قبل از تقسیم، بررسی کنید که مخرج صفر نباشد. با یک شرط ساده: if b != 0: result = a / b (که در فصل ۵ یاد می‌گیرید).

❌ خروجی اشتباه به‌خاطر اولویت عملگرها

معنی: پایتون محاسبه را انجام داده، اما نه آن‌طور که شما انتظار داشتید.

علت: مثلاً در 2 + 3 * 4 انتظار داشتید ۲۰ بگیرید، اما ۱۴ گرفتید.

راه‌حل: هر وقت شک دارید، پرانتز بگذارید: (2 + 3) * 4. پرانتز نه هزینه دارد و نه سرعت را کم می‌کند؛ فقط وضوح می‌آورد.

❌ مقایسه‌ی یک عدد با متن

معنی: پایتون نمی‌تواند عدد و متن را با هم مقایسه کند.

علت: مثلاً نوشته‌اید "10" > 5. چون "10" متن است، پایتون خطای TypeError می‌دهد.

راه‌حل: قبل از مقایسه، مطمئن شوید انواع یکسانند. با int("10") یا str(5) تبدیل انجام دهید. یا از input() که متن برمی‌گرداند، قبلش int() بگیرید.

❌ خروجی 10 / 2 می‌شود 5.0، نه 5

معنی: این خطا نیست، ولی اگر انتظار ۵ داشتید، باید بدانید.

علت: در پایتون ۳، عملگر / همیشه خروجی float می‌دهد.

راه‌حل: اگر خروجی صحیح می‌خواهید، از // استفاده کنید. این تفاوت در چاپ خروجی و در فرمت‌بندی اهمیت دارد.

❌ استفاده از کلمه‌ی and یا or به‌جای علامت

معنی: بعضی زبان‌ها از && و || استفاده می‌کنند، اما پایتون از کلمات انگلیسی.

علت: مثلاً نوشته‌اید a && b یا a || b.

راه‌حل: در پایتون همیشه از and، or، not استفاده کنید — با حروف کوچک و انگلیسی.

🏋️ تمرین‌های تثبیت

پاسخ‌ها را اول خودتان بنویسید، بعد باز کنید:

🏋️ تمرین پایه — پیش‌بینی خروجی

بدون اجرا، خروجی این عبارات را حدس بزنید. سپس اجرا کنید و جواب‌ها را بررسی کنید:

predict.pyPython
print(2 + 3 * 4)
print((2 + 3) * 4)
print(10 / 3)
print(10 // 3)
print(10 % 3)
print(2 ** 3 ** 2)     # ← این یکی سوال خوبی است!
print(5 > 3 and 2 < 4)
print(5 > 3 or 2 > 4)
print(not 5 > 3)

پاسخ:

  • 2 + 3 * 4 → 14 (ضرب اول)
  • (2 + 3) * 4 → 20 (پرانتز اول)
  • 10 / 3 → 3.3333...
  • 10 // 3 → 3
  • 10 % 3 → 1
  • 2 ** 3 ** 2 → 512 (توان از راست به چپ: 3² = 9، بعد 2⁹ = 512 — نه (2³)² = 64)
  • 5 > 3 and 2 < 4 → True
  • 5 > 3 or 2 > 4 → True
  • not 5 > 3 → False (چون 5 > 3 می‌شود True، و not آن می‌شود False)
🏋️ تمرین توسعه — تشخیص زوج و فرد

برنامه‌ای بنویسید که عددی از کاربر بگیرد و مشخص کند که زوج یا فرد است:

# تشخیص زوج یا فرد

number = int(input("یک عدد وارد کنید: "))

# باقیمانده تقسیم بر 2
remainder = number % 2

# بررسی: اگر باقیمانده 0 بود، زوج است
is_even = (remainder == 0)
is_odd = (remainder != 0)

print()
print(f"عدد شما: {number}")
print(f"باقیمانده تقسیم بر 2: {remainder}")
print(f"زوج است؟ {is_even}")
print(f"فرد است؟ {is_odd}")

نکته: در فصل ۵، با if، این کد را طوری می‌نویسیم که فقط یک پیام (زوج یا فرد) نمایش دهد، نه هر دو را. الان چون if بلد نیستیم، هر دو را چاپ می‌کنیم.

🏋️ تمرین خطایابی — چهار خطا

این کد چهار خطا دارد. هر کدام را پیدا کنید:

  • خطا ۱: ZeroDivisionError. تقسیم بر صفر مجاز نیست. راه‌حل: مخرج را قبل از تقسیم بررسی کنید یا تغییر دهید.

📝 آزمون تعاملی فصل

پرسش‌های چهارگزینه‌ای زیر را پاسخ دهید؛ بلافاصله بعد از انتخاب، پاسخ درست و توضیحش را می‌بینید. حد نصاب قبولی ۶۰٪ است و بهترین نمره‌تان ذخیره می‌شود.

۱) خروجی 10 // 3 چیست؟

💡 عملگر // تقسیم صحیح است — اعشار را حذف می‌کند. نتیجه ۳ (عدد صحیح) می‌شود.

۲) خروجی 10 % 3 چیست؟

💡 عملگر % باقیمانده تقسیم را برمی‌گرداند. ۱۰ = ۳ × ۳ + ۱، پس باقیمانده ۱ است.

۳) خروجی 2 + 3 * 4 چیست؟

💡 ضرب قبل از جمع محاسبه می‌شود: ۳ × ۴ = ۱۲، بعد ۲ + ۱۲ = ۱۴.

۴) تفاوت = و == چیست؟

💡 = یعنی «این مقدار را در متغیر بریز» (انتساب). == یعنی «آیا این دو برابرند؟» (مقایسه). اشتباه‌گرفتن این دو، یکی از رایج‌ترین خطاهای مبتدیان است.

۵) خروجی (5 > 3) and (2 > 4) چیست؟

💡 عملگر and فقط وقتی True می‌دهد که هر دو شرط درست باشند. 2 > 4 غلط است، پس نتیجه کلی False می‌شود.

۶) کدام عملگر در پایتون، مقدار متغیر را به‌روزرسانی می‌کند؟

💡 += یک عملگر انتساب ترکیبی است: x += 5 معادل x = x + 5. بقیه گزینه‌ها عملگرهای مقایسه‌ای هستند.

🏗️ پروژه عملی فصل

پروژه: «ماشین‌حساب حقوق ماهانه» — برنامه‌ای که حقوق پایه، اضافه‌کاری و کسورات را از کاربر می‌گیرد و حقوق نهایی را محاسبه می‌کند.

نیازمندی‌ها:

  • فایل در پوشه‌ی پروژه به نام salary.py ذخیره شده باشد.
  • از کاربر این اطلاعات گرفته شود:
    • حقوق پایه (به تومان)
    • ساعت اضافه‌کاری در ماه
    • نرخ هر ساعت اضافه‌کاری (معمولاً ۱.۴ برابر نرخ عادی — اما اینجا عدد مستقیم می‌گیریم)
    • درصد بیمه (معمولاً ۷٪)
  • محاسبات:
    • مبلغ اضافه‌کاری = ساعت × نرخ
    • حقوق ناخالص = پایه + اضافه‌کاری
    • مبلغ بیمه = حقوق ناخالص × (درصد ÷ ۱۰۰)
    • حقوق خالص = ناخالص − بیمه
  • بررسی‌ها:
    • آیا حقوق خالص بیشتر از ۲۰ میلیون است؟ (is_high_salary)
    • آیا ساعت اضافه‌کاری بین ۱۰ و ۳۰ ساعت است؟ (is_normal_overtime)
    • آیا هم حقوق پایه بالا است و هم اضافه‌کاری زیاد؟ (is_deserving_bonus)
  • خروجی نهایی در قالب یک فاکتور با خط‌های جداکننده.
  • حداقل از ۵ عملگر مختلف در برنامه استفاده شده باشد.

💡 چالش اختیاری بعد از اینکه برنامه کار کرد، سعی کنید یک «پاداش» هم اضافه کنید. مثلاً اگر هم حقوق بالا باشد و هم اضافه‌کاری معمولی، ۵٪ حقوق خالص به‌عنوان پاداش در نظر بگیرید. این کار باعث می‌شود هم از عملگر منطقی and استفاده کنید، هم از عملگر انتساب ترکیبی +=.
بخش ۱۳

🎯 جمع‌بندی و دستاوردها

در این فصل یاد گرفتید:

  • عملگر و عملوند چیست و چطور یک عبارت می‌سازند.
  • هفت عملگر حسابی: +، -، *، /، //، %، **.
  • تفاوت / (همیشه اعشاری) با // (همیشه صحیح).
  • کاربرد % برای تشخیص زوج/فرد و بخش‌پذیری.
  • شش عملگر مقایسه‌ای: ==، !=، >، <، >=، <=.
  • سه عملگر منطقی: and، or، not.
  • عملگرهای انتساب ترکیبی: +=، -=، *=، و... .
  • اولویت عملگرها و چطور با پرانتز آن را کنترل کنیم.
💡 ✨ یک‌جمله‌ای که باید یادتان بماند «عملگرها ابزار کار با مقادیرند. اگر اولویت‌شان را بدانید و پرانتز را جدی بگیرید، کدتان همان چیزی می‌شود که در ذهنتان بود.»
بخش ۱۴

❓ سوالات متداول و گام بعدی

چرا پایتون از and/or استفاده می‌کند و نه &&/||؟

چون فلسفه‌ی پایتون این است که کد مثل انگلیسی خوانده شود. if age > 18 and has_id راحت‌تر از if age > 18 && has_id خوانده می‌شود. زبان‌هایی مثل C و JavaScript از علامت استفاده می‌کنند، اما پایتون از کلمه — که خواناتر است.

آیا همیشه باید پرانتز بگذارم که مطمئن باشم؟

در موارد ساده نیازی نیست، اما وقتی شک دارید یا عبارت پیچیده می‌شود، پرانتز بگذارید. حرفه‌ای‌ها به‌جای اینکه روی حفظ کردن اولویت‌ها تکیه کنند، از پرانتز برای وضوح استفاده می‌کنند. پرانتز نه اجرا را کند می‌کند و نه خطا می‌دهد.

چرا 2 ** 3 ** 2 می‌شود ۵۱۲، نه ۶۴؟

چون توان در پایتون از راست به چپ محاسبه می‌شود. یعنی اول 3 ** 2 = 9، بعد 2 ** 9 = 512. اگر می‌خواستید (2 ** 3) ** 2 = 64 بگیرید، باید پرانتز بگذارید. این یکی از استثناهای اولویت در پایتون است.

آیا مقایسه‌ها را می‌توان زنجیره‌ای نوشت؟

بله! پایتون یک ویژگی زیبا دارد: می‌توانید بنویسید 1 < x < 10 که معادل 1 < x and x < 10 است. اما فعلاً نیازی نیست از این استفاده کنید؛ در فصل‌های بعدی می‌بینید.

عملگرهای بیتی مثل & و | و ^ را کی یاد می‌گیریم؟

در این دوره‌ی مقدماتی، عملگرهای بیتی نیاز نمی‌شود. اگر بعداً در حوزه‌های خاصی مثل رمزنگاری، فشرده‌سازی یا برنامه‌نویسی سطح پایین کار کردید، آن‌ها را جداگانه یاد می‌گیرید. الان تمرکزمان روی چیزهایی است که هر روز به‌کار می‌آیند.

📌 🧭 گام بعدی در فصل ۵ با شرط و تصمیم‌گیری آشنا می‌شوید: if، elif، else. این فصل، دقیقاً روی همان عملگرهای مقایسه‌ای و منطقی که این فصل یاد گرفتید بنا می‌شود. حالا که بلدید شرط بسازید، یاد می‌گیرید برنامه بر اساس شرط‌ها تصمیم بگیرد.
