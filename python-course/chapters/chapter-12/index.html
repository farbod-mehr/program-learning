🔭 چشم‌انداز فصل: اهداف و جایگاه

تا اینجا هر برنامه‌ای که نوشتیم، در یک فایل بود. این برای شروع خوب است، اما وقتی برنامه بزرگ می‌شود، یک فایل ۵۰۰ خطی تبدیل به کابوس می‌شود: پیدا کردن یه تابع سخت است، ویرایش خطرناک است، و تست کردن بخش‌های مختلف دشوار.

راه‌حل حرفه‌ای‌ها، ماژول است. یک ماژول، همان یک فایل .py است که توابع و کلاس‌های مرتبط با یک موضوع خاص را در خود دارد. شما می‌توانید کدتان را به چند ماژول تقسیم کنید و از هر کدام در جای مناسب استفاده کنید — مثل قطعه‌های لِگو که می‌توانید هر طور که می‌خواهید به هم وصل کنید.

علاوه بر این، پایتون صدها ماژول آماده دارد که کارهای معمول را برایتان انجام می‌دهند: کار با ریاضی (math)، تولید اعداد تصادفی (random)، کار با تاریخ (datetime)، و... در این فصل یاد می‌گیرید چطور از این‌ها استفاده کنید و چطور ماژول خودتان بسازید.

در پایان این فصل، شما می‌توانید:

  • ماژول بسازید و آن را در فایل دیگری import کنید.
  • از ماژول‌های استاندارد پایتون مثل math، random و datetime استفاده کنید.
  • الگوی if __name__ == "__main__": را بفهمید و درست به‌کار ببرید.
  • بسته (package) بسازید — مجموعه‌ای از ماژول‌های مرتبط.
  • با pip کتابخانه‌های بیرونی نصب کنید و از آن‌ها استفاده کنید.
  • خطاهای رایج import را تشخیص دهید و رفع کنید.
📌 نکته مهم از این فصل به بعد، پروژه‌های شما چند-فایلی می‌شوند. این یکی از نقاط عطف مسیر یادگیری شماست: از «نوشتن اسکریپت» به «ساخت پروژه» عبور می‌کنید.

🤔 سوالات محرک ذهنی

قبل از خواندن آموزش، چند لحظه به این سوال‌ها فکر کنید:

🤔 چرا نمی‌توانم همه چیز را در یک فایل بنویسم؟

فنی می‌توانید، اما در عمل به مشکل می‌خورید. تصور کنید یک آشپز همه ابزار و مواد را روی یک میز بزرگ بچیند — پیدا کردن چاقو بین همه چیز سخت می‌شود. اما اگر چاقوها در یک کشو، بشقاب‌ها در کابینت دیگری و ادویه‌ها در قفسه جدا باشند، همه چیز سریع پیدا می‌شود. ماژول‌ها همین کار را با کد می‌کنند. تازه، اگر فایلی ۵۰۰ خطی داشته باشید و ۵ نفر روی پروژه کار کنند، هر کس باید همیشه کل فایل را کپی کند و ویرایش‌ها با هم تداخل پیدا می‌کنند.

🤔 چرا بعضی ماژول‌ها را باید import کنیم و بعضی‌ها را نه؟

پایتون برای اینکه سبک بماند، همه‌ی ماژول‌ها را به‌طور پیش‌فرض بارگذاری نمی‌کند. اگر همه‌ی ماژول‌های پایتون (که الان چند صدتاست) همیشه لود می‌شدند، هر برنامه‌ی ساده‌ای چند ثانیه طول می‌کشید تا شروع شود. به‌جای این، فقط وقتی که واقعاً به یک ماژول نیاز دارید، با import صدایش می‌زنید. تازه، بعضی از این ماژول‌ها هزاران خط کد اضافه می‌کنند که اصلاً به کار شما نمی‌آید.

🤔 تفاوت import math و from math import pi چیست؟

هر دو کار می‌کنند، اما روش دسترسی بعدی فرق دارد. با import math، همه‌ی چیزهای math در دسترس شماست، ولی باید با پیشوند صدایشان بزنید: math.pi، math.sqrt(4). با from math import pi، فقط pi را آوردید و مستقیم استفاده می‌کنید: pi. روش اول تمیزتر و خواناتر است (شما همیشه می‌دانید این تابع از کجا آمده)، اما روش دوم کد کوتاه‌تری می‌دهد.

🧰 آماده‌سازی و پیش‌نیازها

این فصل روی یازده فصل قبل بنا شده. مطمئن شوید این‌ها را انجام داده‌اید:

  • پایتون نصب است و python --version کار می‌کند.
  • پوشه‌ی پروژه را دارید (مثلاً py-learn).
  • با توابع (def، return، پارامتر) کاملاً راحت هستید.
  • با لیست، دیکشنری، set و comprehension کار کرده‌اید.
  • می‌توانید فایل بسازید، ذخیره کنید و از ترمینال اجرا کنید.
💡 نکته طلایی در این فصل، برای اولین بار پروژه‌ای با چند فایل می‌سازید. حتماً یک پوشه‌ی جدید به نام my_modules در پوشه‌ی py-learn بسازید و همه‌ی فایل‌های این فصل را آنجا نگه دارید.

📖 آموزش گام‌به‌گام: ماژول و بسته

۱) ماژول چیست؟ — یک فایل .py

ساده‌ترین تعریف: هر فایل پایتون با پسوند .py یک ماژول است. همین! اگر شما فایلی به نام utils.py بسازید، آن یک ماژول به نام utils است که می‌توانید از فایل‌های دیگر به آن دسترسی داشته باشید.

در واقع، شما از فصل‌های قبل با ماژول کار کرده‌اید — بدون اینکه بدانید. وقتی می‌نویسید import math، در حال import کردن ماژول math هستید. حالا وقتش است که خودتان هم ماژول بسازید.

۲) استفاده از ماژول‌های آماده — import

پایتون صدها ماژول آماده دارد. برای استفاده از هر کدام، فقط کافی است با import صدایش بزنید:

first_import.pyPython
import math

print(math.pi)              # 3.141592653589793
print(math.sqrt(16))        # 4.0
print(math.floor(3.7))      # 3
print(math.ceil(3.2))       # 4
print(math.pow(2, 10))      # 1024.0

نکته: وقتی با import math وارد می‌کنید، همیشه باید با پیشوند math. صدایش بزنید. این یک مزیت است — چون وقتی کد شما ۵۰۰ خطی شود و از پنج تا ماژول استفاده کنید، همیشه می‌دانید sqrt از کدام ماژول آمده.

۳) نام مستعار — as

گاهی اسم ماژول طولانی است یا با چیز دیگری تداخل دارد. می‌توانید با as یک نام کوتاه برایش انتخاب کنید:

alias.pyPython
import math as m
import random as rnd

print(m.sqrt(25))           # 5.0
print(rnd.randint(1, 6))    # یک عدد تصادفی بین 1 و 6

در جامعه‌ی پایتون چند مستعار رایج است:

  • import numpy as np
  • import pandas as pd
  • import matplotlib.pyplot as plt

این‌ها استانداردند — اگر در پروژه‌ای ببینید کسی numpy را با اسم دیگری import کرده، تعجب کنید!

۴) وارد کردن بخش مشخص — from import

گاهی فقط یک تابع خاص از یک ماژول را می‌خواهید:

from_import.pyPython
from math import pi, sqrt

print(pi)          # 3.141592653589793 (بدون math.)
print(sqrt(16))    # 4.0

# می‌توانید نام مستعار هم بدهید:
from math import sqrt as square_root
print(square_root(25))    # 5.0

کدام روش بهتر است؟

  • import math — خواناتر، پیشنهادشده برای اکثر موارد.
  • from math import pi — کوتاه‌تر، مفید وقتی فقط یکی دو مورد لازم دارید.
⚠️ هشدار از from math import * استفاده نکنید! این کار همه‌ی نام‌های ماژول را به برنامه‌ی شما وارد می‌کند و ممکن است با نام‌های خودتان تداخل داشته باشد. علاوه بر این، معلوم نمی‌شود هر تابع از کجا آمده.

۵) چند ماژول پرکاربرد پایتون

پایتون یک کتابخانه‌ی استاندارد عظیم دارد — ماژول‌هایی که همراه پایتون نصب می‌شوند و نیازی به pip ندارند. اینجا چند تا از پرکاربردترین‌ها را می‌بینید:

الف) math — توابع ریاضی

math_demo.pyPython
import math

# ثابت‌ها
print(math.pi)              # 3.141592653589793
print(math.e)               # 2.718281828459045

# توابع
print(math.sqrt(144))       # 12.0
print(math.factorial(5))    # 120
print(math.gcd(24, 36))     # 12 (بزرگ‌ترین مقسوم‌علیه مشترک)
print(math.sin(math.pi/2))  # 1.0
print(math.log(100, 10))    # 2.0

ب) random — تولید اعداد تصادفی

random_demo.pyPython
import random

# عدد تصادفی اعشاری بین 0 و 1
print(random.random())

# عدد صحیح تصادفی بین a و b (شامل هر دو)
print(random.randint(1, 10))     # مثلاً 7

# انتخاب تصادفی از لیست
fruits = ["سیب", "موز", "پرتقال", "انگور"]
print(random.choice(fruits))

# انتخاب چند مورد بدون تکرار
print(random.sample(fruits, 2))  # مثلاً ['موز', 'انگور']

# به‌هم زدن ترتیب لیست
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(cards)
💡 کاربرد واقعی random در بازی‌ها، شبیه‌سازی‌ها، تست‌های تصادفی و هر جایی که به انتخاب تصادفی نیاز دارید، استفاده می‌شود. در پروژه‌ی این فصل، از آن برای بازی حدس عدد استفاده می‌کنیم.

ج) datetime — کار با تاریخ و زمان

datetime_demo.pyPython
from datetime import datetime, date, timedelta

# تاریخ و زمان الان
now = datetime.now()
print(now)                       # 2024-XX-XX XX:XX:XX.XXXXX
print(now.year)                  # 2024
print(now.month)                 # 1 تا 12
print(now.day)                   # 1 تا 31
print(now.hour, now.minute)      # ساعت و دقیقه

# قالب‌بندی سفارشی
print(now.strftime("%Y/%m/%d"))  # 2024/01/15
print(now.strftime("%H:%M"))     # 14:30

# امروز (فقط تاریخ)
print(date.today())              # 2024-01-15

# محاسبه‌ی تاریخ گذشته یا آینده
tomorrow = date.today() + timedelta(days=1)
print(tomorrow)                  # 2024-01-16

last_week = date.today() - timedelta(days=7)
print(last_week)                 # 2024-01-08

۶) ساخت ماژول خودمان

حالا وقتش است که خودتان ماژول بسازید. کافی است یک فایل .py بسازید. بیایید یک ماژول ریاضی ساده بسازیم:

my_math.pyPython
"""توابع ریاضی سفارشی من."""

PI = 3.141592653589793


def add(a, b):
    """جمع دو عدد."""
    return a + b


def subtract(a, b):
    """تفریق دو عدد."""
    return a - b


def multiply(a, b):
    """ضرب دو عدد."""
    return a * b


def divide(a, b):
    """تقسیم دو عدد."""
    if b == 0:
        return None
    return a / b


def circle_area(radius):
    """مساحت دایره."""
    return PI * radius ** 2

حالا در همان پوشه، یک فایل دیگر بسازید که از این ماژول استفاده کند:

use_my_math.pyPython
"""استفاده از ماژول my_math."""

import my_math


print(my_math.add(3, 4))               # 7
print(my_math.multiply(5, 6))          # 30
print(my_math.circle_area(2))          # 12.566370614359172
print(my_math.PI)                      # 3.141592653589793


# یا از روش from استفاده کنیم
from my_math import add, PI

print(add(10, 20))                     # 30
print(PI)                              # 3.141592653589793
⚠️ نکته مهم برای اینکه import کار کند، هر دو فایل باید در یک پوشه باشند. اگر در پوشه‌های مختلف باشند، پایتون ماژول را پیدا نمی‌کند و خطای ModuleNotFoundError می‌گیرید.

۷) الگوی if __name__ == "__main__":

حالا وقت توضیح دادن آن الگوی معروف است که از فصل ۱ در مثال‌ها می‌دیدید:

چه زمانی اجرا می‌شود؟Python
if __name__ == "__main__":
    # کدهایی که فقط وقتی فایل مستقیماً اجرا شود، اجرا می‌شوند
    main()

توضیح ساده: هر فایل پایتون یک متغیر مخفی به نام __name__ دارد. این متغیر بسته به نحوه‌ی اجرای فایل، یکی از دو مقدار را می‌گیرد:

  • اگر فایل را مستقیماً با python my_file.py اجرا کنید، __name__ می‌شود "__main__".
  • اگر فایل را از فایل دیگری import کنید، __name__ می‌شود اسم فایل، مثلاً "my_file".

حالا چرا این مهم است؟ بیایید یک مثال واقعی ببینیم:

greetings.pyPython
"""ماژول سلام و خداحافظی."""


def say_hello(name):
    """به شخص سلام می‌کند."""
    return f"سلام {name}!"


def say_goodbye(name):
    """به شخص خداحافظی می‌کند."""
    return f"خداحافظ {name}!"


# اگر این فایل مستقیماً اجرا شود، این کدها اجرا می‌شوند
if __name__ == "__main__":
    print("حالت تست:")
    print(say_hello("علی"))
    print(say_goodbye("رضا"))

الان دو حالت را در نظر بگیرید:

حالت اول: فایل را مستقیماً اجرا می‌کنید:

اجرای مستقیمBash
python greetings.py

# خروجی:
# حالت تست:
# سلام علی!
# خداحافظ رضا!

حالت دوم: فایل را از فایل دیگری import می‌کنید:

main.pyPython
import greetings

print(greetings.say_hello("سارا"))
# خروجی: سلام سارا!
# (توجه: "حالت تست:" چاپ نمی‌شود!)

پس این الگو به شما اجازه می‌دهد که:

  • فایل را هم به‌عنوان یک ماژول قابل import استفاده کنید.
  • هم مستقل قابل اجرا باشد، ولی کدهای تستی فقط در حالت اجرای مستقیم اجرا شوند.
💡 عادت حرفه‌ای از این به بعد، همیشه در فایل‌هایتان این ساختار را رعایت کنید:
  1. بالای فایل: توابع و کلاس‌ها.
  2. پایین فایل: تابع main() که منطق اصلی در آن است.
  3. انتها: if __name__ == "__main__": main().

۸) بسته (Package) — پوشه‌ای از ماژول‌ها

وقتی پروژه بزرگ‌تر می‌شود، حتی چند ماژول کافی نیست. باید آن‌ها را در پوشه‌ها سازماندهی کنید. به این پوشه‌ها می‌گویند بسته (package).

ساختار یک بسته‌ی ساده:

ساختار بستهText
my_package/
├── __init__.py
├── math_helpers.py
├── string_helpers.py
└── date_helpers.py

نکته‌ی کلیدی: پوشه‌ای که فایل __init__.py دارد، یک بسته محسوب می‌شود. این فایل می‌تواند خالی باشد یا کد داشته باشد — اما وجودش نشان می‌دهد که این پوشه، یک بسته‌ی پایتون است.

نمونه‌ی __init__.py:

my_package/__init__.pyPython
"""بسته‌ی توابع کمکی من.

این فایل می‌تواند خالی باشد، ولی ما اینجا
ماژول‌های پرکاربرد را re-export می‌کنیم تا
کاربران بسته راحت‌تر بتوانند از آن‌ها استفاده کنند.
"""

from .math_helpers import add, multiply
from .string_helpers import to_upper, count_words

__all__ = ["add", "multiply", "to_upper", "count_words"]

حالا از بسته استفاده می‌کنید:

use_package.pyPython
from my_package import add, multiply

print(add(3, 4))         # 7
print(multiply(5, 6))    # 30


# یا با import کامل:
import my_package

print(my_package.add(10, 20))
📌 بسته چیست در یک جمله؟ بسته = پوشه + فایل __init__.py. تمام. بقیه‌ی پیچیدگی‌ها را بعداً یاد می‌گیرید.

def is_even(number):
    """چک می‌کند عدد زوج است یا نه."""
    return number % 2 == 0


def is_prime(number):
    """چک می‌کند عدد اول است یا نه."""
    if number < 2:
        return False
    for i in range(2, int(number ** 0.5) + 1):
        if number % i == 0:
            return False
    return True


def factorial(n):
    """فاکتوریل یک عدد."""
    if n < 0:
        return None
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

"""بازی حدس عدد — با ماژول random."""

import random


def get_guess(attempt, max_attempts):
    """یک حدس معتبر از کاربر می‌گیرد."""
    while True:
        text = input(f"تلاش {attempt}/{max_attempts} — حدس بزن: ").strip()
        try:
            guess = int(text)
            if 1 <= guess <= 100:
                return guess
            print("⚠️ عدد باید بین 1 و 100 باشد.")
        except ValueError:
            print("⚠️ لطفاً یک عدد معتبر وارد کن.")


def play():
    """یک دور بازی."""
    secret = random.randint(1, 100)
    max_attempts = 7

    print("=" * 45)
    print("      🎯 بازی حدس عدد")
    print("=" * 45)
    print(f"عدد من بین 1 و 100 است. {max_attempts} تلاش داری.")
    print()

    for attempt in range(1, max_attempts + 1):
        guess = get_guess(attempt, max_attempts)

        if guess == secret:
            print(f"\n🎉 آفرین! در {attempt} تلاش درست حدس زدی!")
            return True
        elif guess > secret:
            print("❄️  عدد من کوچک‌تر است.")
        else:
            print("🔥 عدد من بزرگ‌تر است.")

    print(f"\n😔 باختی! عدد درست {secret} بود.")
    return False


def main():
    while True:
        won = play()
        again = input("\nمی‌خواهی دوباره بازی کنی؟ (بله/خیر): ").strip()
        if again != "بله":
            print("👋 خداحافظ!")
            break


if __name__ == "__main__":
    main()

  5. در همه‌ی فایل‌ها docstring بگذارید.
  6. تابع main() در فایل اصلی باید یک منوی تعاملی داشته باشد.

🐞 خطاهای رایج و رفع آن‌ها

این خطاها را در تمرین‌ها زیاد می‌بینید:

❌ ModuleNotFoundError: No module named 'X'

معنی: پایتون ماژول X را پیدا نمی‌کند.

علت: معمولاً یکی از این‌ها: (۱) فایل در پوشه‌ی اشتباه است؛ (۲) نام فایل را اشتباه تایپ کرده‌اید؛ (۳) فایل با اسم کلیدی متناقض است.

راه‌حل: (۱) مطمئن شوید فایل در همان پوشه است یا در sys.path؛ (۲) اسم فایل را با import چک کنید؛ (۳) نام فایل‌تان را با اسم‌های رزرو شده پایتون (مثل math.py، random.py) یکی نکنید.

❌ ImportError: cannot import name 'X' from 'Y'

معنی: ماژول Y را پیدا کرد، ولی تابع یا متغیر X را در آن ندارد.

علت: نام تابع/متغیر را اشتباه نوشته‌اید، یا آن آیتم در ماژول وجود ندارد.

راه‌حل: با dir(module_name) ببینید چه چیزهایی در ماژول هست. املای اسم را چک کنید (پایتون به بزرگی و کوچکی حروف حساس است).

❌ کد ماژول اجرا می‌شود، ولی نمی‌خواستیم!

معنی: وقتی یک ماژول را import می‌کنید، بعضی کدهای درونش اجرا می‌شوند.

علت: کدهای اجرایی (مثل print) را بیرون از بلوک if __name__ == "__main__": گذاشته‌اید.

راه‌حل: همه‌ی کدهای اجرایی را داخل این بلوک بگذارید. فقط تعاریف توابع و کلاس‌ها بیرون بماند.

❌ نام فایل با ماژول استاندارد تناقض دارد

معنی: پایتون به‌جای ماژول استاندارد، فایل خودتان را import می‌کند.

علت: فایلی مثل math.py یا random.py ساخته‌اید که با ماژول استاندارد همنام است.

راه‌حل: فایل را با نام دیگری ذخیره کنید. از اسم‌های math.py، random.py، test.py، json.py و هر اسم ماژول استانداردی پرهیز کنید.

❌ خطای ModuleNotFoundError برای پکیج‌های pip

معنی: پکیج نصب‌شده در محیط مجازی فعلی نیست.

علت: پکیج را در محیط دیگری (یا محیط سراسری) نصب کرده‌اید.

راه‌حل: مطمئن شوید محیط مجازی فعال است (پیشوند (venv) را در ترمینال ببینید). سپس pip install package_name را در همان محیط اجرا کنید.

❌ File name shadows module name (نام فایل با بسته تناقض دارد)

معنی: فایل اصلی شما با نام پکیجی که import می‌کنید، تناقض دارد.

علت: مثلاً فایل requests.py ساخته‌اید و می‌خواهید import requests (پکیج pip) کنید.

راه‌حل: نام فایل خود را عوض کنید. مثلاً my_requests.py یا test_requests.py.

❌ فراموشی __init__.py در بسته

معنی: پوشه‌ی بسته، به‌عنوان بسته شناخته نمی‌شود.

علت: فایل __init__.py را در پوشه نگذاشته‌اید.

راه‌حل: یک فایل خالی __init__.py (حتی بدون محتوا) در پوشه‌ی بسته بسازید.

🏋️ تمرین توسعه — ماژول محاسبات

یک ماژول calculations.py بسازید که این توابع را داشته باشد:

  • circle_area(r) — مساحت دایره
  • rectangle_area(w, h) — مساحت مستطیل
  • triangle_area(b, h) — مساحت مثلث

سپس در فایل calculator.py از این ماژول استفاده کنید و یک منوی تعاملی بسازید.

پاسخ:

calculations.pyPython
"""محاسبات هندسی."""

import math


def circle_area(r):
    """مساحت دایره با شعاع r."""
    return math.pi * r ** 2


def rectangle_area(w, h):
    """مساحت مستطیل."""
    return w * h


def triangle_area(base, height):
    """مساحت مثلث."""
    return 0.5 * base * height


if __name__ == "__main__":
    print(circle_area(5))          # 78.539...
    print(rectangle_area(4, 5))    # 20
    print(triangle_area(6, 3))     # 9.0

"""ماشین‌حساب مساحت."""

from calculations import circle_area, rectangle_area, triangle_area


def main():

        print("\n" + "=" * 40)
        print("     ماشین‌حساب مساحت")
        print("=" * 40)
        print("  1. دایره")

            if choice == "1":

            elif choice == "2":
                w = float(input("عرض: "))
                h = float(input("ارتفاع: "))

            elif choice == "3":
                b = float(input("قاعده: "))

if __name__ == "__main__":
    main()

📝 آزمون تعاملی فصل

پرسش‌های چهارگزینه‌ای زیر را پاسخ دهید؛ بلافاصله بعد از انتخاب، پاسخ درست و توضیحش را می‌بینید. حد نصاب قبولی ۶۰٪ است و بهترین نمره‌تان ذخیره می‌شود.

۱) ماژول در پایتون چیست؟

💡 هر فایل پایتون با پسوند .py یک ماژول است. وقتی می‌خواهید از کد آن در فایل دیگری استفاده کنید، آن را با import وارد می‌کنید.

۲) برای استفاده از تابع sqrt از ماژول math، کدام روش مستقیم است؟

💡 با import math باید با پیشوند صدا زد: math.sqrt(16). اگر فقط sqrt را می‌خواهید، از from math import sqrt استفاده کنید و بعد sqrt(16).

۳) فایل __init__.py در یک بسته چه کاری انجام می‌دهد؟

💡 وجود __init__.py در یک پوشه، به پایتون می‌گوید آن پوشه یک بسته است که می‌توان ماژول‌هایش را import کرد. بدون این فایل، پایتون پوشه را به‌عنوان بسته نمی‌شناسد.

۴) الگوی if __name__ == "__main__": چه فایده‌ای دارد؟

💡 این الگو باعث می‌شود هم بتوانید ماژول را import کنید (و کدهای تستی اجرا نشوند)، هم بتوانید همان فایل را مستقیماً اجرا کنید. یکی از بهترین عادت‌های حرفه‌ای در پایتون.

۵) برای نصب یک کتابخانه‌ی بیرونی، از کدام دستور استفاده می‌کنیم؟

💡 pip ابزار رسمی نصب کتابخانه‌های پایتون است. با pip install کتابخانه نصب می‌شود، با pip list لیستش را می‌بینید، و با pip uninstall حذفش می‌کنید.

۶) تفاوت import math و from math import pi چیست؟

💡 import math همه‌چیز را زیر نام math نگه می‌دارد (باید math.pi بنویسید)، اما from math import pi فقط pi را مستقیم می‌آورد (باید pi بنویسید). هرکدام کاربرد خودش را دارد.

🎯 جمع‌بندی و دستاوردها

در این فصل یاد گرفتید:

  • ماژول چیست — هر فایل .py یک ماژول است.
  • import module برای دسترسی با پیشوند: module.function().
  • from module import name برای دسترسی مستقیم: name().
  • import module as m برای مستعار.
  • ساخت ماژول خودتان: کافی است یک فایل .py بسازید.
  • الگوی if __name__ == "__main__": و چرا مهم است.
  • بسته (package) — پوشه‌ای با فایل __init__.py که چند ماژول دارد.
  • چند ماژول استاندارد کاربردی: math، random، datetime، os.
  • نصب کتابخانه‌های بیرونی با pip install package_name.
  • محیط مجازی و اهمیت آن برای جدا کردن وابستگی‌های پروژه‌ها.
💡 ✨ یک‌جمله‌ای که باید یادتان بماند «ماژول‌ها به شما اجازه می‌دهند کد را به قطعه‌های کوچک و قابل استفاده تقسیم کنید. از این فصل به بعد، پروژه‌های شما چند-فایلی می‌شوند — و اینجاست که واقعاً حس یک برنامه‌نویس حرفه‌ای را خواهید داشت.»

❓ سوالات متداول و گام بعدی

آیا برای هر تابع کوچک باید ماژول جدا بسازم؟

خیر. ماژول برای گروه‌بندی موضوعی استفاده می‌شود، نه برای هر تابع. اگر ۵ تابع مرتبط با ریاضی دارید، همه را در یک ماژول math_helpers.py بگذارید. قاعده‌ی خوب: هر ماژول حدوداً یک موضوع مشخص داشته باشد.

تفاوت کتابخانه و ماژول و بسته چیست؟

در گفتگوی روزمره، این سه تقریباً یک معنی دارند. اما فنی:
- ماژول: یک فایل .py.
- بسته: پوشه‌ای از ماژول‌ها با __init__.py.
- کتابخانه: مجموعه‌ای از بسته‌ها (معمولاً قابل نصب با pip).
در مکالمه، همه را «کتابخانه» می‌گویند و مشکلی پیش نمی‌آید.

چرا بعضی importها باید با پیشوند باشند و بعضی نه؟

بستگی به نحوه‌ی import دارد. import math → پیشوند اجباری: math.pi. from math import pi → بدون پیشوند: pi. هر کدام کاربرد خودش را دارد. روش اول خواناتر است (مشخص است که pi از کجاست)، روش دوم کوتاه‌تر است.

آیا می‌توانم پکیج را نصب کنم اما از آن استفاده نکنم؟

بله، ولی بیهوده فضا اشغال می‌کند. بهتر است پروژه‌هایتان را با requirements.txt نگه دارید و هر بار که لازم شد، با pip install -r requirements.txt نصب کنید. با pip freeze > requirements.txt فایل وابستگی‌ها را می‌سازید.

چرا نمی‌توانم فایلم را با نام math.py ذخیره کنم؟

چون پایتون وقتی import math را می‌بیند، ابتدا در پوشه‌ی جاری دنبال فایل math.py می‌گردد. اگر آن را با نام خودتان پیدا کند، همان را import می‌کند، نه ماژول استاندارد. نتیجه: کد شما به مشکل می‌خورد. همین اتفاق برای random.py، test.py، json.py، string.py و خیلی اسم‌های دیگر می‌افتد.
