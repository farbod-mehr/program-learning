🔭 چشم‌انداز فصل: اهداف و جایگاه

تا اینجا با حلقه‌ها، لیست‌ها، دیکشنری‌ها و توابع کار کرده‌اید. مثلاً برای ساخت یک لیست از مربع‌های اعداد، احتمالاً کدی مثل این نوشته‌اید:

روش سنتیPython
squares = []
for x in range(10):
    squares.append(x ** 2)

این کد درست است، اما خیلی طولانی. پایتون یک روش کوتاه‌تر و حرفه‌ای‌تر دارد که در همین فصل یاد می‌گیرید:

با comprehension — خیلی تمیزترPython
squares = [x ** 2 for x in range(10)]

این یکی از زیبایی‌های پایتون است که کد شما را کوتاه‌تر، سریع‌تر و خواناتر می‌کند. علاوه بر این، در این فصل با دو تابع بسیار مفید برای پیمایش پیشرفته (enumerate و zip) و همچنین مفهوم generator (مولد) آشنا می‌شوید.

در پایان این فصل، شما می‌توانید:

  • با list comprehension لیست بسازید، در یک خط.
  • با dict comprehension دیکشنری بسازید.
  • شرط داخل comprehension بگذارید و فیلتر کنید.
  • با enumerate روی لیست با ایندکس حرکت کنید.
  • با zip دو لیست را با هم پیمایش کنید.
  • با generator expression داده را به‌صورت تنبل (lazy) پردازش کنید.
  • تفاوت iterable و iterator را بفهمید.
📌 نکته مهم این فصل، شما را از یک برنامه‌نویس «کارآموز» به یک برنامه‌نویس «پایتونیک» تبدیل می‌کند. در مصاحبه‌های فنی، استفاده‌ی درست از comprehension یکی از نشانه‌های برنامه‌نویس خبره است.

🤔 سوالات محرک ذهنی

قبل از خواندن آموزش، چند لحظه به این سوال‌ها فکر کنید:

🤔 آیا کوتاه‌تر همیشه بهتر است؟

خیر! کوتاه‌تر بودن کد، همیشه به معنی بهتر بودن نیست. اگر کد کوتاه‌تر، خوانا نباشد یا منطقش پیچیده باشد، نوشتنش به شکل سنتی بهتر است. قاعده‌ی طلایی: comprehension را فقط وقتی استفاده کنید که منطق ساده و در یک خط جا شود. اگر نیاز دارید شرط‌های زیادی چک کنید یا کارهای پیچیده انجام دهید، از حلقه‌ی معمولی استفاده کنید.

🤔 generator و لیست چه تفاوتی دارند؟ مگر هر دو لیست اعداد تولید نمی‌کنند؟

تفاوت کلیدی این است: یک لیست همه‌ی اعضا را همان لحظه در حافظه ذخیره می‌کند. اما یک generator اعضا را یکی‌یکی و در لحظه‌ی نیاز تولید می‌کند. اگر بخواهید ۱ میلیون عدد را تولید کنید، لیست تمام آن‌ها را در حافظه می‌ریزد (مثلاً ۸ مگابایت)، اما generator فقط یک عدد در هر لحظه دارد (چند بایت). برای داده‌های کوچک تفاوت مهم نیست، اما برای داده‌های بزرگ، generator ناجی است.

🤔 enumerate چه کار می‌کند که range نمی‌کند؟

فرض کنید می‌خواهید روی لیستی از اسم‌ها حرکت کنید و همزمان ایندکس و مقدار را داشته باشید. با range(len(names)) باید دستی به names[i] دسترسی پیدا کنید. اما enumerate این کار را در یک قدم انجام می‌دهد: for i, name in enumerate(names): — هم ایندکس، هم مقدار، آماده. خواناتر، کوتاه‌تر، پایتونیک‌تر.

📖 آموزش گام‌به‌گام: Comprehension و Iterator

۱) List Comprehension — ساخت لیست در یک خط

بیایید با یک مثال شروع کنیم. فرض کنید می‌خواهید لیستی از مربع اعداد ۰ تا ۹ بسازید. راه سنتی:

traditional.pyPython
squares = []
for x in range(10):
    squares.append(x ** 2)

print(squares)
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

حالا همان کار با list comprehension:

comprehension.pyPython
squares = [x ** 2 for x in range(10)]
print(squares)
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

دقیقاً همان نتیجه، ولی در یک خط. ساختار کلی list comprehension:

ساختار کلیPython
[عبارت for متغیر in iterable]

سه بخش دارد:

  • عبارت: کاری که روی هر عضو انجام می‌دهید (مثلاً x ** 2).
  • for متغیر in iterable: روی چی حلقه می‌زنید (مثلاً range(10)).
  • براکت [ ]: یعنی نتیجه یک لیست خواهد بود.

مثال‌های ساده‌ی بیشتر:

more_examples.pyPython
# مربع اعداد
squares = [x ** 2 for x in range(1, 6)]
print(squares)   # [1, 4, 9, 16, 25]

# دو برابر اعداد
doubles = [x * 2 for x in range(5)]
print(doubles)   # [0, 2, 4, 6, 8]

# تبدیل حروف به بزرگ
names = ["ali", "reza", "sara"]
upper_names = [name.upper() for name in names]
print(upper_names)   # ['ALI', 'REZA', 'SARA']

# طول هر کلمه
words = ["cat", "python", "hello"]
lengths = [len(w) for w in words]
print(lengths)   # [3, 6, 5]

۲) Comprehension با شرط — فیلتر کردن

می‌توانید یک شرط if در انتهای comprehension اضافه کنید تا فقط اعضایی که شرط را برآورده می‌کنند، در نتیجه باشند:

with_if.pyPython
# فقط اعداد زوج
evens = [x for x in range(10) if x % 2 == 0]
print(evens)   # [0, 2, 4, 6, 8]

# فقط اعداد بزرگ‌تر از 5
big = [x for x in range(10) if x > 5]
print(big)   # [6, 7, 8, 9]

# اسم‌هایی که با «س» شروع می‌شوند
names = ["سارا", "علی", "سهیل", "رضا", "سمیرا"]
s_names = [n for n in names if n.startswith("س")]
print(s_names)   # ['سارا', 'سهیل', 'سمیرا']

ساختار با شرط:

ساختار با شرطPython
[عبارت for متغیر in iterable if شرط]

یعنی: «برای هر عضو در iterable، اگر شرط برقرار بود، عبارت را در لیست بگذار».

ترکیب تبدیل و فیلتر

combined.pyPython
# مربع اعداد زوج
even_squares = [x ** 2 for x in range(10) if x % 2 == 0]
print(even_squares)
# [0, 4, 16, 36, 64]

# اسم‌های کوچک‌شده از اسم‌های بلند
words = ["Python", "is", "very", "powerful"]
long_lower = [w.lower() for w in words if len(w) > 3]
print(long_lower)
# ['python', 'very', 'powerful']

if/else داخل comprehension

همچنین می‌توانید مقدار جایگزین برای حالت non-matching هم بدهید:

if_else_comprehension.pyPython
# اعداد زوج را «زوج» و فرد را «فرد» کن
labels = ["زوج" if x % 2 == 0 else "فرد" for x in range(5)]
print(labels)
# ['زوج', 'فرد', 'زوج', 'فرد', 'زوج']

# در این حالت، شرط قبل از for می‌آید
# ساختار: [A if شرط else B for متغیر in iterable]
⚠️ دقت کنید دو نوع استفاده از if در comprehension وجود دارد:
  • فیلتر: [x for x in items if x > 5] — if بعد از for می‌آید.
  • شرط مقداری: [A if cond else B for x in items] — if قبل از for می‌آید.

۳) Dict Comprehension — ساخت دیکشنری در یک خط

همان ایده، اما برای دیکشنری. با کروشه و دو-نقطه:

dict_comp.pyPython
# عدد → مربعش
squares = {x: x ** 2 for x in range(5)}
print(squares)
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# اسم → طول
names = ["علی", "رضا", "سارا"]
name_lengths = {name: len(name) for name in names}
print(name_lengths)
# {'علی': 3, 'رضا': 3, 'سارا': 4}

# با شرط
even_squares = {x: x ** 2 for x in range(10) if x % 2 == 0}
print(even_squares)
# {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}

ساختار کلی:

ساختار dict comprehensionPython
{کلید: مقدار for متغیر in iterable}
{کلید: مقدار for متغیر in iterable if شرط}

مثال واقعی: شمارش کلمات در یک خط

در فصل ۱۰، برای شمارش کلمات از حلقه استفاده کردیم. حالا با comprehension می‌توانیم یک دیکشنری ساده بسازیم:

word_lengths.pyPython
text = "python is great and python is fun"
words = text.split()
unique_words = set(words)

# دیکشنری: هر کلمه یکتا → تعداد تکرارش
counts = {word: words.count(word) for word in unique_words}
print(counts)
# {'python': 2, 'is': 2, 'great': 1, 'and': 1, 'fun': 1}

۴) Set Comprehension — مجموعه در یک خط

برای ساختن set هم همین سینتکس کار می‌کند، فقط با کروشه‌ی بدون دو-نقطه:

set_comp.pyPython
# مربع اعداد یکتا
squares = {x ** 2 for x in range(-3, 4)}
print(squares)   # {0, 1, 4, 9}

# حروف یکتای یک متن
letters = {c for c in "hello world" if c != " "}
print(letters)   # {'h', 'e', 'l', 'o', 'w', 'r', 'd'}

توجه: چون set اعضای تکراری نمی‌پذیرد، اگر comprehension اعضای تکراری تولید کند، خودکار حذف می‌شوند.

۵) enumerate() — ایندکس و مقدار با هم

یکی از رایج‌ترین نیازها: حرکت روی یک لیست، ولی همزمان دانستن ایندکس. راه سنتی:

بدون enumeratePython
names = ["علی", "رضا", "سارا"]
for i in range(len(names)):
    print(f"{i}: {names[i]}")

با enumerate:

with_enumerate.pyPython
names = ["علی", "رضا", "سارا"]
for i, name in enumerate(names):
    print(f"{i}: {name}")

# خروجی:
# 0: علی
# 1: رضا
# 2: سارا

حتی می‌توانید شمارش را از عدد دیگری شروع کنید:

start_from_1.pyPython
names = ["علی", "رضا", "سارا"]
for i, name in enumerate(names, start=1):
    print(f"{i}. {name}")

# خروجی:
# 1. علی
# 2. رضا
# 3. سارا

ترفند مفید برای شماره‌گذاری لیست، از ۱ به‌جای ۰.

۶) zip() — حرکت روی چند لیست با هم

zip دو یا چند لیست را «به هم زیپ» می‌کند و اعضای متناظر را کنار هم می‌گذارد:

zip_demo.pyPython
names = ["علی", "رضا", "سارا"]
ages = [25, 30, 28]
cities = ["تهران", "شیراز", "اصفهان"]

for name, age, city in zip(names, ages, cities):
    print(f"{name} ({age} ساله، {city})")

# خروجی:
# علی (25 ساله، تهران)
# رضا (30 ساله، شیراز)
# سارا (28 ساله، اصفهان)

حتی می‌توانید zip را برای ساخت دیکشنری استفاده کنید:

zip_to_dict.pyPython
names = ["علی", "رضا", "سارا"]
ages = [25, 30, 28]

age_dict = dict(zip(names, ages))
print(age_dict)
# {'علی': 25, 'رضا': 30, 'سارا': 28}

این ترفند خیلی مفید است: وقتی دو لیست متناظر دارید و می‌خواهید یک دیکشنری بسازید، dict(zip(keys, values)) کوتاه‌ترین راه است.

⚠️ نکته اگر طول لیست‌ها متفاوت باشد، zip به کوتاه‌ترین لیست می‌چسبد. یعنی اگر یکی ۳ عضو و دیگری ۵ عضو داشته باشد، فقط ۳ جفت ساخته می‌شود.

۷) Generator Expression — بدون ذخیره در حافظه

حالا یک مفهوم مهم: generator expression. این خیلی شبیه list comprehension است، اما با پرانتز ( ) به‌جای براکت [ ]:

list_vs_generator.pyPython
# List comprehension — همه در حافظه
squares_list = [x ** 2 for x in range(1000000)]

# Generator expression — تنبل
squares_gen = (x ** 2 for x in range(1000000))

print(squares_list[:5])            # [0, 1, 4, 9, 16]
print(squares_gen)                 # 

# برای دیدن اعضای generator باید یکی‌یکی مصرفش کنید
for i, sq in enumerate(squares_gen):
    print(sq)
    if i >= 4:
        break
# 0
# 1
# 4
# 9
# 16

تفاوت کلیدی: لیست، همه‌ی اعضا را همان لحظه می‌سازد و در حافظه نگه می‌دارد. generator، اعضا را یکی‌یکی و در لحظه‌ی نیاز تولید می‌کند. برای داده‌های بزرگ، این تفاوت خیلی مهم است.

💡 نکته طلایی generator را نمی‌توانید دو بار مصرف کنید! اگر یک بار روی آن حلقه بزنید، تمام می‌شود و بار دوم خالی است. مثل یک بطری آب است که وقتی سرازیرش کردی، دیگر آبی در آن نیست.

استفاده از generator برای مجموع، max، min

توابع آماده‌ای مثل sum، max، min می‌توانند مستقیم روی generator کار کنند:

gen_direct.pyPython
# مجموع مربع اعداد 1 تا 100، بدون ذخیره در حافظه
total = sum(x ** 2 for x in range(1, 101))
print(total)   # 338350

# بزرگ‌ترین عدد زوج کمتر از 1000
biggest_even = max(x for x in range(1000) if x % 2 == 0)
print(biggest_even)   # 998

این الگو در پروژه‌های واقعی خیلی استفاده می‌شود چون باعث صرفه‌جویی در حافظه می‌شود.

۸) Iterable و Iterator — یک نگاه سریع

حالا که با حلقه‌ها راحت هستید، بیایید دو مفهوم زیربنایی را بفهمیم:

  • Iterable: هر چیزی که می‌توان روی آن حلقه زد. لیست، تاپل، رشته، دیکشنری، set، range، و... همه iterable هستند.
  • Iterator: شیئی که یکی‌یکی اعضا را بیرون می‌دهد. هر iterable می‌تواند یک iterator بدهد.

تفاوت را با مثال ببینیم:

iterable_iterator.pyPython
# لیست، iterable است
my_list = [1, 2, 3]

# تبدیل به iterator
it = iter(my_list)

# یکی‌یکی اعضا را بگیر
print(next(it))   # 1
print(next(it))   # 2
print(next(it))   # 3

# اگر باز هم next کنی، خطا می‌دهد:
# print(next(it))   # StopIteration

حلقه‌ی for پشت صحنه همین کار را انجام می‌دهد: اول iter() می‌سازد، بعد با next() اعضا را می‌گیرد تا به StopIteration برسد.

چرا مهم است؟ چون generator هم یک iterator است. و این توضیح می‌دهد که چرا generator یک‌بارمصرف است — چون بعد از StopIteration، دیگر چیزی برای دادن ندارد.

📌 نکته نیازی نیست همیشه با iter و next کار کنید — پایتون این را پشت صحنه انجام می‌دهد. اما دانستن این مفاهیم باعث می‌شود درک عمیق‌تری از حلقه‌ها و generator داشته باشید.

۹) تابع با yield — generator function

یک تابع معمولی با return یک بار مقدار می‌دهد. اما اگر بخواهید یک تابع بنویسید که چند مقدار یکی‌یکی تولید کند، از yield استفاده می‌کنید:

generator_function.pyPython
def countdown(n):
    """از n تا 1 می‌شمارد و یکی‌یکی تحویل می‌دهد."""
    while n > 0:
        yield n
        n -= 1

# استفاده در حلقه
for num in countdown(5):
    print(num)
# 5
# 4
# 3
# 2
# 1

تفاوت yield با return:

  • return: تابع را کاملاً تمام می‌کند و یک مقدار برمی‌گرداند.
  • yield: تابع را «معلق» می‌کند، یک مقدار بیرون می‌دهد، و اگر دوباره صدایش بزنند، از همان‌جا ادامه می‌دهد.

به این نوع تابع می‌گویند generator function. وقتی صدا زده می‌شود، یک generator برمی‌گرداند که می‌توان رویش حلقه زد.

مثال کاربردی: خواندن فایل‌های بزرگ به‌صورت تکه‌تکه

read_large_file.pyPython
def read_lines(filepath):
    """خط‌های یک فایل را یکی‌یکی تحویل می‌دهد."""
    with open(filepath, "r", encoding="utf-8") as f:
        for line in f:
            yield line.strip()

۱۰) کدام را استفاده کنیم؟ — راهنمای انتخاب

بعد از این‌همه ابزار، ممکن است سؤال کنید کدام را انتخاب کنید. اینجا یک راهنمای ساده:

  • list comprehension: برای ساخت لیست در یک خط، وقتی منطق ساده است.
  • dict comprehension: برای ساخت دیکشنری از یک iterable.
  • generator expression: وقتی داده بزرگ است یا فقط می‌خواهید یک بار روی آن حرکت کنید.
  • for معمولی: وقتی منطق پیچیده است، چند مرحله دارد، یا خوانایی بهتری می‌دهد.

قاعده‌ی طلایی: اگر comprehension را در یک نگاه می‌فهمید، استفاده کنید؛ اگر نه، به for معمولی برگردید.

def analyze_words(words):
    """گزارش کاملی از لیست کلمات تهیه می‌کند."""
    # فقط کلمات بلندتر از 3 حرف
    long_words = [w for w in words if len(w) > 3]

    # همه به حروف کوچک
    lower_words = [w.lower() for w in words]

    # کلمات یکتا
    unique_words = {w.lower() for w in words}

    # طول هر کلمه
    word_lengths = {w: len(w) for w in set(words)}

    return {
        "total": len(words),
        "long_count": len(long_words),
        "unique_count": len(unique_words),
        "long_words": long_words,
        "unique_words": unique_words,
        "word_lengths": word_lengths,
    }


def main():
    print("=" * 45)
    print("       تحلیل‌گر متن")
    print("=" * 45)

    text = input("یک متن بنویسید:\n").strip()

    if not text:

    report = analyze_words(words)

    print()
    print("-" * 45)

    print("\n  📊 طول کلمات:")
    for word, length in report["word_lengths"].items():
        print(f"      {word}: {length}")


if __name__ == "__main__":

grade_analyzer.pyPython
"""تحلیل‌گر نمرات — با comprehension در همه اشکال."""


def score_to_letter(score):
    """نمره را به برچسب حرفی تبدیل می‌کند."""
    if score >= 18:
        return "A"
    if score >= 15:
        return "B"
    if score >= 12:
        return "C"
    if score >= 10:
        return "D"
    return "F"


def show_report(scores):
    """گزارش کامل نمرات را نمایش می‌دهد."""
    print("\n" + "=" * 50)
    print("           تحلیل نمرات")
    print("=" * 50)

    # آمار پایه با generator expression
    total = sum(s for s in scores)
    avg = total / len(scores)
    maximum = max(s for s in scores)
    minimum = min(s for s in scores)

    print(f"  تعداد نمرات  : {len(scores)}")
    print(f"  میانگین      : {avg:.2f}")
    print(f"  بیشترین      : {maximum}")
    print(f"  کمترین       : {minimum}")
    print("-" * 50)

    # نمرات قبول‌شده با list comprehension
    passed = [s for s in scores if s >= 10]
    print(f"\n  ✅ قبول‌شده‌ها ({len(passed)}): {passed}")

    # نمرات به مقیاس 100
    scaled = [s * 5 for s in scores]
    print(f"\n  📈 مقیاس 100  : {scaled}")

    # گرد‌شده
    rounded = [round(s) for s in scores]
    print(f"  🔄 گرد‌شده    : {rounded}")

    # دیکشنری: نمره → برچسب
    labels = {s: score_to_letter(s) for s in scores}
    print(f"\n  🏷️  برچسب‌ها:")
    for score, label in labels.items():
        print(f"      {score} → {label}")

    # برچسب‌های یکتا با set comprehension
    unique_labels = {score_to_letter(s) for s in scores}
    print(f"\n  🎯 برچسب‌های یکتا: {sorted(unique_labels)}")

    # توزیع برچسب‌ها
    distribution = {
        label: sum(1 for s in scores if score_to_letter(s) == label)
        for label in unique_labels
    }
    print(f"\n  📊 توزیع:")
    for label in sorted(distribution.keys()):
        count = distribution[label]
        bar = "█" * count
        print(f"      {label}: {count} {bar}")


def find_ranks(scores):
    """نمرات را از بزرگ به کوچک مرتب و رتبه‌بندی می‌کند."""
    print(f"\n  🏆 رتبه‌بندی (بالاترین اول):")
    # مرتب‌سازی نزولی
    ranked = sorted(scores, reverse=True)
    for i, score in enumerate(ranked, start=1):
        print(f"      {i}. {score}")


def main():
    # نمرات نمونه
    scores = [18.5, 15.0, 19.5, 17.0, 12.5, 8.0, 10.0, 14.0, 16.5, 13.0]

    show_report(scores)
    find_ranks(scores)

    print("\n" + "=" * 50)


if __name__ == "__main__":
    main()

🐞 خطاهای رایج و رفع آن‌ها

این خطاها را در تمرین‌ها زیاد می‌بینید:

❌ SyntaxError در comprehension (براکت یا پرانتز اشتباه)

معنی: پایتون سینتکس comprehension را تشخیص نمی‌دهد.

علت: جایی از براکت، پرانتز یا دو-نقطه را اشتباه گذاشته‌اید.

راه‌حل: حتماً بررسی کنید:

  • list → [...]
  • dict → {k: v for ...}
  • set → {...} (بدون دو-نقطه)
  • generator → (...)

❌ NameError در comprehension

معنی: متغیری که داخل comprehension استفاده کرده‌اید، تعریف نشده.

علت: مثلاً نوشته‌اید [y for x in range(5)] — y هیچ‌جا تعریف نشده.

راه‌حل: مطمئن شوید متغیرِ بعد از for، همانی است که در ابتدای comprehension استفاده می‌کنید.

❌ generator یک‌بارمصرف است

معنی: بار دوم که روی generator حلقه می‌زنید، خالی است.

علت: generator فقط می‌تواند یک بار مصرف شود.

راه‌حل: اگر می‌خواهید چند بار روی داده حرکت کنید، آن را به list(gen) تبدیل کنید یا از همان ابتدا list comprehension بسازید.

❌ StopIteration روی generator

معنی: می‌خواهید بیشتر از اعضای موجود از generator بگیرید.

علت: روی generator بی‌محافظ next() صدا زده‌اید.

راه‌حل: از next(gen, default) استفاده کنید یا با for مصرفش کنید تا خودش مدیریت کند.

❌ comprehension غیرخوانا

معنی: کد شما کار می‌کند، اما سخت فهم است.

علت: comprehension را برای منطق پیچیده استفاده کرده‌اید — مثلاً دو for تو در تو با دو شرط.

راه‌حل: اگر comprehension بیشتر از ۸۰ کاراکتر می‌شود یا بیش از یک for دارد، احتمالاً بهتر است به for معمولی برگردید.

❌ zip با لیست‌های ناهمتا

معنی: zip فقط تا کوتاه‌ترین لیست پیش می‌رود.

علت: طول لیست‌ها متفاوت است و فکر می‌کنید همه اعضا پیمایش می‌شوند.

راه‌حل: قبل از zip، طول‌ها را چک کنید: if len(a) != len(b): print("طول‌ها فرق دارند"). یا از itertools.zip_longest استفاده کنید (پیشرفته).

❌ dict comprehension با کلید تکراری

معنی: اگر در dict comprehension کلید تکراری تولید شود، فقط آخرین مقدار می‌ماند.

علت: dict نمی‌تواند کلید تکراری داشته باشد.

راه‌حل: اگر می‌خواهید همه‌ی مقادیر با یک کلید را نگه دارید، از دیکشنری لیست استفاده کنید (مثل defaultdict(list)) که در فصل‌های پیشرفته می‌بینید.

نکته: وقتی کد سنتی را به comprehension تبدیل می‌کنید، سه چیز را از هم جدا کنید: ۱) چه کاری روی هر عضو انجام می‌شود؛ ۲) روی چه چیزی حلقه می‌زنید؛ ۳) چه شرطی دارید. سپس در قالب comprehension بچینید.

🏋️ تمرین خطایابی — چهار خطا

این کد چهار خطا دارد. هر کدام را پیدا کنید:

broken.pyPython
# خطا 1 — استفاده از y بدون تعریف
result = [y * 2 for x in range(5)]

# خطا 2 — براکت اشتباه برای dict
result = [k: v for k, v in [("a", 1), ("b", 2)]]

# خطا 3 — generator را دو بار مصرف می‌کنیم
gen = (x * 2 for x in range(3))
print(list(gen))     # [0, 2, 4]
print(list(gen))     # خالی! چون مصرف شده

# خطا 4 — comprehension با دو for تو در تو، غیرخوانا
result = [x * y for x in range(3) for y in range(3) if x != y if x + y > 2]

پاسخ:

  • خطا ۱: NameError. متغیر y جایی تعریف نشده. باید [x * 2 for x in range(5)] باشد.
  • خطا ۲: برای dict comprehension باید از { } استفاده شود، نه [ ]. راه‌حل: {k: v for k, v in [("a", 1), ("b", 2)]}.
  • خطا ۳: generator یک‌بارمصرف است. اگر می‌خواهید دو بار مصرف کنید، به لیست تبدیلش کنید: values = list(x * 2 for x in range(3)) — بعد values را هر چند بار استفاده کنید.
  • خطا ۴: کاملاً غیرخوانا. دو for تو در تو + دو شرط در یک خط. راه‌حل: به for معمولی برگردید:
    نسخه‌ی خواناPython
    result = []
for x in range(3):
    for y in range(3):
        if x != y and x + y > 2:
            result.append(x * y)

درس مهم: comprehension برای کد ساده است. اگر منطق پیچیده شد، به for معمولی برگردید — خوانایی مهم‌تر از کوتاهی است.

بخش ۱۱

📝 آزمون تعاملی فصل

پرسش‌های چهارگزینه‌ای زیر را پاسخ دهید؛ بلافاصله بعد از انتخاب، پاسخ درست و توضیحش را می‌بینید. حد نصاب قبولی ۶۰٪ است و بهترین نمره‌تان ذخیره می‌شود.

۱) خروجی [x * 2 for x in range(4)] چیست؟

💡 range(4) می‌دهد ۰، ۱، ۲، ۳. هر کدام در ۲ ضرب می‌شود: ۰، ۲، ۴، ۶.

۲) کدام یک یک list comprehension معتبر است؟

💡 list comprehension با [ ] ساخته می‌شود. {...} برای set یا dict، و (...) برای generator است.

۳) خروجی {x: x ** 2 for x in range(3)} چیست؟

💡 dict comprehension با {k: v for ...} ساخته می‌شود. کلید x است و مقدار x² .

۴) تفاوت اصلی list و generator expression چیست؟

💡 تفاوت کلیدی: list کل داده را در حافظه دارد، اما generator داده را تنبل (lazy) و یکی‌یکی تولید می‌کند.

۵) خروجی این کد چیست؟
names = ["a", "b"]
ages = [10, 20]
for n, a in zip(names, ages):
    print(n, a)

💡 zip اعضای متناظر دو لیست را کنار هم می‌گذارد. دو لیست دو عضوی داریم، پس دو جفت ساخته می‌شود.

۶) برای پیمایش لیست همراه با ایندکس، کدام تابع مناسب است؟

💡 enumerate به‌طور خودکار ایندکس و مقدار را کنار هم می‌دهد: for i, item in enumerate(my_list):.
بخش ۱۲

🏗️ پروژه عملی فصل

پروژه: «تحلیل‌گر متن پیشرفته» — برنامه‌ای که یک متن می‌گیرد و تحلیل جامعی از آن ارائه می‌دهد، با استفاده از تمام ابزارهای این فصل.

نیازمندی‌ها:

  • فایل در پوشه‌ی پروژه به نام advanced_analyzer.py ذخیره شود.
  • تابع get_words(text): متن را به لیست کلمات تبدیل می‌کند (با lower() و split()).
  • تابع long_words(words, min_len=4): با list comprehension، فقط کلمات با طول مشخص را برمی‌گرداند.
  • تابع word_lengths(words): با dict comprehension، نگاشت کلمه → طول را می‌سازد.
  • تابع unique_words(words): با set comprehension، کلمات یکتا را برمی‌گرداند.
  • تابع word_frequencies(words): با dict comprehension و .count()، تعداد تکرار هر کلمه را برمی‌گرداند (فقط کلمات یکتا).
  • تابع top_words(freq, n=5): با sorted روی items()، n کلمه‌ی پرتکرار را برمی‌گرداند.
  • تابع show_letter_summary(words): با Counter یا حلقه، توزیع حروف اول کلمات را نشان دهد (می‌توانید از یک dict comprehension ساده استفاده کنید).
  • تابع indexed_words(words): با enumerate، کلمات را با ایندکس چاپ کند.
  • تابع show_report(text): همه‌ی تحلیل‌ها را در قالب یک گزارش زیبا چاپ کند.
  • در یک جای برنامه، حداقل یک generator expression استفاده شود (مثلاً برای مجموع طول کلمات).
  • هر تابع یک docstring داشته باشد.

🎯 جمع‌بندی و دستاوردها

در این فصل یاد گرفتید:

  • list comprehension برای ساخت لیست در یک خط: [x**2 for x in range(10)].
  • افزودن شرط به comprehension برای فیلتر: [x for x in items if x > 5].
  • حالت if/else در comprehension: [A if cond else B for x in items].
  • dict comprehension برای ساخت دیکشنری در یک خط.
  • set comprehension برای ساخت مجموعه در یک خط.
  • generator expression — همان ایده، ولی با ( ) و تنبل (بدون ذخیره در حافظه).
  • enumerate() برای پیمایش با ایندکس.
  • zip() برای پیمایش همزمان چند لیست.
  • مفهوم iterable و iterator و تفاوتشان.
  • تابع با yield (generator function) برای تولید داده‌ی بزرگ به‌صورت تنبل.
  • کِی از comprehension استفاده کنیم و کِی نه.
💡 ✨ یک‌جمله‌ای که باید یادتان بماند «comprehension ابزار قدرتمندی است، اما فقط وقتی استفاده کنید که خوانا باشد. کد کوتاه ولی گیج‌کننده، بدتر از کد بلند ولی واضح است.»

❓ سوالات متداول و گام بعدی

آیا comprehension از for معمولی سریع‌تر است؟

بله، معمولاً. چون پایتون می‌تواند comprehension را بهینه‌تر اجرا کند. اما این تفاوت در داده‌های کوچک قابل توجه نیست. برای داده‌های بزرگ، generator می‌تواند از نظر حافظه هم مفید باشد. اما مهم‌ترین دلیل استفاده از comprehension، خوانایی و پایتونیک بودن است، نه فقط سرعت.

چند سطح for تو در تو در comprehension مجاز است؟

فنی می‌توانید چند سطح داشته باشید، ولی توصیه نمی‌شود. اگر بیش از دو for دارید، تقریباً همیشه بهتر است به for معمولی برگردید. کدی که در یک نگاه فهمیده نشود، دشمن شماست.

آیا می‌توانم در comprehension از تابع استفاده کنم؟

بله، همین توصیه می‌شود! مثلاً [len(w) for w in words] یا [w.upper() for w in words]. اگر منطق پیچیده دارید، بهتر است آن را در یک تابع جدا بنویسید و در comprehension صدایش بزنید.

تفاوت generator و list comprehension فقط در سینتکس است؟

خیر. تفاوت اصلی در رفتار است: list comprehension کل داده را یک‌جا در حافظه می‌سازد، اما generator تنبل است و یکی‌یکی داده می‌دهد. یکی از کاربردهای مهم: اگر داده بی‌نهایت باشد (مثلاً generator که همیشه عدد تولید می‌کند)، فقط با generator می‌توانید کار کنید.

آیا generator را می‌توان در comprehension استفاده کرد؟

بله. مثلاً [x*2 for x in my_generator] کار می‌کند. اما توجه کنید که مصرف کردن generator در comprehension، آن را تمام می‌کند. بعد از این کار، اگر دوباره روی generator حلقه بزنید، خالی است.
