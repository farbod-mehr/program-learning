🔭 چشم‌انداز فصل: اهداف و جایگاه

در فصل ۹ یاد گرفتیم که چطور چند مقدار را در یک لیست نگه داریم. برای دسترسی به اعضای لیست، از ایندکس (شماره) استفاده می‌کردیم: names[0]، names[1]. اما این روش یک مشکل دارد: شماره‌ها معنی‌دار نیستند. اگر کسی بپرسد «تلفن علی چیه؟» نمی‌توانید بگویید «phone_list[3]»!

اینجاست که دیکشنری وارد می‌شود. دیکشنری به شما اجازه می‌دهد به‌جای ایندکس عددی، از اسم استفاده کنید: phone_book["علی"]. این کار نه‌فقط خواناتر است، بلکه طبیعی‌تر هم است. در کنار دیکشنری، با مجموعه (set) هم آشنا می‌شوید — نوع خاصی از داده که اعضای یکتا نگه می‌دارد و برای حذف تکراری‌ها و عملیات مجموعه‌ای (مثل اشتراک و اجتماع) عالیه.

در پایان این فصل، شما می‌توانید:

  • دیکشنری بسازید و با کلید به مقدار دسترسی پیدا کنید.
  • مقادیر دیکشنری را اضافه، ویرایش و حذف کنید.
  • روی دیکشنری‌ها حلقه بزنید (روی کلیدها، مقادیر یا هر دو).
  • از متدهای مهم دیکشنری مثل get()، keys()، values()، items()، update() استفاده کنید.
  • مجموعه (set) بسازید و عملیات مجموعه‌ای (اشتراک، اجتماع، تفاضل) انجام دهید.
  • بدانید کِی از لیست، کِی از دیکشنری و کِی از مجموعه استفاده کنید.
📌 نکته مهم دیکشنری، پرکاربردترین ساختمان داده در پایتون بعد از لیست است. در پروژه‌های واقعی، تقریباً هر جا داده‌ای با ساختار «فیلد-مقدار» دارید، دیکشنری استفاده می‌شود. مجموعه (set) هم کمتر استفاده می‌شود ولی در موقعیت‌های خاص (مثل حذف تکراری‌ها) حیاتی است.

🤔 سوالات محرک ذهنی

قبل از خواندن آموزش، چند لحظه به این سوال‌ها فکر کنید:

🤔 تفاوت اصلی لیست و دیکشنری چیست؟

لیست بر اساس ایندکس عددی (۰، ۱، ۲، ...) سازماندهی می‌شود — یعنی ترتیب مهم است. دیکشنری بر اساس کلید سازماندهی می‌شود — یعنی می‌توانید از هر چیزی که معنی‌دار است استفاده کنید: اسم، شماره دانشجویی، کد ملی. اگر در برنامه‌تان «ترتیب» مهم است، لیست بهتر است. اگر «اسم‌گذاری» مهم است، دیکشنری بهتر است.

🤔 چرا my_dict["کلید_ناموجود"] خطا می‌دهد اما my_dict.get("کلید_ناموجود") خطا نمی‌دهد؟

این یکی از زیبایی‌های پایتون است. با کروشه [ ]، اگر کلید وجود نداشته باشد، خطای KeyError می‌گیرید — که یعنی برنامه متوقف می‌شود. اما با .get()، اگر کلید نباشد، مقدار None برمی‌گردد (یا مقداری که خودتان مشخص می‌کنید) بدون اینکه خطا بدهد. در خیلی از موارد، این رفتار «دوستانه‌تر» است. مثلاً در شمارش کلمات، می‌خواهید اگر کلمه‌ای اولین بار دیده می‌شود، صفر حساب شود — .get() این کار را برایتان انجام می‌دهد.

🤔 چه زمانی از set استفاده کنم و چه زمانی از list؟

از set استفاده کنید اگر: (۱) می‌خواهید اعضای تکراری حذف شوند؛ (۲) فقط می‌خواهید چک کنید که آیا یک مقدار خاص در مجموعه هست یا نه؛ (۳) می‌خواهید عملیات مجموعه‌ای (اشتراک، اجتماع، تفاضل) انجام دهید. از list استفاده کنید اگر: ترتیب اعضا مهم است، یا می‌خواهید اعضای تکراری هم داشته باشید.

📖 آموزش گام‌به‌گام: دیکشنری و مجموعه

۱) دیکشنری چیست؟ — یک دفترچه با کلید

دیکشنری مثل یک دفترچه تلفن است: برای پیدا کردن شماره‌ی «علی»، اسمش را جست‌وجو می‌کنید، نه اینکه صفحه‌به‌صفحه بگردید. هر عضو دیکشنری یک جفت کلید-مقدار است: کلید، اسمی است که برمی‌گزینید؛ مقدار، چیزی است که ذخیره می‌کنید. ساختارش با کروشه { } است:

first_dict.pyPython
# یک دیکشنری از اطلاعات یک شخص
person = {
    "name": "علی",
    "age": 25,
    "city": "تهران",
}

# یک دیکشنری خالی
empty = {}

# دیکشنری دفترچه تلفن
phone_book = {
    "علی": "09123456789",
    "رضا": "09387654321",
    "سارا": "09121112222",
}

print(person)
print(phone_book)

خروجی:

خروجیText
{'name': 'علی', 'age': 25, 'city': 'تهران'}
{'علی': '09123456789', 'رضا': '09387654321', 'سارا': '09121112222'}

چند نکته:

  • هر جفت با دو-نقطه از هم جدا می‌شود: "کلید": مقدار.
  • جفت‌ها با کاما از هم جدا می‌شوند.
  • دیکشنری خالی با {} ساخته می‌شود — توجه کنید که این با set خالی متفاوت است (بعداً توضیح می‌دهیم).

۲) دسترسی به مقادیر — از طریق کلید

برای گرفتن یک مقدار، از کلید استفاده می‌کنیم، داخل کروشه:

access.pyPython
person = {
    "name": "علی",
    "age": 25,
    "city": "تهران",
}

print(person["name"])   # علی
print(person["age"])    # 25
print(person["city"])   # تهران
⚠️ هشدار اگر کلیدی که می‌خواهید وجود نداشته باشد، خطای KeyError می‌گیرید:
خطای کلید نامعتبرPython
print(person["email"])   # KeyError: 'email'
در بخش بعدی یاد می‌گیریم چطور این خطا را با .get() جلوگیری کنیم.

۳) اضافه کردن و ویرایش کردن

دیکشنری تغییرپذیر است. اضافه کردن و ویرایش، سینتکس یکسانی دارند:

add_modify.pyPython
person = {"name": "علی", "age": 25}

# اضافه کردن یک کلید جدید
person["city"] = "تهران"
print(person)
# {'name': 'علی', 'age': 25, 'city': 'تهران'}

# ویرایش یک مقدار موجود
person["age"] = 26
print(person)
# {'name': 'علی', 'age': 26, 'city': 'تهران'}

پایتون خودش تشخیص می‌دهد: اگر کلید وجود داشته باشد، مقدارش عوض می‌شود؛ اگر نباشد، کلید جدید اضافه می‌شود.

۴) متد get() — دسترسی امن

برای جلوگیری از خطای KeyError، از .get() استفاده کنید:

safe_get.pyPython
person = {"name": "علی", "age": 25}

# اگر کلید باشد، مقدارش را می‌دهد
print(person.get("name"))                # علی

# اگر کلید نباشد، None می‌دهد
print(person.get("email"))               # None

# می‌توانید مقدار پیش‌فرض هم بدهید
print(person.get("email", "ثبت نشده"))    # ثبت نشده
💡 عادت طلایی وقتی مطمئن نیستید کلید وجود دارد یا نه، همیشه از .get() استفاده کنید. این کار باعث می‌شود برنامه‌تان به‌جای کرش کردن، با آرامش ادامه دهد.

۵) متدهای مهم دیکشنری

الف) keys()، values()، items()

dict_methods.pyPython
person = {"name": "علی", "age": 25, "city": "تهران"}

# همه‌ی کلیدها
print(person.keys())
# dict_keys(['name', 'age', 'city'])

# همه‌ی مقادیر
print(person.values())
# dict_values(['علی', 25, 'تهران'])

# همه‌ی جفت‌های کلید-مقدار به‌صورت تاپل
print(person.items())
# dict_items([('name', 'علی'), ('age', 25), ('city', 'تهران')])

خروجی‌های keys()، values() و items() «شیء view» هستند — یعنی می‌توانید رویشان حلقه بزنید یا با list() به لیست تبدیلشان کنید:

to_list.pyPython
keys_list = list(person.keys())
print(keys_list)    # ['name', 'age', 'city']

ب) update() — ادغام دو دیکشنری

update.pyPython
person = {"name": "علی", "age": 25}
extra = {"city": "تهران", "age": 26}

person.update(extra)
print(person)
# {'name': 'علی', 'age': 26, 'city': 'تهران'}

نکته: اگر کلید در هر دو دیکشنری باشد (مثل age در مثال بالا)، مقدار دیکشنری دوم، جایگزین می‌شود.

ج) pop()، popitem()، del — حذف

remove.pyPython
person = {"name": "علی", "age": 25, "city": "تهران"}

# pop — حذف با کلید و برگرداندن مقدار
age = person.pop("age")
print(age)              # 25
print(person)           # {'name': 'علی', 'city': 'تهران'}

# pop با مقدار پیش‌فرض (اگر کلید نبود، خطا نده)
email = person.pop("email", None)
print(email)            # None

# del — حذف با کلید
del person["city"]
print(person)           # {'name': 'علی'}

# popitem — حذف آخرین جفت اضافه‌شده
person = {"a": 1, "b": 2, "c": 3}
last = person.popitem()
print(last)             # ('c', 3)
print(person)           # {'a': 1, 'b': 2}

۶) حلقه روی دیکشنری

دیکشنری‌ها با for خیلی راحت پیمایش می‌شوند:

loop_dict.pyPython
person = {"name": "علی", "age": 25, "city": "تهران"}

# فقط روی کلیدها (پیش‌فرض)
for key in person:
    print(key)
# name
# age
# city

# روی کلیدها صریحاً
for key in person.keys():
    print(key)

# فقط روی مقادیر
for value in person.values():
    print(value)
# علی
# 25
# تهران

# روی هر دو (پرکاربردترین حالت)
for key, value in person.items():
    print(f"{key}: {value}")
# name: علی
# age: 25
# city: تهران
💡 الگوی پرکاربرد for key, value in person.items(): پرکاربردترین الگو برای پیمایش دیکشنری است. اگر فقط کلیدها را می‌خواهید، for key in person: کوتاه‌ترین راه است.

۷) دیکشنری تو در تو (Nested Dict)

می‌توانید داخل یک دیکشنری، دیکشنری دیگری داشته باشید. این برای ذخیره‌ی داده‌های سلسله‌مراتبی (مثل اطلاعات چند کاربر) عالیه:

nested_dict.pyPython
users = {
    "ali": {
        "name": "علی محمدی",
        "age": 25,
        "city": "تهران",
    },
    "reza": {
        "name": "رضا احمدی",
        "age": 30,
        "city": "شیراز",
    },
}

# دسترسی به اطلاعات یک کاربر
print(users["ali"]["name"])     # علی محمدی
print(users["reza"]["city"])     # شیراز

# پیمایش
for username, info in users.items():
    print(f"{username} ({info['age']} ساله، {info['city']})")

خروجی:

خروجیText
ali (25 ساله، تهران)
reza (30 ساله، شیراز)

۸) الگوی شمارنده با دیکشنری

یکی از پرکاربردترین الگوهای دیکشنری: شمارش تعداد تکرار هر عضو:

counter.pyPython
# شمارش تعداد تکرار هر حرف در یک متن
text = "python programming"
counts = {}

for char in text:
    if char in counts:
        counts[char] += 1
    else:
        counts[char] = 1

print(counts)

# یا با get که تمیزتر است
counts = {}
for char in text:
    counts[char] = counts.get(char, 0) + 1

print(counts)

خروجی:

خروجیText
{'p': 2, 'y': 1, 't': 1, 'h': 1, 'o': 2, 'n': 2, ' ': 1, 'r': 2, 'g': 2, 'a': 1, 'm': 2, 'i': 1}

الگوی counts[x] = counts.get(x, 0) + 1 یکی از معروف‌ترین الگوهای پایتون است. اگر x قبلاً دیده شده، یک اضافه می‌کند؛ اگر نه، از صفر شروع می‌کند.

۹) مجموعه (Set) — اعضای یکتا

مجموعه (set) مجموعه‌ای از اعضاست که: (۱) ترتیبی ندارند؛ (۲) عضو تکراری نمی‌پذیرند؛ (۳) خیلی سریع می‌توان چک کرد که آیا یک مقدار در آن‌ها هست یا نه. ساختارش هم با کروشه است، اما بدون جفت کلید-مقدار:

first_set.pyPython
# با اعضای مستقیم
colors = {"قرمز", "سبز", "آبی"}
print(colors)

# از یک لیست (تکراری‌ها خودکار حذف می‌شوند)
numbers = [1, 2, 2, 3, 3, 3, 4]
unique = set(numbers)
print(unique)              # {1, 2, 3, 4}

# set خالی — دقت کنید!
empty_set = set()          # ✅ درست
# empty = {}               # ❌ این یک دیکشنری خالی است، نه set!
⚠️ دام مهم {} یک دیکشنری خالی است، نه یک set خالی. برای set خالی باید از set() استفاده کنید.

چند متد مهم set

set_methods.pyPython
fruits = {"سیب", "موز"}

# اضافه کردن
fruits.add("پرتقال")
print(fruits)              # {'سیب', 'موز', 'پرتقال'}

# حذف
fruits.remove("موز")
print(fruits)              # {'سیب', 'پرتقال'}

# discard — مثل remove ولی خطا نمی‌دهد اگر نبود
fruits.discard("انگور")    # بدون خطا
fruits.discard("سیب")      # حذف می‌شود
print(fruits)              # {'پرتقال'}

# بررسی وجود
fruits.add("سیب")
print("سیب" in fruits)      # True
print("انگور" in fruits)    # False

# تعداد اعضا
print(len(fruits))          # 2

# خالی کردن
fruits.clear()
print(fruits)              # set()

عملیات مجموعه‌ای

یک ویژگی زیبای set این است که می‌توانید عملیات ریاضی روی آن انجام دهید:

set_ops.pyPython
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# اشتراک (اعضای مشترک)
print(a & b)                # {3, 4}
print(a.intersection(b))    # {3, 4}

# اجتماع (همه اعضا بدون تکرار)
print(a | b)                # {1, 2, 3, 4, 5, 6}
print(a.union(b))           # {1, 2, 3, 4, 5, 6}

# تفاضل (اعضای a که در b نیستند)
print(a - b)                # {1, 2}
print(a.difference(b))      # {1, 2}

# تفاضل متقارن (اعضایی که فقط در یکی هستند)
print(a ^ b)                # {1, 2, 5, 6}
print(a.symmetric_difference(b))  # {1, 2, 5, 6}

این عملیات وقتی طلایی می‌شوند که بخواهید دو مجموعه را با هم مقایسه کنید — مثلاً «کاربرانی که در هر دو سایت عضو هستند» یا «محصولاتی که در انبار A هست ولی در B نیست».

۱۰) کدام ساختمان داده را انتخاب کنم؟

حالا که هر چهار ساختمان داده را می‌شناسید، این جدول تصمیم‌گیری را به‌خاطر بسپارید:

ساختمانسینتکستغییرپذیر؟تکراری مجاز؟کاربرد اصلی
لیست (list)[1, 2, 3]✅✅دنباله‌ی مرتب داده‌ها
تاپل (tuple)(1, 2, 3)❌✅داده‌ی ثابت (مثل مختصات)
دیکشنری (dict){"k": "v"}✅کلید: ❌ / مقدار: ✅نگاشت کلید-مقدار

برنامه‌ای که تعداد تکرار کلمات یک متن را می‌شمارد و پرتکرارترین‌ها را نشان می‌دهد:

word_counter.pyPython
"""شمارنده کلمات — با دیکشنری."""


def count_words(text):
    """تعداد تکرار هر کلمه را در یک دیکشنری برمی‌گرداند."""
    words = text.lower().split()
    counts = {}
    for word in words:
        counts[word] = counts.get(word, 0) + 1
    return counts


def show_top(counts, n=5):
    """n کلمه‌ی پرتکرار را نمایش می‌دهد."""
    # items() → تاپل‌ها، sort بر اساس مقدار (x[1]) نزولی
    sorted_items = sorted(counts.items(), key=lambda x: x[1], reverse=True)

    print(f"\n🏆 {n} کلمه پرتکرار:")
    for i, (word, count) in enumerate(sorted_items[:n], start=1):
        print(f"  {i}. {word} — {count} بار")


def main():
    print("=" * 40)
    print("     شمارنده کلمات")
    print("=" * 40)

    text = input("یک متن بنویسید:\n").strip()

    if not text:
        print("⚠️ متن خالی است.")
        return

    counts = count_words(text)
    print(f"\n📊 تعداد کلمات یکتا: {len(counts)}")
    show_top(counts, n=5)


if __name__ == "__main__":
    main()

یک «دفترچه تلفن دیکشنری» که همه‌ی متدهای مهم دیکشنری را نشان می‌دهد:

phone_book_dict.pyPython
"""دفترچه تلفن با دیکشنری."""


def add_contact(book):
    """مخاطب جدید اضافه می‌کند."""
    name = input("نام: ").strip()
    if not name:
        print("⚠️ نام نمی‌تواند خالی باشد.")
        return
    if name in book:
        print(f"⚠️ «{name}» قبلاً وجود دارد.")
        return

    phone = input("شماره: ").strip()
    city = input("شهر: ").strip()

    # ذخیره به‌عنوان یک دیکشنری داخلی
    book[name] = {
        "phone": phone,
        "city": city,
    }
    print(f"✅ «{name}» اضافه شد.")


def show_all(book):
    """همه‌ی مخاطبین را نمایش می‌دهد."""
    if not book:
        print("\n📭 دفترچه خالی است.")
        return

    print(f"\n📞 دفترچه تلفن ({len(book)} مخاطب):")
    print("-" * 50)
    for i, (name, info) in enumerate(book.items(), start=1):
        print(f"  {i}. {name}")
        print(f"     ☎️  {info['phone']}")
        print(f"     🏙️  {info['city']}")
        print("-" * 50)


def search(book):
    """جست‌وجو در دفترچه."""
    if not book:
        print("📭 دفترچه خالی است.")
        return

    query = input("جست‌وجو (نام یا شهر): ").strip().lower()
    results = []

    for name, info in book.items():
        if query in name.lower() or query in info["city"].lower():
            results.append((name, info))

    if not results:
        print("❌ نتیجه‌ای یافت نشد.")
        return

    print(f"\n🔍 {len(results)} نتیجه:")
    for name, info in results:
        print(f"  • {name} — {info['phone']} ({info['city']})")


def edit_contact(book):
    """مخاطب موجود را ویرایش می‌کند."""
    name = input("نام مخاطب برای ویرایش: ").strip()

    if name not in book:
        print(f"❌ «{name}» پیدا نشد.")
        return

    print(f"اطلاعات فعلی: {book[name]}")
    new_phone = input(f"شماره جدید (Enter = بدون تغییر): ").strip()
    new_city = input(f"شهر جدید (Enter = بدون تغییر): ").strip()

    if new_phone:
        book[name]["phone"] = new_phone
    if new_city:
        book[name]["city"] = new_city

    print("✅ ویرایش شد.")


def delete_contact(book):
    """مخاطب را حذف می‌کند."""
    name = input("نام مخاطب برای حذف: ").strip()

    if name not in book:
        print(f"❌ «{name}» پیدا نشد.")
        return

    book.pop(name)
    print(f"🗑 «{name}» حذف شد.")


def list_cities(book):
    """شهرهای یکتای دفترچه را نمایش می‌دهد."""
    if not book:
        print("📭 دفترچه خالی است.")
        return

    cities = {info["city"] for info in book.values()}
    print(f"\n🏙️ شهرهای دفترچه ({len(cities)} شهر یکتا):")
    for city in sorted(cities):
        print(f"  • {city}")


def main():
    book = {}

    while True:
        print("\n" + "=" * 40)
        print("       دفترچه تلفن دیکشنری")
        print("=" * 40)
        print("  1. افزودن مخاطب")
        print("  2. نمایش همه")
        print("  3. جست‌وجو")
        print("  4. ویرایش")
        print("  5. حذف")
        print("  6. لیست شهرها (set)")
        print("  7. خروج")
        print("-" * 40)

        choice = input("انتخاب شما: ").strip()

        if choice == "1":
            add_contact(book)
        elif choice == "2":
            show_all(book)
        elif choice == "3":
            search(book)
        elif choice == "4":
            edit_contact(book)
        elif choice == "5":
            delete_contact(book)
        elif choice == "6":
            list_cities(book)
        elif choice == "7":
            print("👋 خداحافظ!")
            break
        else:
            print("⚠️ گزینه نامعتبر.")


if __name__ == "__main__":
    main()

🛠️ کارگاه عملی

یک «سیستم نظرسنجی» بسازید که نظرهای کاربران را در یک دیکشنری نگه دارد و تحلیل کند:

  1. فایل جدیدی به نام survey.py در پوشه‌ی پروژه بسازید.
  2. یک دیکشنری خالی بسازید که در آن هر کاربر به یک پاسخ رأی داده باشد: votes = {}.
  3. از کاربر چند رأی بگیرید. هر رأی شامل «نام کاربر» و «گزینه انتخابی» (مثلاً «A»، «B»، «C») است. تا وقتی کاربر «تمام» نزند، ادامه دهید.
  4. اگر یک کاربر قبلاً رأی داده بود، رأی جدیدش جایگزین رأی قبلی شود.
  5. تابعی به نام show_results(votes) بسازید که:
    • تعداد کل رأی‌دهندگان را نمایش دهد.
    • تعداد رأی هر گزینه را با شمارش روی values() نمایش دهد.
    • گزینه‌ی برنده را مشخص کند.
  6. تابعی به نام show_voters(votes) بسازید که نام رأی‌دهندگانی که به یک گزینه‌ی خاص رأی داده‌اند را نمایش دهد (گزینه را از کاربر بگیرید).
  7. تابعی به نام get_unique_options(votes) بسازید که با set، گزینه‌های یکتای رأی‌داده‌شده را برگرداند.
  8. تابع main() با منوی تعاملی که همه‌ی این قابلیت‌ها را به کاربر ارائه دهد.
  9. هر تابع یک docstring داشته باشد.

survey.pyPython
"""سیستم نظرسنجی — با دیکشنری و set."""


def collect_votes():
    """رأی‌ها را از کاربر جمع می‌کند."""
    votes = {}
    print("\nرأی‌گیری شروع شد. گزینه‌ها: A، B، C")
    print("برای پایان، در فیلد نام بنویسید: تمام\n")

    while True:
        name = input("نام رأی‌دهنده: ").strip()
        if name == "تمام":
            break
        if not name:
            print("⚠️ نام نمی‌تواند خالی باشد.")
            continue

        choice = input("گزینه (A/B/C): ").strip().upper()
        if choice not in ("A", "B", "C"):
            print("⚠️ گزینه نامعتبر. فقط A یا B یا C.")
            continue

        # اگر کاربر قبلاً رأی داده، رأی جدید جایگزین می‌شود
        if name in votes:
            print(f"🔄 رأی «{name}» از {votes[name]} به {choice} تغییر کرد.")

        votes[name] = choice

    return votes


def show_results(votes):
    """نتایج نظرسنجی را نمایش می‌دهد."""
    if not votes:
        print("\n📭 هیچ رأی‌ای ثبت نشده.")
        return

    # شمارش آرا
    counts = {}
    for choice in votes.values():
        counts[choice] = counts.get(choice, 0) + 1

    print("\n" + "=" * 45)
    print("           نتایج نظرسنجی")
    print("=" * 45)
    print(f"  تعداد کل رأی‌دهندگان: {len(votes)}")
    print("-" * 45)

    # مرتب‌سازی گزینه‌ها بر اساس تعداد آرا
    sorted_options = sorted(counts.items(), key=lambda x: x[1], reverse=True)

    for option, count in sorted_options:
        # نوار بصری
        bar = "█" * count
        percent = count / len(votes) * 100
        print(f"  {option}: {count} رأی ({percent:.1f}%) {bar}")

    # برنده
    winner = sorted_options[0]
    print("-" * 45)
    print(f"  🏆 برنده: گزینه {winner[0]} با {winner[1]} رأی")
    print("=" * 45)


def show_voters(votes):
    """رأی‌دهندگان یک گزینه را نشان می‌دهد."""
    if not votes:
        print("📭 هیچ رأی‌ای ثبت نشده.")
        return

    choice = input("کدام گزینه؟ (A/B/C): ").strip().upper()
    voters = [name for name, c in votes.items() if c == choice]

    if not voters:
        print(f"❌ هیچ‌کس به گزینه {choice} رأی نداده.")
        return

    print(f"\n👥 {len(voters)} نفر به گزینه {choice} رأی داده‌اند:")
    for name in voters:
        print(f"  • {name}")


def get_unique_options(votes):
    """گزینه‌های یکتا را با set برمی‌گرداند."""
    return set(votes.values())


def main():
    votes = {}

    while True:
        print("\n" + "=" * 40)
        print("         سیستم نظرسنجی")
        print("=" * 40)
        print("  1. رأی‌گیری")
        print("  2. نمایش نتایج")
        print("  3. رأی‌دهندگان یک گزینه")
        print("  4. گزینه‌های یکتا (set)")
        print("  5. خروج")
        print("-" * 40)

        choice = input("انتخاب شما: ").strip()

        if choice == "1":
            votes = collect_votes()
        elif choice == "2":
            show_results(votes)
        elif choice == "3":
            show_voters(votes)
        elif choice == "4":
            options = get_unique_options(votes)
            print(f"\n🎯 {len(options)} گزینه یکتا رأی گرفته‌اند: {sorted(options)}")
        elif choice == "5":
            print("👋 خداحافظ!")
            break
        else:
            print("⚠️ گزینه نامعتبر.")


if __name__ == "__main__":
    main()

✅ نکته‌های کلیدی این راه‌حل

چند نکته‌ی مهم:

  1. دیکشنری ساده برای رأی‌ها: votes[name] = choice — کلید اسم، مقدار گزینه. این ساده‌ترین شکل ذخیره‌ی داده است. نکته‌ی جالب: چون کلیدها در دیکشنری یکتا هستند، خودکاراً رأی قبلی یک نفر با رأی جدیدش جایگزین می‌شود — نیازی به کد اضافه نیست!
  2. الگوی شمارش: counts[c] = counts.get(c, 0) + 1 — یک الگوی بسیار رایج که در این فصل یاد گرفتید.
  3. مرتب‌سازی با key: sorted(counts.items(), key=lambda x: x[1], reverse=True) — مرتب‌سازی بر اساس عضو دوم تاپل (که مقدار است). lambda در فصل ۱۱ کامل آموزش داده می‌شود.
  4. استفاده از set: set(votes.values()) مستقیم گزینه‌های یکتا را می‌دهد — بدون حلقه و بدون مقایسه.
  5. list comprehension: [name for name, c in votes.items() if c == choice] — یک روش کوتاه برای فیلتر کردن. در فصل ۱۱ یاد می‌گیرید.

  • فایل survey.py بدون خطا اجرا می‌شود.
  • می‌دانید چرا دیکشنری به‌طور خودکار رأی تکراری را جایگزین می‌کند.
  • با .get() و .items() و .values() راحت هستید.
  • می‌دانید چه زمانی از set به‌جای لیست استفاده کنید.
  • تفاوت دیکشنری خالی {} و set خالی set() را می‌دانید.

🐞 خطاهای رایج و رفع آن‌ها

این خطاها را در تمرین‌ها زیاد می‌بینید:

❌ KeyError: 'کلید_ناموجود'

معنی: کلیدی که با کروشه صدا زدید، در دیکشنری وجود ندارد.

علت: my_dict["ناموجود"] وقتی کلید وجود ندارد.

راه‌حل: از .get() استفاده کنید: my_dict.get("ناموجود", "پیش‌فرض"). یا قبل از دسترسی با in بررسی کنید: if "key" in my_dict:.

❌ TypeError: unhashable type: 'list'

معنی: نمی‌توان از لیست به‌عنوان کلید دیکشنری استفاده کرد.

علت: دیکشنری فقط کلیدهای تغییرناپذیر (immutable) می‌پذیرد: رشته، عدد، تاپل. لیست تغییرپذیر است، پس نمی‌شود کلید.

راه‌حل: اگر مجبور به استفاده از چند مقدار به‌عنوان کلید هستید، از تاپل استفاده کنید: my_dict[(1, 2)] = "مقدار". یا کلید را به رشته تبدیل کنید: str(my_list).

❌ دیکشنری خالی {} به‌جای set خالی

معنی: فکر کردید set ساختید، اما دیکشنری ساختید.

علت: x = {} یک دیکشنری خالی است.

راه‌حل: برای set خالی از set() استفاده کنید: x = set().

❌ AttributeError: 'dict' object has no attribute 'append'

معنی: دیکشنری متد append ندارد — چون append مخصوص لیست است.

علت: عادت لیست را روی دیکشنری اجرا کرده‌اید.

راه‌حل: برای اضافه کردن به دیکشنری از انتساب استفاده کنید: my_dict["key"] = value.

❌ تغییر دیکشنری هنگام پیمایش

معنی: RuntimeError: dictionary changed size during iteration

علت: در حال حلقه روی دیکشنری، آن را تغییر می‌دهید.

راه‌حل: از یک کپی از کلیدها استفاده کنید: for key in list(my_dict.keys()): — چون list() یک کپی مستقل می‌سازد.

❌ set غیرقابل مرتب‌سازی است

معنی: نمی‌توانید set را با set[0] صدا بزنید.

علت: set ترتیب ندارد و ایندکس نمی‌پذیرد.

راه‌حل: اگر به ترتیب نیاز دارید، set را به لیست تبدیل کنید و مرتب نمایید: sorted(my_set) یا list(my_set).

❌ تغییر set، تأثیر عجیب روی iteration دارد

معنی: وقتی در حال پیمایش set هستید، اضافه یا حذف کردن، خطا می‌دهد.

علت: شبیه دیکشنری، set هم نمی‌شود هنگام پیمایش تغییر کرد.

راه‌حل: از یک کپی استفاده کنید: for x in list(my_set):.

  • مورد ۶: {3} و {1, 2, 3, 4, 5}
🏋️ تمرین توسعه — سیستم ثبت‌نام کلاس

برنامه‌ای بنویسید که اطلاعات دانشجویان را در یک دیکشنری نگه دارد و امکان جست‌وجو بدهد:

students.pyPython
students = {
    "99001": {"name": "علی محمدی", "gpa": 18.5, "major": "کامپیوتر"},
    "99002": {"name": "رضا احمدی", "gpa": 17.2, "major": "برق"},
    "99003": {"name": "سارا رضایی", "gpa": 19.1, "major": "کامپیوتر"},
}

# جست‌وجو با شماره دانشجویی
def find_student(student_id):
    return students.get(student_id)

# میانگین GPA کلاس
def class_average():
    if not students:
        return 0
    total = sum(s["gpa"] for s in students.values())
    return total / len(students)

# رشته‌های یکتا (با set)
def unique_majors():
    return set(s["major"] for s in students.values())

# بهترین دانشجو
def top_student():
    return max(students.items(), key=lambda x: x[1]["gpa"])

# استفاده
print(find_student("99001"))
print(f"میانگین: {class_average():.2f}")
print(f"رشته‌ها: {unique_majors()}")
print(f"بهترین: {top_student()}")

خروجی:

خروجیText
{'name': 'علی محمدی', 'gpa': 18.5, 'major': 'کامپیوتر'}
میانگین: 18.27
رشته‌ها: {'کامپیوتر', 'برق'}
بهترین: ('99003', {'name': 'سارا رضایی', 'gpa': 19.1, 'major': 'کامپیوتر'})

نکته: در این مثال، دیکشنری تودرتو با values()، items()، set و even generator expression (که در فصل ۱۱ یاد می‌گیرید) همه با هم کار می‌کنند. این خودش نشان می‌دهد که چطور ساختمان‌های داده در پایتون به هم وصل می‌شوند.

🏋️ تمرین خطایابی — چهار خطا

این کد چهار خطا دارد. هر کدام را پیدا کنید:

broken.pyPython
# خطا 1
person = {"name": "علی"}
print(person["age"])

# خطا 2
colors = {}
colors.add("red")

# خطا 3
data = {}
data[[1, 2]] = "value"

# خطا 4
d = {"a": 1, "b": 2, "c": 3}
for key in d:
    if d[key] > 1:
        del d[key]

پاسخ:

  • خطا ۱: KeyError. کلید age وجود ندارد. راه‌حل: از person.get("age", "نامشخص") استفاده کنید.
  • خطا ۲: AttributeError. {} یک دیکشنری است، نه set. دیکشنری متد add ندارد. راه‌حل: colors = set() یا colors["red"] = True.
  • خطا ۳: TypeError: unhashable type: 'list'. لیست نمی‌تواند کلید دیکشنری باشد. راه‌حل: از تاپل استفاده کنید: data[(1, 2)] = "value".
  • خطا ۴: RuntimeError. دیکشنری هنگام پیمایش تغییر می‌کند. راه‌حل: روی یک کپی از کلیدها حلقه بزنید: for key in list(d.keys()):.

نسخه‌ی اصلاح‌شده:

fixed.pyPython
# اصلاح 1
person = {"name": "علی"}
print(person.get("age", "نامشخص"))

# اصلاح 2
colors = set()
colors.add("red")
print(colors)

# اصلاح 3
data = {}
data[(1, 2)] = "value"
print(data)

# اصلاح 4
d = {"a": 1, "b": 2, "c": 3}
for key in list(d.keys()):
    if d[key] > 1:
        del d[key]
print(d)   # {'a': 1}
بخش ۱۱

📝 آزمون تعاملی فصل

پرسش‌های چهارگزینه‌ای زیر را پاسخ دهید؛ بلافاصله بعد از انتخاب، پاسخ درست و توضیحش را می‌بینید. حد نصاب قبولی ۶۰٪ است و بهترین نمره‌تان ذخیره می‌شود.

۱) کدام سینتکس برای ساخت یک دیکشنری خالی درست است؟

💡 دیکشنری خالی با {} ساخته می‌شود. [] لیست خالی، () تاپل خالی، و set() set خالی است.

۲) خروجی {"a": 1, "b": 2}.get("c", 0) چیست؟

💡 .get("c", 0) یعنی «اگر c بود، مقدارش را بده؛ وگرنه 0». چون کلید c وجود ندارد، مقدار پیش‌فرض 0 برگردانده می‌شود.

۳) کدام یک set است، نه دیکشنری؟

💡 {1, 2, 3} یک set است — چون فقط مقادیر دارد، نه جفت کلید-مقدار. توجه کنید که {"key"} هم یک set تک‌عضوی است، اما گزینه‌ی ج درست، واضح‌ترین است.

۴) خروجی {1, 2, 3} & {3, 4, 5} چیست؟

💡 عملگر & اشتراک (intersection) است — یعنی اعضای مشترک. عدد ۳ در هر دو set هست، پس نتیجه {3} است.

۵) کدام الگو برای شمارش در دیکشنری صحیح است؟

💡 الگوی d[key] = d.get(key, 0) + 1 اگر کلید باشد، به مقدارش یک اضافه می‌کند؛ اگر نباشد، از صفر شروع می‌کند. گزینه‌ی الف برای کلیدهای جدید خطا می‌دهد.

۶) برای پیمایش دیکشنری و دسترسی همزمان به کلید و مقدار، کدام متد درست است؟

💡 .items() جفت‌های کلید-مقدار را به‌صورت تاپل برمی‌گرداند. با for k, v in d.items(): همزمان به هر دو دسترسی دارید.
بخش ۱۲

🎯 جمع‌بندی و دستاوردها

در این فصل یاد گرفتید:

  • دیکشنری چیست و چطور با { "کلید": مقدار } بسازید.
  • دسترسی با کروشه [ ] و روش امن با .get().
  • اضافه کردن و ویرایش با انتساب مستقیم.

❓ سوالات متداول و گام بعدی

آیا دیکشنری ترتیب دارد؟

از پایتون ۳.۷ به بعد، بله — دیکشنری ترتیب درج اعضا را حفظ می‌کند. یعنی اگر «علی» را اول اضافه کنید و «رضا» را بعد، هنگام پیمایش، علی اول می‌آید. اما توجه کنید که این ترتیب «قابل اعتماد برای منطق برنامه» نیست — به آن به‌عنوان یک ویژگی مفید نگاه کنید، نه تضمین.

آیا set ترتیب دارد؟

خیر — set هیچ ترتیب تضمین‌شده‌ای ندارد. اگر روی یک set حلقه بزنید، ممکن است ترتیب اعضا هر بار متفاوت باشد. اگر ترتیب مهم است، از لیست استفاده کنید یا set را با sorted() مرتب کنید.

تفاوت pop() و popitem() در دیکشنری چیست؟

pop(key) با مشخص کردن کلید، آن جفت را حذف می‌کند و مقدارش را برمی‌گرداند. popitem() آخرین جفت اضافه‌شده را حذف می‌کند و خودِ جفت را به‌صورت تاپل برمی‌گرداند — بدون اینکه لازم باشد کلید را بدانید.

آیا می‌توانم از یک set به‌عنوان کلید دیکشنری استفاده کنم؟

خیر — set تغییرپذیر است و کلید دیکشنری باید تغییرناپذیر باشد. اما frozenset (نسخه‌ی تغییرناپذیر set) می‌تواند کلید باشد. این در فصل‌های پیشرفته‌تر کاربرد دارد.

چطور دو دیکشنری را با هم مقایسه کنم؟

می‌توانید با == مقایسه کنید: اگر محتوا و ترتیب یکسان باشد، True برمی‌گردد. برای پیدا کردن تفاوت‌ها، از عملیات set روی keys() استفاده کنید: set(d1.keys()) - set(d2.keys()) کلیدهایی که فقط در d1 هستند را می‌دهد.

📌 🧭 گام بعدی در فصل ۱۱ با Comprehension و Iterator آشنا می‌شوید: یک روش کوتاه و پایتونیک برای ساخت لیست، دیکشنری و set در یک خط. این یکی از ویژگی‌های منحصر به‌فرد پایتون است که کد شما را کوتاه‌تر، سریع‌تر و خواناتر می‌کند. اگر تا اینجا با ساختمان‌های داده راحت شده‌اید، فصل ۱۱ لذت واقعی پایتون را نشانتان می‌دهد.
