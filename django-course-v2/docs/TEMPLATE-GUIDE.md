
به‌علاوه یک قطعه کوچک **داخل head** که تم و اندازه فونت را پیش از رنگ‌آمیزی صفحه اعمال می‌کند (جلوگیری از سوسو زدن تم).

## ۳) قرارداد واژه‌نامه (هوار + پایان فصل + جامع)

### ۳.۱ نشانه‌گذاری واژه در متن

هر جا اصطلاح تخصصی برای نخستین بار آمد، فقط یک `span`:

```html
<span class="term" data-term="orm">ORM</span>
<span class="term" data-term="migration">مهاجرت</span>
```

- موتور به‌طور خودکار `tabindex` و برچسب‌های دسترسی‌پذیری اضافه می‌کند.
- **دسکتاپ:** هاور → تولتیپ (معادل انگلیسی + ترجمه فارسی + توضیح + لینک واژه‌نامه).
- **موبایل:** لمس → همان تولتیپ؛ لمس بیرون یا Esc → بستن.
- **کیبورد:** Tab تا واژه → نمایش؛ Esc → بستن.
- اگر کلیدی در دیکشنری نباشد، واژه با خط‌چین قرمز علامت می‌خورد (`term-unknown`) تا در بازبینی محتوا پیدا شود.

> نکته ویرایشی: در هر فصل، **اولین کاربرد** هر واژه را نشانه‌گذاری کنید (و مواردی که جای توضیح مجدد دارند). تکرار بیش از حد، متن را شلوغ می‌کند.

### ۳.۲ افزودن واژه جدید به دیکشنری

فقط در فایل `assets/js/glossary-data.js`:

```js
'viewset': {
  en: 'ViewSet',                       // معادل انگلیسی
  fa: 'مجموعه‌ویو',                    // ترجمه/معادل فارسی
  cat: 'API',                          // دسته‌بندی (یکی از ۸ دسته موجود)
  desc: 'کلاسی در DRF که همه عملیات CRUD یک مدل را یکجا فراهم می‌کند.'
},
```

همین یک ورودی، همزمان در **تولتیپ هاور**، **واژه‌نامه پایان فصل** و **واژه‌نامه جامع** ظاهر می‌شود. دسته‌های فعلی: `مبانی وب`، `معماری و ساختار`، `ویو، قالب و URL`، `مدل و پایگاه داده`، `فرم، امنیت و احراز هویت`، `ابزارها و تست`، `API`، `کارایی و استقرار`.

### ۳.۳ واژه‌نامه پایان فصل (بخش ۱۵) — کاملاً خودکار

```html
<section class="part" id="p15">
  <div class="part-head"><span class="part-num">بخش ۱۵</span><h2>📖 واژه‌نامه تخصصی فصل</h2></div>
  <p style="color:var(--muted);font-size:.88rem">توضیح کوتاه...</p>
  <div class="chapter-glossary" data-auto="true"></div>
</section>
```

اسکریپت، همه واژه‌های **به‌کاررفته در همان فصل** را جمع‌آوری و یکتا می‌کند و به‌صورت کارت فهرست می‌سازد؛ با جست‌وجوی زنده و کلیک روی هر کارت → پرش به اولین کاربرد واژه در متن و برجسته‌سازی آن. شمارنده واژه‌ها در هیروی فصل (`#chapter-term-count`) هم خودکار پر می‌شود.

### ۳.۴ واژه‌نامه جامع (`glossary.html`) — کاملاً خودکار

کافی است `<div id="glossary-all"></div>` در صفحه باشد؛ همه ۷۶+ واژه بر اساس دسته‌بندی با جست‌وجوی زنده (فارسی و انگلیسی) رندر می‌شوند.

## ۴) قرارداد آزمون تعاملی (بخش ۱۱)

```html
<div class="quiz" data-id="ch-01" data-title="آزمون فصل ۱ — ..." data-pass="60">

  <div class="quiz-q" data-answer="b">
    <h4 class="quiz-q-text">۱) متن پرسش؟</h4>
    <div class="quiz-opts">
      <button type="button" class="quiz-opt" data-key="a">گزینه ۱</button>
      <button type="button" class="quiz-opt" data-key="b">گزینه ۲</button>
      <button type="button" class="quiz-opt" data-key="c">گزینه ۳</button>
      <button type="button" class="quiz-opt" data-key="d">گزینه ۴</button>
    </div>
    <div class="quiz-explain">💡 توضیح آموزشی پاسخ درست...</div>
  </div>

  <!-- پرسش‌های بعدی ... -->
</div>
```

**قواعد:**

| ویژگی | مقدار |
| --- | --- |
| `data-id` | شناسه یکتای فصل (`ch-01` تا `ch-30`) — کلید ذخیره نمره |
| `data-answer` | کلید گزینه درست (`a`/`b`/`c`/`d`) |
| `data-pass` | حد نصاب قبولی درصدی (پیشنهاد: ۶۰) |
| توضیح پاسخ | `<div class="quiz-explain">` یا ویژگی `data-explain="..."` روی پرسش |
| حروف گزینه‌ها | خودکار «الف/ب/ج/د» درج می‌شود (`data-key-fa` برای override) |

**امکانات موتور (همه خودکار):** بازخورد فوری سبز/قرمز + نمایش گزینه درست، توضیح هر پرسش، نوار پیشرفت و شمارنده، زمان‌سنج زنده، کارت نتیجه (درصد، قبولی، ستاره ⭐ تا ⭐⭐⭐، رکورد جدید)، ذخیره بهترین نمره، شروع دوباره، مرور پاسخ‌های نادرست، نشان‌کردن پرسش‌ها 🚩 و فیلتر نشان‌شده‌ها.

**توصیه محتوایی:** هر فصل ≥ ۶ پرسش؛ توزیع گزینه درست یکنواخت باشد؛ هر پرسش یک مفهوم را بسنجد و توضیح پاسخ، «چرایی» را بگوید نه فقط «چیستی».

## ۶) سایر قراردادهای نشانه‌گذاری

**بلوک کد** (دکمه کپی و رنگ‌آمیزی نحو خودکار اضافه می‌شود):

```html
<div class="code-box">
  <div class="code-head"><span>عنوان بلوک</span><span class="lang">Python</span></div>
  <pre class="code"><code data-lang="python"># data-lang: python | bash</code></pre>
</div>
```

**فراخوان‌ها:** `<div class="callout tip|info|warn|danger"><b class="title">💡 عنوان</b> متن</div>`

**پاسخ بازشو:** `<details class="answer"><summary>✅ عنوان پاسخ</summary><div class="answer-body">...</div></details>`

**خطای رایج:** `<div class="err-card"><b class="err-title">❌ عنوان خطا</b> <p>توضیح و راه‌حل</p></div>`

**کد داخل متن:** `<code class="inline-code">manage.py</code>`

**دکمه پایان فصل:** `<button id="mark-done" class="btn" data-chapter="ch-01">✔️ این فصل را تمام کردم</button>`

**پیمایش فصل‌ها:** `#prev-chap` و `#next-chap` در `.pager` (با کیبورد هم کار می‌کنند).

## ۸) میان‌برهای کیبورد

| کلید | کار |
| --- | --- |
| `?` | مودال راهنمای میان‌برها |
