🧱 مبانی و اصول پایه

از صفر شروع کنید؛ این ۶ فصل پایه‌های جنگو است.

🌱 آشنایی با جنگو

وب و HTTP چیست؟ چرا فریم‌ورک؟ معماری MTV، تاریخچه جنگو، تفاوت با Flask و معرفی کامل اکوسیستم آن — بدون نیاز به هیچ پیش‌نیازی.

⏱ ۷۵ دقیقه🎓 صفر مطلق

🛠️ نصب، راه‌اندازی و محیط توسعه

قدم‌به‌قدم نصب پایتون و جنگو، ساخت اولین پروژه، آشنایی با ترمینال، محیط مجازی و اجرای اولین سرور — همراه دستورات ویندوز و مک/لینوکس.

⏱ ۹۰ دقیقه🎓 صفر مطلق

🧩 اپلیکیشن‌ها (Apps) در جنگو

تفاوت پروژه و اپ، ساخت اولین اپ با startapp، ثبت در INSTALLED_APPS و نوشتن اولین ویو و مسیر URL — اولین کد واقعی شما!

⏱ ۸۰ دقیقه🎓 مبتدی

🗄️ مدل‌ها (Models) و پایگاه داده

پایگاه داده و ORM، انواع فیلد و پارامترهایشان، روابط ForeignKey و ManyToMany، کلاس Meta، ساخت مدل وبلاگ و کار با داده در شل جنگو.

⏱ ۱۱۰ دقیقه🎓 مبتدی

🚂 مهاجرت‌ها (Migrations) و مدیریت پایگاه داده

چرخه کامل مهاجرت: makemigrations، migrate، showmigrations و sqlmigrate؛ آناتومی فایل‌های مهاجرت، بازگشت به عقب و مدیریت تغییرات مدل بدون از دست رفتن داده.

⏱ ۸۵ دقیقه🎓 مبتدی

🎛️ پنل مدیریت (Admin Panel)

ساخت ابرکاربر، ثبت مدل‌ها در پنل، شخصی‌سازی با list_display، list_filter، search_fields و fieldsets — و آماده‌سازی پنل برای پروژه واقعی.

⏱ ۸۰ دقیقه🎓 مبتدی

📐 ساختار و Views

مسیریابی، ویوها، قالب‌ها، فرم‌ها و کاربران.

🧭 URLها و مسیریابی (Routing)

کامل‌ترین آموزش مسیریابی: تابع path و تبدیل‌کننده‌های نوع، پارامترهای پویا، include، نام‌گذاری و reverse، فضای نام و re_path — با مثال‌های واقعی وبلاگ.

⏱ ۹۰ دقیقه🎓 مبتدی

🎯 ویوها — ویوی تابعی (FBV)

درخواست و پاسخ، تابع render با قالب و بافت، redirect، get_object_or_404، کلاس‌های HttpResponse و JsonResponse و روش‌های GET و POST — قلب پروژه‌های جنگو.

⏱ ۱۰۰ دقیقه🎓 مبتدی

⚙️ ویوها — ویوی کلاسی (CBV)

ویوهای آماده TemplateView، ListView، DetailView، CreateView، UpdateView و DeleteView با مثال کامل؛ مقایسه FBV با CBV، تابع as_view و شخصی‌سازی با get_context_data.

⏱ ۱۰۵ دقیقه🎓 مبتدی

🎨 قالب‌ها (Templates)

موتور قالب جنگو: متغیرها، تگ‌ها، فیلترها، حلقه و شرط، include، ارث‌بری با extends و block، ساختار حرفه‌ای base.html و امنیت XSS.

⏱ ۱۰۰ دقیقه🎓 مبتدی

📝 فرم‌ها (Forms) در جنگو

کلاس forms.Form و ModelForm، انواع فیلد فرم، ویجتها، اعتبارسنجی با clean_، نمایش فرم و مدیریت خطاها — به‌همراه CSRF.

⏱ ۱۱۰ دقیقه🎓 متوسط

🔐 احراز هویت (Authentication) و کاربران

مدل User، ثبت‌نام با UserCreationForm، ورود و خروج با LoginView و LogoutView، محافظت صفحه‌ها با @login_required و LoginRequiredMixin و ساخت پروفایل کاربری.

⏱ ۱۰۵ دقیقه🎓 متوسط

⚡ پیشرفته‌ها و ابزارها

مجوزها، فایل‌ها، QuerySet پیشرفته، سیگنال‌ها، میان‌افزار و نشست.

🛡️ گروه‌ها و مجوزها (Permissions)

سامانه مجوزهای جنگو: Group و Permission، ساخت گروه در پنل، @permission_required و PermissionRequiredMixin، مجوز سفارشی در Meta و بررسی perms در قالب.

⏱ ۹۵ دقیقه🎓 متوسط

🖼️ فایل‌های ایستا و رسانه (Static و Media)

تفاوت فایل ایستا و رسانه، تنظیمات STATIC_URL و MEDIA_URL، تگ {% static %}، دستور collectstatic و آپلود فایل با FileField و ImageField.

⏱ ۸۵ دقیقه🎓 متوسط

🔍 مدیریت پیشرفته پایگاه داده — QuerySetها

QuerySetهای حرفه‌ای: filter و exclude، شیء Q، order_by، برش، aggregate و annotate، select_related و prefetch_related و حل مشکل N+1.

⏱ ۱۰۵ دقیقه🎓 متوسط

🔔 سیگنال‌ها (Signals) — مدیریت رویدادها

سیگنالهای آماده جنگو: pre_save، post_save، pre_delete، post_delete و m2m_changed؛ ساخت پروفایل خودکار هنگام ثبت‌نام با receiver، مهاجرت داده و کاربردهای واقعی.

⏱ ۸۰ دقیقه🎓 متوسط

🛂 میان‌افزار (Middleware)

زنجیره پردازش درخواست، ساخت میان‌افزار سفارشی، ثبت در MIDDLEWARE، اهمیت ترتیب و کاربردهای واقعی: زمان‌سنجی، لاگ‌گیری، نگهداری و مسدودسازی IP.

⏱ ۸۵ دقیقه🎓 متوسط

🍪 نشست (Session) و کوکی‌ها

ذخیره اطلاعات بین درخواستها با request.session، تفاوت نشست و کوکی، نمونه سبد خرید، تنظیمات عمر نشست و امنیت آن‌ها.

⏱ ۸۰ دقیقه🎓 متوسط

🎨 بهینه‌سازی و API

کش، تست، اشکال‌زدایی و ساخت API حرفه‌ای.

⚡ کش کردن (Cache)

چرا کش؟ بک‌اندهای کش (LocalMemory، پایگاه داده، فایل، Redis)، کش ویو با cache_page، تگ {% cache %}، کش دستی با cache.set/get و باطل‌سازی هوشمند.

⏱ ۸۵ دقیقه🎓 متوسط

🧪 تست‌نویسی (Testing) در جنگو

چرا تست؟ TestCase و TestClient، تست مدل‌ها، ویوها و فرم‌ها، setUp، assertهای کاربردی، اجرای تست‌ها و الگوی TDD ساده.

⏱ ۹۵ دقیقه🎓 متوسط

🐞 اشکال‌زدایی (Debug) و لاگ‌گیری

روش‌های حرفه‌ای یافتن ریشه خطا: خواندن Traceback، نقشه راه DEBUG، ابزار pdb، Debug Toolbar، پیکربندی لاگ و صفحه‌های خطای سفارشی.

⏱ ۸۰ دقیقه🎓 متوسط

🔌 REST API با DRF — مقدماتی

ساخت اولین API با Django REST Framework: مفاهیم REST و endpoint، سریالایزرها، APIView، جنریک‌ها و کاوشگر API (Browsable API).

⏱ ۱۰۰ دقیقه🎓 متوسط

🚀 DRF پیشرفته — ViewSet، مجوزها و JWT

ViewSet و Router برای CRUD فشرده، کلاس‌های مجوز، صفحه‌بندی و فیلترینگ، Throttling، احراز هویت Token/JWT و مستندسازی OpenAPI.

⏱ ۱۰۵ دقیقه🎓 پیشرفته

🕐 تسک‌های ناهمگام با Celery

کارهای زمان‌بر (ایمیل، پردازش تصویر، گزارش) را از چرخه درخواست بیرون می‌کشیم: Celery + بروکر Redis، تسک‌ها، زمان‌بندی، تلاش مجدد و پایش.

⏱ ۱۱۰ دقیقه🎓 پیشرفته

🌍 چندزبانه‌سازی و بومی‌سازی (i18n/L10n)

سایت چندزبانه با i18n جنگو: gettext در کد و قالب، فایل‌های .po/.mo، تغییر زبان کاربر، فرمت تاریخ و عدد فارسی و منطقه زمانی.

⏱ ۸۰ دقیقه🎓 متوسط

🚀 استقرار و پروژه‌های عملی

زبان‌سازی، استقرار، کارایی و پروژه‌های واقعی.

📦 استقرار (Deployment) روی سرور واقعی

از localhost تا اینترنت: آماده‌سازی امن پروژه، PostgreSQL، Gunicorn و Nginx، فایل‌های ایستا، HTTPS رایگان، systemd و داکر — با چک‌لیست نهایی استقرار.

⏱ ۱۲۰ دقیقه🎓 پیشرفته

🏎️ بهینه‌سازی کارایی (Performance)

متدولوژی بهینه‌سازی: اول اندازه‌گیری، بعد اصلاح. ایندکس‌ها، کوئری‌های بهینه، N+1، لایه‌های کش، GZip، تصاویر و پایش تولید.

⏱ ۹۵ دقیقه🎓 پیشرفته

🎭 جنگو و فرانت‌اند — HTMX، Tailwind و SPA

طیف انتخاب فرانت‌اند برای جنگو: قالب‌ها + HTMX برای تعامل بدون JS سنگین، Tailwind برای استایل، و React/Vue + DRF برای SPA — با مثال عملی هرکدام.

⏱ ۱۰۵ دقیقه🎓 پیشرفته

🆕 جنگوی امروز — 5.2 LTS و 6.0

چه چیزی در جنگو ۵.۲ (LTS) و ۶.۰ تازه است: Background Tasks داخلی، Template Partials، پشتیبانی بومی CSP، کلیدهای اصلی مرکب، AsyncPaginator و متدولوژی ارتقای نسخه.

⏱ ۹۰ دقیقه🎓 پیشرفته

🏆 پروژه‌های عملی نهایی

سه پروژه کامل که همه دوره را به کار می‌گیرند: پلتفرم وبلاگ‌نویسی چند نویسنده، فروشگاه اینترنتی و سامانه مدیریت وظایف تیمی — با نقشه راه مرحله‌به‌مرحله و چک‌لیست کیفیت.

⏱ ۱۲۰ دقیقه🎓 پیشرفته
