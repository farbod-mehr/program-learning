# 🌿 دوره جامع جنگو (Django) — نسخه ۲ کامل

**۳۰ فصل کامل فارسی، از صفر مطلق تا سطح حرفه‌ای — با واژه‌نامه هاور، آزمون تعاملی نمره‌دار و داشبورد پیشرفت**

همه ۳۰ فصل دوره تولید شده و آماده مطالعه است. پروژه HTML ایستا و کاملاً آفلاین است: `index.html` را در مرورگر باز کنید — بدون سرور، بدون اینترنت، بدون نصب.

---

## 🚀 شروع سریع

1. پوشه پروژه را دانلود و از حالت فشرده خارج کنید.
2. فایل **`index.html`** را دابل‌کلیک کنید.
3. «شروع یادگیری از فصل ۱» را بزنید و از فصل ۱ تا ۳۰ پیش بروید.

## ✨ قابلیت‌ها

- 🖱️ **واژه‌نامه هاور** — روی هر واژه تخصصی خط‌چین‌دار، موس را ببرید (موبایل: لمس کنید): معادل انگلیسی + ترجمه فارسی + توضیح کوتاه + لینک واژه‌نامه
- 📖 **واژه‌نامه پایان هر فصل** (بخش ۱۵) — به‌طور خودکار از واژه‌های همان فصل ساخته می‌شود + جست‌وجو + پرش به کاربرد واژه در متن
- 🌐 **واژه‌نامه جامع دوره** (`glossary.html`) — ۱۲۱ واژه در ۸ دستهٔ موضوعی با جست‌وجوی زنده
- 📝 **آزمون تعاملی چندگزینه‌ای** (بخش ۱۱) — بازخورد فوری، توضیح هر پرسش، زمان‌سنج، حد نصاب قبولی، ستاره، بهترین رکورد، شروع دوباره، مرور نادرست‌ها، نشان‌کردن پرسش‌ها 🚩
- 📊 **داشبورد یادگیری** — درصد پیشرفت دوره، آزمون‌های داده‌شده، میانگین نمرات + نشان نمره روی کارت هر فصل
- 📓 **یادداشت‌های من** (بخش ۱۶) — ذخیره خودکار در مرورگر
- 🌙 **حالت تاریک** + 🔠 **تنظیم اندازه فونت** (سه سطح)
- 🎨 **رنگ‌آمیزی نحو کد** پایتون، بش، HTML، JSON و متن (بدون کتابخانه خارجی)
- ⌨️ **میان‌برهای کیبورد**: `?` راهنما، `/` جست‌وجو، `D` تم، جهت‌نماها پیمایش فصل
- 🔔 **توست** برای همه رویدادها، ♿ بهبود دسترسی‌پذیری، 🖨️ حالت چاپ تمیز
- 🔍 **جست‌وجو و فیلتر فصل‌ها** در صفحه اصلی

## 📐 ساختار پروژه

```text
django-course-v2/
├── index.html                  ← صفحه اصلی + داشبورد + فهرست ۳۰ فصل
├── glossary.html               ← واژه‌نامه جامع
├── assets/css/style.css        ← استایل کامل (روشن/تاریک)
├── assets/js/                  ← util / glossary-data / glossary / quiz / app
├── chapters/chapter-01..30/    ← ۳۰ فصل کامل با قالب ۱۶ بخشی
├── docs/REVIEW.md              ← بررسی نسخه قبل
├── docs/TEMPLATE-GUIDE.md      ← راهنمای قالب و قراردادها
└── tools/
    ├── build_chapters.py       ← تولیدکننده فصل‌های ۲ تا ۳۰
    ├── data_chapters.py        ← ترکیب داده فصل‌ها + پیمایش قبلی/بعدی
    ├── data_a.py … data_f.py   ← محتوای فصل‌ها (۲-۶ … ۲۶-۳۰)
    └── build_home_cards.py     ← تولید کارت فصل‌های صفحه اصلی
```

**قالب ۱۶ بخشی هر فصل:** ۱ چشم‌انداز • ۲ نقشه راه • ۳ سوالات محرک • ۴ آماده‌سازی • ۵ آموزش مفاهیم • ۶ مثال عملی • ۷ کارگاه عملی • ۸ پاسخ کارگاه • ۹ خطاهای رایج • ۱۰ تمرین تثبیت • ۱۱ **آزمون تعاملی** • ۱۲ پروژه فصل • ۱۳ جمع‌بندی • ۱۴ سوالات متداول • ۱۵ **واژه‌نامه فصل** • ۱۶ **یادداشت‌های من**

## 🔧 بازتولید فصل‌ها

فصل ۱ دست‌نویس است؛ فصل‌های ۲ تا ۳۰ از داده‌های `tools/data_*.py` تولید می‌شوند:

```bash
cd tools
python3 data_chapters.py      # فهرست و سلامت داده فصل‌ها
python3 build_chapters.py     # بازتولید chapters/chapter-02..30 + کنترل کیفیت
python3 build_home_cards.py   # بازتولید کارت‌های صفحه اصلی
```

`build_chapters.py` هنگام ساخت، خودکار بررسی می‌کند: همه `data-term`ها در واژه‌نامه موجود باشند، هر آزمون ≥۶ پرسش با ۴ گزینه داشته باشد، هیچ بخش ۱۶گانه خالی نباشد و جای‌گذاری پرنشده نماند.
