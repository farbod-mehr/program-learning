# دوره جامع Python (اسکلت ۱۴ بخشی)

این مخزن شامل یک دوره کامل Python با ۳۵ فصل است که هر فصل بر اساس ساختار آموزشی ۱۴ بخشی (شامل نقشه راه، سوالات محرک، خطاهای رایج و پروژه نهایی) طراحی شده است.

## ساختار پوشه‌ها
- **`assets/`** : فایل‌های CSS، JS و تصاویر مشترک
- **`chapters/`** : پوشه‌های هر فصل (هر کدام شامل `index.html`)

## نحوه استفاده
۱. فایل `index.html` را در مرورگر باز کنید.
۲. از فهرست، فصل مورد نظر را انتخاب کنید.
۳. در هر فصل، می‌توانید با لینک‌های قبلی/بعدی بین فصل‌ها حرکت کنید.

## توسعه و تکمیل محتوا
برای هر فصل، فایل `index.html` مربوطه را ویرایش کنید و بخش‌های placeholder را با محتوای واقعی (متن، مثال، کد، تصویر) پر کنید.

## ویژگی‌ها
- ✅ ۳۵ فصل پوشش‌دهنده تمام مباحث Python از پایه تا پیشرفته
- ✅ ساختار ۱۴ بخشی در هر فصل (همانند دوره‌های حرفه‌ای)
- ✅ طراحی واکنش‌گرا و زیبا
- ✅ پیمایش آسان با لینک‌های قبلی/بعدی
- ✅ آماده برای انتشار به عنوان سایت استاتیک
