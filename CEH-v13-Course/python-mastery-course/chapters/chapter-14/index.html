کار با فایل‌ها یکی از مهم‌ترین مهارت‌های هر برنامه‌نویس پایتون است. با فایل‌ها می‌توانید داده‌ها را ذخیره کنید، تنظیمات برنامه را نگه دارید، لاگ‌ها را ثبت کنید، داده‌ها را با برنامه‌های دیگر به اشتراک بگذارید و خیلی کارهای دیگر.

در این فصل با همه‌ی مباحث کار با فایل‌ها آشنا می‌شوید: باز کردن، خواندن، نوشتن، بستن، کار با CSV، JSON، فایل‌های باینری و مدیریت مسیرها.

🧠 بدنه اصلی آموزش

۱۴.۱ باز کردن فایل با open() و حالت‌های مختلف

تابع open() برای باز کردن فایل‌ها استفاده می‌شود و یک شیء فایل برمی‌گرداند. دو پارامتر اصلی: نام فایل و حالت (mode).

  • حالت‌های اصلی (Mode):
    • 'r' – خواندن (پیش‌فرض) – فایل باید وجود داشته باشد.
    • 'w' – نوشتن – اگر فایل وجود داشته باشد، محتوای آن پاک می‌شود. اگر نباشد، ایجاد می‌شود.
    • 'a' – افزودن (append) – به انتهای فایل اضافه می‌کند.
    • 'x' – ایجاد انحصاری – اگر فایل وجود داشته باشد، خطا می‌دهد.
    • 'b' – حالت باینری (مثل 'rb'، 'wb').
    • 't' – حالت متنی (پیش‌فرض – 'rt').
    • '+' – خواندن و نوشتن همزمان (مثل 'r+'، 'w+').
# باز کردن فایل برای خواندن (پیش‌فرض)
file = open("test.txt", "r")
content = file.read()
file.close()

# باز کردن فایل برای نوشتن (محتوای قبلی پاک می‌شود)
file = open("test.txt", "w")
file.write("Hello World!")
file.close()

# باز کردن فایل برای افزودن به انتها
file = open("test.txt", "a")
file.write(" - اضافه شد")
file.close()

# باز کردن فایل برای خواندن و نوشتن
file = open("test.txt", "r+")
content = file.read()
file.write(" جدید")
file.close()

# باز کردن فایل در حالت باینری
file = open("image.jpg", "rb")
data = file.read()
file.close()
حالت توضیح فایل وجود دارد فایل وجود ندارد 'r' خواندن ✅ باز می‌شود ❌ FileNotFoundError 'w' نوشتن (پاک می‌کند) ✅ پاک و باز ✅ ایجاد می‌کند 'a' افزودن به انتها ✅ باز (انتهای فایل) ✅ ایجاد می‌کند 'x' ایجاد انحصاری ❌ FileExistsError ✅ ایجاد می‌کند
💡 نکته: همیشه بعد از کار با فایل، آن را با close() ببندید. اما بهتر است از with استفاده کنید که به‌طور خودکار فایل را می‌بندد (بخش بعدی).
🧪 تمرین: یک فایل جدید با نام sample.txt در حالت نوشتن ایجاد کنید و یک متن در آن بنویسید. سپس با حالت خواندن آن را باز کنید و محتوا را چاپ کنید.

۱۴.۲ خواندن از فایل: read()، readline() و readlines()

سه روش اصلی برای خواندن محتوای فایل:

  • read(size): کل فایل یا تعداد مشخصی کاراکتر را می‌خواند.
  • readline(): یک خط کامل را می‌خواند (تا \n).
  • readlines(): همه‌ی خطوط را به‌صورت لیست برمی‌گرداند.
# خواندن کل فایل
with open("test.txt", "r") as f:
    content = f.read()
    print(content)

# خواندن تعداد مشخصی کاراکتر
with open("test.txt", "r") as f:
    part = f.read(10)  # ۱۰ کاراکتر اول
    print(part)

# خواندن خط به خط با readline()
with open("test.txt", "r") as f:
    line = f.readline()
    while line:
        print(line.strip())
        line = f.readline()

# خواندن همه‌ی خطوط با readlines()
with open("test.txt", "r") as f:
    lines = f.readlines()
    for line in lines:
        print(line.strip())

# پیمایش مستقیم با for (رایج‌ترین روش)
with open("test.txt", "r") as f:
    for line in f:
        print(line.strip())
💎 نکته طلایی: برای فایل‌های بزرگ، از for line in f استفاده کنید که خط‌به‌خط می‌خواند و حافظه را کم مصرف می‌کند. از read() برای فایل‌های کوچک استفاده کنید.
🧪 تمرین: یک فایل با چند خط متن ایجاد کنید. با استفاده از readlines() همه‌ی خطوط را بخوانید و با enumerate() شماره‌ی هر خط را چاپ کنید.

۱۴.۳ نوشتن در فایل: write() و writelines()

دو روش اصلی برای نوشتن در فایل:

  • write(string): یک رشته را در فایل می‌نویسد.
  • writelines(list): یک لیست از رشته‌ها را می‌نویسد (بدون اضافه کردن \n).
# نوشتن یک رشته
with open("output.txt", "w") as f:
    f.write("سلام دنیا!\n")
    f.write("این خط دوم است.\n")

# نوشتن با writelines
lines = ["خط اول\n", "خط دوم\n", "خط سوم\n"]
with open("output.txt", "w") as f:
    f.writelines(lines)

# افزودن به فایل (append)
with open("output.txt", "a") as f:
    f.write("این خط به انتها اضافه شد.\n")

# نوشتن با استفاده از join
items = ["سیب", "موز", "پرتقال"]
with open("fruits.txt", "w") as f:
    f.write("\n".join(items))

# نوشتن داده‌های ساختاریافته
data = [
    {"name": "علی", "age": 25},
    {"name": "سارا", "age": 30}
]
with open("data.txt", "w") as f:
    for item in data:
        f.write(f"{item['name']},{item['age']}\n")
💡 نکته: writelines() به‌طور خودکار \n اضافه نمی‌کند. باید خودتان خط جدید را مدیریت کنید.
🧪 تمرین: یک لیست از ۵ اسم حیوان ایجاد کنید. با استفاده از writelines() آنها را در یک فایل بنویسید و سپس فایل را بخوانید و محتوا را چاپ کنید.

۱۴.۴ مدیریت خودکار فایل با with

with یک Context Manager است که به‌طور خودکار فایل را بعد از پایان بلوک می‌بندد، حتی اگر خطا رخ دهد. این روش امن‌ترین و خوانا‌ترین روش برای کار با فایل‌هاست.

# با with (توصیه‌شده)
with open("test.txt", "r") as f:
    content = f.read()
    print(content)
# فایل به‌طور خودکار بسته می‌شود

# بدون with (قدیمی)
f = open("test.txt", "r")
try:
    content = f.read()
    print(content)
finally:
    f.close()

# چندین فایل با with
with open("input.txt", "r") as infile, open("output.txt", "w") as outfile:
    content = infile.read()
    outfile.write(content.upper())

# with در توابع
def read_file_safe(filename):
    try:
        with open(filename, "r") as f:
            return f.read()
    except FileNotFoundError:
        return "فایل وجود ندارد!"

print(read_file_safe("test.txt"))
print(read_file_safe("notexist.txt"))
💎 نکته طلایی: همیشه از with برای کار با فایل‌ها استفاده کنید. این کار از نشت منابع جلوگیری می‌کند و کد را تمیزتر می‌کند.
🧪 تمرین: یک تابع copy_file(src, dst) بنویسید که با استفاده از with محتویات یک فایل را به فایل دیگر کپی کند.

۱۴.۵ کار با فایل‌های CSV

CSV (Comma-Separated Values) یک فرمت ساده برای ذخیره‌سازی داده‌های جدولی است. ماژول csv ابزارهای کامل برای خواندن و نوشتن CSV ارائه می‌دهد.

import csv

# نوشتن در فایل CSV
data = [
    ["name", "age", "city"],
    ["علی", 25, "تهران"],
    ["سارا", 30, "اصفهان"],
    ["رضا", 28, "شیراز"]
]

with open("users.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(data)

# نوشتن با DictWriter
fieldnames = ["name", "age", "city"]
data2 = [
    {"name": "علی", "age": 25, "city": "تهران"},
    {"name": "سارا", "age": 30, "city": "اصفهان"}
]

with open("users_dict.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(data2)

# خواندن از فایل CSV
with open("users.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# خواندن با DictReader
with open("users_dict.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(f"{row['name']} - {row['age']} - {row['city']}")
➜ ['name', 'age', 'city']
➜ ['علی', '25', 'تهران']
➜ علی - 25 - تهران
💡 نکته: پارامتر newline="" در open() از ایجاد خطوط خالی اضافی در فایل‌های CSV جلوگیری می‌کند.
🧪 تمرین: یک فایل CSV با اطلاعات چند دانش‌آموز (نام، نمره، کلاس) ایجاد کنید. سپس با csv.reader آن را بخوانید و میانگین نمرات را محاسبه کنید.

۱۴.۶ کار با فایل‌های JSON

JSON (JavaScript Object Notation) یک فرمت استاندارد برای تبادل داده است که در وب بسیار رایج است. ماژول json برای کار با JSON در پایتون استفاده می‌شود.

import json

# داده‌های نمونه
data = {
    "name": "علی",
    "age": 25,
    "city": "تهران",
    "skills": ["Python", "JavaScript", "CSS"],
    "is_student": False
}

# نوشتن در فایل JSON
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# خواندن از فایل JSON
with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
    print(loaded["name"])      # "علی"
    print(loaded["skills"])    # ['Python', 'JavaScript', 'CSS']

# تبدیل رشته JSON به دیکشنری
json_str = '{"name": "سارا", "age": 30}'
parsed = json.loads(json_str)
print(parsed["name"])  # "سارا"

# تبدیل دیکشنری به رشته JSON
dict_data = {"name": "رضا", "age": 28}
json_str2 = json.dumps(dict_data, ensure_ascii=False)
print(json_str2)  # {"name": "رضا", "age": 28}

# مدیریت خطاها در JSON
try:
    with open("invalid.json", "r") as f:
        data = json.load(f)
except json.JSONDecodeError:
    print("❌ فایل JSON نامعتبر است!")
except FileNotFoundError:
    print("❌ فایل وجود ندارد!")
➜ علی
➜ ['Python', 'JavaScript', 'CSS']
💎 نکته طلایی: از json.dump() با indent=2 و ensure_ascii=False برای ذخیره‌سازی خوانا و پشتیبانی از فارسی استفاده کنید.
🧪 تمرین: یک دیکشنری از اطلاعات یک کتاب (عنوان، نویسنده، سال، قیمت) ایجاد کنید و آن را در یک فایل JSON ذخیره کنید. سپس فایل را بخوانید و اطلاعات را چاپ کنید.

۱۴.۷ مدیریت مسیرها و دایرکتوری‌ها با os و pathlib

برای کار با مسیرها، دایرکتوری‌ها و فایل‌ها در سیستم‌عامل، از ماژول‌های os و pathlib استفاده می‌شود.

import os
from pathlib import Path

# os - کار با مسیرها و دایرکتوری‌ها
print(os.getcwd())                    # مسیر فعلی
os.mkdir("new_folder")                # ایجاد دایرکتوری
os.chdir("new_folder")                # تغییر مسیر
os.rmdir("new_folder")                # حذف دایرکتوری (خالی)

# os.path - کار با مسیرها
print(os.path.exists("test.txt"))     # وجود فایل
print(os.path.isfile("test.txt"))     # آیا فایل است؟
print(os.path.isdir("new_folder"))    # آیا دایرکتوری است؟
print(os.path.join("folder", "file.txt"))  # folder/file.txt
print(os.path.basename("/path/to/file.txt"))  # file.txt
print(os.path.dirname("/path/to/file.txt"))   # /path/to

# pathlib - روش مدرن‌تر (توصیه‌شده)
path = Path("test.txt")
print(path.exists())                  # وجود فایل
print(path.is_file())                 # آیا فایل است؟
print(path.parent)                    # دایرکتوری والد
print(path.name)                      # نام فایل
print(path.stem)                      # نام بدون پسوند
print(path.suffix)                    # پسوند (.txt)

# ایجاد دایرکتوری با pathlib
Path("data/images").mkdir(parents=True, exist_ok=True)

# لیست فایل‌های یک دایرکتوری
for file in Path(".").iterdir():
    if file.is_file():
        print(f"📄 {file.name}")
    else:
        print(f"📁 {file.name}")

# جستجوی فایل‌ها با الگو (glob)
for file in Path(".").glob("*.py"):
    print(file)
📁 project/
  ├── 📄 main.py
  ├── 📄 config.json
  ├── 📁 utils/
  │  ├── 📄 __init__.py
  │  └── 📄 helpers.py
  └── 📁 data/
     ├── 📄 users.csv
     └── 📄 data.json
💡 نکته: pathlib روش مدرن‌تر و شی‌گرا برای کار با مسیرهاست و در پروژه‌های جدید توصیه می‌شود.
🧪 تمرین: با استفاده از pathlib، یک دایرکتوری به نام backup ایجاد کنید. سپس همه‌ی فایل‌های .txt را از دایرکتوری فعلی به دایرکتوری backup کپی کنید.

تمرین عملی

یک برنامه بنویسید که:

  • یک فایل students.csv با ستون‌های name, grade, subject ایجاد کند.
  • با csv.writer ۵ دانش‌آموز را در آن بنویسد.
  • با csv.DictReader فایل را بخواند و میانگین نمرات را محاسبه کند.
  • نتیجه را در یک فایل summary.json ذخیره کند.

📌 جمع‌بندی و خلاصه

نکات طلایی

  • 🔹 open() برای باز کردن فایل با حالت‌های 'r'، 'w'، 'a'، 'x'.
  • 🔹 with برای مدیریت خودکار فایل‌ها (بستن خودکار).
  • 🔹 خواندن: read()، readline()، readlines().
  • 🔹 نوشتن: write()، writelines().
  • 🔹 CSV با ماژول csv (reader، writer، DictReader، DictWriter).
  • 🔹 JSON با ماژول json (dump، load، dumps، loads).
  • 🔹 os و pathlib برای مدیریت مسیرها و دایرکتوری‌ها.
  • 🔹 همیشه از with و مدیریت خطاها استفاده کنید.

برگه تقلب

# باز کردن فایل
with open("file.txt", "r") as f:
    content = f.read()

# نوشتن
with open("file.txt", "w") as f:
    f.write("Hello")

# CSV
import csv
with open("data.csv", "r") as f:
    reader = csv.reader(f)
    for row in reader: ...

# JSON
import json
with open("data.json", "w") as f:
    json.dump(data, f)

# مسیرها
from pathlib import Path
p = Path("file.txt")
p.exists()
p.is_file()

# os
import os
os.getcwd()
os.mkdir("folder")

📖 واژه‌نامه تخصصی

  • File I/O: ورودی/خروجی فایل – خواندن و نوشتن در فایل‌ها.
  • Mode (حالت): نحوه‌ی باز کردن فایل ('r', 'w', 'a', ...).
  • Context Manager: شیءی که منابع را با with مدیریت می‌کند.
  • CSV: فرمت داده‌های جدولی با جداکننده‌ی کاما.
  • JSON: فرمت استاندارد تبادل داده (JavaScript Object Notation).
  • Serialization (سریال‌سازی): تبدیل داده به فرمت قابل ذخیره‌سازی.
  • Deserialization (دی‌سریال‌سازی): تبدیل داده ذخیره‌شده به ساختار داده.
  • Path (مسیر): آدرس یک فایل یا دایرکتوری در سیستم‌عامل.
  • Directory (دایرکتوری): پوشه‌ای که فایل‌ها را سازماندهی می‌کند.

❓ سوالات محرک (برای درگیری ذهن)

  • ❓ اگر یک فایل را با 'w' باز کنیم و بعد از آن با 'r' بخوانیم، چه اتفاقی می‌افتد؟
  • ❓ چرا with بهتر از try/finally برای مدیریت فایل‌هاست؟
  • ❓ چه تفاوتی بین ذخیره‌سازی داده‌ها در CSV و JSON وجود دارد؟
  • ❓ اگر یک فایل JSON بزرگ داشته باشیم، چگونه می‌توانیم بدون بارگذاری کامل، آن را پردازش کنیم؟
  • ❓ چه تفاوتی بین os.path و pathlib وجود دارد؟ کدام یک بهتر است؟

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن بستن فایل با close() (یا استفاده نکردن از with).
    🔧 راه حل: همیشه از with استفاده کنید تا فایل به‌طور خودکار بسته شود.
  • 🔴 اشتباه: استفاده از 'r' برای فایلی که وجود ندارد که باعث FileNotFoundError می‌شود.
    🔧 راه حل: قبل از باز کردن، وجود فایل را با os.path.exists() بررسی کنید یا از try/except استفاده کنید.
  • 🔴 اشتباه: فراموش کردن newline="" در open() برای CSV که باعث ایجاد خطوط خالی اضافی می‌شود.
    🔧 راه حل: همیشه از newline="" در open() برای فایل‌های CSV استفاده کنید.
  • 🔴 اشتباه: استفاده از json.load() برای فایلی که JSON معتبر ندارد که باعث JSONDecodeError می‌شود.
    🔧 راه حل: از try/except برای مدیریت خطاهای JSON استفاده کنید.
  • 🔴 اشتباه: استفاده از مسیرهای نسبی بدون در نظر گرفتن دایرکتوری فعلی که ممکن است فایل پیدا نشود.
    🔧 راه حل: از os.path.join() یا Path() برای ساخت مسیرهای صحیح استفاده کنید.

🏆 پروژه نهایی این فصل

عنوان پروژه: ساخت یک سیستم مدیریت کتابخانه با فایل‌های JSON

شرح: یک برنامه‌ی خط فرمان برای مدیریت کتابخانه با ذخیره‌سازی در فایل JSON بسازید:

  • داده‌های کتاب‌ها را در یک فایل library.json ذخیره کنید (لیست دیکشنری‌ها).
  • از ماژول‌های json، os و pathlib استفاده کنید.
  • توابع زیر را پیاده‌سازی کنید:
    • load_books() – بارگذاری کتاب‌ها از فایل JSON.
    • save_books(books) – ذخیره‌سازی کتاب‌ها در فایل JSON.
    • add_book(title, author, year, isbn) – افزودن کتاب جدید.
    • search_books(query) – جستجوی کتاب بر اساس عنوان یا نویسنده.
    • delete_book(isbn) – حذف کتاب بر اساس ISBN.
    • list_books() – نمایش همه‌ی کتاب‌ها.
    • get_stats() – نمایش آمار (تعداد کتاب‌ها، قدیمی‌ترین، جدیدترین).
    • export_to_csv() – خروجی‌گرفتن از کتاب‌ها به فرمت CSV.
  • از with برای کار با فایل‌ها استفاده کنید.
  • مدیریت خطاها (FileNotFoundError، JSONDecodeError) را اضافه کنید.
  • یک منوی تعاملی با while ایجاد کنید.
  • با pathlib، یک پوشه‌ی backup ایجاد کنید و هر بار که برنامه بسته می‌شود، یک نسخه پشتیبان از فایل JSON در آن ذخیره کنید.
  • همه‌ی توابع را با Docstring و Type Hints مستند کنید.

کد خود را در VS Code بنویسید و با python3 main.py اجرا کنید.
