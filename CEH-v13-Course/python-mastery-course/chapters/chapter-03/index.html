  • ✔️ با عملگرهای مقایسه‌ای (==, !=, >, <, >=, <=) شرایط مختلف را بررسی و مقادیر بولی تولید کنید.
  • ✔️ با استفاده از عملگرهای منطقی (and, or, not) شرط‌های پیچیده و چندگانه بسازید و منطق برنامه را کنترل کنید.

  • ✔️ اولویت عملگرها را در عبارات پیچیده به‌درستی مدیریت کنید و با استفاده از پرانتز، کد خوانا و بدون ابهام بنویسید.

🚀 مقدمه و انگیزه‌بخشی

در فصل قبل با متغیرها و انواع داده آشنا شدید – یعنی ذخیره‌سازی داده‌ها. حالا وقت آن است که با عملگرها آشنا شوید که به شما امکان دستکاری و پردازش این داده‌ها را می‌دهند. عملگرها قلب تپنده‌ی هر برنامه هستند؛ بدون آنها نمی‌توانید محاسبه کنید، مقایسه کنید، تصمیم بگیرید یا داده‌ها را تغییر دهید.

در این فصل با همه‌ی عملگرهای اصلی پایتون آشنا می‌شوید: عملگرهای حسابی برای محاسبات ریاضی (از جمع ساده تا توان)، عملگرهای مقایسه‌ای برای بررسی روابط بین مقادیر، عملگرهای منطقی برای ترکیب چند شرط، عملگرهای انتساب برای تغییر مقدار متغیرها، عملگرهای هویتی برای مقایسه‌ی هویت اشیاء در حافظه و عملگرهای عضویت برای بررسی وجود یک عنصر در یک مجموعه.

تسلط بر عملگرها، کلید اصلی نوشتن برنامه‌های کاربردی و هوشمند است. با این فصل، می‌توانید برنامه‌هایی بنویسید که محاسبات پیچیده، مقایسه‌های دقیق و تصمیم‌گیری‌های هوشمندانه انجام دهند. این مهارت‌ها پایه‌ی تمام مباحث بعدی مانند شرط‌ها، حلقه‌ها و توابع هستند.

🧠 بدنه اصلی آموزش

۳.۱ عملگرهای حسابی (Arithmetic Operators)

عملگرهای حسابی برای انجام عملیات ریاضی روی اعداد (صحیح و اعشاری) استفاده می‌شوند. این عملگرها پایه‌ی تمام محاسبات در برنامه‌نویسی هستند.

+ جمع 5 + 3 = 8
- تفریق 5 - 3 = 2
* ضرب 5 * 3 = 15
/ تقسیم اعشاری 10 / 3 = 3.333...
// تقسیم صحیح 10 // 3 = 3
% باقیمانده (مدول) 10 % 3 = 1
** توان 2 ** 3 = 8

نکات مهم:

  • عملگر / همیشه یک عدد اعشاری (float) برمی‌گرداند، حتی اگر حاصل تقسیم دقیق باشد (مثل 4 / 2 که 2.0 می‌شود).
  • عملگر // (تقسیم صحیح) قسمت صحیح حاصل تقسیم را برمی‌گرداند و اعشار را حذف می‌کند (مثبت یا منفی بودن عدد در نحوه‌ی گرد کردن تأثیر دارد).
  • عملگر % (مدول) باقیمانده‌ی تقسیم را برمی‌گرداند و برای کارهایی مثل تشخیص زوج/فرد، چرخش‌های دوره‌ای و محاسبات ماژولار بسیار مفید است.
# ========== عملیات پایه ==========
print(5 + 3)      # 8
print(10 - 4)     # 6
print(6 * 7)      # 42
print(15 / 4)     # 3.75
print(15 // 4)    # 3 (تقسیم صحیح)
print(15 % 4)     # 3 (باقیمانده)
print(2 ** 5)     # 32 (توان)

# ========== ترکیب عملگرها با پرانتز ==========
result = (10 + 5) * 2 - 4
print(result)     # 26

# ========== کاربرد عملی: محاسبه‌ی مساحت و محیط ==========
radius = 5
pi = 3.14159
area = pi * (radius ** 2)      # مساحت دایره: πr²
circumference = 2 * pi * radius  # محیط دایره: 2πr
print(f"مساحت: {area:.2f}, محیط: {circumference:.2f}")

# ========== کاربرد عملی: تبدیل دما ==========
celsius = 25
fahrenheit = (celsius * 9/5) + 32
print(f"{celsius}°C = {fahrenheit:.1f}°F")

# ========== کاربرد عملی: محاسبه‌ی معدل ==========
scores = [18, 15, 19, 14, 17]
average = sum(scores) / len(scores)
print(f"میانگین نمرات: {average:.2f}")

💡 نکته مهم: در پایتون، عملگر / همیشه یک عدد اعشاری برمی‌گرداند. اگر به تقسیم صحیح نیاز دارید، از // استفاده کنید. همچنین عملگر % برای تشخیص زوج بودن عدد (عدد % 2 == 0) بسیار کاربرد دارد.
🧪 تمرین: یک برنامه بنویسید که شعاع یک دایره را از کاربر دریافت کند و محیط و مساحت آن را محاسبه کند. (از pi = 3.14159 استفاده کنید و نتایج را با ۲ رقم اعشار نمایش دهید.)

۳.۲ عملگرهای مقایسه‌ای (Comparison Operators)

عملگرهای مقایسه‌ای دو مقدار را با هم مقایسه می‌کنند و یک مقدار بولی (Boolean) یعنی True یا False برمی‌گردانند. این عملگرها پایه‌ی تصمیم‌گیری در برنامه هستند (در فصل بعد با if از آنها استفاده خواهید کرد).

== برابری 5 == 5 → True
!= نابرابری 5 != 3 → True
> بزرگ‌تر 5 > 3 → True
< کوچک‌تر 3 < 5 → True
>= بزرگ‌تر یا مساوی 5 >= 5 → True
<= کوچک‌تر یا مساوی 3 <= 5 → True

نکات مهم:

  • عملگر == برای مقایسه‌ی مقدار است، در حالی که = برای انتساب (مقداردهی) استفاده می‌شود. اشتباه گرفتن این دو یکی از رایج‌ترین خطاها در برنامه‌نویسی است.
  • رشته‌ها نیز با عملگرهای مقایسه‌ای قابل مقایسه هستند. مقایسه بر اساس ترتیب لغوی (Lexicographic) انجام می‌شود (بر اساس کد ASCII کاراکترها).
  • در مقایسه‌ی رشته‌ها، حروف بزرگ از حروف کوچک کوچک‌تر هستند (چون کد ASCII آنها کمتر است). برای مقایسه‌ی بدون حساسیت به بزرگی/کوچکی، ابتدا رشته‌ها را با lower() یا upper() یکسان کنید.
# ========== مقایسه اعداد ==========
x = 10
y = 20

print(x == y)      # False
print(x != y)      # True
print(x > y)       # False
print(x < y)       # True
print(x >= 10)     # True
print(y <= 20)     # True

# ========== مقایسه رشته‌ها ==========
print("apple" == "apple")      # True
print("apple" != "orange")     # True
print("banana" > "apple")      # True ('b' > 'a')
print("Apple" > "apple")       # False ('A' < 'a' در ASCII)
print("apple".lower() == "APPLE".lower())  # True (نادیده گرفتن حساسیت)

# ========== ترکیب با متغیرها ==========
age = 18
is_adult = age >= 18
print(is_adult)    # True

# ========== کاربرد عملی: بررسی محدوده سنی ==========
age = int(input("سن خود را وارد کنید: "))
is_child = age < 13
is_teen = 13 <= age < 18
is_adult = age >= 18
print(f"کودک: {is_child}, نوجوان: {is_teen}, بزرگسال: {is_adult}")

# ========== مقایسه اعداد اعشاری (دقت) ==========
# توجه: به دلیل نمایش ممیز شناور، مقایسه مستقیم اعداد اعشاری ممکن است دقیق نباشد
print(0.1 + 0.2 == 0.3)   # False (به دلیل خطای گرد کردن)
print(abs((0.1 + 0.2) - 0.3) < 1e-9)  # True (مقایسه با تلورانس)

💎 نکته طلایی: از == برای مقایسه‌ی برابری مقدار استفاده کنید. = عملگر انتساب است و برای مقداردهی استفاده می‌شود. اشتباه گرفتن این دو یکی از رایج‌ترین خطاهاست که منجر به SyntaxError (در صورت استفاده در شرط) یا رفتار نادرست برنامه می‌شود.
🧪 تمرین: یک برنامه بنویسید که دو عدد از کاربر دریافت کند و با عملگرهای مقایسه‌ای مشخص کند که آیا عدد اول بزرگ‌تر، کوچک‌تر یا مساوی عدد دوم است. نتیجه را با پیام مناسب نمایش دهید.

۳.۳ عملگرهای منطقی (Logical Operators)

عملگرهای منطقی برای ترکیب چند شرط بولی و ایجاد منطق پیچیده‌تر استفاده می‌شوند. این عملگرها به شما امکان می‌دهند شرایط چندگانه را در یک عبارت بررسی کنید.

عملگر توضیح مثال نتیجه
and و – True اگر همه شرط‌ها True باشند True and True → True
True and False → False		 True / False
or یا – True اگر حداقل یکی از شرط‌ها True باشد True or False → True
False or False → False		 True / False
not نقیض – برعکس کردن مقدار بولی not True → False
not False → True		 False / True

نکته مهم – Short-circuit (ارزیابی کوتاه‌مدت):

  • در عملگر and، اگر شرط اول False باشد، بقیه‌ی شرط‌ها اصلاً بررسی نمی‌شوند (چون نتیجه قطعاً False است).
  • در عملگر or، اگر شرط اول True باشد، بقیه‌ی شرط‌ها بررسی نمی‌شوند (چون نتیجه قطعاً True است).
  • این ویژگی می‌تواند برای بهینه‌سازی عملکرد و جلوگیری از خطا (مثلاً بررسی وجود یک متغیر قبل از دسترسی به آن) استفاده شود.
# ========== and - هر دو شرط باید True باشند ==========
age = 25
has_license = True
can_drive = age >= 18 and has_license
print(can_drive)   # True

# ========== or - حداقل یکی از شرط‌ها True باشد ==========
is_weekend = True
is_holiday = False
can_rest = is_weekend or is_holiday
print(can_rest)    # True

# ========== not - برعکس کردن ==========
is_raining = False
is_sunny = not is_raining
print(is_sunny)    # True

# ========== ترکیب چند عملگر منطقی ==========
score = 85
is_passed = score >= 60 and score <= 100
print(is_passed)   # True

# ========== کاربرد عملی: بررسی شرایط پیچیده ==========
age = 22
has_permission = True
is_active = False

# کاربر می‌تواند وارد شود اگر سن ≥ ۱۸ و (دسترسی داشته باشد یا فعال باشد)
can_login = (age >= 18) and (has_permission or is_active)
print(f"مجاز به ورود: {can_login}")  # True

# ========== استفاده از Truthy/Falsy در عملگرهای منطقی ==========
name = "Ali"
if name:  # رشته غیرخالی → Truthy
    print("نام وجود دارد")  # این خط اجرا می‌شود

user_input = ""
if not user_input:
    print("ورودی خالی است")  # این خط اجرا می‌شود

# ========== Short-circuit در عملگرهای منطقی ==========
def expensive_check():
    print("بررسی گران‌قیمت انجام شد")
    return True

# شرط دوم بررسی نمی‌شود (چون شرط اول True است و or با True قطعی است)
result = True or expensive_check()  # expensive_check() اجرا نمی‌شود
print(result)  # True

# ========== استفاده از عملگرهای منطقی در شرط‌های لایه‌ای ==========
age = 30
income = 6000000
credit_score = 750

# وام تأیید می‌شود اگر: سن ≥ 18 و درآمد ≥ 5M و امتیاز اعتباری ≥ 700
loan_approved = (age >= 18) and (income >= 5000000) and (credit_score >= 700)
print(f"وام تأیید شد: {loan_approved}")  # True

💡 نکته مهم: عملگرهای منطقی در پایتون Short-circuit هستند. یعنی اگر نتیجه‌ی عبارت از اول مشخص باشد، بقیه‌ی عبارت ارزیابی نمی‌شود. این ویژگی می‌تواند در جلوگیری از خطاهای AttributeError یا IndexError مفید باشد (مثلاً بررسی وجود یک کلید در دیکشنری قبل از دسترسی به آن).
🧪 تمرین: یک برنامه بنویسید که سن و وضعیت تحصیلی کاربر (دانشجو بودن یا نبودن) را دریافت کند و مشخص کند که آیا او واجد شرایط دریافت وام تحصیلی است یا نه. شرایط: سن بین ۱۸ تا ۳۰ سال (شامل) و دانشجو بودن.

۳.۴ عملگرهای انتساب (Assignment Operators)

عملگرهای انتساب برای مقداردهی و به‌روزرسانی متغیرها استفاده می‌شوند. عملگر پایه = است و عملگرهای ترکیبی (مثل +=) یک عملیات حسابی و انتساب را همزمان انجام می‌دهند.

= مقداردهی ساده x = 10
+= افزایش x += 5 → x = x + 5
-= کاهش x -= 3 → x = x - 3
*= ضرب x *= 2 → x = x * 2
/= تقسیم اعشاری x /= 4 → x = x / 4
//= تقسیم صحیح x //= 3 → x = x // 3
%= باقیمانده x %= 5 → x = x % 5
**= توان x **= 2 → x = x ** 2

مزایای استفاده از عملگرهای ترکیبی:

  • کد کوتاه‌تر و خواناتر می‌شود.
  • از تکرار نام متغیر جلوگیری می‌کند و احتمال خطای تایپی را کاهش می‌دهد.
  • در برخی موارد، عملکرد (Performance) بهتری نسبت به نوشتن کامل دارند (اگرچه در پایتون این تفاوت ناچیز است).
# ========== عملگرهای ترکیبی ==========
x = 10
x += 5      # x = 15
x -= 3      # x = 12
x *= 2      # x = 24
x /= 4      # x = 6.0 (تقسیم اعشاری)
x //= 2     # x = 3.0 (تقسیم صحیح)
x %= 2      # x = 1.0
x **= 3     # x = 1.0

print(x)    # 1.0

# ========== کاربرد عملی: شمارنده ==========
counter = 0
counter += 1   # 1
counter += 1   # 2
counter += 1   # 3
print(f"شمارنده: {counter}")  # 3

# ========== کاربرد عملی: محاسبه مجموع ==========
total = 0
for i in range(1, 6):
    total += i  # جمع ۱ تا ۵
print(f"مجموع: {total}")  # 15

# ========== کاربرد عملی: به‌روزرسانی قیمت ==========
price = 100
discount = 20
price -= discount  # قیمت جدید: 80
tax = price * 0.1
price += tax       # قیمت با مالیات: 88
print(f"قیمت نهایی: {price}")  # 88.0

# ========== استفاده از عملگرهای ترکیبی با رشته‌ها ==========
text = "Hello"
text += " World"    # "Hello World"
print(text)         # "Hello World"

# ========== استفاده از عملگرهای ترکیبی با لیست‌ها ==========
my_list = [1, 2, 3]
my_list += [4, 5]   # [1, 2, 3, 4, 5]
print(my_list)      # [1, 2, 3, 4, 5]
➜ 1.0
➜ شمارنده: 3
➜ مجموع: 15
➜ قیمت نهایی: 88.0
➜ Hello World
➜ [1, 2, 3, 4, 5]
💎 نکته طلایی: عملگرهای انتساب ترکیبی کد را کوتاه‌تر و خواناتر می‌کنند. به‌جای x = x + 1 از x += 1 و به‌جای x = x * 2 از x *= 2 استفاده کنید. این کار به‌ویژه در حلقه‌ها و محاسبات تکراری بسیار مفید است.
🧪 تمرین: یک برنامه بنویسید که یک متغیر total با مقدار ۰ داشته باشد. سپس از کاربر ۵ عدد دریافت کند و با استفاده از عملگر += آنها را به total اضافه کند. در نهایت مجموع و میانگین اعداد را چاپ کند.

۳.۵ عملگرهای هویتی (Identity Operators)

عملگرهای هویتی برای بررسی اینکه آیا دو متغیر به همان شیء (Object) در حافظه اشاره می‌کنند یا نه، استفاده می‌شوند. این عملگرها با عملگر == تفاوت دارند: == برابری مقدار را بررسی می‌کند، در حالی که is برابری هویت (آدرس حافظه) را بررسی می‌کند.

  • is: True اگر دو متغیر به یک شیء اشاره کنند.
  • is not: True اگر دو متغیر به اشیاء متفاوتی اشاره کنند.

چه زمانی از is استفاده کنیم؟

  • برای بررسی None: if x is None: (روش استاندارد و توصیه‌شده)
  • برای مقایسه با Singletonها (مانند True، False و None)
  • در مواقعی که نیاز به بررسی هویت شیء دارید (مثلاً در دیباگ)
# ========== اعداد صحیح کوچک (cached) ==========
a = 10
b = 10
print(a is b)        # True (هر دو به یک شیء در حافظه اشاره می‌کنند)

# ========== رشته‌ها (cached) ==========
x = "hello"
y = "hello"
print(x is y)        # True (رشته‌های کوچک در حافظه کش می‌شوند)

# ========== لیست‌ها (هر بار شیء جدید) ==========
list1 = [1, 2, 3]
list2 = [1, 2, 3]
print(list1 is list2)   # False (اشاره به اشیاء متفاوت)
print(list1 == list2)   # True (مقادیر برابر هستند)

# ========== is not ==========
print(list1 is not list2)  # True

# ========== بررسی None (استاندارد) ==========
value = None
if value is None:
    print("مقدار None است")

# ========== مقایسه با True/False ==========
is_active = True
if is_active is True:  # این کار معمولاً لازم نیست، چون خود is_active بولی است
    print("فعال است")

# بهتر است اینطور بنویسید:
if is_active:
    print("فعال است")

# ========== اعداد بزرگ (cached نیستند) ==========
c = 1000
d = 1000
print(c is d)        # False (اعداد بزرگ کش نمی‌شوند)
print(c == d)        # True (مقادیر برابر هستند)

# ========== کاربرد عملی: استفاده از is برای Singleton ==========
# در طراحی الگوهای Singleton یا مقایسه با مقادیر خاص
status = "pending"
if status is not None:
    print(f"وضعیت: {status}")

💡 نکته مهم: برای مقایسه‌ی مقادیر از == استفاده کنید. برای بررسی اینکه آیا دو متغیر به یک شیء اشاره می‌کنند، از is استفاده کنید. معمولاً برای بررسی None از is None استفاده می‌شود که روش استاندارد و توصیه‌شده است.
🧪 تمرین: یک لیست بسازید و آن را به یک متغیر دیگر اختصاص دهید. با is بررسی کنید که آیا هر دو به یک شیء اشاره می‌کنند یا خیر. سپس با == مقادیر را مقایسه کنید. تفاوت را توضیح دهید.

۳.۶ عملگرهای عضویت (Membership Operators)

عملگرهای عضویت برای بررسی وجود یک عنصر در یک مجموعه (لیست، رشته، تاپل، دیکشنری، مجموعه و ...) استفاده می‌شوند. این عملگرها در برنامه‌نویسی روزمره بسیار کاربرد دارند، مخصوصاً برای اعتبارسنجی و جستجو.

  • in: True اگر عنصر در مجموعه وجود داشته باشد.
  • not in: True اگر عنصر در مجموعه وجود نداشته باشد.

نکات مهم:

  • در دیکشنری‌ها، عملگر in کلیدها را بررسی می‌کند، نه مقادیر را. برای بررسی مقادیر از in dict.values() استفاده کنید.
  • عملگرهای عضویت با حساسیت به بزرگی/کوچکی حروف کار می‌کنند. برای جستجوی بدون حساسیت، هر دو طرف را به یک حالت (کوچک یا بزرگ) تبدیل کنید.
  • عملگرهای عضویت در حلقه‌های for نیز برای پیمایش عناصر استفاده می‌شوند.
# ========== لیست ==========
fruits = ["apple", "banana", "orange"]
print("banana" in fruits)        # True
print("grape" in fruits)         # False
print("grape" not in fruits)     # True

# ========== رشته ==========
text = "Hello, World!"
print("World" in text)           # True
print("Python" in text)          # False
print("world" in text)           # False (حساس به بزرگی/کوچکی)

# جستجوی بدون حساسیت
print("world".lower() in text.lower())  # True

# ========== دیکشنری (بررسی کلیدها) ==========
person = {"name": "Ali", "age": 25}
print("name" in person)          # True (کلید وجود دارد)
print("Ali" in person)           # False (مقدار بررسی نمی‌شود)
print("Ali" in person.values())  # True (بررسی مقادیر)

# ========== تاپل ==========
colors = ("red", "green", "blue")
print("green" in colors)         # True

# ========== مجموعه (Set) ==========
numbers = {1, 2, 3, 4, 5}
print(3 in numbers)              # True

# ========== کاربرد عملی: اعتبارسنجی ورودی ==========
allowed_operators = ["+", "-", "*", "/"]
operator = input("عملگر را وارد کنید: ")
if operator in allowed_operators:
    print("عملگر مجاز است")
else:
    print("عملگر نامعتبر است")

# ========== کاربرد عملی: جستجو در لیست ==========
students = ["علی", "سارا", "رضا", "مریم"]
search = input("نام دانش‌آموز را وارد کنید: ")
if search in students:
    print(f"{search} در لیست وجود دارد")
else:
    print(f"{search} در لیست وجود ندارد")

# ========== حلقه با in ==========
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    print(num, end=" ")           # 1 2 3 4 5

🧪 تمرین: یک برنامه بنویسید که از کاربر یک حرف دریافت کند و با عملگر in بررسی کند که آیا آن حرف در یک رشته‌ی از پیش تعریف‌شده (مثل "python programming") وجود دارد یا نه. جستجو بدون حساسیت به بزرگی/کوچکی انجام شود.

۳.۷ اولویت عملگرها (Operator Precedence)

در عبارات پیچیده که شامل چندین عملگر هستند، ترتیب اجرای عملگرها بر اساس اولویت (Precedence) تعیین می‌شود. درک اولویت عملگرها برای نوشتن عبارات صحیح و خوانا ضروری است.

ترتیب اولویت از بالا به پایین (بالاترین اولویت در بالا):

  1. پرانتز () – بالاترین اولویت، همیشه ابتدا محاسبه می‌شود.
  2. توان ** – از راست به چپ ارزیابی می‌شود.
  3. منفی یکانی (Unary) -x و not – عملگرهای یک‌عملوندی.
  4. ضرب، تقسیم، تقسیم صحیح، باقیمانده *, /, //, % – از چپ به راست.
  5. جمع و تفریق +, - – از چپ به راست.
  6. عملگرهای مقایسه‌ای <, <=, >, >=, ==, != – غیرانجمنی (چپ به راست).
  7. عملگرهای هویتی is, is not.
  8. عملگرهای عضویت in, not in.
  9. عملگرهای منطقی not, and, or – به‌ترتیب از بالاترین به پایین‌ترین اولویت.

قانون طلایی: اگر از اولویت عملگرها مطمئن نیستید، از پرانتز استفاده کنید. پرانتز هم خوانایی کد را افزایش می‌دهد و هم از بروز خطاهای محاسباتی جلوگیری می‌کند.

# ========== مثال‌های اولویت ==========
# ضرب اولویت بیشتری نسبت به جمع دارد
result = 10 + 5 * 2
print(result)      # 20 (ابتدا 5*2 = 10، سپس 10+10 = 20)

# با پرانتز اولویت را تغییر می‌دهیم
result = (10 + 5) * 2
print(result)      # 30

# ========== ترکیب چند عملگر ==========
a = 5
b = 10
c = 3
result = a + b * c - 2 ** 3
# 1. توان: 2**3 = 8
# 2. ضرب: b * c = 30
# 3. جمع و تفریق (چپ به راست): 5 + 30 - 8 = 27
print(result)      # 27

# ========== منطقی با مقایسه‌ای ==========
x = 10
y = 20
z = 30
is_true = x < y and y < z   # True and True = True
print(is_true)               # True

# ========== استفاده از پرانتز برای خوانایی ==========
age = 25
has_license = True
is_learner = False

# بدون پرانتز (خود پایتون اولویت را می‌داند، اما خوانایی کم است)
is_valid1 = age >= 18 and has_license or is_learner

# با پرانتز (خوانا و واضح)
is_valid2 = (age >= 18) and (has_license or is_learner)
print(is_valid2)   # True

# ========== مثال از چپ‌به‌راست بودن عملگرهای حسابی ==========
# 8 / 4 / 2 به صورت (8/4)/2 = 1.0
print(8 / 4 / 2)   # 1.0

# ========== مثال از راست‌به‌چپ بودن توان ==========
# 2 ** 3 ** 2 به صورت 2 ** (3 ** 2) = 2 ** 9 = 512
print(2 ** 3 ** 2)  # 512

💡 نکته مهم: برای خوانایی بیشتر و جلوگیری از اشتباه، همیشه از پرانتز برای مشخص کردن اولویت در عبارات پیچیده استفاده کنید. کد خوانا به‌اندازه‌ی کد درست کار کردن اهمیت دارد.
🧪 تمرین: عبارت زیر را بدون اجرا، مقدار آن را حدس بزنید:
result = 8 + 2 * 3 ** 2 - 4 / 2
سپس با پایتون محاسبه کنید و نتیجه را بررسی کنید. مراحل محاسبه را توضیح دهید.

🛠️ کارگاه عملی

گام‌به‌گام: ساخت یک ماشین‌حساب پیشرفته با عملگرها

در این کارگاه، یک ماشین‌حساب کامل می‌سازیم که از همه‌ی عملگرهای این فصل استفاده می‌کند. این برنامه به کاربر اجازه می‌دهد دو عدد و یک عملگر وارد کند و نتیجه را با تحلیل‌های تکمیلی مشاهده کند.

  1. ایجاد فایل: یک فایل جدید به نام calculator_advanced.py در VS Code ایجاد کنید.
  2. دریافت ورودی: از کاربر دو عدد و یک عملگر (+, -, *, /, //, %, **) با input() دریافت کنید. اعداد را به float تبدیل کنید (برای پشتیبانی از اعداد اعشاری).
  3. اعتبارسنجی: با استفاده از عملگر in بررسی کنید که عملگر واردشده در لیست عملگرهای مجاز وجود داشته باشد. اگر نه، پیام خطا نمایش دهید.
  4. محاسبه: با استفاده از یک سری if/elif/else (فصل بعد) یا ساختار match-case، عملیات مربوطه را انجام دهید. برای تقسیم، با if بررسی کنید که مخرج صفر نباشد.
  5. تحلیل نتیجه:
    • با عملگرهای مقایسه‌ای: مشخص کنید که نتیجه مثبت است، منفی است یا صفر.
    • با عملگرهای منطقی: بررسی کنید که آیا هر دو عدد زوج هستند یا خیر (با استفاده از %).
    • با عملگرهای عضویت: بررسی کنید که آیا عدد اول در یک بازه (مثلاً ۱ تا ۱۰۰) قرار دارد.
    • با عملگرهای هویتی: بررسی کنید که آیا دو عدد به یک شیء اشاره می‌کنند (برای اعداد صحیح کوچک).
  6. نمایش خروجی: با استفاده از f-string، یک گزارش کامل شامل: اعداد ورودی، عملگر، نتیجه، وضعیت نتیجه (مثبت/منفی/صفر)، وضعیت زوج بودن و نتیجه‌ی بررسی عضویت و هویت نمایش دهید.

کد نمونه (بخش اصلی):

# دریافت ورودی
num1 = float(input("عدد اول: "))
num2 = float(input("عدد دوم: "))
op = input("عملگر (+, -, *, /, //, %, **): ")

# لیست عملگرهای مجاز
allowed_ops = ["+", "-", "*", "/", "//", "%", "**"]

# بررسی عضویت
if op not in allowed_ops:
    print("❌ عملگر نامعتبر!")
else:
    # محاسبه (با شرط‌های ساده)
    if op == "+":
        result = num1 + num2
    elif op == "-":
        result = num1 - num2
    elif op == "*":
        result = num1 * num2
    elif op == "/":
        if num2 == 0:
            print("❌ تقسیم بر صفر مجاز نیست!")
            exit()
        result = num1 / num2
    # ... ادامه برای سایر عملگرها

    # تحلیل نتیجه
    is_positive = result > 0
    is_negative = result < 0
    is_zero = result == 0
    both_even = (num1 % 2 == 0) and (num2 % 2 == 0)
    is_in_range = 1 <= num1 <= 100
    same_object = (num1 is num2)  # فقط برای اعداد صحیح کوچک

    # نمایش گزارش
    print(f"\n📊 گزارش محاسبه:")
    print(f"{num1} {op} {num2} = {result}")
    print(f"وضعیت نتیجه: {'مثبت' if is_positive else 'منفی' if is_negative else 'صفر'}")
    print(f"هر دو عدد زوج هستند: {'✅' if both_even else '❌'}")
    print(f"عدد اول در بازه ۱-۱۰۰: {'✅' if is_in_range else '❌'}")
    print(f"عدد اول و دوم یک شیء هستند: {'✅' if same_object else '❌'}")

📝 پرسش‌ها و تمرینات

سوالات تشریحی

  1. تفاوت بین عملگرهای / و // چیست؟ در چه شرایطی از هرکدام استفاده می‌کنیم؟
  2. تفاوت بین عملگرهای == و is چیست؟ مثال بزنید.
  3. عملگرهای and و or چگونه کار می‌کنند؟ مفهوم Short-circuit را توضیح دهید.
  4. چرا باید از عملگرهای انتساب ترکیبی (مثل +=) استفاده کنیم؟ چه مزایایی دارند؟
  5. عملگرهای عضویت چه کاربردی دارند؟ در دیکشنری‌ها، in چه چیزی را بررسی می‌کند؟

سوالات چهارگزینه‌ای

  1. خروجی 15 // 4 چیست؟
    أ) 3.75 ب) 3 ج) 4 د) 3.0
  2. خروجی 10 % 6 چیست؟
    أ) 4 ب) 1.66 ج) 1 د) 6
  3. کدام یک از موارد زیر برای بررسی برابری دو مقدار استفاده می‌شود؟
    أ) = ب) == ج) is د) !=
  4. خروجی عبارت 2 + 3 * 4 ** 2 چیست؟
    أ) 80 ب) 50 ج) 26 د) 100
  5. کدام یک از موارد زیر True است اگر مقدار x بین ۱۰ و ۲۰ باشد (شامل ۱۰ و ۲۰)؟

  • از کاربر دو عدد دریافت کند.
  • با عملگرهای حسابی همه‌ی عملیات زیر را محاسبه و نمایش دهد:

  • با عملگرهای عضویت بررسی کند که آیا عدد اول در یک بازه (مثلاً ۱ تا ۱۰۰) قرار دارد.
  • همه‌ی نتایج را با f-string به‌صورت زیبا و خوانا نمایش دهد.

📌 جمع‌بندی و خلاصه

نکات طلایی

  • 🔹 عملگرهای حسابی: +, -, *, /, //, %, ** – برای محاسبات ریاضی.
  • 🔹 عملگرهای مقایسه‌ای: ==, !=, >, <, >=, <= – برای مقایسه مقادیر و تولید True/False.
  • 🔹 عملگرهای منطقی: and, or, not – برای ترکیب شرط‌ها و ایجاد منطق پیچیده (با Short-circuit).
  • 🔹 عملگرهای انتساب: =, +=, -=, *=, /=, //=, %=, **= – برای به‌روزرسانی کارآمد متغیرها.
  • 🔹 عملگرهای هویتی: is, is not – برای مقایسه‌ی هویت اشیاء در حافظه (متفاوت از ==).
  • 🔹 عملگرهای عضویت: in, not in – برای بررسی وجود عنصر در مجموعه‌ها (لیست، رشته، دیکشنری).
  • 🔹 اولویت عملگرها: با استفاده از پرانتز، اولویت را کنترل و کد را خوانا کنید.

برگه تقلب (Cheat Sheet)

# ========== حسابی ==========
5 + 3   # 8
5 - 3   # 2
5 * 3   # 15
5 / 3   # 1.666
5 // 3  # 1
5 % 3   # 2
5 ** 3  # 125

# ========== مقایسه‌ای ==========
5 == 5  # True
5 != 3  # True
5 > 3   # True
5 < 8   # True

# ========== منطقی ==========
True and True   # True
True or False   # True
not True        # False

# ========== انتساب ==========
x = 10
x += 5  # x = 15

# ========== هویتی ==========
x is y
x is not y

# ========== عضویت ==========
"a" in "apple"        # True
"x" not in "apple"    # True
"name" in {"name": "Ali"}  # True (بررسی کلید)

# ========== اولویت (به‌ترتیب) ==========
# () → ** → -x, not → *, /, //, % → +, - → مقایسه‌ای → is → in → not, and, or

📖 واژه‌نامه تخصصی

  • Operator (عملگر): نماد یا کلمه‌ای که یک عملیات را روی یک یا چند مقدار (عملوند) انجام می‌دهد.
  • Arithmetic Operator (عملگر حسابی): عملگرهای ریاضی برای محاسبات پایه و پیشرفته.
  • Comparison Operator (عملگر مقایسه‌ای): عملگر برای مقایسه‌ی دو مقدار و تولید نتیجه‌ی بولی.
  • Logical Operator (عملگر منطقی): عملگر برای ترکیب چند شرط بولی (and, or, not).
  • Assignment Operator (عملگر انتساب): عملگر برای مقداردهی و به‌روزرسانی متغیرها.
  • Identity Operator (عملگر هویتی): عملگر برای مقایسه‌ی هویت اشیاء (is, is not).
  • Membership Operator (عملگر عضویت): عملگر برای بررسی وجود یک عنصر در مجموعه (in, not in).
  • Precedence (اولویت): ترتیب اجرای عملگرها در یک عبارت.
  • Short-circuit (ارزیابی کوتاه‌مدت): توقف ارزیابی عبارت در زمانی که نتیجه از قبل مشخص است (در and و or).
  • Operand (عملوند): مقداری که عملگر روی آن اعمال می‌شود (مثلاً در 5 + 3، ۵ و ۳ عملوند هستند).

❓ سوالات محرک (برای درگیری ذهن)

  • ❓ چرا 0.1 + 0.2 در پایتون دقیقاً برابر 0.3 نیست؟ چگونه می‌توان این مشکل را در مقایسه‌ی اعداد اعشاری حل کرد؟
  • ❓ چه تفاوتی بین is و == در مقایسه‌ی اعداد صحیح کوچک و بزرگ وجود دارد؟ چرا این تفاوت وجود دارد؟
  • ❓ عملگرهای منطقی چگونه از Short-circuit استفاده می‌کنند و این ویژگی چه کاربردهایی در بهینه‌سازی کد و جلوگیری از خطا دارد؟
  • ❓ چرا استفاده از پرانتز در عبارات پیچیده توصیه می‌شود، حتی اگر از اولویت عملگرها مطمئن باشید؟
  • ❓ آیا می‌توان از عملگرهای عضویت روی دیکشنری‌ها استفاده کرد؟ چگونه می‌توان وجود یک مقدار را در دیکشنری بررسی کرد؟

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: استفاده از = به‌جای == در شرط‌ها (انتساب به‌جای مقایسه) که باعث می‌شود مقداردهی انجام شود و شرط همیشه True باشد (یا در برخی موارد SyntaxError).
    🔧 راه حل: برای مقایسه از == استفاده کنید. if x = 5 در پایتون خطای SyntaxError می‌دهد، اما در زبان‌های دیگر ممکن است اشتباه باشد.
  • 🔴 اشتباه: فراموش کردن اولویت عملگرها و عدم استفاده از پرانتز که منجر به محاسبه‌ی اشتباه می‌شود.
    🔧 راه حل: همیشه با پرانتز، اولویت را به‌صورت واضح مشخص کنید. به‌ویژه در عبارات با ترکیب and و or، از پرانتز استفاده کنید.
  • 🔴 اشتباه: انتظار اینکه is برای مقایسه‌ی مقادیر (مانند اعداد بزرگ) کار کند، در حالی که is هویت شیء را بررسی می‌کند.
    🔧 راه حل: برای مقایسه‌ی مقدار از == و برای هویت از is استفاده کنید. برای بررسی None، is None استاندارد است.
  • 🔴 اشتباه: استفاده از in روی دیکشنری بدون در نظر گرفتن اینکه فقط کلیدها را بررسی می‌کند، در حالی که انتظار بررسی مقادیر را دارید.
    🔧 راه حل: برای بررسی مقادیر در دیکشنری از in dict.values() استفاده کنید.
  • 🔴 اشتباه: فراموش کردن اینکه عملگرهای مقایسه‌ای رشته‌ها به بزرگی/کوچکی حروف حساس هستند.
    🔧 راه حل: برای مقایسه‌ی بدون حساسیت، هر دو طرف را با lower() یا upper() یکسان کنید.
  • 🔴 اشتباه: استفاده از and و or به‌جای عملگرهای بیتی (& و |) در عملیات‌های بیتی.
    🔧 راه حل: عملگرهای and، or، not برای مقادیر بولی هستند. برای عملیات بیتی از &، | و ~ استفاده کنید.

عنوان پروژه: ساخت یک تحلیل‌گر عددی پیشرفته با عملگرها

شرح: یک برنامه‌ی خط فرمان (CLI) کامل بسازید که یک عدد از کاربر دریافت کند و تحلیل‌های متنوعی روی آن انجام دهد. این پروژه شما را با تمام عملگرهای این فصل در یک سناریوی واقعی آشنا می‌کند.

مراحل پیاده‌سازی:

  • مرحله ۱ (ورودی): یک عدد صحیح از کاربر با input() دریافت کنید و به int تبدیل کنید (با مدیریت خطا).
  • مرحله ۲ (تحلیل حسابی):
    • مربع، مکعب و توان چهارم عدد را محاسبه کنید (با **).
    • جذر عدد را با math.sqrt() محاسبه کنید (نیاز به import math).
    • فاکتوریل عدد را با یک حلقه محاسبه کنید (می‌توانید از math.factorial نیز استفاده کنید).
  • مرحله ۳ (تحلیل مقایسه‌ای و منطقی):
    • با عملگرهای مقایسه‌ای مشخص کنید که عدد مثبت است، منفی است یا صفر.
    • بررسی کنید که آیا عدد زوج است یا فرد (با %).
    • بررسی کنید که آیا عدد بین ۰ تا ۱۰۰ است (با and).
    • بررسی کنید که آیا عدد بخش‌پذیر بر ۳ و ۵ است (با % و and).
  • مرحله ۴ (عضویت و هویت):
    • یک لیست از اعداد اول کوچک تعریف کنید: [2, 3, 5, 7, 11, 13, 17, 19].
    • با in بررسی کنید که آیا عدد در این لیست وجود دارد.
    • یک متغیر دیگر با همان مقدار تعریف کنید و با is بررسی کنید که آیا به یک شیء اشاره می‌کنند (برای اعداد کوچک).
  • مرحله ۵ (انتساب):
    • عدد را به یک متغیر موقت اختصاص دهید و با عملگرهای +=، -=، *= و **= آن را تغییر دهید و هر مرحله را نمایش دهید.
  • مرحله ۶ (خروجی): همه‌ی نتایج را با f-string به‌صورت یک گزارش کامل و زیبا (با خطوط جداکننده و توضیحات) نمایش دهید.

چالش‌های بیشتر (اختیاری):

  • قابلیت دریافت چندین عدد و مقایسه‌ی آنها با هم (بزرگ‌ترین، کوچک‌ترین، میانگین) را اضافه کنید.
  • با عملگرهای منطقی، یک سیستم امتیازدهی ساده بر اساس عدد ورودی (مثلاً بین ۰-۲۰: ضعیف، ۲۰-۵۰: متوسط، ۵۰-۸۰: خوب، ۸۰-۱۰۰: عالی) بسازید.
  • با عملگرهای عضویت، یک جستجوگر کلمات در یک جمله‌ی بلند پیاده‌سازی کنید (از کاربر کلمه و جمله بگیرید و بررسی کنید که آیا کلمه در جمله وجود دارد).
