🚀 مقدمه و انگیزه‌بخشی

در دنیای واقعی، هر روز با تصمیم‌گیری‌های مختلف روبرو هستیم: «اگر باران بیاید، چتر برمی‌دارم» یا «اگر گرسنه باشم، غذا می‌خورم» و «اگر هوا سرد باشد، کت می‌پوشم». در برنامه‌نویسی هم دقیقاً همینطور است. ساختارهای شرطی به برنامه اجازه می‌دهند بر اساس شرایط مختلف، تصمیم‌گیری کند و مسیرهای مختلفی را طی کند. بدون شرط‌ها، برنامه‌ها فقط یک مسیر ثابت را دنبال می‌کردند و نمی‌توانستند به ورودی‌های کاربر یا تغییرات محیط واکنش نشان دهند.

در این فصل با همه‌ی ابزارهای تصمیم‌گیری در پایتون آشنا می‌شوید: از if و else ساده گرفته تا elif برای چندین شرط، match-case برای مقایسه‌ی الگو (مشابه switch در زبان‌های دیگر)، و عملگر شرطی (Ternary) برای نوشتن شرط‌های کوتاه و خواناتر. همچنین با مفهوم Truthy و Falsy آشنا می‌شوید که یکی از مفاهیم کلیدی و منحصربه‌فرد پایتون است و به شما امکان می‌دهد شرط‌ها را به‌صورت بسیار مختصر بنویسید.

تسلط بر ساختارهای شرطی، یکی از مهم‌ترین مهارت‌های هر برنامه‌نویسی است. با این فصل، می‌توانید برنامه‌هایی بنویسید که هوشمندانه رفتار کنند، به ورودی‌های کاربر پاسخ مناسب بدهند و در شرایط مختلف، بهترین تصمیم را بگیرند. این مهارت‌ها پایه‌ی مباحث بعدی مانند حلقه‌ها و توابع هستند.

🧠 بدنه اصلی آموزش

۴.۱ دستور if و else

if ساده‌ترین و اساسی‌ترین ساختار شرطی در پایتون است. اگر شرط (که یک عبارت بولی است) True باشد، بلوک کد زیر آن اجرا می‌شود. else که اختیاری است، زمانی اجرا می‌شود که شرط False باشد.

  • تورفتگی (Indentation): در پایتون، به‌جای استفاده از آکولاد {} (مانند جاوا یا C++)، از تورفتگی برای مشخص کردن بلوک کد استفاده می‌شود. این یکی از ویژگی‌های منحصربه‌فرد پایتون است که خوانایی کد را به‌شدت افزایش می‌دهد. استاندارد استفاده از ۴ فاصله (Space) است (نه Tab).
  • همیشه بعد از if، elif و else از : (کولن) استفاده کنید.
  • شرط می‌تواند هر عبارتی باشد که یک مقدار بولی (True یا False) برمی‌گرداند.
# ========== if ساده (بدون else) ==========
age = 18
if age >= 18:
    print("شما بزرگسال هستید.")  # این خط اجرا می‌شود

# ========== if/else (دو مسیر) ==========
temperature = 30
if temperature > 25:
    print("هوا گرم است")        # این خط اجرا می‌شود
else:
    print("هوا خنک است")

# ========== شرط با ورودی کاربر ==========
score = int(input("امتیاز خود را وارد کنید: "))
if score >= 50:
    print("✅ قبول شدید")
else:
    print("❌ رد شدید")

# ========== تورفتگی بسیار مهم است ==========
if True:
    print("این خط اجرا می‌شود")
    print("این خط هم اجرا می‌شود")  # هر دو داخل if هستند
print("این خط همیشه اجرا می‌شود")   # خارج از if است

# ========== مثال عملی: تعیین وضعیت آب و هوا ==========
temp = int(input("دمای امروز را وارد کنید: "))
if temp >= 30:
    print("🔥 خیلی گرم است، کولر را روشن کنید!")
else:
    print("❄️ هوا خنک است، پنجره را باز کنید!")
➜ شما بزرگسال هستید.
➜ هوا گرم است
💡 نکته مهم: در پایتون، تورفتگی (Indentation) فقط برای زیبایی نیست – بلکه نحوی (Syntactic) است و عدم رعایت آن باعث خطای IndentationError می‌شود. از ۴ فاصله (Space) استفاده کنید و از ترکیب Tab و Space خودداری کنید (بیشتر ویرایشگرها این را به‌طور خودکار مدیریت می‌کنند).
🧪 تمرین: یک برنامه بنویسید که عددی را از کاربر دریافت کند و با if/else مشخص کند که عدد زوج است یا فرد. (راهنمایی: از عملگر % استفاده کنید.)

۴.۲ دستور elif (چندین شرط)

وقتی بیش از دو حالت (مسیر) داریم، از elif (مخفف else if) استفاده می‌کنیم. این ساختار به شما اجازه می‌دهد چندین شرط را پشت سر هم بررسی کنید و به محض پیدا کردن اولین شرط True، بلوک مربوطه را اجرا کرده و از بقیه‌ی شرط‌ها صرف‌نظر کند.

نکات کلیدی:

  • ترتیب شرط‌ها در elif مهم است. پایتون از بالا به پایین بررسی می‌کند و اولین شرط True را انتخاب می‌کند.
  • شرط‌های خاص‌تر را بالاتر قرار دهید و شرط‌های عمومی‌تر را پایین‌تر.
  • قسمت else در انتها اختیاری است و در صورتی اجرا می‌شود که هیچ‌یک از شرط‌ها True نباشند.
# ========== سیستم نمره‌دهی ==========
score = int(input("نمره خود را وارد کنید: "))
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
print(f"نمره: {score} → {grade}")

# ========== وضعیت آب و هوا بر اساس دما ==========
temp = int(input("دمای امروز را وارد کنید: "))
if temp > 35:
    status = "بسیار گرم ☀️"
elif temp > 25:
    status = "گرم 🌤️"
elif temp > 15:
    status = "معتدل 🌥️"
elif temp > 5:
    status = "خنک 🧥"
else:
    status = "سرد 🥶"
print(f"وضعیت آب و هوا: {status}")

# ========== تشخیص رنج سنی ==========
age = int(input("سن خود را وارد کنید: "))
if age < 13:
    category = "کودک"
elif age < 18:
    category = "نوجوان"
elif age < 65:
    category = "بزرگسال"
else:
    category = "سالمند"
print(f"گروه سنی: {category}")

# ========== مثال با ترتیب اشتباه (خطرناک!) ==========
# این کد را اجرا نکنید – ترتیب غلط است!
# value = 85
# if value > 50:
#     print("بیشتر از ۵۰")
# elif value > 80:   # این هرگز اجرا نمی‌شود چون ۸۵ > ۵۰ است
#     print("بیشتر از ۸۰")
➜ نمره: 85 → B
➜ وضعیت آب و هوا: گرم 🌤️
➜ گروه سنی: بزرگسال
💎 نکته طلایی: ترتیب شرط‌ها در elif حیاتی است. همیشه شرط‌های خاص‌تر را بالاتر قرار دهید. اگر شرط عمومی‌تر (مثلاً value > 50) را بالاتر بگذارید، شرط‌های خاص‌تر (value > 80) هرگز اجرا نمی‌شوند.
🧪 تمرین: یک برنامه بنویسید که سن کاربر را دریافت کند و بر اساس آن، گروه سنی را به‌صورت زیر مشخص کند: زیر ۱۲ سال (کودک)، ۱۲ تا ۱۷ (نوجوان)، ۱۸ تا ۶۴ (بزرگسال)، ۶۵ به بالا (سالمند). از elif استفاده کنید.

۴.۳ match-case (Python 3.10+)

match-case یک ساختار شرطی جدید است که در پایتون ۳.۱۰ معرفی شده و مشابه switch در زبان‌های دیگر (مانند جاوا، C++ و JavaScript) عمل می‌کند. این ساختار برای مقایسه‌ی یک مقدار با چندین الگوی مختلف بسیار مناسب است و کد را خواناتر می‌کند.

نکات کلیدی:

  • match مقداری را که می‌خواهیم مقایسه کنیم مشخص می‌کند.
  • case هر الگو را تعریف می‌کند. اگر الگو با مقدار مطابقت داشته باشد، بلوک مربوطه اجرا می‌شود.
  • case _ مانند default در switch عمل می‌کند و اگر هیچ‌یک از الگوها مطابقت نداشت، اجرا می‌شود.
  • با استفاده از | (OR) می‌توانید چند مقدار را در یک case ترکیب کنید.
  • match-case فراتر از مقایسه‌ی ساده است و از الگوهای ساختاری (Structural Pattern Matching) پشتیبانی می‌کند (مثلاً برای تطابق با تاپل‌ها، لیست‌ها و کلاس‌ها).
# ========== مثال ساده: روزهای هفته ==========
day = 3
match day:
    case 1:
        name = "شنبه"
    case 2:
        name = "یکشنبه"
    case 3:
        name = "دوشنبه"
    case 4:
        name = "سه‌شنبه"
    case 5:
        name = "چهارشنبه"
    case 6:
        name = "پنج‌شنبه"
    case 7:
        name = "جمعه"
    case _:
        name = "روز نامعتبر"
print(f"روز شماره {day}: {name}")  # روز شماره 3: دوشنبه

# ========== match-case با مقادیر مختلف ==========
command = "start"
match command:
    case "start":
        print("▶️ شروع برنامه")
    case "stop":
        print("⏹️ توقف برنامه")
    case "restart":
        print("🔄 راه‌اندازی مجدد")
    case _:
        print("❌ دستور نامعتبر")

# ========== ترکیب چند مقدار با | (OR) ==========
number = 5
match number:
    case 0:
        print("صفر")
    case 1 | 2 | 3:
        print("یک تا سه")
    case 4 | 5 | 6:
        print("چهار تا شش")
    case _:
        print("بیشتر از شش")

# ========== استفاده از match-case برای HTTP status codes ==========
status_code = 404
match status_code:
    case 200:
        message = "OK - موفق"
    case 201:
        message = "Created - ایجاد شد"
    case 400:
        message = "Bad Request - درخواست نامعتبر"
    case 404:
        message = "Not Found - یافت نشد"
    case 500:
        message = "Internal Server Error - خطای سرور"
    case _:
        message = f"کد وضعیت ناشناخته: {status_code}"
print(f"وضعیت: {message}")  # وضعیت: Not Found - یافت نشد

# ========== تطابق با الگوهای ساختاری (پیشرفته) ==========
point = (2, 3)  # یک تاپل
match point:
    case (0, 0):
        print("نقطه در مبدأ")
    case (x, 0):
        print(f"روی محور X در {x}")
    case (0, y):
        print(f"روی محور Y در {y}")
    case (x, y):
        print(f"نقطه در ({x}, {y})")  # نقطه در (2, 3)
➜ روز شماره 3: دوشنبه
➜ ▶️ شروع برنامه
➜ چهار تا شش
➜ وضعیت: Not Found - یافت نشد
➜ نقطه در (2, 3)
💡 نکته مهم: match-case از Python 3.10 به بعد در دسترس است. اگر از نسخه‌های قدیمی‌تر پایتون استفاده می‌کنید (مثلاً Python 3.8 یا 3.9)، از if/elif/else استفاده کنید. برای بررسی نسخه‌ی پایتون، از python --version در ترمینال استفاده کنید.
🧪 تمرین: با استفاده از match-case یک برنامه بنویسید که نام ماه (به انگلیسی) را دریافت کند و تعداد روزهای آن ماه را چاپ کند. از | برای ترکیب ماه‌هایی که روزهای مشابه دارند استفاده کنید (مثلاً فروردین و اردیبهشت و ...).

۴.۴ عملگر شرطی (Ternary Operator)

عملگر شرطی (Ternary Operator) یک روش کوتاه و فشرده برای نوشتن if/else ساده است. ساختار آن به این صورت است: مقدار_درست if شرط else مقدار_نادرست. این عملگر برای زمانی مناسب است که یک شرط ساده دارید و می‌خواهید در یک خط، یکی از دو مقدار را انتخاب کنید.

مزایا:

  • کد کوتاه‌تر و فشرده‌تر می‌شود.
  • برای انتساب شرطی (مقداردهی بر اساس شرط) بسیار مناسب است.
  • می‌تواند درون print()، لیست‌ها و سایر عبارات استفاده شود.

معایب:

  • برای شرط‌های پیچیده، خوانایی را کاهش می‌دهد.
  • از Ternary تو در تو (nested ternary) باید خودداری کنید.
# ========== Ternary ساده ==========
age = 20
status = "بزرگسال" if age >= 18 else "نوجوان"
print(status)  # "بزرگسال"

# ========== معادل با if/else ==========
if age >= 18:
    status = "بزرگسال"
else:
    status = "نوجوان"

# ========== استفاده در محاسبات ==========
score = 85
result = "قبول" if score >= 60 else "رد"
print(f"نتیجه: {result}")  # "نتیجه: قبول"

# ========== استفاده درون print() ==========
x = 10
y = 20
print("x بزرگ‌تر است" if x > y else "y بزرگ‌تر است")  # "y بزرگ‌تر است"

# ========== Ternary با توابع ==========
def get_discount(price):
    return price * 0.9 if price > 100 else price  # تخفیف ۱۰٪ برای قیمت‌های بالای ۱۰۰

print(get_discount(150))  # 135.0
print(get_discount(50))   # 50

# ========== ❌ Ternary تو در تو (اجتناب کنید) ==========
num = 0
msg = "مثبت" if num > 0 else "منفی" if num < 0 else "صفر"
print(msg)  # "صفر"
# بهتر است این را با if/elif/else بنویسید

# ========== ✅ استفاده از Ternary برای انتخاب لیست ==========
even_odd = ["فرد", "زوج"]
num = 7
result = even_odd[num % 2 == 0]  # اگر num % 2 == 0 باشد، index=1 (زوج) وگرنه index=0 (فرد)
print(f"{num} → {result}")  # 7 → فرد
➜ بزرگسال
➜ نتیجه: قبول
➜ y بزرگ‌تر است
➜ 135.0
➜ 50
➜ صفر
➜ 7 → فرد
💎 نکته طلایی: از Ternary فقط برای شرط‌های ساده و کوتاه (حداکثر یک خط) استفاده کنید. اگر شرط شما بیش از یک سطح تو رفتگی دارد، یا شامل چندین and یا or است، از if/elif/else استفاده کنید. از Ternary تو در تو (nested) به‌شدت خودداری کنید، زیرا خوانایی کد را به‌شدت کاهش می‌دهد.
🧪 تمرین: با استفاده از Ternary Operator، یک متغیر is_even تعریف کنید که اگر عددی زوج بود True و اگر فرد بود False برگرداند. همچنین یک پیام مناسب با Ternary چاپ کنید.

۴.۵ مفهوم Truthy و Falsy در پایتون

یکی از ویژگی‌های جالب و قدرتمند پایتون، مفهوم Truthy و Falsy است. در پایتون، هر مقدار (نه فقط True و False) را می‌توان در یک شرط استفاده کرد. اگر مقدار در شرط معادل True رفتار کند، آن را Truthy و اگر معادل False رفتار کند، Falsy می‌نامیم.

مقادیر Falsy در پایتون:

  • None – عدم وجود مقدار
  • False – مقدار بولی نادرست
  • 0 و 0.0 – عدد صفر (صحیح و اعشاری)
  • '' و "" – رشته‌ی خالی
  • [] – لیست خالی
  • {} – دیکشنری خالی
  • () – تاپل خالی
  • set() – مجموعه‌ی خالی
  • range(0) – محدوده‌ی خالی

همه‌ی مقادیر دیگر Truthy هستند.

💡 نکته مهم: مفهوم Truthy/Falsy در پایتون بسیار قدرتمند است و به شما اجازه می‌دهد کدهای مختصر، خوانا و پایتونیک بنویسید. با این حال، مراقب باشید که در برخی موارد (مثلاً وقتی ۰ یک مقدار معتبر است) استفاده از if not value ممکن است اشتباه باشد. در چنین مواردی، از مقایسه‌ی صریح استفاده کنید: if value is None یا if value == 0.
🧪 تمرین: یک برنامه بنویسید که یک رشته از کاربر دریافت کند. اگر رشته خالی بود، پیام "ورودی خالی" و اگر نه، پیام "ورودی: [متن]" را با استفاده از if text: (بدون مقایسه با "") نمایش دهد. همچنین یک لیست از اعداد تعریف کنید و با if my_list: بررسی کنید که آیا لیست خالی است یا خیر.

۴.۶ شرط‌های تو در تو (Nested Conditions)

گاهی اوقات نیاز داریم شرطی را داخل شرط دیگری قرار دهیم. به این کار شرط تو در تو (Nested) می‌گویند. این کار زمانی مفید است که یک شرط وابسته به شرط دیگری باشد و باید سلسله‌مراتب تصمیم‌گیری را پیاده‌سازی کنیم.

نکات مهم:

  • تا حد امکان از شرط‌های تو در تو با عمق بیش از ۲-۳ سطح خودداری کنید، زیرا خوانایی کد را کاهش می‌دهند.
  • در بسیاری از موارد، می‌توانید با استفاده از عملگرهای and و or شرط‌های تو در تو را به یک شرط ترکیبی تبدیل کنید.
  • اگر شرط‌های تو در تو پیچیده شدند، می‌توانید آنها را به توابع جداگانه منتقل کنید.
# ========== بررسی احراز هویت (nested) ==========
username = "admin"
password = "12345"
if username == "admin":
    if password == "12345":
        print("✅ ورود موفق")
    else:
        print("❌ رمز عبور اشتباه است")
else:
    print("❌ نام کاربری اشتباه است")

# ========== بررسی وام (nested) ==========
age = 25
income = 6000000
credit_score = 720
if age >= 18:
    if income >= 5000000:
        if credit_score >= 700:
            print("✅ وام تایید شد")
        else:
            print("❌ امتیاز اعتباری پایین است")
    else:
        print("❌ درآمد کافی نیست")
else:
    print("❌ سن کافی نیست")

# ========== بهتر: ترکیب شرط‌ها با and ==========
if age >= 18 and income >= 5000000 and credit_score >= 700:
    print("✅ وام تایید شد")
else:
    print("❌ شرایط را ندارید")

# ========== مثال واقعی: سیستم رزرو هتل ==========
is_weekend = True
is_holiday = False
has_discount_code = True
room_available = True

if room_available:
    if is_weekend or is_holiday:
        price = 150
        if has_discount_code:
            price *= 0.9
            print(f"قیمت با تخفیف: {price} تومان")
        else:
            print(f"قیمت تعطیلات: {price} تومان")
    else:
        print(f"قیمت عادی: 100 تومان")
else:
    print("❌ اتاق موجود نیست")

# ========== جایگزین بهتر با and و or ==========
if room_available and (is_weekend or is_holiday):
    price = 150 if not has_discount_code else 135
    print(f"قیمت: {price} تومان")
elif room_available:
    print("قیمت عادی: 100 تومان")
else:
    print("❌ اتاق موجود نیست")
➜ ✅ ورود موفق
➜ ✅ وام تایید شد
➜ قیمت با تخفیف: 135.0 تومان
💎 نکته طلایی: شرط‌های تو در تو را تا حد ممکن ساده کنید. اگر بیش از ۲-۳ سطح تو در تو دارید، بهتر است از and و or برای ترکیب شرط‌ها استفاده کنید یا کد را با توابع جداگانه بازنویسی کنید تا خوانایی و قابلیت نگهداری کد افزایش یابد. قانون کلی: اگر کد شما شبیه به یک مثلث (با تورفتگی‌های زیاد) شد، زمان بازنویسی آن فرا رسیده است.
🧪 تمرین: یک برنامه بنویسید که وضعیت یک کاربر را بررسی کند: اگر کاربر وارد شده باشد (logged_in = True) و ادمین باشد (is_admin = True)، پیام "خوش آمدید ادمین" را چاپ کند. اگر وارد شده باشد ولی ادمین نباشد، "خوش آمدید کاربر" را چاپ کند. در غیر این صورت "لطفاً وارد شوید" را چاپ کند. از شرط‌های تو در تو استفاده کنید، سپس همان را با and و or بازنویسی کنید.

در این کارگاه، یک برنامه‌ی کامل برای ارزیابی عملکرد دانش‌آموزان می‌سازیم که از تمام ساختارهای شرطی این فصل استفاده می‌کند.

  1. ایجاد فایل: یک فایل جدید به نام student_evaluator.py در VS Code ایجاد کنید.
  2. دریافت ورودی: نام، سن و نمره (۰ تا ۱۰۰) دانش‌آموز را با input() دریافت کنید و نمره را به float تبدیل کنید.
  3. تعیین سطح با if/elif/else: نمره را به یکی از سطوح زیر تبدیل کنید:
    • ۹۰-۱۰۰: عالی 🌟
    • ۷۵-۸۹: خوب 👍
    • ۵۰-۷۴: متوسط 📚
    • کمتر از ۵۰: نیاز به تلاش بیشتر 💪
  4. پیام تشویقی با match-case: بر اساس سطح، یک پیام تشویقی مناسب نمایش دهید (مثلاً برای "عالی": "شگفت‌انگیز! ادامه بده!"، برای "خوب": "عالی است، می‌توانی بهتر هم بشوی!" و ...).
  5. وضعیت قبولی با Ternary: با استفاده از Ternary Operator مشخص کنید که آیا دانش‌آموز قبول شده است یا نه (نمره >= ۶۰).

  7. نکته اضافی با Truthy/Falsy: بررسی کنید که آیا کاربر نام معتبر وارد کرده است (با if name:) و اگر نه، پیام "نام وارد نشده" نمایش دهید.
  8. خروجی نهایی: همه‌ی نتایج را با f-string به‌صورت یک کارنامه‌ی کامل و زیبا نمایش دهید.

📝 پرسش‌ها و تمرینات

سوالات تشریحی

  1. تفاوت بین if/elif/else و match-case چیست؟ هرکدام چه زمانی مناسب‌تر هستند؟
  2. مقادیر Falsy در پایتون کدام‌ها هستند؟ چرا این مفهوم در پایتون مهم است؟
  3. عملگر Ternary چه زمانی استفاده می‌شود و چه مزیتی نسبت به if/else دارد؟ چه زمانی نباید از آن استفاده کرد؟
  4. چرا تورفتگی (Indentation) در پایتون اهمیت نحوی دارد و چگونه از خطاهای مرتبط با آن جلوگیری کنیم؟
  5. چه زمانی باید از شرط‌های تو در تو استفاده کنیم و چه زمانی نه؟ چگونه می‌توان آنها را ساده‌تر کرد؟

سوالات چهارگزینه‌ای

  1. کدام یک از موارد زیر یک مقدار Falsy نیست؟
    أ) [] ب) [0] ج) "" د) None
  2. خروجی کد زیر چیست؟
    x = 5; result = "بزرگ" if x > 3 else "کوچک"; print(result)
    أ) "بزرگ" ب) "کوچک" ج) None د) خطای SyntaxError
  3. در match-case، برای مقدار پیش‌فرض (هیچ‌کدام از الگوها مطابقت نداشت) از کدام case استفاده می‌شود؟
    أ) case default: ب) case _: ج) case else: د) case any:
  4. کدام یک از موارد زیر کد پایتونیک‌تر (Pythonic) برای بررسی خالی نبودن یک رشته است؟
    أ) if len(text) > 0: ب) if text != "": ج) if text: د) if text is not None:

تمرین عملی

یک برنامه کامل بنویسید که:

  • نام، سن و نمره‌ی یک دانش‌آموز را از کاربر دریافت کند.
  • با if/elif/else نمره را به حرف تبدیل کند (A: ۹۰-۱۰۰، B: ۷۵-۸۹، C: ۵۰-۷۴، D: کمتر از ۵۰).
  • با match-case یک پیام تشویقی بر اساس نمره‌ی حرفی نمایش دهد.
  • با Ternary Operator مشخص کند که آیا دانش‌آموز قبول شده است یا نه (نمره >= ۶۰).
  • با شرط‌های تو در تو بررسی کند که آیا دانش‌آموز می‌تواند در المپیاد شرکت کند (شرط: نمره >= ۸۰ و سن <= ۱۸).
  • با استفاده از Truthy/Falsy، بررسی کند که آیا کاربر نام معتبر وارد کرده است (رشته خالی نباشد).
  • همه‌ی نتایج را با f-string به‌صورت یک کارنامه‌ی کامل و خوانا نمایش دهد.

📌 جمع‌بندی و خلاصه

نکات طلایی

  • 🔹 if و else برای تصمیم‌گیری‌های دوطرفه (یا/یا).
  • 🔹 elif برای بررسی چندین شرط به‌صورت زنجیره‌ای.
  • 🔹 match-case (Python 3.10+) برای مقایسه‌ی یک مقدار با چندین الگوی مختلف (مشابه switch).
  • 🔹 Ternary Operator (if ... else) برای شرط‌های کوتاه و ساده (حداکثر یک خط).
  • 🔹 مقادیر Falsy: None, False, 0, 0.0, '', [], {}, (), set().
  • 🔹 همه‌ی مقادیر دیگر Truthy هستند.
  • 🔹 از شرط‌های تو در تو با احتیاط استفاده کنید (حداکثر ۲-۳ سطح) و تا حد ممکن از and/or برای ترکیب شرط‌ها استفاده کنید.
  • 🔹 تورفتگی (Indentation) در پایتون نحوی است و بلوک‌های کد را مشخص می‌کند.

برگه تقلب (Cheat Sheet)

# ========== if/elif/else ==========
if condition:
    # code
elif condition2:
    # code
else:
    # code

# ========== match-case (Python 3.10+) ==========
match value:
    case 1:
        # code
    case 2 | 3:
        # code
    case _:
        # code

# ========== Ternary ==========
result = value_if_true if condition else value_if_false

# ========== Truthy/Falsy ==========
if value:  # اگر value Truthy باشد (نه خالی، نه صفر، نه None)
    print("True")

# ========== Nested (با احتیاط) ==========
if condition1:
    if condition2:
        # code

📖 واژه‌نامه تخصصی

  • Conditional (شرطی): ساختاری که بر اساس یک شرط، تصمیم‌گیری می‌کند و مسیر اجرا را تغییر می‌دهد.
  • if: دستور شرطی پایه که اگر شرط True باشد، بلوک کد را اجرا می‌کند.
  • else: بخشی که در صورت False بودن شرط if اجرا می‌شود.
  • elif: ترکیبی از else و if برای بررسی شرط‌های اضافی در یک زنجیره.
  • match-case: ساختار شرطی برای مقایسه‌ی یک مقدار با چندین الگو (Python 3.10+).
  • Ternary Operator (عملگر شرطی): یک روش فشرده برای نوشتن if/else در یک خط.
  • Truthy: مقداری که در یک شرط، معادل True رفتار می‌کند (مثلاً رشته‌ی غیرخالی، عدد غیرصفر).
  • Falsy: مقداری که در یک شرط، معادل False رفتار می‌کند (مثلاً None، ۰، رشته‌ی خالی).
  • Indentation (تورفتگی): فاصله‌ی ابتدای خط (معمولاً ۴ فاصله) که بلوک‌های کد را در پایتون مشخص می‌کند.
  • Nested Condition (شرط تو در تو): شرطی که داخل شرط دیگری قرار دارد.
  • Structural Pattern Matching: قابلیت match-case برای تطابق با ساختارهای داده مانند تاپل‌ها و لیست‌ها.

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن : در انتهای خط if، elif، else یا match که باعث SyntaxError می‌شود.
    🔧 راه حل: همیشه از : بعد از شرط استفاده کنید. این یک قانون ثابت در پایتون است.
  • 🔴 اشتباه: استفاده از = (انتساب) به‌جای == (مقایسه) در شرط‌ها. این خطا در پایتون باعث SyntaxError نمی‌شود (در برخی زبان‌ها خطا می‌دهد) اما منطق برنامه را به‌هم می‌زند.
    🔧 راه حل: برای مقایسه از == استفاده کنید. if x = 5 در پایتون خطای SyntaxError می‌دهد، اما if x = y اگر y قابل انتساب باشد، ممکن است اشتباهاً True شود.
  • 🔴 اشتباه: فراموش کردن تورفتگی که باعث IndentationError می‌شود. مثلاً کد زیر خطا دارد:
    if True:
    print("Hello") (بدون تورفتگی)
    🔧 راه حل: از ۴ فاصله (Space) برای تورفتگی استفاده کنید و همیشه یکنواخت باشید. در VS Code، می‌توانید از Shift+Tab برای خارج کردن و Tab برای داخل کردن استفاده کنید.
  • 🔴 اشتباه: استفاده از elif بدون if قبلی که باعث SyntaxError می‌شود.
    🔧 راه حل: elif همیشه بعد از یک if باید بیاید. نمی‌توان از elif به‌تنهایی استفاده کرد.
  • 🔴 اشتباه: فراموش کردن _ در match-case که باعث می‌شود مقادیر پیش‌بینی‌نشده مدیریت نشوند و برنامه با خطا مواجه شود (اگر هیچ‌یک از caseها مطابقت نداشته باشد).
    🔧 راه حل: همیشه یک case _: برای مقدار پیش‌فرض قرار دهید، حتی اگر فقط یک پیام خطا چاپ کند.
  • 🔴 اشتباه: استفاده از is برای مقایسه‌ی عددی به‌جای == (مخصوصاً برای اعداد بزرگ).
    🔧 راه حل: is برای مقایسه‌ی هویت اشیاء است، نه مقدار. برای مقایسه‌ی اعداد از == استفاده کنید.

🏆 پروژه نهایی فصل ۴

عنوان پروژه: ساخت یک سیستم تشخیص وضعیت آب و هوا و پیشنهاد فعالیت

شرح: یک برنامه‌ی خط فرمان (CLI) کامل بسازید که با دریافت اطلاعات آب و هوا از کاربر، تحلیل‌های مختلف انجام دهد و پیشنهادهای هوشمندانه ارائه کند. این پروژه از تمام ساختارهای شرطی این فصل استفاده می‌کند.

مراحل پیاده‌سازی:

  • مرحله ۱ (ورودی): اطلاعات زیر را از کاربر با input() دریافت کنید:
    • دمای فعلی (عدد اعشاری)
    • وضعیت بارش (یکی از: باران، برف، آفتابی، ابری، مه‌آلود)
    • سرعت باد (کیلومتر بر ساعت، عدد)
    • رطوبت (درصد، عدد)
  • مرحله ۲ (توصیه‌ی لباس با if/elif/else): بر اساس دما، یک توصیه‌ی لباس ارائه دهید:
    • زیر ۵°C: "کت سنگین، شال گردن و دستکش"
    • ۵ تا ۱۵°C: "کت متوسط و ژاکت"
    • ۱۵ تا ۲۵°C: "لباس معمولی و یک پیراهن سبک"
    • بالای ۲۵°C: "لباس تابستانی و عینک آفتابی"
  • مرحله ۳ (توصیه‌ی فعالیت با match-case): بر اساس وضعیت بارش، یک فعالیت پیشنهاد دهید:
    • "آفتابی": "☀️ پیاده‌روی در پارک"
    • "باران": "🌧️ بمان در خانه و فیلم ببین"
    • "برف": "❄️ اسکی یا برف‌بازی"
    • "ابری": "🌥️ دوچرخه‌سواری یا پیاده‌روی سبک"
    • "مه‌آلود": "🌫️ فعالیت‌های indoor مانند مطالعه"
  • مرحله ۴ (مناسب بودن برای سفر با Ternary): با Ternary Operator مشخص کنید که آیا هوا برای سفر مناسب است (شرط: دما بین ۱۵ تا ۳۰ درجه و وضعیت بارش "آفتابی" یا "ابری").
  • مرحله ۵ (شرایط خطرناک با Nested): با شرط‌های تو در تو بررسی کنید که آیا شرایط خطرناک وجود دارد:
    • باد شدید (سرعت باد > ۵۰ کیلومتر بر ساعت) و باران → هشدار طوفان
    • دمای زیر ۰ و برف → هشدار یخ‌بندان
    • دمای بالای ۳۵ و رطوبت بالا (> ۶۰٪) → هشدار گرمازدگی
  • مرحله ۶ (اعتبارسنجی با Truthy/Falsy): با استفاده از if not یا if value: بررسی کنید که کاربر همه‌ی داده‌ها را وارد کرده است. اگر ورودی خالی بود، پیام "اطلاعات کامل وارد نشده" نمایش دهید.
  • مرحله ۷ (خروجی): همه‌ی نتایج را با f-string به‌صورت یک گزارش کامل و زیبا (با خطوط جداکننده و ایموجی‌ها) نمایش دهید.

چالش‌های بیشتر (اختیاری برای کاربران پیشرو):

  • یک سیستم پیشنهاد سفر بر اساس آب و هوا اضافه کنید (با match-case).
  • با and و or شرط‌های پیچیده‌تری برای تشخیص شرایط اضطراری (سیل، کولاک، گردوغبار) بسازید.
  • از ifهای تو در تو برای تحلیل دقیق‌تر (مثل ترکیب دما و رطوبت برای احساس گرما) استفاده کنید.
  • یک سیستم امتیازدهی برای کیفیت هوا (بر اساس دما، رطوبت و باد) با if/elif/else اضافه کنید.
