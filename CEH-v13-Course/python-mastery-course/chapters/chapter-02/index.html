🚀 مقدمه و انگیزه‌بخشی

در فصل قبل با پایتون و نحوه‌ی نصب و اجرای آن آشنا شدید. حالا وقت آن است که با قلب تپنده‌ی هر برنامه یعنی متغیرها و انواع داده آشنا شوید. متغیرها مانند جعبه‌هایی در حافظه هستند که اطلاعات را در خود ذخیره می‌کنند. هر جعبه یک نوع داده مشخص دارد که تعیین می‌کند چه نوع اطلاعاتی (عدد، متن، مقدار منطقی و...) می‌تواند در آن قرار گیرد و چه عملیاتی روی آن مجاز است.

در این فصل با همه‌ی انواع داده‌ی اصلی پایتون آشنا می‌شوید: اعداد صحیح و اعشاری، رشته‌ها، مقادیر بولی (True/False) و مقدار خاص None که نشان‌دهنده‌ی "هیچ" است. همچنین یاد می‌گیرید که چگونه با input() از کاربر ورودی بگیرید، آن را به نوع مناسب تبدیل کنید و با print() و f-strings خروجی‌های زیبا و حرفه‌ای تولید کنید.

تسلط بر متغیرها و انواع داده، پایه‌ی تمام مباحث بعدی مانند حلقه‌ها، شرط‌ها، توابع و برنامه‌نویسی شی‌گرا است. اگر این مفاهیم را به‌خوبی درک کنید، یادگیری بقیه‌ی پایتون برای شما بسیار آسان‌تر و لذت‌بخش‌تر خواهد شد.

🧠 بدنه اصلی آموزش

۲.۱ متغیرها در پایتون و قوانین نام‌گذاری

در پایتون برای تعریف متغیر، فقط کافی است یک نام انتخاب کنید و با عملگر = به آن مقدار بدهید. نیازی به اعلام نوع داده نیست، زیرا پایتون یک زبان Dynamically Typed (نوع‌دهی پویا) است و نوع متغیر را بر اساس مقدار اختصاص‌داده‌شده تشخیص می‌دهد.

  • قوانین اجباری نام‌گذاری (در غیر این صورت خطای SyntaxError می‌گیرید):
    • نام متغیر باید با یک حرف (a-z, A-Z) یا کاراکتر _ شروع شود (نه عدد).
    • نام متغیر فقط می‌تواند شامل حروف، اعداد و _ باشد (بدون فاصله یا کاراکترهای خاص مثل @, #, $).
    • پایتون به حروف بزرگ و کوچک حساس است؛ یعنی age و Age و AGE سه متغیر متفاوت هستند.
    • از کلمات کلیدی (Keywords) پایتون مثل if، for، while، class، def و ... استفاده نکنید، زیرا این کلمات برای ساختار زبان رزرو شده‌اند.
  • بهترین شیوه‌ها (Best Practices) برای نام‌گذاری خوانا:
    • از snake_case استفاده کنید (همه حروف کوچک و کلمات با _ از هم جدا شوند) مانند user_age، total_price، is_logged_in.
    • نام‌ها باید معنی‌دار باشند. به‌جای x از age و به‌جای d از date_of_birth استفاده کنید.
    • برای متغیرهای بولی، از نام‌هایی که با is_، has_ یا can_ شروع می‌شوند استفاده کنید تا خوانایی افزایش یابد (مثل is_student).
    • ثابت‌ها (مقادیری که قرار نیست تغییر کنند) را با حروف بزرگ و _ بنویسید: PI = 3.14، MAX_CONNECTIONS = 100.
# تعریف متغیرهای معنی‌دار
first_name = "علی"
last_name = "رضایی"
age = 25
height = 1.78
is_student = True

# چاپ متغیرها
print(first_name)      # "علی"
print(age)             # 25
print(height)          # 1.78
print(is_student)      # True

# تغییر مقدار متغیر (متغیرها در پایتون قابل تغییر هستند)
age = 26               # مقدار قبلی (25) جایگزین می‌شود
print(age)             # 26

# تعریف چند متغیر در یک خط (unpacking)
x, y, z = 10, 20, 30
print(x, y, z)         # 10 20 30

# مقدار یکسان برای چند متغیر (زنجیره‌ای)
a = b = c = 0
print(a, b, c)         # 0 0 0

# ❌ نام‌های نامعتبر (خطا می‌دهند):
# 2nd_name = "سارا"      # شروع با عدد ممنوع
# my-name = "رضا"        # استفاده از خط فاصله ممنوع
# class = "ریاضی"        # کلمه کلیدی ممنوع

# ✅ نام‌های معتبر و خوانا
user_age = 30
total_price = 199_000   # زیرخط برای خوانایی اعداد بزرگ
is_logged_in = False
➜ علی
➜ 25
➜ 1.78
➜ True
➜ 26
💡 نکته مهم: در پایتون، متغیرها به‌صورت پویا (Dynamic) نوع‌دهی می‌شوند. یعنی یک متغیر می‌تواند در طول اجرای برنامه نوع خود را تغییر دهد (مثلاً از عدد به رشته)، اما این کار معمولاً توصیه نمی‌شود زیرا باعث سردرگمی و بروز باگ‌های ناخواسته می‌شود. سعی کنید هر متغیر را برای یک نوع داده‌ی مشخص نگه دارید.
🧪 تمرین: سه متغیر با نام‌های first_name، birth_year و monthly_salary تعریف کنید و مقادیر مناسب (رشته، عدد صحیح و عدد اعشاری) به آنها بدهید. سپس آنها را با print() در یک خط نمایش دهید.

۲.۲ انواع داده‌های اصلی در پایتون

پایتون دارای انواع داده‌های داخلی متعددی است، اما در این فصل با ۵ نوع داده‌ی اصلی و پرکاربرد آشنا می‌شوید:

🔢 int اعداد صحیح (بدون اعشار)
مثال: 10, -5, 0, 1000
🔢 float اعداد اعشاری (با ممیز شناور)
مثال: 3.14, -0.5, 2.0, 1e-3
📝 str رشته‌ها (دنباله‌ای از کاراکترها)
مثال: "سلام", 'Python', "123"
✅ bool مقادیر منطقی (درست/نادرست)
مثال: True, False
❌ NoneType مقدار خالی یا عدم وجود مقدار
مثال: None

نکته: None در پایتون معادل "هیچ" یا "بی‌مقدار" است و برای نشان دادن عدم وجود یک مقدار معنی‌دار استفاده می‌شود. این نوع داده بسیار پرکاربرد است، مخصوصاً در توابعی که مقداری برای بازگشت ندارند.

# int - اعداد صحیح (بدون محدودیت اندازه در پایتون ۳)
age = 30
temperature = -5
population = 8_000_000_000   # استفاده از زیرخط برای خوانایی

# float - اعداد اعشاری (با دقت مضاعف)
pi = 3.14159
price = 19.99
weight = 0.5
scientific = 1.5e-3          # 0.0015

# str - رشته‌ها (با ' یا ")
name = "علی رضایی"
message = 'سلام دنیا!'
multi_line = """این یک رشته
چند خطی است
که می‌تواند چندین خط داشته باشد"""

# bool - مقادیر بولی (برای شرط‌ها و تصمیم‌گیری)
is_logged_in = True
is_admin = False
has_permission = True

# None - مقدار خالی (معادل "هیچ")
result = None
user = None
response = None

# نمایش نوع هر متغیر با type()
print(type(age))          # <class 'int'>
print(type(pi))           # <class 'float'>
print(type(name))         # <class 'str'>
print(type(is_logged_in)) # <class 'bool'>
print(type(result))       # <class 'NoneType'>
💎 نکته طلایی: برای تشخیص نوع داده‌ی یک متغیر در حین اجرا، از تابع type() استفاده کنید. این کار در دیباگ و درک کدهای دیگران بسیار کمک‌کننده است.
🧪 تمرین: یک متغیر از هر یک از ۵ نوع داده‌ی اصلی (int, float, str, bool, None) تعریف کنید و با استفاده از type() نوع هر کدام را در کنسول چاپ کنید.

۲.۳ تشخیص نوع داده با type()

تابع type() یکی از پرکاربردترین توابع داخلی پایتون برای دیباگ و درک کد است. این تابع نوع داده‌ی یک شیء (متغیر، مقدار، یا حتی یک عبارت) را برمی‌گرداند. در محیط‌های تعاملی و در حین توسعه، استفاده از type() به شما کمک می‌کند تا بفهمید دقیقاً با چه نوع داده‌ای سروکار دارید.

# تشخیص نوع داده برای مقادیر مستقیم
print(type(10))          # <class 'int'>
print(type(3.14))        # <class 'float'>
print(type("سلام"))      # <class 'str'>
print(type(True))        # <class 'bool'>
print(type(None))        # <class 'NoneType'>

# تشخیص نوع متغیرها
x = 42
y = 3.14
z = "Python"
print(type(x))  # <class 'int'>
print(type(y))  # <class 'float'>
print(type(z))  # <class 'str'>

# استفاده در شرط‌ها (مثلاً برای اعتبارسنجی)
value = 10
if type(value) == int:
    print("✅ این یک عدد صحیح است")
else:
    print("❌ این عدد صحیح نیست")

# type() روی عبارت‌ها و عملیات‌ها
print(type(5 + 3))        # <class 'int'>
print(type("5" + "3"))    # <class 'str'>
print(type(10 / 3))       # <class 'float'> (تقسیم همیشه float برمی‌گرداند)
➜ <class 'int'>
➜ <class 'float'>
➜ <class 'str'>
➜ <class 'bool'>
➜ <class 'NoneType'>
💡 نکته: type() در شرایطی که داده‌ها از منابع خارجی (مثل ورودی کاربر، فایل‌ها یا APIها) دریافت می‌شوند، بسیار مفید است تا مطمئن شوید داده‌ها به فرمت مورد انتظار شما هستند.
🧪 تمرین: یک متغیر data = "123" تعریف کنید. با type() نوع آن را ببینید. سپس آن را با int() به عدد تبدیل کنید و دوباره نوع آن را بررسی کنید. تفاوت را توضیح دهید.

۲.۴ تبدیل نوع (Type Casting)

در پایتون، گاهی نیاز داریم یک مقدار را از یک نوع داده به نوع دیگری تبدیل کنیم. این کار با استفاده از توابع تبدیل نوع (Type Casting) انجام می‌شود. مهم‌ترین این توابع عبارتند از:

  • int(): تبدیل به عدد صحیح (اگر مقدار قابل تبدیل نباشد، ValueError می‌دهد).
  • float(): تبدیل به عدد اعشاری.
  • str(): تبدیل به رشته (هر نوع داده‌ای را به رشته تبدیل می‌کند).
  • bool(): تبدیل به مقدار بولی (طبق قوانین Truthy/Falsy).

قوانین تبدیل به bool (Truthy و Falsy):

  • Falsy (معادل False): None، False، 0، 0.0، رشته‌ی خالی ""، لیست خالی []، دیکشنری خالی {} و ...
  • Truthy (معادل True): هر مقداری که در لیست Falsy نباشد.
# ========== تبدیل به int ==========
print(int(3.14))          # 3 (اعشار حذف می‌شود، نه گرد)
print(int("123"))         # 123
print(int(True))          # 1
print(int(False))         # 0

# ========== تبدیل به float ==========
print(float(5))           # 5.0
print(float("3.14"))      # 3.14
print(float(True))        # 1.0

# ========== تبدیل به str ==========
print(str(123))           # "123"
print(str(3.14))          # "3.14"
print(str(True))          # "True"
print(str(None))          # "None"

# ========== تبدیل به bool ==========
print(bool(0))            # False
print(bool(1))            # True
print(bool(-5))           # True (هر عدد غیرصفر)
print(bool(""))           # False (رشته خالی)
print(bool("سلام"))       # True (رشته غیرخالی)
print(bool(None))         # False
print(bool([]))           # False (لیست خالی)
print(bool([1, 2]))       # True (لیست غیرخالی)

# ========== کاربرد عملی: تبدیل ورودی کاربر ==========
age_str = input("سن خود را وارد کنید: ")   # ورودی همیشه رشته است
age = int(age_str)                         # تبدیل به int برای محاسبات
print(f"سال آینده {age + 1} ساله می‌شوید")

# ========== خطا در تبدیل ==========
# int("abc")     # ❌ ValueError: invalid literal for int() with base 10: 'abc'
# float("hello") # ❌ ValueError: could not convert string to float: 'hello'

# ========== تبدیل اعداد با کاما (با replace) ==========
price_str = "1,200,000"
price = int(price_str.replace(",", ""))  # "1200000"
print(price)                             # 1200000
➜ 3, 123, 1, 0
➜ 5.0, 3.14, 1.0
➜ "123", "3.14", "True", "None"
➜ False, True, True, False, True, False
💡 نکته مهم: در پایتون، هر متغیر را می‌توان به نوع دیگری تبدیل کرد، اما اگر تبدیل معنی‌دار نباشد (مثل تبدیل "abc" به عدد)، خطای ValueError رخ می‌دهد. برای جلوگیری از کرش برنامه، همیشه از try/except (در فصل ۱۲) یا اعتبارسنجی اولیه استفاده کنید.
🧪 تمرین: یک رشته‌ی عددی مثل "42.5" را به float تبدیل کنید، سپس به int و در نهایت به str تبدیل کنید و هر مرحله را با print() و توضیح همراه نمایش دهید.

۲.۵ دریافت ورودی با input()

تابع input() یکی از راه‌های اصلی تعامل با کاربر در برنامه‌های خط فرمان است. این تابع یک پیام (اختیاری) را به کاربر نمایش می‌دهد، منتظر می‌ماند تا کاربر متنی را وارد کند و پس از فشردن کلید Enter، آن را به‌صورت یک رشته (str) برمی‌گرداند.

نکات کلیدی:

  • خروجی input() همیشه یک رشته است، حتی اگر کاربر عدد وارد کرده باشد.
  • برای دریافت اعداد، باید خروجی input() را با توابعی مثل int() یا float() تبدیل کنید.
  • اگر کاربر ورودی نامعتبر وارد کند، خطای ValueError رخ می‌دهد که در فصل مدیریت خطاها با آن آشنا می‌شوید.
# ========== دریافت رشته ==========
name = input("نام خود را وارد کنید: ")
print(f"سلام {name}!")

# ========== دریافت عدد صحیح ==========
age = int(input("سن خود را وارد کنید: "))
print(f"شما {age} ساله هستید و سال آینده {age + 1} ساله می‌شوید.")

# ========== دریافت عدد اعشاری ==========
height = float(input("قد خود را به متر وارد کنید: "))
print(f"قد شما {height} متر است.")

# ========== دریافت چند مقدار در یک خط (با split) ==========
# کاربر دو عدد را با فاصله وارد می‌کند: 10 20
values = input("دو عدد با فاصله وارد کنید: ").split()
num1 = int(values[0])
num2 = int(values[1])
print(f"مجموع: {num1 + num2}")

# ========== محاسبه با ورودی ==========
num1 = int(input("عدد اول: "))
num2 = int(input("عدد دوم: "))
print(f"{num1} + {num2} = {num1 + num2}")
print(f"{num1} - {num2} = {num1 - num2}")
print(f"{num1} * {num2} = {num1 * num2}")
print(f"{num1} / {num2} = {num1 / num2:.2f}")  # با ۲ رقم اعشار

# ========== دریافت ورودی با تبدیل خودکار (اگر عدد نبود خطا می‌دهد) ==========
try:
    score = int(input("نمره خود را وارد کنید: "))
    print(f"نمره ثبت شد: {score}")
except ValueError:
    print("❌ لطفاً یک عدد معتبر وارد کنید.")
➜ نام خود را وارد کنید: علی
➜ سلام علی!
💎 نکته طلایی: همیشه ورودی‌های عددی را با int() یا float() تبدیل کنید. اگر کاربر به‌جای عدد، متن وارد کند، برنامه با ValueError متوقف می‌شود. برای ساخت برنامه‌های مقاوم، در فصل ۱۲ با مدیریت خطاها (try/except) آشنا خواهید شد.
🧪 تمرین: برنامه‌ای بنویسید که از کاربر دو عدد (اعشاری) دریافت کند، میانگین آنها را محاسبه کند و نتیجه را با پیام "میانگین دو عدد: X.XX" چاپ کند (با ۲ رقم اعشار).

۲.۶ f-strings و فرمت‌دهی خروجی

f-strings (رشته‌های f) که از پایتون ۳.۶ به بعد معرفی شده‌اند، مدرن‌ترین، ساده‌ترین و سریع‌ترین روش برای فرمت‌دهی رشته‌ها در پایتون هستند. با قرار دادن حرف f قبل از رشته و استفاده از {} برای درج متغیرها یا عبارات، می‌توانید خروجی‌های زیبا، خوانا و حرفه‌ای تولید کنید.

قابلیت‌های کلیدی f-strings:

  • درج مستقیم متغیرها با {variable}
  • اجرای عبارات و محاسبات درون {}
  • فرمت‌دهی اعداد (تعداد ارقام اعشار، جداکننده هزارگان، تراز چپ/راست)
  • فراخوانی توابع درون {}
name = "علی"
age = 25
height = 1.78
score = 95.5

# ========== f-string ساده ==========
print(f"نام: {name}، سن: {age}")           # "نام: علی، سن: 25"

# ========== محاسبه درون f-string ==========
print(f"سال آینده {age + 1} ساله می‌شوید")  # "سال آینده 26 ساله می‌شوید"
print(f"سن دو برابر: {age * 2}")           # "سن دو برابر: 50"

# ========== فرمت‌دهی اعداد اعشاری ==========
pi = 3.14159265
print(f"pi با 2 رقم اعشار: {pi:.2f}")    # "pi با 2 رقم اعشار: 3.14"
print(f"pi با 4 رقم اعشار: {pi:.4f}")    # "pi با 4 رقم اعشار: 3.1416"
print(f"pi با 8 رقم اعشار: {pi:.8f}")    # "pi با 8 رقم اعشار: 3.14159265"

# ========== جداکننده هزارگان (کاما) ==========
price = 19900000
print(f"قیمت: {price:,} تومان")           # "قیمت: 19,900,000 تومان"

# ========== تراز چپ/راست و پر کردن با فاصله ==========
print(f"امتیاز: {score:>10}")              # "امتیاز:       95.5" (راست‌چین با ۱۰ فاصله)
print(f"امتیاز: {score:<10}")              # "امتیاز: 95.5      " (چپ‌چین با ۱۰ فاصله)
print(f"امتیاز: {score:^10}")              # "امتیاز:   95.5   " (وسط‌چین)

# ========== ترکیب چند قابلیت ==========
discount = 0.15
final_price = price * (1 - discount)
print(f"قیمت با {discount * 100:.0f}% تخفیف: {final_price:,.0f} تومان")
# خروجی: "قیمت با 15% تخفیف: 16,915,000 تومان"

# ========== فراخوانی توابع درون f-string ==========
print(f"نام با حروف بزرگ: {name.upper()}")  # "نام با حروف بزرگ: علی"

# ========== مقایسه با روش‌های قدیمی ==========
# روش .format() (قدیمی‌تر)
print("نام: {}, سن: {}".format(name, age))
# روش % (قدیمی‌ترین)
print("نام: %s, سن: %d" % (name, age))
➜ نام: علی، سن: 25
➜ سال آینده 26 ساله می‌شوید
➜ pi با 2 رقم اعشار: 3.14
➜ قیمت با 15% تخفیف: 16,915,000 تومان
💡 نکته مهم: f-strings از Python 3.6 به بعد در دسترس هستند و توصیه‌شده‌ترین روش برای فرمت‌دهی رشته‌ها محسوب می‌شوند. اگر از نسخه‌های قدیمی‌تر پایتون استفاده می‌کنید، از متد .format() استفاده کنید.
🧪 تمرین: برنامه‌ای بنویسید که نام، سن، حقوق ماهانه و درصد مالیات را از کاربر دریافت کند و با f-string یک گزارش حقوقی زیبا شامل حقوق خالص (پس از کسر مالیات) با فرمت هزارگان و ۲ رقم اعشار نمایش دهد.

۲.۷ متغیرهای قابل تغییر (Mutable) و غیرقابل تغییر (Immutable)

یکی از مفاهیم کلیدی و مهم در پایتون، تفاوت بین انواع داده‌های قابل تغییر (Mutable) و غیرقابل تغییر (Immutable) است. درک این تفاوت برای جلوگیری از باگ‌های عجیب در برنامه‌های پیچیده، مخصوصاً هنگام کار با توابع و اشیاء، حیاتی است.

  • Immutable (غیرقابل تغییر): پس از ایجاد، نمی‌توان مقدار آنها را تغییر داد. هر تغییری در واقع یک شیء جدید ایجاد می‌کند. شامل: int، float، str، bool، tuple، frozenset.
  • Mutable (قابل تغییر): می‌توان مقدار آنها را بدون ایجاد شیء جدید تغییر داد. شامل: list، dict، set، bytearray.
# ========== Immutable: رشته‌ها ==========
text = "سلام"
print(f"آدرس قبلی: {id(text)}")  # آدرس حافظه
text = text + " دنیا"            # رشته‌ی جدید ایجاد می‌شود
print(f"آدرس جدید: {id(text)}")  # آدرس تغییر کرده است
# (رشته اصلی تغییر نکرد، یک رشته‌ی جدید ساخته شد)

# ========== Immutable: اعداد ==========
x = 10
print(f"آدرس x: {id(x)}")
x = x + 5                        # عدد جدید ایجاد می‌شود
print(f"آدرس جدید x: {id(x)}")   # آدرس تغییر کرده است

# ========== Mutable: لیست‌ها (در فصل بعد) ==========
my_list = [1, 2, 3]
print(f"آدرس لیست: {id(my_list)}")
my_list.append(4)                # لیست تغییر می‌کند (همان شیء)
print(f"آدرس لیست بعد از append: {id(my_list)}")  # آدرس ثابت می‌ماند

# ========== Mutable: دیکشنری‌ها ==========
my_dict = {"name": "علی"}
print(f"آدرس دیکشنری: {id(my_dict)}")
my_dict["age"] = 25              # اضافه کردن کلید جدید (همان شیء)
print(f"آدرس دیکشنری بعد از تغییر: {id(my_dict)}")  # آدرس ثابت

# ========== تفاوت رفتار در توابع (مهم!) ==========
def change_value(x):
    x = x + 10                   # ایجاد متغیر محلی جدید (Immutable)
    print(f"داخل تابع: {x}")

def change_list(lst):
    lst.append(10)               # تغییر لیست اصلی (Mutable)
    print(f"داخل تابع: {lst}")

num = 5
change_value(num)
print(f"بعد از تابع: {num}")     # 5 (تغییر نکرد)

my_list2 = [1, 2, 3]
change_list(my_list2)
print(f"بعد از تابع: {my_list2}")  # [1, 2, 3, 10] (تغییر کرده)
➜ آدرس قبلی: 140002345678
➜ آدرس جدید: 140002345999
➜ داخل تابع: 15
➜ بعد از تابع: 5
➜ داخل تابع: [1, 2, 3, 10]
➜ بعد از تابع: [1, 2, 3, 10]
💎 نکته طلایی: درک تفاوت بین Mutable و Immutable به شما کمک می‌کند تا بفهمید چرا برخی از تغییرات در توابع بر روی داده‌های اصلی تأثیر می‌گذارند و برخی نه. این موضوع در برنامه‌نویسی واقعی، مخصوصاً هنگام کار با داده‌های حجیم و اشتراک‌گذاری داده‌ها بین بخش‌های مختلف برنامه، بسیار حیاتی است.
🧪 تمرین: یک رشته تعریف کنید و با عملگر + آن را تغییر دهید. با id() آدرس حافظه را قبل و بعد از تغییر بررسی کنید. سپس یک لیست (با []) تعریف کنید و با append() به آن عنصر اضافه کنید و دوباره آدرس را بررسی کنید. تفاوت را توضیح دهید.

🛠️ کارگاه عملی

گام‌به‌گام: برنامه‌ای برای محاسبه‌ی BMI (شاخص توده بدنی)

در این کارگاه، یک برنامه‌ی کامل برای محاسبه‌ی BMI (Body Mass Index) می‌نویسیم که از مفاهیم این فصل (متغیرها، انواع داده، ورودی/خروجی، تبدیل نوع و f-strings) استفاده می‌کند.

  1. ایجاد فایل: یک فایل جدید به نام bmi_calculator.py در VS Code ایجاد کنید.
  2. دریافت ورودی: از کاربر وزن (به کیلوگرم) و قد (به متر) را با input() دریافت کنید. هر دو را به float تبدیل کنید. 
    weight = float(input("وزن خود را به کیلوگرم وارد کنید: "))
height = float(input("قد خود را به متر وارد کنید: "))
  3. محاسبه‌ی BMI: BMI را با فرمول weight / (height ** 2) محاسبه کنید.
  4. تعیین وضعیت: با استفاده از شرط‌های ساده (if/elif/else که در فصل ۴ یاد می‌گیرید)، وضعیت را مشخص کنید. برای اینجا از یک سری شرط ساده استفاده می‌کنیم:
    • کمتر از 18.5: "کمبود وزن"
    • 18.5 تا 24.9: "وزن طبیعی"
    • 25 تا 29.9: "اضافه وزن"
    • 30 و بالاتر: "چاقی"
  5. نمایش خروجی: با استفاده از f-string، BMI را با ۲ رقم اعشار و وضعیت آن را نمایش دهید.
  6. نوع داده‌ها: با استفاده از type() نوع هر متغیر (وزن، قد، BMI) را در کنسول چاپ کنید تا ببینید همه float هستند.

کد کامل:

# دریافت ورودی از کاربر
weight = float(input("وزن خود را به کیلوگرم وارد کنید: "))
height = float(input("قد خود را به متر وارد کنید: "))

# محاسبه BMI
bmi = weight / (height ** 2)

# تعیین وضعیت (با شرط‌های ساده - در فصل ۴ کامل می‌شود)
if bmi < 18.5:
    status = "کمبود وزن"
elif 18.5 <= bmi < 25:
    status = "وزن طبیعی"
elif 25 <= bmi < 30:
    status = "اضافه وزن"
else:
    status = "چاقی"

# نمایش نتیجه با f-string
print(f"\n📊 شاخص توده بدنی (BMI) شما: {bmi:.2f}")
print(f"وضعیت: {status}")

# نمایش نوع داده‌ها (برای اهداف آموزشی)
print(f"\nنوع داده‌ها:")
print(f"وزن: {type(weight)}")
print(f"قد: {type(height)}")
print(f"BMI: {type(bmi)}")

سوالات تشریحی

  1. قوانین نام‌گذاری متغیرها در پایتون چیست؟ تفاوت بین snake_case و camelCase را توضیح دهید و کدام در پایتون ترجیح داده می‌شود؟
  2. تفاوت بین int و float چیست؟ چه زمانی از هرکدام استفاده می‌کنیم؟
  3. input() چه نوع داده‌ای برمی‌گرداند و چرا باید آن را به نوع مناسب تبدیل کنیم؟ اگر تبدیل را فراموش کنیم، چه اتفاقی می‌افتد؟
  4. f-strings چه مزایایی نسبت به روش‌های قدیمی‌تر (مثل .format() یا %) دارند؟ حداقل سه مزیت را نام ببرید.
  5. تفاوت بین انواع Mutable و Immutable چیست؟ مثال‌هایی از هرکدام بیاورید و توضیح دهید که چرا این تفاوت در برنامه‌نویسی مهم است.

سوالات چهارگزینه‌ای

  1. کدام یک از موارد زیر یک نام متغیر معتبر در پایتون است؟
    أ) 2name ب) name-2 ج) _name د) name 2
  2. خروجی کد زیر چیست؟
    print(type(3.14))
    أ) <class 'int'> ب) <class 'float'> ج) <class 'str'> د) <class 'bool'>
  3. برای تبدیل یک رشته‌ی عددی به عدد صحیح از کدام تابع استفاده می‌شود؟
    أ) str() ب) float() ج) int() د) bool()
  4. کدام یک از موارد زیر مقدار False را در شرط‌ها (Falsy) ندارد؟
    أ) "" ب) [] ج) None د) "False"
  5. کدام یک از انواع داده‌های زیر قابل تغییر (Mutable) است؟
    أ) str ب) int ج) list د) tuple

تمرین عملی

یک برنامه بنویسید که:

  • از کاربر سه عدد (اعشاری) با input() دریافت کند و هر کدام را به float تبدیل کند.
  • مجموع، میانگین و حاصلضرب آنها را محاسبه کند.
  • همه‌ی نتایج را با f-string به‌صورت زیبا و با ۲ رقم اعشار نمایش دهد.
  • نوع داده‌ی هر متغیر (هر سه عدد و نتایج) را با type() در کنسول چاپ کند.
  • اگر کاربر یکی از اعداد را به‌صورت غیرعددی وارد کرد، پیام "ورودی نامعتبر" را چاپ کند (با استفاده از try/except که در فصل ۱۲ یاد می‌گیرید، ولی فعلاً می‌توانید از if و isinstance استفاده کنید).

نکات طلایی

  • 🔹 متغیرها با نام‌گذاری snake_case تعریف می‌شوند و باید معنی‌دار باشند.
  • 🔹 انواع داده‌ی اصلی: int (اعداد صحیح)، float (اعداد اعشاری)، str (رشته)، bool (مقادیر منطقی) و None (مقدار خالی).
  • 🔹 type() تابعی برای تشخیص نوع داده‌ی متغیرها است و در دیباگ بسیار مفید است.
  • 🔹 input() ورودی را همیشه به‌صورت رشته برمی‌گرداند؛ برای محاسبات باید آن را با int() یا float() تبدیل کرد.
  • 🔹 int()، float()، str() و bool() توابع اصلی تبدیل نوع هستند.
  • 🔹 f-strings بهترین و مدرن‌ترین روش برای فرمت‌دهی خروجی با قابلیت‌های پیشرفته (فرمت اعداد، تراز، محاسبات درون‌خطی).
  • 🔹 انواع Immutable (غیرقابل تغییر) مانند int، str و tuple و انواع Mutable (قابل تغییر) مانند list و dict را بشناسید و تفاوت رفتار آنها را درک کنید.

📖 واژه‌نامه تخصصی

  • Variable (متغیر): نامی برای ارجاع به یک مقدار در حافظه.
  • int: نوع داده برای اعداد صحیح (بدون اعشار) مانند 10، -5، 0.
  • float: نوع داده برای اعداد اعشاری با ممیز شناور مانند 3.14، 2.0، 0.5.
  • str: نوع داده برای رشته‌ها (دنباله‌ای از کاراکترها) که با ' یا " مشخص می‌شود.
  • bool: نوع داده برای مقادیر منطقی (True یا False).
  • None: مقدار خاص برای نشان دادن "هیچ" یا عدم وجود مقدار.
  • Type Casting (تبدیل نوع): فرآیند تبدیل یک مقدار از یک نوع داده به نوع دیگر با استفاده از توابعی مانند int()، float()، str() و bool().
  • f-string: روش مدرن و کارآمد برای فرمت‌دهی رشته‌ها با قرار دادن f قبل از رشته و استفاده از {} برای درج متغیرها و عبارات.
  • Mutable (قابل تغییر): نوع داده‌ای که می‌توان مقدار آن را پس از ایجاد تغییر داد (مثلاً لیست‌ها و دیکشنری‌ها).
  • Immutable (غیرقابل تغییر): نوع داده‌ای که پس از ایجاد، مقدار آن قابل تغییر نیست (مثلاً اعداد، رشته‌ها و تاپل‌ها).
  • Truthy / Falsy: مفهومی که مشخص می‌کند یک مقدار در شرط‌ها معادل True یا False رفتار می‌کند. مقادیر Falsy شامل None، False، 0، رشته‌ی خالی، لیست خالی و ... هستند.

❓ سوالات محرک (برای درگیری ذهن)

  • ❓ چرا پایتون یک زبان "Dynamically Typed" است و این ویژگی چه مزایا و معایبی دارد؟
  • ❓ چه اتفاقی می‌افتد اگر int("abc") را اجرا کنیم؟ چرا این خطا رخ می‌دهد و چگونه می‌توان از آن جلوگیری کرد؟
  • ❓ تفاوت بین input() و print() از نظر نوع داده و کاربرد چیست؟
  • ❓ چرا f-strings بهتر از استفاده از عملگر + برای ترکیب رشته‌ها هستند؟ (به عملکرد و خوانایی فکر کنید).
  • ❓ اگر یک رشته را با عملگر + تغییر دهیم، آیا رشته‌ی اصلی تغییر می‌کند یا یک رشته‌ی جدید ساخته می‌شود؟ چگونه می‌توان این را با id() بررسی کرد؟
  • ❓ چه تفاوتی بین None و "" (رشته خالی) وجود دارد؟ هرکدام در چه شرایطی استفاده می‌شوند؟

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن تبدیل ورودی input() به عدد، که باعث می‌شود عملیات ریاضی روی رشته‌ها (ترکیب به‌جای جمع) انجام شود یا با خطای TypeError مواجه شوید.
    🔧 راه حل: همیشه ورودی‌های عددی را با int() یا float() تبدیل کنید: age = int(input("سن: ")).
  • 🔴 اشتباه: استفاده از نام متغیرهای غیرمعتبر (شروع با عدد، استفاده از فاصله یا کاراکترهای خاص) که باعث خطای SyntaxError می‌شود.
    🔧 راه حل: از snake_case و شروع با حرف یا _ استفاده کنید: user_name، _private.
  • 🔴 اشتباه: فراموش کردن f قبل از f-string که باعث می‌شود {} به‌عنوان متن معمولی نمایش داده شود.
    🔧 راه حل: همیشه قبل از رشته‌ی خود f قرار دهید: f"متن {var}".
  • 🔴 اشتباه: استفاده از = به‌جای == در شرط‌ها (مربوط به فصل بعد) که باعث انتساب به‌جای مقایسه می‌شود.
    🔧 راه حل: برای مقایسه از == استفاده کنید و از = فقط برای مقداردهی استفاده کنید.
  • 🔴 اشتباه: تغییر یک متغیر Immutable و انتظار اینکه همان شیء تغییر کند. مثلاً فرض کنید text = "hello" و سپس text[0] = "H" که خطای TypeError می‌دهد.
    🔧 راه حل: بدانید که رشته‌ها و اعداد غیرقابل تغییر هستند و هر تغییر یک شیء جدید ایجاد می‌کند. برای تغییر رشته‌ها، از روش‌های جایگزین مانند replace() یا ترکیب برش‌ها استفاده کنید.
  • 🔴 اشتباه: استفاده از type() برای مقایسه نوع به‌صورت type(x) == int که در برخی موارد کار می‌کند، اما روش استاندارد استفاده از isinstance(x, int) است.
    🔧 راه حل: برای بررسی نوع، از isinstance() استفاده کنید: isinstance(x, int).

🏆 پروژه نهایی فصل ۲

عنوان پروژه: ساخت یک ماشین‌حساب پیشرفته با ورودی کاربر و اعتبارسنجی

شرح: یک برنامه‌ی خط فرمان (CLI) بسازید که مانند یک ماشین‌حساب هوشمند عمل کند و از مفاهیم این فصل (متغیرها، انواع داده، تبدیل نوع، f-strings، ورودی/خروجی) استفاده کند.

ویژگی‌های مورد نیاز:

  • برنامه با یک پیام خوش‌آمدگویی زیبا شروع شود: "به ماشین‌حساب پیشرفته خوش آمدید!"
  • از کاربر دو عدد (با input()) دریافت کند و آنها را به نوع مناسب تبدیل کند (در صورت ورود غیرعددی، پیام خطا نمایش دهد).
  • از کاربر یک عملگر (+, -, *, /) را با input() دریافت کند (در صورت ورود عملگر نامعتبر، پیام خطا نمایش دهد).
  • بر اساس عملگر، عملیات ریاضی را انجام دهد و نتیجه را با f-string با ۲ رقم اعشار نمایش دهد.
  • در صورت تقسیم بر صفر، پیام "تقسیم بر صفر مجاز نیست" را نمایش دهد.
  • با type() نوع داده‌ی ورودی‌ها (قبل و بعد از تبدیل) را در کنسول چاپ کند تا فرآیند تبدیل نوع را نشان دهد.
  • یک گزارش نهایی با f-string شامل: دو عدد ورودی، عملگر، نتیجه و نوع داده‌ی هر متغیر نمایش دهد.

چالش‌های بیشتر (اختیاری برای کاربران پیشرو):

  • پشتیبانی از عملگرهای توان (**) و باقیمانده (%) را اضافه کنید.
  • اجازه‌ی ادامه‌ی محاسبه با نتیجه‌ی قبلی را بدهید (مانند ماشین‌حساب واقعی). یعنی بعد از هر محاسبه، از کاربر بپرسید "آیا می‌خواهید با نتیجه ادامه دهید؟ (y/n)".
  • تاریخچه‌ی عملیات را در یک لیست ذخیره کنید و در پایان برنامه، تمام عملیات‌های انجام‌شده را نمایش دهید.
  • با استفاده از try/except (که در فصل ۱۲ به طور کامل یاد می‌گیرید)، ورودی‌های غیرعددی را مدیریت کنید و از کرش برنامه جلوگیری کنید.
