🚀 مقدمه و انگیزه‌بخشی

پایتون یکی از محبوب‌ترین زبان‌های برنامه‌نویسی جهان است که در حال حاضر توسط غول‌های فناوری مانند گوگل، اینستاگرام، اسپاتیفای و نتفلیکس استفاده می‌شود. از توسعه‌ی وب (با Django و Flask) تا دیتا ساینس (با Pandas و NumPy)، از اتومیشن و اسکریپت‌نویسی تا هوش مصنوعی و یادگیری ماشین – پایتون در همه‌جا حضور دارد. اما چه چیزی پایتون را اینقدر خاص می‌کند؟

  • سادگی و خوانایی: کد پایتون شبیه به زبان انگلیسی است و یادگیری آن بسیار آسان است. این ویژگی باعث می‌شود تازه‌کاران سریع‌تر پیشرفت کنند.
  • جامعه‌ی بزرگ و پشتیبانی عالی: هزاران کتابخانه و فریم‌ورک آماده برای هر نیازی (از وب گرفته تا رباتیک) وجود دارد.
  • همه‌کاره بودن: پایتون یک زبان همه‌منظوره است؛ یعنی می‌توانید با یک زبان، هم وب‌سایت بسازید، هم داده تحلیل کنید و هم بازی بسازید.
  • بازار کار عالی: تقاضای بالا برای توسعه‌دهندگان پایتون در سراسر جهان، آن را به یکی از پردرآمدترین مهارت‌های حوزه فناوری تبدیل کرده است.

در این فصل، با مبانی پایتون آشنا می‌شوید: تاریخچه، نصب، راه‌اندازی محیط توسعه و نوشتن اولین برنامه. این فصل پایه‌ی تمام مباحث بعدی است، پس با دقت و حوصله پیش بروید.

🧠 بدنه اصلی آموزش

۱.۱ پایتون چیست و چه کاربردهایی دارد؟

پایتون (Python) یک زبان برنامه‌نویسی سطح‌بالا، تفسیری و همه‌کاره است که توسط خودو فان روسوم (Guido van Rossum) در سال ۱۹۹۱ ایجاد شد. فلسفه‌ی اصلی پایتون "خوانایی کد" است و بر استفاده از فاصله‌گذاری (Indentation) برای مشخص کردن بلوک‌های کد تأکید دارد.

کاربردهای اصلی پایتون در دنیای واقعی:

  • توسعه‌ی وب (Backend): Django (برای پروژه‌های بزرگ)، Flask (برای پروژه‌های سبک و API)، FastAPI (برای APIهای فوق‌سریع).
  • دیتا ساینس و تحلیل داده: Pandas (دستکاری داده)، NumPy (محاسبات عددی)، Matplotlib و Seaborn (رسم نمودار).
  • هوش مصنوعی و یادگیری ماشین: TensorFlow و PyTorch (یادگیری عمیق)، Scikit-learn (یادگیری ماشین کلاسیک).
  • اتومیشن و اسکریپت‌نویسی: نوشتن اسکریپت برای انجام کارهای تکراری، مدیریت فایل‌ها، Web Scraping (با BeautifulSoup و Scrapy).
  • توسعه‌ی دسکتاپ: Tkinter (ساده)، PyQt و Kivy (حرفه‌ای‌تر و چندسکویی).
  • توسعه‌ی بازی: Pygame (برای ساخت بازی‌های دو بعدی).
  • علوم و مهندسی: محاسبات علمی، شبیه‌سازی‌های فیزیک و زیست‌شناسی محاسباتی.
💡 نکته فرهنگی: نام "پایتون" از گروه کمدی Monty Python گرفته شده است، نه از مار پایتون! این نام نشان‌دهنده‌ی رویکرد شوخ‌طبعانه‌ی خالق آن است و در مستندات رسمی نیز به این گروه اشاره شده است.

۱.۲ تاریخچه و تکامل پایتون (Python 1.x تا Python 3.x)

پایتون در سال ۱۹۹۱ منتشر شد و از آن زمان تاکنون نسخه‌های مختلفی از آن منتشر شده است. درک این تاریخچه به شما کمک می‌کند تا دلیل تفاوت نسخه‌ها را بهتر درک کنید:

  • Python 1.0 (۱۹۹۴): اولین نسخه‌ی رسمی با پشتیبانی از توابع، ماژول‌ها و استثناها.
  • Python 2.0 (۲۰۰۰): اضافه شدن List Comprehensions و یک سیستم جمع‌آوری زباله (Garbage Collector) کارآمد.
  • Python 2.7 (۲۰۱۰): آخرین نسخه‌ی Python 2 که پشتیبانی آن تا ژانویه ۲۰۲۰ ادامه داشت و اکنون کاملاً منسوخ شده است.
  • Python 3.0 (۲۰۰۸): یک تغییر بنیادین و ناسازگار با نسخه‌ی ۲ (مانند تابعی شدن print، تغییر در تقسیم اعداد و بهبود Unicode).
  • Python 3.6 (۲۰۱۶): اضافه شدن f-strings (ساده‌ترین روش فرمت‌دهی رشته‌ها) و نوع‌دهی (Type Hints).
  • Python 3.8 (۲۰۱۹): اضافه شدن عملگر := (Walrus Operator) برای انتساب درون عبارات.
  • Python 3.10 (۲۰۲۱): اضافه شدن match-case (شبیه به Switch در زبان‌های دیگر).
  • Python 3.12 (۲۰۲۳): بهبود قابل توجه عملکرد و رفع اشکالات.
  • Python 3.13 (۲۰۲۴): پشتیبانی آزمایشی از کامپایلر JIT و بهبودهای بیشتر در سرعت.
💎 نکته طلایی: امروزه Python 3 استاندارد اصلی است و Python 2 به‌طور رسمی منسوخ شده است. هنگام جستجوی راهنما یا نصب پکیج‌ها، همیشه مطمئن شوید که آموزش مربوط به Python 3 است.

۱.۳ نصب پایتون روی Windows، macOS و Linux

ویندوز (Windows):

  1. به سایت python.org بروید و روی دکمه‌ی دانلود Python کلیک کنید.
  2. آخرین نسخه‌ی Python 3 را دانلود کنید (فایل .exe).
  3. قبل از کلیک روی Install، حتماً گزینه‌ی "Add Python to PATH" را در پایین پنجره فعال کنید. این کار از بروز خطاهای بعدی جلوگیری می‌کند.
  4. روی Install Now کلیک کنید و منتظر بمانید تا نصب کامل شود.

macOS:

  1. از python.org نصب‌کننده (فایل .pkg) را دانلود کنید.
  2. فایل را اجرا کرده و مراحل نصب را طی کنید.
  3. روش جایگزین (برای کاربران حرفه‌ای): اگر Homebrew نصب دارید، با دستور brew install python پایتون را نصب کنید.

Linux (Ubuntu/Debian و توزیع‌های مشابه):

  1. ابتدا لیست بسته‌ها را به‌روز کنید: sudo apt update
  2. سپس پایتون ۳ و pip را نصب کنید: sudo apt install python3 python3-pip
# بررسی صحت نصب (اجرا در ترمینال یا Command Prompt)
python3 --version
# خروجی مورد انتظار: Python 3.12.0 (یا نسخه‌ی جدیدتر)

# اجرای محیط تعاملی پایتون (REPL)
python3
# خروجی: Python 3.12.0 (main, ...) [GCC ...] on linux
# Type "help", "copyright", "credits" or "license" for more information.
# >>>
➜ Python 3.12.0
💡 نکته عیب‌یابی: اگر بعد از نصب، دستور python3 در ترمینال شناسایی نشد، یعنی مسیر پایتون به PATH اضافه نشده است. در ویندوز، می‌توانید مسیر C:\Users\[YourUsername]\AppData\Local\Programs\Python\Python312\ را به متغیر محیطی PATH اضافه کنید.
🧪 تمرین: پایتون را روی سیستم خود نصب کنید و با python3 --version (یا python --version در ویندوز) نسخه‌ی نصب‌شده را بررسی کنید. نتیجه را یادداشت کنید.

۱.۴ راه‌اندازی VS Code و نصب افزونه‌ی Python

VS Code (Visual Studio Code) یکی از محبوب‌ترین و بهترین ویرایشگرهای کد برای پایتون است که به‌صورت رایگان در دسترس است. مراحل راه‌اندازی:

  1. VS Code را از code.visualstudio.com دانلود و نصب کنید.
  2. برنامه را باز کنید و به بخش Extensions (با کلیک روی آیکون مستطیل شکل در سمت چپ یا کلیدهای Ctrl+Shift+X) بروید.
  3. در نوار جستجو، عبارت Python را تایپ کنید و افزونه‌ی ارائه‌شده توسط Microsoft را انتخاب و نصب کنید. (این افزونه شامل IntelliSense، Linting، Debugging و Jupyter Notebook support است).
  4. پس از نصب، یک پوشه خالی برای پروژه‌های خود ایجاد کنید و آن را در VS Code باز کنید (File > Open Folder).
  5. برای تست، یک فایل جدید با پسوند .py (مثلاً hello.py) ایجاد کنید.
  6. در پایین سمت چپ VS Code، مطمئن شوید که Python Interpreter صحیح انتخاب شده است. اگر نه، با Ctrl+Shift+P و تایپ Python: Select Interpreter آن را انتخاب کنید.
# فایل hello.py
print("سلام دنیا!")

# برای اجرا، می‌توانید از ترمینال داخلی VS Code استفاده کنید
# (Ctrl + ` برای باز کردن ترمینال) و سپس دستور زیر را وارد کنید:
# python3 hello.py
➜ سلام دنیا!
💡 نکته: VS Code به‌طور خودکار پیشنهادهای کد (IntelliSense)، اشکال‌زدایی گام‌به‌گام (Debugging) و اجرای مستقیم اسکریپت‌ها را فراهم می‌کند. از کلید F5 برای اجرا در حالت دیباگ و Ctrl+F5 برای اجرای بدون دیباگ استفاده کنید.
🧪 تمرین: VS Code را نصب کنید، افزونه‌ی Python را اضافه کنید و یک فایل test.py با محتوای print("Hello from VS Code") ایجاد کنید و آن را اجرا کنید.

۱.۵ اولین برنامه: print() و محیط تعاملی (REPL)

ساده‌ترین برنامه‌ی پایتون، چاپ یک پیام با تابع print() است. دو روش اصلی برای اجرای کد پایتون وجود دارد که هرکدام کاربرد خاص خود را دارند:

  • محیط تعاملی (REPL): مخفف Read-Eval-Print Loop. در این روش، کد را خط‌به‌خط تایپ می‌کنید و بلافاصله نتیجه را می‌بینید. برای یادگیری و تست سریع دستورات عالی است. با دستور python3 در ترمینال وارد آن شوید و با exit() یا Ctrl+D خارج شوید.
  • اسکریپت (فایل .py): کد را در یک فایل متنی با پسوند .py ذخیره کرده و کل برنامه را یکجا با python3 filename.py اجرا می‌کنید. این روش برای پروژه‌های واقعی و کدهای طولانی مناسب است.
# ===============================
# ۱. محیط تعاملی (REPL)
# ===============================
>>> print("سلام دنیا!")   # چاپ متن ساده
سلام دنیا!
>>> 2 + 3                # مفسر پایتون مانند یک ماشین‌حساب عمل می‌کند
5
>>> name = "علی"          # تعریف متغیر (در ادامه به آن می‌پردازیم)
>>> print("سلام", name)   # چاپ ترکیبی
سلام علی
>>> exit()               # خروج از محیط تعاملی

# ===============================
# ۲. اسکریپت (فایل hello.py)
# ===============================
# محتوای فایل hello.py:
print("این یک برنامه‌ی پایتون است")
print(10 + 20)
print("نام من:", "رضا")

# اجرا در ترمینال:
# python3 hello.py
➜ سلام دنیا!
➜ این یک برنامه‌ی پایتون است
➜ 30
➜ نام من: رضا
💎 نکته طلایی: محیط تعاملی (REPL) برای تست سریع کدها، بررسی کتابخانه‌ها و یادگیری مفاهیم جدید بسیار عالی است. از آن به‌عنوان یک "دفترچه‌ی آزمایشی" (Sandbox) استفاده کنید. اما فراموش نکنید که کدهای نهایی را در فایل‌های .py ذخیره کنید تا از دست نروند.
🧪 تمرین: در محیط تعاملی پایتون، سه پیام مختلف با print() چاپ کنید (مثلاً نام، سن و شهر خود را). سپس یک فایل first.py ایجاد کنید، دو خط کد در آن بنویسید و با python3 first.py اجرا کنید.

۱.۶ آشنایی با pip و نصب پکیج‌ها

pip مخفف "Pip Installs Packages" است و به‌عنوان مدیر بسته‌های رسمی پایتون شناخته می‌شود. با استفاده از pip می‌توانید هزاران کتابخانه‌ی شخص ثالث را از مخزن PyPI (Python Package Index) نصب کنید.

  • نصب یک پکیج: pip install package_name
  • نصب نسخه‌ی خاص: pip install package_name==1.2.3
  • آپگرید کردن پکیج: pip install --upgrade package_name
  • حذف یک پکیج: pip uninstall package_name
  • نمایش پکیج‌های نصب‌شده: pip list
  • نمایش اطلاعات یک پکیج: pip show package_name
# نصب پکیج محبوب requests (برای ارسال درخواست HTTP)
pip install requests

# نصب یک نسخه‌ی خاص از numpy
pip install numpy==1.24.0

# به‌روزرسانی pip خودش (توصیه می‌شود)
pip install --upgrade pip

# نصب چند پکیج به‌صورت همزمان
pip install pandas matplotlib jupyter

# نصب از روی فایل requirements.txt (بسیار کاربردی)
pip install -r requirements.txt
💡 نکته مهم: پکیج‌های نصب‌شده با pip در فضای سراسری سیستم (یا در محیط مجازی فعال) نصب می‌شوند. برای جلوگیری از تداخل نسخه‌ها بین پروژه‌های مختلف، همیشه از محیط‌های مجازی استفاده کنید که در بخش بعدی توضیح داده می‌شود.
🧪 تمرین: با استفاده از pip پکیج‌های requests و numpy را نصب کنید. سپس با دستور pip list لیست پکیج‌های نصب‌شده را مشاهده کنید.

۱.۷ محیط‌های مجازی (venv) و اهمیت حیاتی آنها

محیط مجازی (Virtual Environment) یک فضای ایزوله و مستقل برای هر پروژه‌ی پایتون است. فرض کنید پروژه‌ی A نیاز به نسخه‌ی ۱.۰ کتابخانه‌ی X دارد و پروژه‌ی B نیاز به نسخه‌ی ۲.۰ همان کتابخانه. اگر در سیستم به‌صورت سراسری نصب کنید، تداخل رخ می‌دهد. محیط مجازی این مشکل را حل می‌کند.

  • ایجاد محیط مجازی: python3 -m venv venv (در ویندوز ممکن است python -m venv venv باشد).
  • فعال‌سازی در Windows (Command Prompt): venv\Scripts\activate
  • فعال‌سازی در Windows (PowerShell): venv\Scripts\Activate.ps1
  • فعال‌سازی در macOS/Linux: source venv/bin/activate
  • خروج از محیط: deactivate
# ۱. ایجاد محیط مجازی با نام myenv
python3 -m venv myenv

# ۲. فعال‌سازی (در لینوکس/مک)
source myenv/bin/activate

# ۲. فعال‌سازی (در ویندوز - CMD)
myenv\Scripts\activate

# پس از فعال‌سازی، نام (myenv) در ابتدای خط ترمینال ظاهر می‌شود

# ۳. نصب پکیج‌ها در این محیط (ایزوله)
pip install flask

# ۴. ذخیره‌سازی لیست وابستگی‌های فعلی در فایل requirements.txt
pip freeze > requirements.txt

# ۵. خروج از محیط مجازی
deactivate

# ۶. برای نصب وابستگی‌ها در محیط جدید (مثلاً روی سیستم دوستتان)
# ابتدا محیط را فعال کنید، سپس:
pip install -r requirements.txt
💎 نکته طلایی: همیشه برای هر پروژه‌ی پایتونی، حتی پروژه‌های کوچک، یک محیط مجازی ایجاد کنید. این کار باعث می‌شود پروژه‌ها از هم مستقل باشند و از سردرگمی‌های نسخه‌های مختلف جلوگیری شود. فایل requirements.txt را همیشه به همراه پروژه ذخیره کنید تا دیگران بتوانند به‌راحتی محیط شما را بازسازی کنند.
🧪 تمرین: یک محیط مجازی به نام myproject ایجاد کنید، آن را فعال کنید، پکیج flask را نصب کنید و وابستگی‌ها را در فایل requirements.txt ذخیره کنید. سپس از محیط خارج شده و دوباره وارد آن شوید.

🛠️ کارگاه عملی

گام‌به‌گام: ساخت یک برنامه‌ی تعاملی کامل با پایتون

در این کارگاه، یک برنامه می‌نویسیم که از کاربر اطلاعات شخصی دریافت کرده و یک کارت شناسایی ساده برای او چاپ می‌کند.

  1. ایجاد پوشه و محیط: یک پوشه به نام my_profile ایجاد کنید. در ترمینال وارد آن شوید و یک محیط مجازی با python3 -m venv venv بسازید.
  2. فعال‌سازی: محیط را با دستور مربوط به سیستم‌عامل خود فعال کنید.
  3. ایجاد فایل: فایل profile.py را در VS Code باز کنید.
  4. نوشتن کد: کد زیر را در فایل بنویسید (توجه کنید که از input() و print() با فرمت‌دهی استفاده شده است): 
    # دریافت اطلاعات
name = input("نام خود را وارد کنید: ")
age = input("سن خود را وارد کنید: ")
city = input("شهر محل زندگی: ")

# نمایش کارت شناسایی
print("\n" + "="*30)
print("        کارت شناسایی کاربر")
print("="*30)
print(f"نام: {name}")
print(f"سن: {age} سال")
print(f"شهر: {city}")
print("="*30)
print("از همراهی شما متشکریم!")
  5. اجرا: برنامه را با python3 profile.py اجرا کنید و اطلاعات خواسته‌شده را وارد کنید.
  6. ذخیره وابستگی‌ها: با pip freeze > requirements.txt وابستگی‌ها را ذخیره کنید (اگر از پکیج خاصی استفاده نکردید، فایل خالی می‌ماند).

چالش کدنویسی

یک برنامه بنویسید که:

  • از کاربر دو عدد (با input()) دریافت کند و آن‌ها را به عدد (int) تبدیل کند.
  • مجموع، تفریق، ضرب و تقسیم اعشاری (/) و تقسیم صحیح (//) آنها را محاسبه کند.
  • نتایج را با توضیحات کامل و با print() در خطوط جداگانه نمایش دهد.
  • در صورت وارد کردن عدد صفر برای تقسیم، پیام "تقسیم بر صفر ممکن نیست" را چاپ کند.

📝 پرسش‌ها و تمرینات

سوالات تشریحی

  1. پایتون چه مزایایی نسبت به سایر زبان‌های برنامه‌نویسی دارد؟ (حداقل ۴ مورد را توضیح دهید).
  2. تفاوت بین Python 2 و Python 3 چیست و چرا باید از Python 3 استفاده کنیم؟
  3. pip چیست و چگونه می‌توان یک کتابخانه را با آن نصب یا حذف کرد؟
  4. محیط مجازی (venv) چه مزیتی دارد و چرا باید از آن استفاده کنیم؟ تفاوت آن با نصب سراسری چیست؟
  5. تفاوت بین محیط تعاملی (REPL) و اجرای اسکریپت چیست؟ هرکدام چه زمانی مناسب‌تر هستند؟

سوالات چهارگزینه‌ای

  1. کدام دستور برای نصب یک پکیج در پایتون استفاده می‌شود؟
    أ) python install ب) pip install ج) package install د) install pip
  2. برای ایجاد یک محیط مجازی با نام env از کدام دستور استفاده می‌شود؟
    أ) python -m virtual env ب) python3 -m venv env ج) venv create env د) python venv env
  3. خالق زبان برنامه‌نویسی پایتون چه کسی است؟
    أ) Guido van Rossum ب) Brendan Eich ج) Linus Torvalds د) Tim Berners-Lee
  4. کدام دستور برای خروج از محیط تعاملی (REPL) استفاده می‌شود؟
    أ) exit() ب) quit() ج) Ctrl+D د) تمام موارد فوق

تمرین عملی (پروژه کوچک)

یک پروژه‌ی جدید با محیط مجازی ایجاد کنید و یک برنامه بنویسید که:

  • نام، سن و شهر کاربر را با input() دریافت کند.
  • یک پیام خوش‌آمدگویی با تمام اطلاعات در قالبی زیبا نمایش دهد (مثلاً با استفاده از - یا * برای خطوط جداکننده).
  • از پکیج requests برای دریافت اطلاعات یک API عمومی (مثلاً https://api.github.com) استفاده کرده و وضعیت اتصال را چاپ کند (اختیاری).

نکات طلایی

  • 🔹 پایتون یک زبان ساده، خوانا، همه‌کاره و متن‌باز است که برای حوزه‌های مختلف کاربرد دارد.
  • 🔹 همیشه از Python 3 استفاده کنید؛ Python 2 به‌طور کامل منسوخ شده است.
  • 🔹 VS Code به‌همراه افزونه‌ی Python، یک محیط توسعه‌ی قدرتمند و رایگان است.
  • 🔹 print() برای نمایش خروجی و input() برای دریافت ورودی از کاربر استفاده می‌شود.
  • 🔹 pip مدیر بسته‌ها است و venv ابزار ایجاد محیط‌های مجازی.
  • 🔹 همیشه از محیط مجازی برای ایزوله کردن پروژه‌ها استفاده کنید تا وابستگی‌ها تداخل نکنند.

برگه تقلب (Cheat Sheet)

# چاپ خروجی در کنسول
print("Hello")

# دریافت ورودی از کاربر
name = input("نام: ")

# ایجاد محیط مجازی
python3 -m venv venv

# فعال‌سازی (لینوکس/مک)
source venv/bin/activate

# فعال‌سازی (ویندوز)
venv\Scripts\activate

# نصب پکیج با pip
pip install package_name

# ذخیره وابستگی‌ها
pip freeze > requirements.txt

# نصب از روی requirements.txt
pip install -r requirements.txt

# خروج از محیط مجازی
deactivate

📖 واژه‌نامه تخصصی

  • Python: زبان برنامه‌نویسی سطح‌بالا، تفسیری و همه‌منظوره.
  • REPL: محیط تعاملی (Read-Eval-Print Loop) برای اجرای خط‌به‌خط کد.
  • pip: مدیر بسته‌های استاندارد پایتون (Pip Installs Packages).
  • venv: ابزار داخلی پایتون برای ایجاد محیط‌های مجازی (Virtual Environment).
  • VS Code: یک ویرایشگر کد منبع‌باز و سبک از شرکت مایکروسافت.
  • print(): تابع داخلی برای چاپ متن یا متغیرها در خروجی استاندارد (کنسول).
  • input(): تابع داخلی برای دریافت ورودی از کاربر (به‌صورت رشته).
  • requirements.txt: فایل متنی شامل لیست پکیج‌ها و نسخه‌های مورد نیاز پروژه.
  • PyPI (Python Package Index): مخزن رسمی و اصلی پکیج‌های پایتون.
  • PATH: متغیر محیطی که به سیستم‌عامل می‌گوید که فایل‌های اجرایی در کدام مسیرها قرار دارند.

❓ سوالات محرک (برای درگیری ذهن)

  • ❓ چرا پایتون با وجود سرعت کمتر نسبت به زبان‌هایی مثل C++، اینقدر محبوب است؟ (به خوانایی و کتابخانه‌های آن فکر کنید).
  • ❓ چه تفاوتی بین print() در Python 2 و Python 3 وجود دارد که باعث شد این تغییر ایجاد شود؟
  • ❓ چرا باید از محیط‌های مجازی استفاده کنیم؟ اگر از آن استفاده نکنیم، چه مشکلاتی ممکن است در بلندمدت رخ دهد؟
  • ❓ اگر pip به‌درستی کار نکند و ارور بدهد، چه راه‌حل‌هایی وجود دارد؟ (مثلاً بررسی مسیر یا آپگرید pip).
  • ❓ محیط تعاملی (REPL) چه مزیتی نسبت به اجرای اسکریپت دارد و در چه سناریوهایی استفاده از آن هوشمندانه‌تر است؟

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن افزودن پایتون به PATH در هنگام نصب (ویندوز) که باعث می‌شود دستور python یا python3 در ترمینال شناسایی نشود.
    🔧 راه حل: در زمان نصب، گزینه‌ی "Add Python to PATH" را فعال کنید. اگر از قبل نصب کرده‌اید، می‌توانید با جستجوی "Edit environment variables" در ویندوز، مسیر پایتون را به‌صورت دستی به PATH اضافه کنید.
  • 🔴 اشتباه: استفاده از python به‌جای python3 در سیستم‌هایی که Python 2 به‌عنوان پیش‌فرض نصب دارند (مثل بسیاری از توزیع‌های لینوکس).
    🔧 راه حل: همیشه از python3 استفاده کنید تا مطمئن باشید Python 3 اجرا می‌شود. در ویندوز معمولاً python به نسخه‌ی ۳ اشاره دارد.
  • 🔴 اشتباه: فراموش کردن فعال‌سازی محیط مجازی قبل از نصب پکیج‌ها، که باعث می‌شود پکیج‌ها در فضای سراسری نصب شوند.
    🔧 راه حل: قبل از هرگونه نصب با pip، بررسی کنید که نام محیط مجازی در ابتدای خط ترمینال نمایش داده می‌شود. اگر نمایش داده نمی‌شود، با دستور فعال‌سازی، آن را فعال کنید.
  • 🔴 اشتباه: نوشتن کدهای مهم صرفاً در محیط تعاملی (REPL) و بستن ترمینال، که باعث از دست رفتن کامل کدها می‌شود.
    🔧 راه حل: محیط تعاملی فقط برای تست دستورات کوتاه است. کدهای نهایی و طولانی را همیشه در فایل‌های .py ذخیره کنید و با اجرای اسکریپت تست کنید.
  • 🔴 اشتباه: استفاده از print بدون پرانتز (مانند print "Hello") که مربوط به Python 2 است و در Python 3 باعث بروز SyntaxError می‌شود.
    🔧 راه حل: در Python 3، print یک تابع است و همیشه باید با پرانتز استفاده شود: print("Hello").

🏆 پروژه نهایی فصل ۱

عنوان پروژه: ساخت یک دفترچه‌ی یادداشت ساده (Simple Note Keeper)

شرح: یک برنامه‌ی خط فرمان (CLI) بسازید که به کاربر اجازه دهد یادداشت‌های خود را ذخیره و مشاهده کند. این پروژه مفاهیم حلقه، شرط، ورودی/خروجی و کار با فایل را به‌کار می‌گیرد.

مراحل پیاده‌سازی:

  • مرحله ۱ (ساختار اصلی): یک حلقه‌ی while True ایجاد کنید که تا زمانی که کاربر گزینه‌ی خروج را انتخاب نکند، اجرا شود. سه گزینه به کاربر نشان دهید: ۱. نوشتن یادداشت جدید، ۲. مشاهده یادداشت‌ها، ۳. خروج.
  • مرحله ۲ (ذخیره‌سازی): وقتی کاربر گزینه‌ی ۱ را انتخاب کرد، یک متن با input() دریافت کنید و آن را با یک خط جدید (همراه با تاریخ) در انتهای یک فایل متنی به نام notes.txt اضافه کنید (با حالت 'a' در open()).
  • مرحله ۳ (نمایش): وقتی کاربر گزینه‌ی ۲ را انتخاب کرد، فایل notes.txt را با حالت 'r' باز کنید، تمام خطوط را با readlines() بخوانید و هر خط را با شماره‌ی ترتیب به کاربر نمایش دهید.
  • مرحله ۴ (پایان): وقتی کاربر گزینه‌ی ۳ را انتخاب کرد، برنامه با break از حلقه خارج شده و پیام خروج چاپ شود.
  • مرحله ۵ (مدیریت): برای این پروژه یک محیط مجازی ایجاد کنید (حتی اگر وابستگی خاصی نداشته باشد، عادت به این کار را در خود تقویت کنید) و یک فایل requirements.txt برای وابستگی‌ها (در صورت نیاز) ایجاد کنید.

کد خود را در VS Code بنویسید و با python3 main.py اجرا کنید.

  • گزینه‌ی ۴: جستجو در یادداشت‌ها بر اساس یک کلمه‌ی کلیدی اضافه کنید.
  • گزینه‌ی ۵: حذف یک یادداشت خاص بر اساس شماره‌ی آن را پیاده‌سازی کنید (نیاز به بازنویسی کل فایل دارد).
