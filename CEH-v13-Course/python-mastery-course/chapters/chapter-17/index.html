🚀 مقدمه و انگیزه‌بخشی

تا اینجا با برنامه‌نویسی رویه‌ای (Procedural) کار کرده‌اید – توابع و داده‌ها از هم جدا بودند. اما در دنیای واقعی، همه‌چیز به‌صورت شیء (Object) وجود دارد: یک ماشین دارای ویژگی‌ها (رنگ، مدل، سرعت) و رفتارها (روشن شدن، حرکت کردن، توقف) است. یک دانش‌آموز دارای ویژگی‌ها (نام، سن، نمرات) و رفتارها (مطالعه کردن، امتحان دادن) است.

برنامه‌نویسی شی‌گرا (Object-Oriented Programming - OOP) یک پارادایم است که به شما اجازه می‌دهد داده‌ها و توابع مرتبط را در کنار هم، در قالب کلاس‌ها (Classes) و اشیاء (Objects) سازماندهی کنید. این روش باعث می‌شود کد شما ساختاریافته‌تر، قابل‌استفاده‌ی مجدد و قابل‌نگهداری‌تر شود.

در این فصل با همه‌ی مفاهیم پایه‌ی OOP در پایتون آشنا می‌شوید: تعریف کلاس، ایجاد شیء، ویژگی‌ها، متدها، self، __init__ و متدهای جادویی. این مبانی پایه‌ی مباحث پیشرفته‌تر مانند وراثت، چندریختی و کپسوله‌سازی در فصل بعدی هستند.

🧠 بدنه اصلی آموزش

۱۷.۱ مقدمه‌ای بر برنامه‌نویسی شی‌گرا (OOP)

برنامه‌نویسی شی‌گرا (OOP) یک سبک برنامه‌نویسی است که در آن کد به‌صورت اشیاء سازماندهی می‌شود. هر شیء شامل داده‌ها (ویژگی‌ها) و رفتارها (متدها) است.

  • کلاس (Class): یک طرح یا قالب برای ایجاد اشیاء. مانند یک نقشه برای ساختن خانه.
  • شیء (Object): یک نمونه از کلاس. مانند یک خانه‌ی واقعی که از روی نقشه ساخته شده است.
  • ویژگی (Attribute): داده‌ای که وضعیت یک شیء را توصیف می‌کند.
  • متد (Method): تابعی که رفتار یک شیء را تعریف می‌کند.

مزایای OOP:

  • کپسوله‌سازی (Encapsulation): داده‌ها و توابع مرتبط در یکجا جمع می‌شوند.
  • ارث‌بری (Inheritance): کلاس‌ها می‌توانند از کلاس‌های دیگر ارث‌بری کنند.
  • چندریختی (Polymorphism): متدهای یکسان می‌توانند رفتارهای متفاوتی داشته باشند.
  • قابل استفاده‌ی مجدد: کد را می‌توان در پروژه‌های مختلف استفاده کرد.
class Car {
    - brand: str
    - model: str
    - year: int
    - speed: int

    + __init__(brand, model, year)
    + accelerate()
    + brake()
    + get_info()
}
💡 نکته: OOP یکی از محبوب‌ترین پارادایم‌های برنامه‌نویسی است و در زبان‌های مختلفی مانند Java، C++، Python و C# استفاده می‌شود.
🧪 تمرین: سه شیء در دنیای واقعی (مثل کتاب، دانش‌آموز، گوشی) را انتخاب کنید و ویژگی‌ها و رفتارهای هرکدام را لیست کنید.

۱۷.۳ __init__ و مقداردهی اولیه

متد __init__ یک متد ویژه (جادویی) است که هنگام ایجاد یک شیء، به‌طور خودکار فراخوانی می‌شود. از آن برای مقداردهی اولیه ویژگی‌های شیء استفاده می‌شود.

  • self: ارجاع به خود شیء. اولین پارامتر همه‌ی متدهای کلاس است.
  • __init__: سازنده (Constructor) کلاس.
class Student:
    def __init__(self, name, grade, student_id):
        self.name = name
        self.grade = grade
        self.student_id = student_id
        self.is_active = True  # مقدار پیش‌فرض
    
    def get_info(self):
        return f"دانش‌آموز: {self.name}, کلاس: {self.grade}, شماره: {self.student_id}"

# ایجاد اشیاء با مقادیر مختلف
student1 = Student("علی", 10, "S001")
student2 = Student("سارا", 11, "S002")

print(student1.get_info())  # "دانش‌آموز: علی, کلاس: 10, شماره: S001"
print(student2.is_active)   # True
➜ دانش‌آموز: علی, کلاس: 10, شماره: S001
➜ True
💡 نکته: پارامتر self به‌طور خودکار توسط پایتون ارسال می‌شود و شما نیازی به ارسال آن ندارید. همه‌ی متدهای کلاس باید حداقل یک پارامتر (معمولاً self) داشته باشند.
🧪 تمرین: یک کلاس Product با ویژگی‌های name، price و stock تعریف کنید و در __init__ آنها را مقداردهی کنید. سپس یک شیء ایجاد کنید.

۱۷.۴ ویژگی‌ها (Attributes) و متدها (Methods)

  • ویژگی‌ها (Attributes): داده‌هایی که وضعیت شیء را ذخیره می‌کنند. با self.attribute_name تعریف و دسترسی پیدا می‌کنند.
  • متدها (Methods): توابعی که رفتار شیء را تعریف می‌کنند. اولین پارامتر آنها self است.
📊 ویژگی (Attribute) داده‌ی ذخیره‌شده در شیء
⚙️ متد (Method) رفتار و عملکرد شیء 
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner          # ویژگی
        self.balance = balance      # ویژگی
        self.transactions = []      # ویژگی (لیست)
    
    def deposit(self, amount):      # متد
        if amount > 0:
            self.balance += amount
            self.transactions.append(f"+{amount}")
            return True
        return False
    
    def withdraw(self, amount):     # متد
        if 0 < amount <= self.balance:
            self.balance -= amount
            self.transactions.append(f"-{amount}")
            return True
        return False
    
    def get_balance(self):          # متد
        return self.balance
    
    def get_history(self):          # متد
        return self.transactions

# استفاده
account = BankAccount("علی", 1000)
account.deposit(500)
account.withdraw(200)
print(account.get_balance())   # 1300
print(account.get_history())   # ['+500', '-200']
➜ 1300
➜ ['+500', '-200']
💎 نکته طلایی: متدها می‌توانند ویژگی‌ها را تغییر دهند، محاسبات انجام دهند، و نتایج را برگردانند. از متدها برای کپسوله‌سازی منطق مربوط به شیء استفاده کنید.
🧪 تمرین: به کلاس Product یک متد sell(quantity) اضافه کنید که موجودی را کاهش دهد و در صورت کمبود موجودی، پیام خطا برگرداند.

۱۷.۵ self و نقش آن در کلاس‌ها

self یک ارجاع به نمونه‌ی فعلی (شیء) کلاس است. با استفاده از self می‌توانید به ویژگی‌ها و متدهای دیگر همان شیء دسترسی پیدا کنید.

  • self اولین پارامتر تمام متدهای کلاس است.
  • نام self یک قرارداد است (می‌توانید از نام دیگری استفاده کنید، اما self استاندارد است).
  • برای دسترسی به ویژگی‌ها و متدها، از self.attribute و self.method() استفاده کنید.
class Circle:
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return 3.14159 * self.radius ** 2  # self.radius به ویژگی دسترسی دارد
    
    def perimeter(self):
        return 2 * 3.14159 * self.radius
    
    def scale(self, factor):
        self.radius *= factor  # تغییر ویژگی
        return self.area()     # فراخوانی متد دیگر

c = Circle(5)
print(c.area())           # 78.53975
print(c.perimeter())      # 31.4159
c.scale(2)                # شعاع ۲ برابر می‌شود
print(c.radius)           # 10
print(c.area())           # 314.159
➜ 78.53975
➜ 31.4159
➜ 10
💡 نکته: self به شما امکان می‌دهد بین ویژگی‌های مختلف و متغیرهای محلی تفاوت قائل شوید. همیشه از self برای دسترسی به ویژگی‌های شیء استفاده کنید.
🧪 تمرین: در کلاس BankAccount، یک متد transfer بنویسید که به یک شیء دیگر و مبلغ را دریافت کند و موجودی را بین دو حساب جابه‌جا کند.

۱۷.۶ متدهای جادویی (Magic Methods) – __str__ و __repr__

متدهای جادویی متدهای ویژه‌ای هستند که با __ شروع و خاتمه می‌یابند. آنها رفتارهای خاصی را برای اشیاء تعریف می‌کنند.

  • __str__: نمایش خوانای شیء برای کاربر. با print() و str() فراخوانی می‌شود.
  • __repr__: نمایش توسعه‌دهنده‌ای (غیرابهامی) از شیء. برای دیباگ استفاده می‌شود.
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __str__(self):
        return f"Person: {self.name} (سن: {self.age})"
    
    def __repr__(self):
        return f"Person('{self.name}', {self.age})"

p = Person("علی", 25)
print(p)           # Person: علی (سن: 25)  ← __str__
print(str(p))      # Person: علی (سن: 25)
print(repr(p))     # Person('علی', 25)      ← __repr__

# در لیست‌ها و REPL
people = [Person("سارا", 30), Person("رضا", 28)]
print(people)      # [Person('سارا', 30), Person('رضا', 28)]

# سایر متدهای جادویی
class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author
    
    def __len__(self):
        return len(self.title)  # طول عنوان
    
    def __eq__(self, other):
        if not isinstance(other, Book):
            return False
        return self.title == other.title and self.author == other.author

book1 = Book("پایتون", "علی رضایی")
book2 = Book("پایتون", "علی رضایی")
print(len(book1))        # 6 (تعداد حروف)
print(book1 == book2)    # True
➜ Person: علی (سن: 25)
➜ Person('علی', 25)
➜ 6
➜ True
💎 نکته طلایی: همیشه __str__ را برای نمایش خوانا و __repr__ را برای نمایش توسعه‌دهنده‌ای پیاده‌سازی کنید. این کار دیباگ را بسیار آسان‌تر می‌کند.
🧪 تمرین: کلاس Book را با __str__ و __repr__ کامل کنید. همچنین یک متد __eq__ برای مقایسه بر اساس عنوان و نویسنده اضافه کنید.

۱۷.۷ متدهای جادویی بیشتر – __add__، __len__ و __getitem__

متدهای جادویی دیگری نیز وجود دارند که رفتار اشیاء را در عملگرها و عملیات خاص تعریف می‌کنند.

class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __add__(self, other):
        if isinstance(other, Vector):
            return Vector(self.x + other.x, self.y + other.y)
        return NotImplemented
    
    def __sub__(self, other):
        if isinstance(other, Vector):
            return Vector(self.x - other.x, self.y - other.y)
        return NotImplemented
    
    def __mul__(self, scalar):
        if isinstance(scalar, (int, float)):
            return Vector(self.x * scalar, self.y * scalar)
        return NotImplemented
    
    def __str__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(2, 3)
v2 = Vector(4, 5)
v3 = v1 + v2      # __add__
v4 = v2 - v1      # __sub__
v5 = v1 * 3       # __mul__

print(v3)  # Vector(6, 8)
print(v4)  # Vector(2, 2)
print(v5)  # Vector(6, 9)

# __len__ و __getitem__ برای رفتار شبیه به لیست
class Playlist:
    def __init__(self, songs):
        self.songs = songs
    
    def __len__(self):
        return len(self.songs)
    
    def __getitem__(self, index):
        return self.songs[index]
    
    def __setitem__(self, index, value):
        self.songs[index] = value
    
    def __contains__(self, item):
        return item in self.songs

playlist = Playlist(["song1", "song2", "song3"])
print(len(playlist))      # 3
print(playlist[1])        # "song2"
playlist[1] = "new_song"
print(playlist[1])        # "new_song"
print("song1" in playlist)  # True
➜ Vector(6, 8)
➜ Vector(2, 2)
➜ 3
💡 نکته: با پیاده‌سازی متدهای جادویی، می‌توانید اشیاء خود را مانند انواع داخلی پایتون (لیست، عدد و ...) رفتار دهید.
🧪 تمرین: یک کلاس Matrix برای ماتریس‌های ۲×۲ بسازید و متدهای __add__، __sub__ و __mul__ را برای آن پیاده‌سازی کنید.

  • 🔹 کلاس یک قالب برای ایجاد اشیاء است.
  • 🔹 شیء یک نمونه از کلاس است که ویژگی‌ها و متدهای خود را دارد.
  • 🔹 __init__ متد سازنده برای مقداردهی اولیه.
  • 🔹 self ارجاع به نمونه‌ی فعلی شیء.
  • 🔹 ویژگی‌ها داده‌های شیء و متدها رفتارهای شیء هستند.
  • 🔹 متدهای جادویی مانند __str__، __repr__، __add__ و __len__ رفتارهای خاصی را تعریف می‌کنند.

برگه تقلب

# تعریف کلاس
class ClassName:
    def __init__(self, params):
        self.attribute = params
    
    def method(self):
        return self.attribute

# ایجاد شیء
obj = ClassName(value)

# متدهای جادویی
__str__(self)   # نمایش خوانا
__repr__(self)  # نمایش توسعه‌دهنده‌ای
__add__(self, other)  # +
__len__(self)   # len()
__eq__(self, other)   # ==

📖 واژه‌نامه تخصصی

  • OOP (Object-Oriented Programming): برنامه‌نویسی شی‌گرا.
  • Class (کلاس): قالب برای ایجاد اشیاء.
  • Object (شیء): نمونه‌ای از یک کلاس.
  • Attribute (ویژگی): داده‌ای که وضعیت شیء را توصیف می‌کند.
  • Method (متد): تابعی که رفتار شیء را تعریف می‌کند.
  • self: ارجاع به نمونه‌ی فعلی شیء.
  • __init__: متد سازنده (Constructor).
  • Magic Method (متد جادویی): متد ویژه با __.
  • Encapsulation (کپسوله‌سازی): پنهان کردن جزئیات داخلی.
  • Inheritance (ارث‌بری): به‌ارث‌بردن ویژگی‌ها و متدها.
  • Polymorphism (چندریختی): رفتارهای متفاوت برای یک متد.

❓ سوالات محرک (برای درگیری ذهن)

  • ❓ اگر کلاس را به‌عنوان "قالب" در نظر بگیریم، شیء چه چیزی است؟
  • ❓ چرا از self برای دسترسی به ویژگی‌ها استفاده می‌کنیم؟
  • ❓ چه تفاوتی بین __str__ و __repr__ وجود دارد و هرکدام چه زمانی استفاده می‌شوند؟
  • ❓ اگر __init__ را در کلاس تعریف نکنیم، چه اتفاقی می‌افتد؟
  • ❓ چرا باید از متدهای جادویی استفاده کنیم؟

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن self در متدها که باعث TypeError می‌شود.
    🔧 راه حل: همه‌ی متدهای کلاس باید حداقل یک پارامتر (معمولاً self) داشته باشند.
  • 🔴 اشتباه: فراموش کردن self در دسترسی به ویژگی‌ها که باعث ایجاد متغیر محلی می‌شود.
    🔧 راه حل: برای دسترسی به ویژگی‌ها، همیشه از self.attribute استفاده کنید.
  • 🔴 اشتباه: فراموش کردن return در متدها که باعث می‌شود None برگردانند.
    🔧 راه حل: اگر متد باید مقداری برگرداند، از return استفاده کنید.
  • 🔴 اشتباه: استفاده از == برای مقایسه‌ی اشیاء بدون پیاده‌سازی __eq__ که مقایسه‌ی مرجع انجام می‌دهد.
    🔧 راه حل: برای مقایسه‌ی محتوایی، متد __eq__ را پیاده‌سازی کنید.
  • 🔴 اشتباه: تعریف متدهای جادویی با نام اشتباه (مثلاً __str__ به‌جای __str__ که خطا می‌دهد).
    🔧 راه حل: نام متدهای جادویی را دقیقاً با دو __ در ابتدا و انتها بنویسید.

🏆 پروژه نهایی این فصل

عنوان پروژه: ساخت یک سیستم مدیریت کاربران با کلاس‌ها

شرح: یک برنامه‌ی خط فرمان برای مدیریت کاربران با استفاده از کلاس‌ها بسازید:

  • یک کلاس User با ویژگی‌های:
    • username – نام کاربری
    • password – رمز عبور (ذخیره‌سازی هش‌شده)
    • email – ایمیل
    • is_active – وضعیت فعال/غیرفعال
    • created_at – تاریخ ایجاد (با datetime)
  • متدهای User:
    • change_password(old, new) – تغییر رمز با بررسی رمز قدیمی
    • toggle_active() – تغییر وضعیت فعال/غیرفعال
    • __str__ و __repr__
    • __eq__ – مقایسه بر اساس نام کاربری
  • یک کلاس UserManager با ویژگی‌های users (لیست کاربران) و متدهای:
    • add_user(username, password, email) – افزودن کاربر جدید
    • remove_user(username) – حذف کاربر
    • find_user(username) – جستجوی کاربر
    • list_users() – نمایش همه‌ی کاربران
    • save_to_file(filename) – ذخیره‌سازی در فایل JSON
    • load_from_file(filename) – بارگذاری از فایل JSON
  • استفاده از __len__ برای تعداد کاربران.
  • استفاده از __getitem__ برای دسترسی به کاربران با اندیس.
  • مدیریت خطاها (کاربر تکراری، کاربر وجود ندارد و ...).
  • یک منوی تعاملی با while برای کاربر ایجاد کنید.

کد خود را در VS Code بنویسید و با python3 main.py اجرا کنید.
