🚀 مقدمه و انگیزه‌بخشی

در فصل قبل با لیست‌ها و تاپل‌ها آشنا شدید – ساختارهایی که داده‌ها را به‌صورت دنباله‌ای (Sequence) و با اندیس‌های عددی ذخیره می‌کنند. اما در دنیای واقعی، داده‌ها اغلب به‌صورت کلید-مقدار (Key-Value) سازماندهی می‌شوند: یک دفترچه تلفن که با نام (کلید) شماره (مقدار) را پیدا می‌کند، یک سیستم مدیریت کاربران که با شناسه (کلید) اطلاعات کاربر (مقدار) را بازیابی می‌کند، یا یک کش (Cache) که با یک کلید منحصربه‌فرد، داده‌های ذخیره‌شده را برمی‌گرداند. اینجاست که دیکشنری‌ها (Dictionaries) وارد می‌شوند.

همچنین گاهی نیاز داریم مجموعه‌ای از عناصر یکتا (Unique) داشته باشیم – مثلاً لیست کلمات منحصربه‌فرد یک متن، یا مجموعه‌ی کاربران فعال یک سیستم. مجموعه‌ها (Sets) این نیاز را با کارایی بالا و بدون نگرانی از تکرار برآورده می‌کنند.

در این فصل با همه‌ی مبانی دیکشنری‌ها و مجموعه‌ها آشنا می‌شوید: ایجاد، دسترسی، متدها، عملیات‌ها، Comprehension و کاربردهای عملی. این ساختارها در بسیاری از برنامه‌ها (مدیریت کاربران، کش داده، پردازش متن، تحلیل داده، ذخیره‌سازی تنظیمات و ...) کاربرد دارند و تسلط بر آنها برای هر توسعه‌دهنده‌ای ضروری است.

🧠 بدنه اصلی آموزش

۷.۱ ایجاد دیکشنری و دسترسی به مقادیر

دیکشنری‌ها با آکولاد ({}) ایجاد می‌شوند و از جفت‌های key: value تشکیل شده‌اند. کلیدها باید غیرقابل تغییر (Immutable) باشند (رشته، عدد، تاپل) – بنابراین لیست‌ها نمی‌توانند کلید باشند. مقادیر می‌توانند هر نوع داده‌ای (از جمله لیست، دیکشنری دیگر و حتی توابع) باشند.

نکات کلیدی:

  • دسترسی به مقدار با dict[key] – اگر کلید وجود نداشته باشد، KeyError می‌دهد.
  • روش ایمن‌تر: dict.get(key, default) – اگر کلید وجود نداشته باشد، default برمی‌گرداند (پیش‌فرض None).
  • افزودن کلید-مقدار جدید: dict[new_key] = value.
  • حذف: del dict[key] یا dict.pop(key).
  • کلیدها در دیکشنری یکتا هستند – اگر کلید تکراری باشد، مقدار قبلی بازنویسی می‌شود.
# ========== ایجاد دیکشنری ==========
person = {
    "name": "علی",
    "age": 30,
    "city": "تهران",
    "is_student": False,
    "skills": ["Python", "JavaScript", "CSS"]  # مقدار می‌تواند لیست باشد
}

# ========== دسترسی به مقادیر با کلید ==========
print(person["name"])      # "علی"
print(person["age"])       # 30
print(person["skills"][0]) # "Python"

# ========== دسترسی با get() (ایمن‌تر) ==========
print(person.get("job"))              # None
print(person.get("job", "نامشخص"))    # "نامشخص"
print(person.get("city", "نامشخص"))   # "تهران" (چون وجود دارد)

# ========== افزودن کلید-مقدار جدید ==========
person["job"] = "برنامه‌نویس"
print(person)  # {'name': 'علی', 'age': 30, 'city': 'تهران', 'is_student': False, 'skills': [...], 'job': 'برنامه‌نویس'}

# ========== تغییر مقدار ==========
person["age"] = 31

# ========== حذف یک کلید ==========
del person["is_student"]    # روش ۱
removed = person.pop("city") # روش ۲ (مقدار حذف‌شده را برمی‌گرداند)
print(removed)  # "تهران"

# ========== بررسی وجود کلید با in ==========
if "name" in person:
    print("✅ نام وجود دارد")
else:
    print("❌ نام وجود ندارد")

# ========== دیکشنری خالی ==========
empty_dict = {}  # یا dict()
print(type(empty_dict))  # <class 'dict'>

# ========== دیکشنری با کلیدهای عددی ==========
scores = {1: "ضعیف", 2: "متوسط", 3: "خوب", 4: "عالی"}
print(scores[3])  # "خوب"

# ========== دیکشنری تو در تو ==========
users = {
    "user1": {"name": "علی", "age": 25},
    "user2": {"name": "سارا", "age": 30}
}
print(users["user1"]["name"])  # "علی"
➜ علی
➜ 30
➜ {'name': 'علی', 'age': 31, 'job': 'برنامه‌نویس', 'skills': ['Python', 'JavaScript', 'CSS']}
💡 نکته مهم: کلیدهای دیکشنری باید غیرقابل تغییر (Immutable) باشند. بنابراین لیست‌ها نمی‌توانند کلید باشند (چون قابل تغییر هستند)، اما تاپل‌ها و رشته‌ها می‌توانند. این محدودیت به‌دلیل پیاده‌سازی داخلی دیکشنری با هش (Hash) است.
🧪 تمرین: یک دیکشنری با اطلاعات یک کتاب (عنوان، نویسنده، سال انتشار، قیمت، ژانر) ایجاد کنید. سپس با get() قیمت را دریافت کنید و اگر وجود نداشت، مقدار پیش‌فرض "نامشخص" برگردانید. یک کلید جدید "موضوع" به آن اضافه کنید و دیکشنری نهایی را چاپ کنید.

۷.۲ متدهای اصلی دیکشنری

دیکشنری‌ها متدهای مفیدی برای مدیریت داده‌ها دارند. در این بخش با پرکاربردترین آنها آشنا می‌شوید:

🔑 keys() برگشت‌دهنده‌ی لیستی از کلیدها
📊 values() برگشت‌دهنده‌ی لیستی از مقادیر
📋 items() برگشت‌دهنده‌ی لیستی از (کلید، مقدار)
➕ update() ترکیب/به‌روزرسانی با دیکشنری دیگر
🗑️ pop() حذف با کلید و برگرداندن مقدار
🧹 clear() پاک کردن همه‌ی آیتم‌ها
📝 copy() کپی کردن دیکشنری
🔍 get() دسترسی با fallback (پیش‌فرض)
📤 popitem() حذف و برگرداندن آخرین آیتم 
person = {"name": "علی", "age": 30, "city": "تهران", "job": "برنامه‌نویس"}

# ========== keys() - دریافت کلیدها ==========
print(person.keys())    # dict_keys(['name', 'age', 'city', 'job'])

# ========== values() - دریافت مقادیر ==========
print(person.values())  # dict_values(['علی', 30, 'تهران', 'برنامه‌نویس'])

# ========== items() - دریافت جفت‌ها (کلید، مقدار) ==========
print(person.items())   # dict_items([('name', 'علی'), ('age', 30), ('city', 'تهران'), ('job', 'برنامه‌نویس')])

# ========== پیمایش با items() ==========
for key, value in person.items():
    print(f"🔑 {key} → {value}")

# ========== update() - ترکیب دو دیکشنری ==========
extra = {"age": 31, "salary": 8000000}  # age بازنویسی می‌شود، salary اضافه می‌شود
person.update(extra)
print(person)  # {'name': 'علی', 'age': 31, 'city': 'تهران', 'job': 'برنامه‌نویس', 'salary': 8000000}

# ========== pop() - حذف با کلید ==========
removed = person.pop("city")
print(removed)   # "تهران"
print(person)    # {'name': 'علی', 'age': 31, 'job': 'برنامه‌نویس', 'salary': 8000000}

# ========== popitem() - حذف آخرین آیتم ==========
last = person.popitem()
print(last)      # ('salary', 8000000)
print(person)    # {'name': 'علی', 'age': 31, 'job': 'برنامه‌نویس'}

# ========== copy() - کپی کردن ==========
person_copy = person.copy()  # کپی سطحی (Shallow Copy)
print(person_copy)

# ========== clear() - پاک کردن همه ==========
person.clear()
print(person)    # {}
💎 نکته طلایی: از items() در حلقه‌های for برای پیمایش همزمان کلیدها و مقادیر استفاده کنید – این روش پایتونیک‌ترین و خواناترین روش است. از update() برای ترکیب دو دیکشنری (یا به‌روزرسانی دیکشنری با داده‌های جدید) استفاده کنید.
🧪 تمرین: یک دیکشنری با ۳ کلید-مقدار (نام، سن، شهر) ایجاد کنید. با keys() کلیدها را چاپ کنید، با values() مقادیر را چاپ کنید، با items() همه را پیمایش کنید و با pop() کلید "شهر" را حذف کنید. سپس با update() یک دیکشنری جدید به آن اضافه کنید.

۷.۳ Dictionary Comprehension (درک دیکشنری)

Dictionary Comprehension روشی فشرده، سریع و خوانا برای ایجاد دیکشنری‌ها با استفاده از یک حلقه‌ی for و شرط‌های اختیاری است. ساختار کلی: {key_expression: value_expression for item in iterable if condition}

مزایا:

  • کد کوتاه‌تر و خواناتر از حلقه‌های معمولی.
  • در بسیاری موارد سریع‌تر از حلقه‌های for سنتی.
  • قابل ترکیب با zip() برای ساخت دیکشنری از دو لیست.

چه زمانی از آن استفاده نکنیم؟ وقتی منطق پیچیده است (چندین شرط تو در تو) یا نیاز به تغییر دیکشنری در حین پیمایش دارید، از حلقه‌های معمولی استفاده کنید.

# ========== ایجاد دیکشنری از لیست اعداد ==========
numbers = [1, 2, 3, 4, 5]
squares = {x: x**2 for x in numbers}
print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# ========== فیلتر کردن اعداد زوج ==========
evens = {x: x**2 for x in range(1, 11) if x % 2 == 0}
print(evens)    # {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}

# ========== تبدیل دو لیست به دیکشنری با zip() ==========
names = ["علی", "سارا", "رضا", "مریم"]
ages = [25, 30, 28, 22]
people = {name: age for name, age in zip(names, ages)}
print(people)   # {'علی': 25, 'سارا': 30, 'رضا': 28, 'مریم': 22}

# ========== معکوس کردن کلید و مقدار ==========
original = {"a": 1, "b": 2, "c": 3, "d": 4}
reversed_dict = {value: key for key, value in original.items()}
print(reversed_dict)  # {1: 'a', 2: 'b', 3: 'c', 4: 'd'}

# ========== شرط روی مقدار ==========
filtered = {k: v for k, v in original.items() if v > 2}
print(filtered)  # {'c': 3, 'd': 4}

# ========== شرط روی کلید ==========
filtered_by_key = {k: v for k, v in original.items() if k in "ab"}
print(filtered_by_key)  # {'a': 1, 'b': 2}

# ========== استفاده از if/else در مقدار ==========
scores = {"علی": 85, "سارا": 92, "رضا": 78, "مریم": 95}
status = {name: "قبول" if score >= 80 else "رد" for name, score in scores.items()}
print(status)   # {'علی': 'قبول', 'سارا': 'قبول', 'رضا': 'رد', 'مریم': 'قبول'}

# ========== ساخت دیکشنری از دو لیست با enumerate ==========
items = ["apple", "banana", "orange"]
index_dict = {i: item for i, item in enumerate(items, start=1)}
print(index_dict)  # {1: 'apple', 2: 'banana', 3: 'orange'}

# ========== ترکیب دو حلقه (حاصلضرب دکارتی) ==========
keys = ["A", "B"]
values = [1, 2, 3]
cartesian = {k: v for k in keys for v in values}
print(cartesian)  # {'A': 3, 'B': 3} (آخرین مقدار برای هر کلید)
➜ {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
➜ {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
💡 نکته مهم: Dictionary Comprehension می‌تواند با حلقه‌های تو در تو و شرط‌های پیچیده ترکیب شود، اما برای خوانایی بهتر، از حلقه‌های ساده‌تر استفاده کنید. همچنین اگر کلیدها تکراری شوند، آخرین مقدار باقی می‌ماند.
🧪 تمرین: دو لیست از نام‌ها و نمرات دانش‌آموزان (حداقل ۵ نفر) ایجاد کنید. با Dictionary Comprehension:
  • یک دیکشنری از دانش‌آموزان و نمرات آنها بسازید.
  • دانش‌آموزانی که نمره‌ی بالای ۱۷ دارند را فیلتر کنید و دیکشنری جدیدی بسازید.
  • یک دیکشنری از وضعیت قبولی (قبول/رد) بر اساس نمره (حد نصاب ۱۲) ایجاد کنید.

۷.۴ مجموعه‌ها (Sets) – ایجاد و عملیات

مجموعه‌ها (Sets) ساختارهایی برای ذخیره‌سازی عناصر یکتا و غیرتکراری هستند. مجموعه‌ها نامرتب هستند (ترتیب عناصر تضمینی نیست) و از عملیات‌های ریاضی مجموعه‌ها (اجتماع، اشتراک، تفاضل) پشتیبانی می‌کنند.

ویژگی‌های کلیدی:

  • با {} یا set() ایجاد می‌شوند (مجموعه‌ی خالی با set()، نه {} که دیکشنری است).
  • فقط شامل عناصر hashable (غیرقابل تغییر) هستند – لیست‌ها نمی‌توانند عضو مجموعه باشند.
  • برای حذف تکراری‌ها از یک لیست بسیار مفید هستند.
  • عملیات‌های مجموعه‌ها سریع هستند (پیچیدگی زمانی O(1) برای عضویت).
# ========== ایجاد مجموعه ==========
colors = {"قرمز", "سبز", "آبی", "قرمز"}  # تکراری‌ها حذف می‌شوند
print(colors)  # {'سبز', 'آبی', 'قرمز'} (ترتیب ممکن است متفاوت باشد)

# ========== ایجاد مجموعه با set() از لیست ==========
numbers = set([1, 2, 3, 2, 1, 4, 4])
print(numbers)  # {1, 2, 3, 4}

# ========== مجموعه خالی ==========
empty_set = set()  # ✅ درست
# empty_set2 = {}  # ❌ این یک دیکشنری خالی است

# ========== افزودن عنصر ==========
colors.add("زرد")
print(colors)   # {'سبز', 'زرد', 'آبی', 'قرمز'}

# ========== حذف عنصر ==========
colors.remove("سبز")   # اگر نباشد خطا می‌دهد (KeyError)
colors.discard("بنفش") # اگر نباشد خطا نمی‌دهد

# ========== عملیات مجموعه‌ها ==========
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}

# اجتماع (Union) – ترکیب دو مجموعه
print(a | b)           # {1, 2, 3, 4, 5, 6, 7, 8}
print(a.union(b))      # {1, 2, 3, 4, 5, 6, 7, 8}

# اشتراک (Intersection) – عناصر مشترک
print(a & b)           # {4, 5}
print(a.intersection(b))  # {4, 5}

# تفاضل (Difference) – عناصر a که در b نیستند
print(a - b)           # {1, 2, 3}
print(a.difference(b)) # {1, 2, 3}
print(b - a)           # {6, 7, 8}

# تفاضل متقارن (Symmetric Difference) – عناصری که در یکی هستند اما نه در هر دو
print(a ^ b)           # {1, 2, 3, 6, 7, 8}
print(a.symmetric_difference(b))  # {1, 2, 3, 6, 7, 8}

# ========== بررسی زیرمجموعه و بالامجموعه ==========
subset = {1, 2, 3}
print(subset.issubset(a))   # True (subset ⊆ a)
print(a.issuperset(subset)) # True (a ⊇ subset)
print(a.isdisjoint(b))      # False (اشتراک دارند)
print({9, 10}.isdisjoint(a)) # True (اشتراک ندارند)

# ========== استفاده از مجموعه برای حذف تکراری‌ها ==========
duplicates = [1, 2, 2, 3, 4, 4, 4, 5]
unique = list(set(duplicates))
print(unique)  # [1, 2, 3, 4, 5] (ترتیب ممکن است تغییر کند)

# ========== پیمایش مجموعه ==========
for color in colors:
    print(color)
➜ {'سبز', 'آبی', 'قرمز'}
➜ {1, 2, 3, 4}
➜ {1, 2, 3, 4, 5, 6, 7, 8}
➜ {4, 5}
💎 نکته طلایی: مجموعه‌ها برای حذف موارد تکراری از یک لیست بسیار مفید هستند: unique = list(set(my_list)). همچنین برای بررسی عضویت (با in) بسیار سریع‌تر از لیست‌ها عمل می‌کنند (O(1) در مقابل O(n)).
🧪 تمرین: یک لیست از اعداد با تکرار (مثلاً [1, 2, 2, 3, 4, 4, 5, 6, 6, 7]) ایجاد کنید. با استفاده از مجموعه، اعداد یکتا را استخراج کنید. سپس دو مجموعه‌ی دیگر (مثلاً {1, 2, 3, 4} و {3, 4, 5, 6}) ایجاد کنید و عملیات اجتماع، اشتراک، تفاضل و تفاضل متقارن را روی آنها انجام دهید و نتایج را چاپ کنید.

۷.۵ Frozenset (مجموعه‌ی غیرقابل تغییر)

Frozenset نسخه‌ی غیرقابل تغییر (Immutable) مجموعه است. پس از ایجاد، نمی‌توانید عناصری به آن اضافه یا از آن حذف کنید. این ویژگی Frozenset را برای موارد زیر مناسب می‌سازد:

  • استفاده به‌عنوان کلید در دیکشنری (چون immutable است).
  • ذخیره‌سازی داده‌های ثابت که نباید تغییر کنند.
  • به‌عنوان عضوی از مجموعه‌های دیگر (چون hashable است).
# ========== ایجاد Frozenset ==========
frozen = frozenset([1, 2, 3, 4, 5])
print(frozen)  # frozenset({1, 2, 3, 4, 5})

# ========== قابل تغییر نیست ==========
# frozen.add(6)   # ❌ AttributeError: 'frozenset' object has no attribute 'add'
# frozen.remove(1) # ❌ AttributeError

# ========== عملیات روی Frozenset (مجموعه جدید برمی‌گرداند) ==========
other = frozenset([3, 4, 5, 6, 7, 8])
union = frozen.union(other)
print(union)  # frozenset({1, 2, 3, 4, 5, 6, 7, 8})
intersection = frozen.intersection(other)
print(intersection)  # frozenset({3, 4, 5})

# ========== استفاده به‌عنوان کلید دیکشنری ==========
cache = {
    frozenset([1, 2, 3]): "مجموعه ۱",
    frozenset([4, 5, 6]): "مجموعه ۲"
}
print(cache[frozenset([1, 2, 3])])  # "مجموعه ۱"

# ========== مجموعه معمولی نمی‌تواند کلید باشد ==========
# invalid = {{1, 2, 3}: "value"}  # ❌ TypeError: unhashable type: 'set'

# ========== Frozenset به‌عنوان عضو مجموعه ==========
set_of_sets = {frozenset([1, 2]), frozenset([3, 4])}
print(set_of_sets)  # {frozenset({1, 2}), frozenset({3, 4})}
# set_of_sets2 = {{1, 2}, {3, 4}}  # ❌ TypeError

# ========== تبدیل لیست به Frozenset برای استفاده در دیکشنری ==========
def get_key_for_list(lst):
    return frozenset(lst)

key = get_key_for_list([1, 2, 3])
data = {key: "اطلاعات"}
print(data)  # {frozenset({1, 2, 3}): 'اطلاعات'}
💡 نکته مهم: Frozenset زمانی مفید است که نیاز به یک مجموعه‌ی ثابت دارید که قرار نیست تغییر کند، یا می‌خواهید از آن به‌عنوان کلید در دیکشنری یا عضوی از مجموعه‌های دیگر استفاده کنید. به‌دلیل غیرقابل تغییر بودن، Frozenset هش‌پذیر (hashable) است.
🧪 تمرین: یک Frozenset از اعداد ۱ تا ۵ ایجاد کنید. سعی کنید با add() یا remove() آن را تغییر دهید و خطای دریافتی را مشاهده کنید. سپس از آن به‌عنوان کلید در یک دیکشنری با یک مقدار دلخواه استفاده کنید و مقدار را چاپ کنید.

۷.۶ Set Comprehension (درک مجموعه)

مشابه List Comprehension و Dictionary Comprehension، می‌توانید با Set Comprehension مجموعه‌های فشرده و کارآمد ایجاد کنید. ساختار: {expression for item in iterable if condition}

ویژگی‌ها:

  • مشابه List Comprehension اما با {} به‌جای [].
  • به‌طور خودکار تکراری‌ها را حذف می‌کند (چون مجموعه است).
  • برای استخراج عناصر یکتا از یک iterable بسیار مناسب است.
# ========== ایجاد مجموعه‌ی مربع‌های اعداد ==========
squares = {x**2 for x in range(1, 7)}
print(squares)  # {1, 4, 9, 16, 25, 36}

# ========== فیلتر کردن اعداد زوج ==========
evens = {x for x in range(1, 11) if x % 2 == 0}
print(evens)    # {2, 4, 6, 8, 10}

# ========== استخراج حروف یکتا از یک رشته (بدون فاصله) ==========
text = "python programming is fun"
unique_letters = {char for char in text if char != ' '}
print(unique_letters)  # {'n', 't', 'h', 'y', 'i', 'o', 'p', 'r', 'g', 'm', 'a', 's', 'f', 'u'}

# ========== تبدیل لیست به مجموعه با شرط ==========
numbers = [1, 2, 2, 3, 4, 4, 5, 6, 6, 7, 8, 8, 9]
unique_odds = {x for x in numbers if x % 2 == 1}
print(unique_odds)  # {1, 3, 5, 7, 9}

# ========== استخراج کلمات با طول مشخص ==========
words = ["apple", "banana", "cherry", "date", "elderberry", "fig"]
long_words = {word for word in words if len(word) > 5}
print(long_words)  # {'banana', 'cherry', 'elderberry'}

# ========== استفاده از Set Comprehension برای حذف تکراری‌ها با تبدیل ==========
names = ["علی", "سارا", "علی", "رضا", "سارا", "مریم"]
unique_names = {name for name in names}
print(unique_names)  # {'سارا', 'مریم', 'علی', 'رضا'}

# ========== ترکیب چند حلقه ==========
pairs = {(x, y) for x in range(3) for y in range(3)}
print(pairs)  # {(0, 0), (0, 1), (0, 2), (1, 0), (1, 1), (1, 2), (2, 0), (2, 1), (2, 2)}

# ========== استفاده از if/else در عبارت ==========
numbers = [1, 2, 3, 4, 5]
status = {"زوج" if x % 2 == 0 else "فرد" for x in numbers}
print(status)  # {'زوج', 'فرد'}  (چون مجموعه است، تکراری‌ها حذف می‌شوند)
➜ {1, 4, 9, 16, 25, 36}
➜ {2, 4, 6, 8, 10}
🧪 تمرین: یک رشته‌ی طولانی (حداقل ۲۰ کاراکتر با تکرار حروف) ایجاد کنید. با Set Comprehension:
  • حروف یکتای آن را استخراج کنید (به‌جز فاصله‌ها).
  • حروف صدادار (a, e, i, o, u) را فیلتر کنید و فقط حروف بی‌صدا را نمایش دهید.
  • حروفی که بیش از یک بار تکرار شده‌اند را پیدا کنید (با استفاده از دو Set Comprehension).

۷.۷ مقایسه دیکشنری، مجموعه و لیست

انتخاب ساختار داده‌ی مناسب تأثیر زیادی بر عملکرد، خوانایی و کارایی کد دارد. در این بخش سه ساختار اصلی پایتون را با هم مقایسه می‌کنیم:

ویژگی لیست (List) مجموعه (Set) دیکشنری (Dict) سینتکس [] {} (یا set()) {key: value} قابل تغییر (Mutable) ✅ ✅ ✅ حفظ ترتیب ✅ (از ۳.۷) ❌ (نامرتب) ✅ (از ۳.۷) عناصر تکراری ✅ مجاز ❌ غیرمجاز ❌ (کلیدها یکتا) دسترسی با اندیس عددی با مقدار (عضویت) با کلید سرعت عضویت (in) O(n) (کند) O(1) (سریع) O(1) (سریع) کاربرد اصلی دنباله‌های مرتب و قابل تکرار مجموعه‌های یکتا و عملیات مجموعه‌ای نگاشت کلید-مقدار کلید قابل استفاده در دیکشنری ❌ خیر ❌ خیر (به‌جز Frozenset) N/A

راهنمای انتخاب:

  • لیست: وقتی به داده‌های مرتب و تکراری نیاز دارید و دسترسی با اندیس مهم است.
  • مجموعه: وقتی به عناصر یکتا نیاز دارید، ترتیب مهم نیست و می‌خواهید عضویت را سریع بررسی کنید.
  • دیکشنری: وقتی به نگاشت کلید-مقدار نیاز دارید و می‌خواهید با یک کلید به مقدار دسترسی پیدا کنید.
# ========== انتخاب ساختار مناسب ==========
# ۱. لیست – برای داده‌های مرتب و قابل تکرار
students = ["علی", "سارا", "رضا", "علی"]  # تکراری مجاز

# ۲. مجموعه – برای داده‌های یکتا
unique_students = {"علی", "سارا", "رضا"}  # تکراری نداریم

# ۳. دیکشنری – برای نگاشت کلید-مقدار
student_scores = {
    "علی": 85,
    "سارا": 92,
    "رضا": 78
}

# ========== سناریوی واقعی ==========
# مدیریت کاربران یک وب‌سایت:
# - لیست کاربران (با ترتیب ورود): List
# - مجموعه‌ی کاربران فعال: Set (یکتا و جستجوی سریع)
# - اطلاعات کامل کاربر (با شناسه): Dict

users_list = ["user1", "user2", "user3"]           # لیست
active_users = {"user1", "user3"}                  # مجموعه
user_profiles = {
    "user1": {"name": "علی", "email": "ali@test.com"},
    "user2": {"name": "سارا", "email": "sara@test.com"},
    "user3": {"name": "رضا", "email": "reza@test.com"}
}  # دیکشنری
💎 نکته طلایی: انتخاب ساختار داده‌ی مناسب تأثیر زیادی بر عملکرد و خوانایی کد دارد. قاعده‌ی کلی: اگر نیاز به داده‌های مرتب و قابل تکرار دارید → لیست. اگر به داده‌های یکتا و عملیات مجموعه‌ای نیاز دارید → مجموعه. اگر به نگاشت کلید-مقدار نیاز دارید → دیکشنری. همیشه به پیچیدگی زمانی عملیات‌ها توجه کنید (O(1) برای دیکشنری و مجموعه، O(n) برای لیست).
🧪 تمرین: یک مسئله‌ی واقعی را انتخاب کنید (مثلاً مدیریت یک فروشگاه آنلاین: محصولات، سبد خرید، کاربران، سفارشات). مشخص کنید که برای هر بخش از کدام ساختار داده (لیست، مجموعه، دیکشنری) استفاده می‌کنید و چرا. پاسخ خود را با مثال‌های کد (ساختارهای فرضی) نشان دهید.

چالش کدنویسی

یک برنامه بنویسید که:

  • یک لیست از کلمات (با تکرار) ایجاد کند.
  • با استفاده از مجموعه، کلمات تکراری را حذف کند و لیست جدیدی بسازد.
  • با یک دیکشنری، تعداد تکرار هر کلمه را بشمارد (با حلقه‌ی for و get()).

📝 پرسش‌ها و تمرینات

سوالات تشریحی

  1. تفاوت بین دیکشنری و لیست چیست؟ هرکدام چه زمانی مناسب هستند؟ مثال بزنید.
  2. مجموعه (Set) چه ویژگی‌هایی دارد و چه تفاوتی با لیست از نظر عملکرد عضویت (in) دارد؟
  3. Frozenset چیست و چه کاربردی دارد؟ چرا می‌تواند کلید دیکشنری باشد در حالی که Set معمولی نمی‌تواند؟
  4. Dictionary Comprehension چه مزیتی نسبت به حلقه‌های معمولی دارد؟ چه زمانی نباید از آن استفاده کرد؟
  5. چرا کلیدهای دیکشنری باید غیرقابل تغییر (Immutable) باشند؟ اگر از کلید mutable استفاده کنیم چه اتفاقی می‌افتد؟

سوالات چهارگزینه‌ای

  1. کدام یک از موارد زیر یک کلید معتبر برای دیکشنری است؟
    أ) [1, 2, 3] ب) (1, 2, 3) ج) {1, 2, 3} د) همه‌ی موارد
  2. خروجی {1, 2, 3}.union({2, 3, 4}) چیست؟
    أ) {1, 2, 3, 4} ب) {2, 3} ج) {1, 4} د) {1, 2, 3}
  3. کدام متد برای ترکیب دو دیکشنری (اضافه کردن کلیدهای جدید و بازنویسی کلیدهای مشترک) استفاده می‌شود؟
    أ) merge() ب) combine() ج) update() د) union()
  4. برای ایجاد یک مجموعه‌ی خالی، از کدام یک از موارد زیر باید استفاده کنیم؟
    أ) {} ب) set() ج) [] د) ()

تمرین عملی

یک برنامه بنویسید که:

  • یک دیکشنری از دانش‌آموزان (نام و نمره) با حداقل ۶ نفر ایجاد کند.
  • با items() همه‌ی دانش‌آموزان را به‌صورت "نام: نمره" نمایش دهد.
  • با Dictionary Comprehension، دانش‌آموزانی که نمره‌ی بالای ۱۷ دارند را فیلتر کرده و دیکشنری جدیدی بسازد.
  • با get() نمره‌ی یک دانش‌آموز خاص را دریافت کند (در صورت وجود، وگرنه "یافت نشد").
  • با pop() یک دانش‌آموز را حذف کند (با مدیریت خطا در صورت عدم وجود).
  • با استفاده از مجموعه، اسامی یکتای دانش‌آموزان را استخراج کند و چاپ کند.

📌 جمع‌بندی و خلاصه

نکات طلایی

  • 🔹 دیکشنری‌ها با {} و جفت‌های key: value ایجاد می‌شوند و برای نگاشت کلید-مقدار استفاده می‌شوند.
  • 🔹 متدهای اصلی دیکشنری: keys()، values()، items()، update()، pop()، get()، copy() و clear().
  • 🔹 مجموعه‌ها (Sets) برای ذخیره‌سازی عناصر یکتا و غیرتکراری با {} یا set() ایجاد می‌شوند.
  • 🔹 عملیات‌های مجموعه‌ها: union() (اجتماع)، intersection() (اشتراک)، difference() (تفاضل)، symmetric_difference() (تفاضل متقارن).
  • 🔹 Dictionary Comprehension روشی فشرده و کارآمد برای ایجاد دیکشنری‌ها با حلقه و شرط.
  • 🔹 Set Comprehension روشی فشرده برای ایجاد مجموعه‌ها با حلقه و شرط.
  • 🔹 Frozenset نسخه‌ی غیرقابل تغییر مجموعه است و می‌تواند کلید دیکشنری باشد.
  • 🔹 انتخاب ساختار داده‌ی مناسب (لیست، مجموعه، دیکشنری) تأثیر زیادی بر عملکرد و خوانایی کد دارد.

برگه تقلب (Cheat Sheet)

# ========== دیکشنری ==========
person = {"name": "علی", "age": 30}
person["job"] = "برنامه‌نویس"          # افزودن
person.get("city", "نامشخص")          # دسترسی ایمن
person.keys(), person.values(), person.items()  # کلیدها، مقادیر، جفت‌ها
person.update({"age": 31})             # به‌روزرسانی
person.pop("city")                     # حذف

# ========== مجموعه ==========
colors = {"قرمز", "سبز", "آبی"}
colors.add("زرد")                     # افزودن
colors.remove("سبز")                  # حذف (خطا اگر نباشد)
colors.discard("بنفش")                # حذف (خطا نمی‌دهد)

# عملیات مجموعه‌ها
a | b  # اجتماع (union)
a & b  # اشتراک (intersection)
a - b  # تفاضل (difference)
a ^ b  # تفاضل متقارن

# ========== Dictionary Comprehension ==========
{x: x**2 for x in range(5)}           # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
{x: x**2 for x in range(10) if x % 2 == 0}  # با شرط

# ========== Set Comprehension ==========
{x**2 for x in range(5)}              # {0, 1, 4, 9, 16}
{x for x in range(10) if x % 2 == 0}  # {0, 2, 4, 6, 8}

📖 واژه‌نامه تخصصی

  • Dictionary (دیکشنری): ساختار داده‌ی کلید-مقدار با {} که دسترسی سریع با کلید را فراهم می‌کند.
  • Set (مجموعه): ساختار داده برای عناصر یکتا و غیرتکراری با {} یا set().
  • Key (کلید): شناسه‌ی منحصربه‌فرد در دیکشنری (باید immutable باشد).
  • Value (مقدار): داده‌ای که به یک کلید متصل است (می‌تواند هر نوع داده‌ای باشد).
  • Frozenset: نسخه‌ی غیرقابل تغییر مجموعه که hashable است و می‌تواند کلید دیکشنری باشد.
  • Union (اجتماع): ترکیب دو مجموعه (همه‌ی عناصر هر دو).
  • Intersection (اشتراک): عناصر مشترک بین دو مجموعه.
  • Difference (تفاضل): عناصر موجود در یک مجموعه اما نه در دیگری.
  • Symmetric Difference (تفاضل متقارن): عناصری که در یکی از دو مجموعه هستند اما نه در هر دو.
  • Mutable (قابل تغییر): ساختاری که می‌توان محتوای آن را پس از ایجاد تغییر داد (لیست، دیکشنری، مجموعه).
  • Immutable (غیرقابل تغییر): ساختاری که پس از ایجاد قابل تغییر نیست (تاپل، رشته، Frozenset).
  • Hashable (هش‌پذیر): مقداری که می‌توان از آن کلید دیکشنری یا عضو مجموعه استفاده کرد (باید immutable باشد).

❓ سوالات محرک (برای درگیری ذهن)

  • ❓ چرا کلیدهای دیکشنری باید غیرقابل تغییر (Immutable) باشند؟ این ویژگی چه تأثیری بر عملکرد و طراحی دیکشنری دارد؟
  • ❓ چه زمانی استفاده از مجموعه (Set) به‌جای لیست (List) می‌تواند عملکرد برنامه را به‌طور چشمگیری بهبود بخشد؟
  • ❓ چگونه می‌توان با استفاده از دیکشنری یک کش (Cache) ساده با حذف خودکار قدیمی‌ترین داده‌ها پیاده‌سازی کرد؟
  • ❓ چه تفاوتی بین remove() و discard() در مجموعه‌ها وجود دارد و هرکدام چه زمانی مناسب هستند؟
  • ❓ چرا Frozenset می‌تواند کلید دیکشنری باشد اما Set معمولی نمی‌تواند؟ چه اتفاقی می‌افتد اگر یک Set را به‌عنوان کلید استفاده کنیم؟

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: استفاده از لیست به‌عنوان کلید دیکشنری که باعث TypeError: unhashable type: 'list' می‌شود.
    🔧 راه حل: از تاپل یا رشته به‌عنوان کلید استفاده کنید یا لیست را به تاپل تبدیل کنید: tuple(my_list).
  • 🔴 اشتباه: دسترسی به کلیدی که در دیکشنری وجود ندارد با [] که باعث KeyError می‌شود.
    🔧 راه حل: از get() با مقدار پیش‌فرض استفاده کنید: dict.get(key, default).
  • 🔴 اشتباه: تغییر یک مجموعه در حین پیمایش با for که باعث RuntimeError: Set changed size during iteration می‌شود.
    🔧 راه حل: از یک کپی از مجموعه برای پیمایش استفاده کنید: for item in set_copy:.
  • 🔴 اشتباه: فراموش کردن اینکه مجموعه‌ها نامرتب هستند و ترتیب عناصر تضمینی نیست – در نتیجه ممکن است کد شما به ترتیب خاصی وابسته باشد و در اجراهای مختلف نتایج متفاوتی بگیرد.
    🔧 راه حل: اگر ترتیب مهم است، از لیست یا دیکشنری (که از Python 3.7 ترتیب را حفظ می‌کنند) استفاده کنید.
  • 🔴 اشتباه: استفاده از {} برای ایجاد مجموعه‌ی خالی – این کار یک دیکشنری خالی ایجاد می‌کند، نه مجموعه.
    🔧 راه حل: برای مجموعه‌ی خالی از set() استفاده کنید.
  • 🔴 اشتباه: استفاده از remove() روی عنصری که در مجموعه وجود ندارد – باعث KeyError می‌شود.
    🔧 راه حل: از discard() استفاده کنید (اگر عنصر نباشد، خطا نمی‌دهد) یا قبل از حذف با in بررسی کنید.
  • 🔴 اشتباه: در Dictionary Comprehension، فراموش کردن اینکه اگر کلیدها تکراری باشند، آخرین مقدار باقی می‌ماند و ممکن است داده‌ها از دست بروند.
    🔧 راه حل: مطمئن شوید که کلیدها یکتا هستند یا اگر تکراری هستند، از منطق مناسب برای ترکیب مقادیر استفاده کنید.

🏆 پروژه نهایی این فصل

عنوان پروژه: ساخت یک سیستم مدیریت دانش‌آموزان با دیکشنری، مجموعه و Comprehension

شرح: یک برنامه‌ی خط فرمان (CLI) کامل برای مدیریت دانش‌آموزان یک مدرسه بسازید که از دیکشنری، مجموعه، Dictionary Comprehension و Set Comprehension استفاده کند. این پروژه شما را با کاربرد عملی همه‌ی مفاهیم این فصل در یک سناریوی واقعی آشنا می‌کند.

مراحل پیاده‌سازی:

  • مرحله ۱ (ساختار داده‌ها):
    • یک دیکشنری students با کلید نام دانش‌آموز و مقدار دیکشنری اطلاعات (شامل سن، کلاس، لیست نمرات) ایجاد کنید.
    • یک مجموعه unique_classes برای ذخیره‌ی کلاس‌های موجود (برای جلوگیری از تکرار) ایجاد کنید.
    • یک مجموعه all_subjects برای ذخیره‌ی همه‌ی دروس (یکتا) ایجاد کنید.
  • مرحله ۲ (توابع اصلی):
    • add_student(name, age, grade, scores_dict) – افزودن دانش‌آموز جدید با اعتبارسنجی (سن، نمرات).
    • get_student(name) – دریافت اطلاعات یک دانش‌آموز با get() (در صورت نبود، پیام خطا).
    • update_score(name, subject, score) – به‌روزرسانی نمره‌ی یک درس خاص.
    • get_top_students(n) – دریافت n دانش‌آموز با بهترین معدل (با استفاده از sorted() و items()).
    • get_subjects() – دریافت مجموعه‌ی همه‌ی دروس (با استفاده از Set Comprehension روی دیکشنری دانش‌آموزان).
    • get_average_by_class(class_name) – محاسبه‌ی میانگین نمرات یک کلاس خاص.
    • get_students_by_grade(grade) – دریافت لیست دانش‌آموزان یک کلاس خاص (با Dictionary Comprehension).
  • مرحله ۳ (قابلیت‌های پیشرفته با Comprehension):
    • با Dictionary Comprehension یک دیکشنری از دانش‌آموزان با معدل بالای ۱۷ بسازید.
    • با Set Comprehension مجموعه‌ی دروس یکتای تدریس‌شده در مدرسه را استخراج کنید.
    • با Dictionary Comprehension یک دیکشنری از کلاس‌ها و تعداد دانش‌آموزان هر کلاس بسازید.
  • مرحله ۴ (مدیریت داده‌ها):
    • با استفاده از Frozenset، مجموعه‌ای از دروس ثابت (مثلاً ریاضی، علوم، ادبیات) ایجاد کنید و از آن به‌عنوان کلید در یک دیکشنری برای ذخیره‌ی نمرات استاندارد استفاده کنید.
    • قابلیت ذخیره‌سازی و بارگذاری داده‌ها در فایل JSON را اضافه کنید (اختیاری – با ماژول json).
  • مرحله ۵ (منوی تعاملی): با یک حلقه‌ی while یک منوی کاربری ایجاد کنید که گزینه‌های زیر را پشتیبانی کند:
    • ۱. افزودن دانش‌آموز
    • ۲. مشاهده‌ی اطلاعات دانش‌آموز
    • ۳. به‌روزرسانی نمره
    • ۴. نمایش دانش‌آموزان برتر
    • ۵. نمایش دروس یکتا
    • ۶. محاسبه‌ی میانگین یک کلاس
    • ۷. نمایش آمار کلی (تعداد دانش‌آموزان، تعداد کلاس‌ها)
    • ۸. خروج

چالش‌های بیشتر (اختیاری):

  • با استفاده از zip() و Dictionary Comprehension، یک گزارش از نمرات هر دانش‌آموز به‌صورت جدولی تهیه کنید.
  • با استفاده از مجموعه، دانش‌آموزانی که در همه‌ی دروس نمره‌ی بالای ۱۷ دارند (مبتکران) را پیدا کنید.
  • با استفاده از statistics یا محاسبات دستی، انحراف معیار نمرات هر کلاس را محاسبه کنید.
  • قابلیت جستجوی دانش‌آموزان بر اساس محدوده‌ی سنی را اضافه کنید.
