🚀 مقدمه و انگیزه‌بخشی

تصور کنید برنامه‌ای می‌نویسید که باید یک کار را چندین بار انجام دهد. مثلاً محاسبه‌ی مساحت چندین مستطیل مختلف. آیا هر بار کد را تکرار می‌کنید؟ یا یکبار کد را می‌نویسید و هر زمان که نیاز داشتید، آن را فراخوانی می‌کنید؟

توابع (Functions) یکی از مهم‌ترین مفاهیم در هر زبان برنامه‌نویسی هستند. آنها به شما اجازه می‌دهند کد را به بلوک‌های قابل استفاده‌ی مجدد تقسیم کنید، از تکرار جلوگیری کنید و برنامه را سازمان‌یافته‌تر و خواناتر بسازید.

در این فصل با همه‌ی مبانی توابع در پایتون آشنا می‌شوید: تعریف تابع، پارامترها، آرگومان‌ها، return، پارامترهای پیش‌فرض، *args و **kwargs، docstring و scope متغیرها. این مبانی پایه‌ی مباحث پیشرفته‌تر مانند توابع لاندا، دکوریتورها و closureها در فصل بعدی هستند.

🧠 بدنه اصلی آموزش

۱۰.۱ تعریف تابع با def و فراخوانی

توابع با کلمه‌ی کلیدی def تعریف می‌شوند و با نام تابع و پرانتز فراخوانی می‌شوند.

# تعریف یک تابع ساده
def say_hello():
    print("سلام دنیا!")

# فراخوانی تابع
say_hello()  # "سلام دنیا!"

# تابع با پارامتر
def greet(name):
    print(f"سلام {name}!")

greet("علی")   # "سلام علی!"
greet("سارا")  # "سلام سارا!"

# تابع با چند پارامتر
def add(a, b):
    result = a + b
    print(f"{a} + {b} = {result}")

add(5, 3)  # "5 + 3 = 8"
➜ سلام دنیا!
➜ سلام علی!
➜ 5 + 3 = 8
💡 نکته: در پایتون، توابع قبل از فراخوانی باید تعریف شده باشند. ترتیب تعریف توابع مهم است.
🧪 تمرین: یک تابع به نام multiply با دو پارامتر تعریف کنید که حاصلضرب آنها را چاپ کند. سپس تابع را با اعداد مختلف فراخوانی کنید.

۱۰.۲ پارامترها و آرگومان‌ها

  • پارامتر (Parameter): متغیری که در تعریف تابع نوشته می‌شود.
  • آرگومان (Argument): مقداری که هنگام فراخوانی به تابع ارسال می‌شود.
# پارامترها: a و b
def subtract(a, b):
    return a - b

# آرگومان‌ها: 10 و 4
result = subtract(10, 4)
print(result)  # 6

# آرگومان‌های کلیدواژه‌ای (Keyword Arguments)
result = subtract(b=4, a=10)  # ترتیب مهم نیست
print(result)  # 6

# ترکیب آرگومان‌های موقعیتی و کلیدواژه‌ای
def introduce(name, age, city):
    print(f"{name}، {age} ساله، اهل {city}")

introduce("علی", 25, "تهران")
introduce(name="سارا", city="اصفهان", age=30)

# پارامترهای پیش‌فرض (Default Parameters)
def greet_user(name, greeting="سلام"):
    print(f"{greeting} {name}!")

greet_user("علی")          # "سلام علی!"
greet_user("سارا", "خوش آمدید")  # "خوش آمدید سارا!"
➜ 6
➜ علی، 25 ساله، اهل تهران
➜ سلام علی!
💎 نکته طلایی: پارامترهای پیش‌فرض باید بعد از پارامترهای بدون پیش‌فرض تعریف شوند. ترتیب مهم است.
🧪 تمرین: یک تابع create_profile با پارامترهای نام، سن و شهر (با پیش‌فرض "تهران") تعریف کنید و با آرگومان‌های مختلف فراخوانی کنید.

۱۰.۳ return و بازگرداندن مقدار

return مقداری را از تابع به بیرون برمی‌گرداند و اجرای تابع را متوقف می‌کند. اگر return ننویسید، تابع None برمی‌گرداند.

# تابع با return
def square(x):
    return x * x

result = square(5)
print(result)  # 25

# تابع بدون return
def print_square(x):
    print(x * x)

result = print_square(4)  # 16
print(result)  # None

# return شرطی
def is_even(number):
    if number % 2 == 0:
        return True
    else:
        return False

print(is_even(4))  # True
print(is_even(7))  # False

# return چندین مقدار (به‌صورت تاپل)
def get_min_max(numbers):
    return min(numbers), max(numbers)

minimum, maximum = get_min_max([1, 5, 2, 8, 3])
print(minimum, maximum)  # 1 8
➜ 25
➜ None
➜ True
➜ 1 8
💡 نکته: بعد از return هیچ کد دیگری در تابع اجرا نمی‌شود. از این ویژگی برای خروج زودهنگام از تابع استفاده کنید.
🧪 تمرین: یک تابع calculate_bmi با پارامترهای وزن و قد بنویسید که BMI را محاسبه کند و آن را برگرداند. (فرمول: weight / (height ** 2))

۱۰.۴ پارامترهای پیش‌فرض و None

پارامترهای پیش‌فرض برای مواقعی که آرگومان ارسال نشود، مقدار پیش‌فرض را استفاده می‌کنند. برای پارامترهای قابل تغییر (مثل لیست) باید از None استفاده کنید.

# پارامتر پیش‌فرض ساده
def greet(name, greeting="سلام"):
    print(f"{greeting} {name}!")

greet("علی")           # "سلام علی!"
greet("سارا", "خوش آمدید")  # "خوش آمدید سارا!"

# مشکل با پارامترهای قابل تغییر
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("سیب"))  # ['سیب']
print(add_item("موز"))  # ['سیب', 'موز'] ← مشکل! لیست بین فراخوانی‌ها به اشتراک گذاشته می‌شود

# راه‌حل صحیح با None
def add_item_correct(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item_correct("سیب"))  # ['سیب']
print(add_item_correct("موز"))  # ['موز']  ← درست

# پارامترهای پیش‌فرض با محاسبه
def create_user(name, age, city="تهران"):
    return {"name": name, "age": age, "city": city}

user1 = create_user("علی", 25)
user2 = create_user("سارا", 30, "اصفهان")
print(user1)  # {'name': 'علی', 'age': 25, 'city': 'تهران'}
print(user2)  # {'name': 'سارا', 'age': 30, 'city': 'اصفهان'}
➜ ['سیب']
➜ ['سیب', 'موز']
➜ ['سیب']
➜ ['موز']
💎 نکته طلایی: برای پارامترهایی که لیست یا دیکشنری هستند، از None به‌عنوان مقدار پیش‌فرض استفاده کنید و در بدنه تابع، مقدار جدید ایجاد کنید. این کار از اشتراک‌گذاری بین فراخوانی‌ها جلوگیری می‌کند.
🧪 تمرین: یک تابع add_student با پارامترهای نام و لیست نمرات (با پیش‌فرض None) بنویسید که دانش‌آموز را به یک دیکشنری اضافه کند.

۱۰.۵ *args و **kwargs – آرگومان‌های متغیر

  • *args: تعداد نامعلومی آرگومان موقعیتی را به‌صورت تاپل دریافت می‌کند.
  • **kwargs: تعداد نامعلومی آرگومان کلیدواژه‌ای را به‌صورت دیکشنری دریافت می‌کند.
# *args - آرگومان‌های موقعیتی متغیر
def sum_all(*args):
    total = 0
    for num in args:
        total += num
    return total

print(sum_all(1, 2, 3))       # 6
print(sum_all(10, 20, 30, 40)) # 100
print(sum_all())              # 0

# **kwargs - آرگومان‌های کلیدواژه‌ای متغیر
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="علی", age=25, city="تهران")
# name: علی
# age: 25
# city: تهران

# ترکیب پارامترهای معمولی با *args و **kwargs
def process_data(required, *args, **kwargs):
    print(f"Required: {required}")
    print(f"Args: {args}")
    print(f"Kwargs: {kwargs}")

process_data("مهم", 1, 2, 3, name="علی", age=25)
# Required: مهم
# Args: (1, 2, 3)
# Kwargs: {'name': 'علی', 'age': 25}
➜ 6
➜ 100
➜ name: علی
➜ age: 25
💡 نکته: ترتیب پارامترها: def func(a, b, *args, **kwargs). *args باید بعد از پارامترهای معمولی و **kwargs باید در آخر باشد.
🧪 تمرین: یک تابع create_profile با *args و **kwargs بنویسید که اطلاعات یک شخص را دریافت و چاپ کند.

۱۰.۶ Docstring و مستندسازی توابع

Docstring یک رشته‌ی مستندسازی است که در اولین خط تابع با سه نقل‌قول نوشته می‌شود. با help() یا .__doc__ قابل مشاهده است.

def calculate_area(length, width):
    """
    محاسبه مساحت مستطیل

    پارامترها:
    length (float): طول مستطیل
    width (float): عرض مستطیل

    بازگشت:
    float: مساحت مستطیل
    """
    return length * width

# مشاهده مستندات
print(calculate_area.__doc__)
# یا
help(calculate_area)

# Docstring چندخطی
def complex_function(a, b, c=10):
    """
    این یک تابع پیچیده است که سه پارامتر دریافت می‌کند.

    :param a: توضیح پارامتر a
    :param b: توضیح پارامتر b
    :param c: توضیح پارامتر c (پیش‌فرض: 10)
    :return: نتیجه‌ی محاسبه
    """
    return a + b + c
➜ محاسبه مساحت مستطیل
💎 نکته طلایی: همیشه برای توابع خود Docstring بنویسید. این کار باعث می‌شود کد شما مستند و قابل‌فهم برای دیگران (و خودتان در آینده) باشد.
🧪 تمرین: تابع calculate_bmi که قبلاً نوشتید را با Docstring کامل مستند کنید.

۱۰.۷ Scope (محدوده) متغیرها در توابع

  • Global Scope: متغیرهایی که خارج از توابع تعریف می‌شوند.
  • Local Scope: متغیرهایی که داخل توابع تعریف می‌شوند.
  • global: برای دسترسی و تغییر متغیرهای سراسری در داخل تابع.
# متغیر سراسری (Global)
x = 10

def show_x():
    print(x)  # دسترسی به متغیر سراسری (فقط خواندن)

show_x()  # 10

def modify_x():
    x = 20  # ایجاد متغیر محلی جدید (سراسری تغییر نمی‌کند)
    print(x)

modify_x()  # 20
print(x)    # 10 (سراسری unchanged)

# استفاده از global برای تغییر متغیر سراسری
y = 5

def change_y():
    global y
    y = 100
    print(y)

change_y()  # 100
print(y)    # 100

# متغیرهای محلی در توابع تو در تو
def outer():
    outer_var = "outside"
    
    def inner():
        inner_var = "inside"
        print(outer_var)  # دسترسی به متغیر تابع خارجی
    
    inner()
    # print(inner_var)  # ❌ خطا (دسترسی نداریم)

outer()  # "outside"
➜ 10
➜ 20
➜ 100
➜ outside
💡 نکته: استفاده از global معمولاً توصیه نمی‌شود. بهتر است متغیرها را به‌عنوان پارامتر به توابع ارسال کنید و نتایج را برگردانید.
🧪 تمرین: یک متغیر سراسری counter با مقدار ۰ تعریف کنید. یک تابع increment بنویسید که با استفاده از global آن را افزایش دهد. سپس تابع را چند بار فراخوانی کنید و مقدار نهایی را چاپ کنید.

سوالات تشریحی

  1. تفاوت بین پارامتر و آرگومان چیست؟
  2. return چه تأثیری روی تابع دارد و اگر ننویسیم چه اتفاقی می‌افتد؟
  3. چرا باید از None به‌عنوان مقدار پیش‌فرض برای پارامترهای قابل تغییر استفاده کنیم؟
  4. *args و **kwargs چه کاربردی دارند و چه تفاوتی با هم دارند؟
  5. Docstring چیست و چرا باید از آن استفاده کنیم؟

سوالات چهارگزینه‌ای

  1. کدام یک از موارد زیر یک تابع صحیح با پارامتر پیش‌فرض است؟
    أ) def func(a, b=2, c) ب) def func(a, b=2, c=3) ج) def func(a=1, b, c=3) د) def func(a, b, c=3, d)
  2. خروجی کد زیر چیست؟
    def test(x): x = 10; return x; x = 5; print(test(3))
    أ) 3 ب) 5 ج) 10 د) None
  3. کدام یک از موارد زیر برای دریافت تعداد نامعلومی آرگومان کلیدواژه‌ای استفاده می‌شود؟
    أ) *args ب) **kwargs ج) *kwargs د) **args

📌 جمع‌بندی و خلاصه

نکات طلایی

  • 🔹 توابع با def تعریف می‌شوند و کد را قابل استفاده‌ی مجدد می‌کنند.
  • 🔹 پارامترها ورودی‌های تابع هستند و آرگومان‌ها مقادیر ارسال‌شده.
  • 🔹 return مقدار را برمی‌گرداند و تابع را متوقف می‌کند.
  • 🔹 پارامترهای پیش‌فرض برای مواقعی که آرگومان ارسال نشود، مقدار پیش‌فرض استفاده می‌کنند.
  • 🔹 برای پارامترهای قابل تغییر از None به‌عنوان مقدار پیش‌فرض استفاده کنید.
  • 🔹 *args برای آرگومان‌های موقعیتی متغیر و **kwargs برای آرگومان‌های کلیدواژه‌ای متغیر.
  • 🔹 Docstring برای مستندسازی توابع استفاده می‌شود و با help() قابل مشاهده است.
  • 🔹 Scope محدوده‌ی دسترسی به متغیرهاست. متغیرهای محلی داخل تابع و سراسری خارج از تابع تعریف می‌شوند.

    global_var = 30

📖 واژه‌نامه تخصصی

  • Function (تابع): بلوک کد قابل استفاده‌ی مجدد.
  • Parameter (پارامتر): متغیر در تعریف تابع.
  • Argument (آرگومان): مقدار ارسال‌شده به تابع.
  • return: بازگرداندن مقدار از تابع.
  • Default Parameter (پارامتر پیش‌فرض): پارامتری که مقدار پیش‌فرض دارد.
  • *args: جمع‌آوری آرگومان‌های موقعیتی متغیر به‌صورت تاپل.
  • **kwargs: جمع‌آوری آرگومان‌های کلیدواژه‌ای متغیر به‌صورت دیکشنری.
  • Docstring: رشته‌ی مستندسازی تابع.
  • Scope (محدوده): ناحیه‌ای که متغیر در آن قابل دسترسی است.
  • Global: متغیر سراسری قابل دسترسی در همه‌جا.
  • Local: متغیر محلی فقط در داخل تابع قابل دسترسی.

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن : در انتهای خط def که باعث SyntaxError می‌شود.
    🔧 راه حل: همیشه از : بعد از def استفاده کنید.
  • 🔴 اشتباه: فراموش کردن return که باعث می‌شود تابع None برگرداند.
    🔧 راه حل: اگر نیاز به مقدار خروجی دارید، از return استفاده کنید.
  • 🔴 اشتباه: استفاده از متغیر سراسری بدون global در داخل تابع که باعث ایجاد متغیر محلی جدید می‌شود.
    🔧 راه حل: برای تغییر متغیر سراسری از global استفاده کنید یا متغیر را به‌عنوان پارامتر ارسال کنید.
  • 🔴 اشتباه: استفاده از لیست به‌عنوان مقدار پیش‌فرض که باعث اشتراک‌گذاری بین فراخوانی‌ها می‌شود.
    🔧 راه حل: از None به‌عنوان مقدار پیش‌فرض استفاده کنید و در بدنه تابع، لیست جدید ایجاد کنید.
  • 🔴 اشتباه: فراموش کردن * در *args یا ** در **kwargs که باعث می‌شود به‌عنوان پارامتر معمولی تفسیر شوند.
    🔧 راه حل: همیشه از *args و **kwargs با ستاره‌ها استفاده کنید.
