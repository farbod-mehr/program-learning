۱۸.۱ وراثت (Inheritance) – ایجاد کلاس‌های مشتق‌شده

وراثت به شما اجازه می‌دهد یک کلاس جدید (فرزند) بر اساس یک کلاس موجود (والد) ایجاد کنید. کلاس فرزند تمام ویژگی‌ها و متدهای کلاس والد را به‌ارث می‌برد و می‌تواند آنها را گسترش دهد یا تغییر دهد.

  • والد (Parent / Base Class): کلاسی که از آن ارث‌بری می‌شود.
  • فرزند (Child / Derived Class): کلاسی که از والد ارث‌بری می‌کند.
  • سینتکس: class Child(Parent):
class Animal {
    - name: str
    - age: int
    + speak(): str
    + move(): str
}
↑ (ارث‌بری)
class Dog extends Animal {
    - breed: str
    + speak(): str (override)
    + fetch(): str
}
↑
class Cat extends Animal {
    - color: str
    + speak(): str (override)
    + climb(): str
} 
# کلاس والد
class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def speak(self):
        return "حیوان صدا می‌دهد"
    
    def move(self):
        return f"{self.name} حرکت می‌کند"

# کلاس فرزند (Dog) که از Animal ارث‌بری می‌کند
class Dog(Animal):
    def __init__(self, name, age, breed):
        super().__init__(name, age)  # فراخوانی سازنده‌ی والد
        self.breed = breed
    
    def speak(self):  # override
        return "ووف ووف!"
    
    def fetch(self):
        return f"{self.name} توپ را می‌آورد"

# کلاس فرزند (Cat) که از Animal ارث‌بری می‌کند
class Cat(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age)
        self.color = color
    
    def speak(self):  # override
        return "میو میو!"
    
    def climb(self):
        return f"{self.name} از درخت بالا می‌رود"

# استفاده
dog = Dog("هاپو", 3, "ژرمن شپرد")
cat = Cat("پیشی", 2, "سفید")

print(dog.name)       # "هاپو" (از والد)
print(dog.breed)      # "ژرمن شپرد" (ویژه‌ی Dog)
print(dog.speak())    # "ووف ووف!" (override)
print(dog.fetch())    # "هاپو توپ را می‌آورد"

print(cat.speak())    # "میو میو!"
print(cat.climb())    # "پیشی از درخت بالا می‌رود"
➜ هاپو
➜ ووف ووف!
➜ میو میو!
💡 نکته: super() به شما اجازه می‌دهد به متدهای کلاس والد دسترسی داشته باشید. در __init__، از super().__init__(...) برای مقداردهی ویژگی‌های والد استفاده کنید.
🧪 تمرین: یک کلاس Vehicle با ویژگی‌های brand و year و متد info() ایجاد کنید. سپس کلاس‌های Car و Motorcycle را با ویژگی‌های اضافی از آن ارث‌بری کنید.

۱۸.۲ super() و فراخوانی متدهای والد

super() یک تابع داخلی است که به شما اجازه می‌دهد متدهای کلاس والد را فراخوانی کنید. این کار برای گسترش عملکرد متدهای والد (نه جایگزینی کامل) بسیار مفید است.

class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
    
    def get_info(self):
        return f"نام: {self.name}, حقوق: {self.salary}"

class Manager(Employee):
    def __init__(self, name, salary, department):
        super().__init__(name, salary)  # مقداردهی ویژگی‌های والد
        self.department = department
    
    def get_info(self):
        # گسترش متد والد
        base_info = super().get_info()
        return f"{base_info}, دپارتمان: {self.department}"
    
    def manage(self):
        return f"{self.name} تیم را مدیریت می‌کند"

class Developer(Employee):
    def __init__(self, name, salary, programming_languages):
        super().__init__(name, salary)
        self.programming_languages = programming_languages
    
    def get_info(self):
        base_info = super().get_info()
        languages = ", ".join(self.programming_languages)
        return f"{base_info}, زبان‌ها: {languages}"
    
    def code(self):
        return f"{self.name} کدنویسی می‌کند"

# استفاده
manager = Manager("علی", 8000000, "فناوری اطلاعات")
developer = Developer("سارا", 7000000, ["Python", "JavaScript", "SQL"])

print(manager.get_info())  # "نام: علی, حقوق: 8000000, دپارتمان: فناوری اطلاعات"
print(developer.get_info())  # "نام: سارا, حقوق: 7000000, زبان‌ها: Python, JavaScript, SQL"

# زنجیره‌ی super در ارث‌بری چندسطحی
class A:
    def show(self):
        print("A")

class B(A):
    def show(self):
        super().show()
        print("B")

class C(B):
    def show(self):
        super().show()
        print("C")

c = C()
c.show()
# خروجی:
# A
# B
# C
➜ نام: علی, حقوق: 8000000, دپارتمان: فناوری اطلاعات
➜ A B C
💎 نکته طلایی: super() برای گسترش عملکرد متدهای والد استفاده می‌شود، نه جایگزینی کامل. این کار باعث می‌شود کد شما قابل‌نگهداری‌تر باشد.
🧪 تمرین: کلاس Student را با ویژگی‌های name و grade ایجاد کنید. سپس کلاس CollegeStudent را با ویژگی‌های major و year از آن ارث‌بری کنید. متد __str__ را در هر دو با super() گسترش دهید.

۱۸.۳ چندریختی (Polymorphism)

چندریختی (Polymorphism) به معنای "چند شکلی" است. در OOP، یعنی یک متد با یک نام می‌تواند در کلاس‌های مختلف رفتارهای متفاوتی داشته باشد.

  • چندریختی با override: کلاس‌های فرزند متدهای والد را بازنویسی می‌کنند.
  • چندریختی با Duck Typing: "اگر مثل اردک راه می‌رود و مثل اردک صدا می‌دهد، پس اردک است".
# چندریختی با override
class Shape:
    def area(self):
        return 0

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return 3.14159 * self.radius ** 2

class Triangle(Shape):
    def __init__(self, base, height):
        self.base = base
        self.height = height
    
    def area(self):
        return 0.5 * self.base * self.height

# استفاده از چندریختی
shapes = [
    Rectangle(5, 10),
    Circle(7),
    Triangle(6, 8)
]

for shape in shapes:
    print(f"مساحت: {shape.area()}")

# چندریختی با Duck Typing
def describe(animal):
    print(animal.speak())
    print(animal.move())

class Duck:
    def speak(self):
        return "کواک کواک!"
    def move(self):
        return "شنا می‌کند"

class Robot:
    def speak(self):
        return "بوق بوق!"
    def move(self):
        return "راه می‌رود"

describe(Duck())   # Duck
describe(Robot())  # Robot (Duck Typing)
➜ مساحت: 50
➜ مساحت: 153.938
➜ مساحت: 24.0
💡 نکته: Duck Typing به این معنی است که "نوع" یک شیء مهم نیست، بلکه "رفتار" آن مهم است. اگر یک شیء متدهای مورد انتظار را داشته باشد، می‌توان از آن استفاده کرد.
🧪 تمرین: یک تابع play_sound(animal) بنویسید که متد make_sound() را روی هر شیء فراخوانی کند. کلاس‌های Dog، Cat و Duck را با پیاده‌سازی‌های مختلف از make_sound() ایجاد کنید.

۱۸.۴ @classmethod و @staticmethod

  • @classmethod: متدی که به کلاس تعلق دارد، نه به یک نمونه. اولین پارامتر آن cls (کلاس) است. برای ایجاد سازنده‌های جایگزین استفاده می‌شود.
  • @staticmethod: متدی که به کلاس تعلق دارد، اما به نمونه یا کلاس دسترسی ندارد. مانند یک تابع معمولی است که در کلاس قرار گرفته.
📋 @classmethod دسترسی به کلاس (cls)
⚡ @staticmethod بدون دسترسی به self/cls 
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    @classmethod
    def from_birth_year(cls, name, birth_year):
        """سازنده‌ی جایگزین بر اساس سال تولد"""
        current_year = 2026
        age = current_year - birth_year
        return cls(name, age)
    
    @classmethod
    def from_dict(cls, data):
        """سازنده از دیکشنری"""
        return cls(data["name"], data["age"])
    
    @staticmethod
    def is_adult(age):
        """بررسی بزرگسالی (وابسته به نمونه نیست)"""
        return age >= 18
    
    def get_info(self):
        return f"{self.name} ({self.age} سال)"

# استفاده از classmethod
person1 = Person("علی", 25)
person2 = Person.from_birth_year("سارا", 1995)  # 2026 - 1995 = 31
person3 = Person.from_dict({"name": "رضا", "age": 28})

print(person1.get_info())  # "علی (25 سال)"
print(person2.get_info())  # "سارا (31 سال)"
print(person3.get_info())  # "رضا (28 سال)"

# استفاده از staticmethod
print(Person.is_adult(20))  # True
print(Person.is_adult(15))  # False

# classmethod برای ارث‌بری
class Student(Person):
    def __init__(self, name, age, student_id):
        super().__init__(name, age)
        self.student_id = student_id
    
    @classmethod
    def from_dict(cls, data):
        return cls(data["name"], data["age"], data["student_id"])

student = Student.from_dict({"name": "علی", "age": 20, "student_id": "S001"})
print(student.get_info())  # "علی (20 سال)"
➜ علی (25 سال)
➜ سارا (31 سال)
➜ True
💎 نکته طلایی: از @classmethod برای ایجاد سازنده‌های جایگزین (Alternative Constructors) استفاده کنید. از @staticmethod برای توابع کمکی که به داده‌های نمونه نیاز ندارند، استفاده کنید.
🧪 تمرین: یک کلاس Date با ویژگی‌های year، month و day ایجاد کنید. یک @classmethod به نام from_string برای ایجاد از رشته‌ای مثل "2026-01-15" و یک @staticmethod به نام is_leap_year برای بررسی سال کبیسه اضافه کنید.

۱۸.۵ @property و ویژگی‌های محاسباتی

@property به شما اجازه می‌دهد متدها را به‌عنوان ویژگی (Attribute) تعریف کنید. این کار برای ویژگی‌های محاسباتی و کنترل دسترسی به ویژگی‌ها بسیار مفید است.

  • Getter: با @property تعریف می‌شود.
  • Setter: با @property.setter تعریف می‌شود.
  • Deleter: با @property.deleter تعریف می‌شود.
class Circle:
    def __init__(self, radius):
        self._radius = radius
    
    @property
    def radius(self):
        """دریافت شعاع"""
        return self._radius
    
    @radius.setter
    def radius(self, value):
        """تنظیم شعاع با اعتبارسنجی"""
        if value < 0:
            raise ValueError("شعاع نمی‌تواند منفی باشد!")
        self._radius = value
    
    @property
    def area(self):
        """مساحت (محاسباتی)"""
        return 3.14159 * self._radius ** 2
    
    @property
    def diameter(self):
        """قطر (محاسباتی)"""
        return 2 * self._radius

# استفاده
c = Circle(5)
print(c.radius)     # 5 (مثل ویژگی)
print(c.area)       # 78.53975 (محاسبه می‌شود)
print(c.diameter)   # 10

c.radius = 10       # از setter استفاده می‌شود
print(c.area)       # 314.159

# c.radius = -5     # ❌ ValueError

class Person:
    def __init__(self, first_name, last_name):
        self.first_name = first_name
        self.last_name = last_name
    
    @property
    def full_name(self):
        return f"{self.first_name} {self.last_name}"
    
    @full_name.setter
    def full_name(self, name):
        parts = name.split()
        if len(parts) != 2:
            raise ValueError("نام و نام‌خانوادگی باید وارد شود")
        self.first_name = parts[0]
        self.last_name = parts[1]

p = Person("علی", "رضایی")
print(p.full_name)        # "علی رضایی"
p.full_name = "سارا محمدی"
print(p.first_name)       # "سارا"
print(p.last_name)        # "محمدی"
➜ 5
➜ 78.53975
➜ علی رضایی
💡 نکته: از @property برای اعتبارسنجی ورودی‌ها، محاسبه‌ی مقادیر و ایجاد API پاک استفاده کنید. ویژگی‌های محاسباتی مانند یک ویژگی معمولی خوانده می‌شوند (بدون پرانتز).
🧪 تمرین: یک کلاس BankAccount با ویژگی‌های balance (با @property) ایجاد کنید. برای balance یک setter با اعتبارسنجی (مثبت بودن) و یک getter ساده اضافه کنید. همچنین یک ویژگی محاسباتی is_overdrawn اضافه کنید که اگر موجودی منفی بود True برگرداند.

۱۸.۶ کپسوله‌سازی (Encapsulation) و کنترل دسترسی

کپسوله‌سازی به معنی پنهان کردن جزئیات داخلی یک کلاس و ارائه‌ی یک رابط عمومی (public interface) است. در پایتون، با استفاده از _ و __ کنترل دسترسی پیاده‌سازی می‌شود.

  • _attribute: نشان‌دهنده‌ی ویژگی محافظت‌شده (Protected) – قرارداد، نه اجباری.
  • __attribute: نام‌گذاری (Name Mangling) – دسترسی سخت‌تر از خارج کلاس.
  • Getter/Setter با @property: کنترل دسترسی و اعتبارسنجی.
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance  # ویژگی خصوصی
        self._transactions = []   # ویژگی محافظت‌شده
    
    @property
    def balance(self):
        """دسترسی به موجودی (فقط خواندنی)"""
        return self.__balance
    
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            self._transactions.append(f"+{amount}")
            return True
        return False
    
    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            self._transactions.append(f"-{amount}")
            return True
        return False
    
    def get_history(self):
        """دسترسی به تاریخچه (فقط خواندنی)"""
        return self._transactions.copy()  # کپی برای جلوگیری از تغییر

# استفاده
acc = BankAccount("علی", 1000)
print(acc.balance)       # 1000
acc.deposit(500)
print(acc.balance)       # 1500

# دسترسی مستقیم به ویژگی‌های خصوصی امکان‌پذیر نیست
# print(acc.__balance)   # ❌ AttributeError

# اما از طریق name mangling می‌توان (توصیه نمی‌شود)
print(acc._BankAccount__balance)  # 1500 (اما نباید استفاده شود)

# ویژگی محافظت‌شده قابل دسترسی است (اما نباید مستقیماً تغییر داده شود)
print(acc._transactions)  # ['+500']

# استفاده از property برای کنترل دسترسی
class User:
    def __init__(self, username, password):
        self.username = username
        self.__password = password  # رمز عبور خصوصی
    
    @property
    def password(self):
        """فقط خواندنی"""
        return "***"  # هرگز رمز واقعی را برنگردانید
    
    def check_password(self, password):
        return self.__password == password

user = User("ali", "12345")
print(user.password)        # "***"
print(user.check_password("12345"))  # True
➜ 1000

۱۸.۷ ارث‌بری چندگانه (Multiple Inheritance) و MRO

ارث‌بری چندگانه به کلاس اجازه می‌دهد از چندین کلاس والد ارث‌بری کند. MRO (Method Resolution Order) ترتیبی است که پایتون برای یافتن متدها در ارث‌بری چندگانه استفاده می‌کند.

  • MRO با الگوریتم C3 محاسبه می‌شود.
  • از ClassName.__mro__ یا ClassName.mro() برای مشاهده‌ی ترتیب استفاده کنید.
class A:
    def method(self):
        print("A")

class B:
    def method(self):
        print("B")

class C(A, B):
    pass

class D(B, A):
    pass

class E(A):
    def method(self):
        print("E")

class F(B):
    def method(self):
        print("F")

class G(E, F):
    pass

class H(D, G):
    pass

# بررسی MRO
print(C.__mro__)  # (C, A, B, object)
print(D.__mro__)  # (D, B, A, object)
print(G.__mro__)  # (G, E, F, B, object)
print(H.__mro__)  # (H, D, B, A, G, E, F, object)

c = C()
c.method()  # A (از A ارث برده، چون اول در MRO است)

d = D()
d.method()  # B (از B ارث برده)

g = G()
g.method()  # E (از E ارث برده)

h = H()
h.method()  # D? (از D ارث برده)

# Diamond Problem
class X:
    def method(self):
        print("X")

class Y(X):
    def method(self):
        print("Y")

class Z(X):
    def method(self):
        print("Z")

class W(Y, Z):
    pass

w = W()
w.method()  # Y (بر اساس MRO: W → Y → Z → X)

print(W.__mro__)  # (W, Y, Z, X, object)
➜ A
➜ B
➜ Y
💡 نکته: ارث‌بری چندگانه می‌تواند پیچیده باشد. از آن با احتیاط استفاده کنید و در صورت امکان از ترکیب (Composition) به‌جای آن استفاده کنید. برای مشاهده‌ی MRO از ClassName.__mro__ استفاده کنید.
🧪 تمرین: کلاس‌های زیر را ایجاد کنید و MRO آنها را بررسی کنید: class A: pass، class B(A): pass، class C(A): pass، class D(B, C): pass. متد method() را در هر کلاس با print متفاوت اضافه کنید و ببینید کدام یک اجرا می‌شود.

سوالات چهارگزینه‌ای

  1. کدام یک از موارد زیر برای ارث‌بری از یک کلاس استفاده می‌شود؟
    أ) class Child extends Parent ب) class Child(Parent) ج) class Child inherits Parent د) class Child : Parent
  2. خروجی کد زیر چیست؟
    class A: def method(self): print("A"); class B(A): def method(self): super().method(); print("B"); b = B(); b.method()
    أ) "A" ب) "B" ج) "A B" د) "B A"
  3. برای تعریف یک ویژگی محاسباتی از کدام دکوریتور استفاده می‌شود؟
    أ) @classmethod ب) @staticmethod ج) @property د) @abstractmethod

📌 جمع‌بندی و خلاصه

نکات طلایی

  • 🔹 وراثت (Inheritance): ایجاد کلاس‌های جدید بر اساس کلاس‌های موجود با class Child(Parent).
  • 🔹 super(): فراخوانی متدهای والد برای گسترش عملکرد.
  • 🔹 چندریختی (Polymorphism): متدهای یکسان با رفتارهای متفاوت در کلاس‌های مختلف.
  • 🔹 @classmethod: متد کلاس با دسترسی به cls – برای سازنده‌های جایگزین.
  • 🔹 @staticmethod: متد استاتیک بدون دسترسی به self یا cls.
  • 🔹 @property: ویژگی‌های محاسباتی و کنترل‌شده با getter/setter.
  • 🔹 کپسوله‌سازی: با _ و __ برای محافظت از داده‌ها.
  • 🔹 ارث‌بری چندگانه: ارث‌بری از چند کلاس با MRO (Method Resolution Order).

برگه تقلب

# وراثت
class Child(Parent):
    def __init__(self, args):
        super().__init__(args)
        self.new_attr = value

# super()
super().method()

# classmethod
@classmethod
def from_dict(cls, data):
    return cls(data["key"])

# staticmethod
@staticmethod
def helper():
    return "helper"

# property
@property
def attr(self):
    return self._attr

@attr.setter
def attr(self, value):
    self._attr = value

# ارث‌بری چندگانه
class Child(Parent1, Parent2):
    pass

📖 واژه‌نامه تخصصی

  • Inheritance (وراثت): ایجاد کلاس جدید بر اساس کلاس موجود.
  • Parent Class (کلاس والد): کلاسی که از آن ارث‌بری می‌شود.
  • Child Class (کلاس فرزند): کلاسی که از والد ارث‌بری می‌کند.
  • super(): تابع برای دسترسی به متدهای والد.
  • Polymorphism (چندریختی): رفتارهای متفاوت برای یک متد در کلاس‌های مختلف.
  • Duck Typing: "اگر مثل اردک راه می‌رود و صدا می‌دهد، پس اردک است".
  • classmethod: متدی که به کلاس تعلق دارد (cls).
  • staticmethod: متدی که به کلاس تعلق دارد اما به self یا cls دسترسی ندارد.
  • property: دکوریتور برای ویژگی‌های محاسباتی و کنترل‌شده.
  • Encapsulation (کپسوله‌سازی): پنهان کردن جزئیات داخلی.
  • MRO (Method Resolution Order): ترتیب جستجوی متدها در ارث‌بری چندگانه.
  • Multiple Inheritance (ارث‌بری چندگانه): ارث‌بری از چند کلاس والد.

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن super().__init__() در کلاس فرزند که باعث می‌شود ویژگی‌های والد مقداردهی نشوند.
    🔧 راه حل: همیشه super().__init__(...) را در __init__ کلاس فرزند فراخوانی کنید.
  • 🔴 اشتباه: استفاده از classmethod به‌جای staticmethod در جایی که به کلاس نیاز نیست، که باعث می‌شود کد غیرضروری پیچیده شود.
    🔧 راه حل: اگر به کلاس یا نمونه دسترسی ندارید، از @staticmethod استفاده کنید.
  • 🔴 اشتباه: فراموش کردن @property در getter که باعث می‌شود متد به‌عنوان تابع فراخوانی شود (با پرانتز).
    🔧 راه حل: برای ویژگی‌های محاسباتی، از @property استفاده کنید تا مانند ویژگی رفتار کنند.
  • 🔴 اشتباه: ایجاد وابستگی‌های پیچیده با ارث‌بری چندگانه که باعث سردرگمی در MRO می‌شود.
    🔧 راه حل: از ارث‌بری چندگانه با احتیاط استفاده کنید و در صورت امکان، از ترکیب (Composition) استفاده کنید.
  • 🔴 اشتباه: استفاده از __attribute بدون آگاهی از Name Mangling که باعث می‌شود دسترسی از خارج کلاس سخت شود.
    🔧 راه حل: برای ویژگی‌های خصوصی از __attribute و برای محافظت‌شده از _attribute استفاده کنید.
