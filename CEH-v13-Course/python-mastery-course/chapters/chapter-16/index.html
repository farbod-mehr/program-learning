۱۶.۱ ماژول collections – ساختارهای داده‌ی پیشرفته

ماژول collections ساختارهای داده‌ی تخصصی‌تری را ارائه می‌دهد که مکمل انواع داخلی پایتون هستند.

🔢 Counter شمارش عناصر
📋 defaultdict دیکشنری با مقدار پیش‌فرض
🔄 deque صف دوطرفه
📦 namedtuple تاپل با نام فیلد
📊 OrderedDict دیکشنری مرتب 
from collections import Counter, defaultdict, deque, namedtuple, OrderedDict

# Counter - شمارش عناصر
words = ["apple", "banana", "apple", "orange", "banana", "apple"]
counter = Counter(words)
print(counter)           # Counter({'apple': 3, 'banana': 2, 'orange': 1})
print(counter.most_common(2))  # [('apple', 3), ('banana', 2)]

# defaultdict - دیکشنری با مقدار پیش‌فرض
dd = defaultdict(int)    # مقدار پیش‌فرض ۰
dd["apple"] += 1
dd["banana"] += 2
print(dd)                # defaultdict(, {'apple': 1, 'banana': 2})

# defaultdict با لیست
dd_list = defaultdict(list)
dd_list["fruits"].append("apple")
dd_list["fruits"].append("banana")
print(dd_list)           # defaultdict(, {'fruits': ['apple', 'banana']})

# deque - صف دوطرفه (عملکرد سریع برای افزودن/حذف از دو طرف)
dq = deque([1, 2, 3])
dq.appendleft(0)         # [0, 1, 2, 3]
dq.append(4)             # [0, 1, 2, 3, 4]
dq.pop()                 # 4
dq.popleft()             # 0
print(dq)                # deque([1, 2, 3])

# namedtuple - تاپل با نام فیلد
Point = namedtuple("Point", ["x", "y"])
p = Point(10, 20)
print(p.x, p.y)          # 10 20
print(p[0], p[1])        # 10 20

# OrderedDict - دیکشنری مرتب (حفظ ترتیب)
od = OrderedDict()
od["a"] = 1
od["b"] = 2
od["c"] = 3
print(od)                # OrderedDict([('a', 1), ('b', 2), ('c', 3)])
➜ Counter({'apple': 3, 'banana': 2, 'orange': 1})
➜ deque([1, 2, 3])
💎 نکته طلایی: Counter برای شمارش عناصر در لیست‌ها، رشته‌ها و هر iterable دیگر بسیار مفید است. deque برای صف‌ها و پشته‌هایی که نیاز به عملیات سریع در دو طرف دارند، انتخاب ایده‌آلی است.
🧪 تمرین: یک متن طولانی ایجاد کنید و با Counter پرتکرارترین کلمات را پیدا کنید. همچنین با defaultdict یک دیکشنری از گروه‌بندی کلمات بر اساس حرف اول بسازید.

۱۶.۲ ماژول itertools – ابزارهای تکرار

ماژول itertools توابعی برای کار با تکرارها (iterators) ارائه می‌دهد که کار با حلقه‌ها و دنباله‌ها را بسیار کارآمدتر می‌کند.

🔗 chain اتصال چند iterable
🔄 cycle تکرار بی‌نهایت
📊 combinations ترکیب‌ها
🔀 permutations جایگشت‌ها
📈 count شمارنده بی‌نهایت
✂️ takewhile تا زمانی که شرط برقرار است 
import itertools

# chain - اتصال چند iterable
list1 = [1, 2, 3]
list2 = [4, 5, 6]
chained = list(itertools.chain(list1, list2))
print(chained)  # [1, 2, 3, 4, 5, 6]

# cycle - تکرار بی‌نهایت
counter = 0
for item in itertools.cycle(["A", "B", "C"]):
    print(item, end=" ")
    counter += 1
    if counter >= 6:
        break
# A B C A B C

# count - شمارنده بی‌نهایت
for i in itertools.count(10, 2):  # از ۱۰ شروع، گام ۲
    print(i, end=" ")
    if i >= 20:
        break
# 10 12 14 16 18 20

# combinations - ترکیب‌ها (ترتیب مهم نیست)
items = [1, 2, 3, 4]
combs = list(itertools.combinations(items, 2))
print(combs)  # [(1,2), (1,3), (1,4), (2,3), (2,4), (3,4)]

# permutations - جایگشت‌ها (ترتیب مهم است)
perms = list(itertools.permutations(items, 2))
print(perms)  # [(1,2), (1,3), ...]

# takewhile - تا زمانی که شرط برقرار است
numbers = [1, 3, 5, 2, 4, 6]
result = list(itertools.takewhile(lambda x: x < 4, numbers))
print(result)  # [1, 3] (بعد از ۵ که شرط نقض می‌شود، متوقف می‌شود)

# product - حاصلضرب دکارتی
colors = ["قرمز", "آبی"]
sizes = ["S", "M", "L"]
products = list(itertools.product(colors, sizes))
print(products)  # [('قرمز', 'S'), ('قرمز', 'M'), ...]
➜ [1, 2, 3, 4, 5, 6]
➜ [(1, 2), (1, 3), (1, 4), (2, 3), (2, 4), (3, 4)]
💡 نکته: توابع itertools حافظه‌ی کمی مصرف می‌کنند زیرا به‌صورت lazy (تاخیری) کار می‌کنند. برای دنباله‌های بزرگ بسیار کارآمد هستند.
🧪 تمرین: با استفاده از itertools.combinations و itertools.permutations، همه‌ی ترکیب‌ها و جایگشت‌های ۳ حرفی از حروف "ABC" را تولید کنید.

۱۶.۳ ماژول functools – توابع مرتبه‌بالا

ماژول functools ابزارهایی برای کار با توابع و توابع مرتبه‌بالا ارائه می‌دهد.

💾 lru_cache کش کردن نتایج تابع
📋 partial ثابت کردن پارامترها
📦 reduce تجمیع عناصر
🏷️ wraps حفظ اطلاعات تابع در دکوریتور 
from functools import lru_cache, partial, reduce, wraps

# lru_cache - کش کردن نتایج تابع (Memoization)
@lru_cache(maxsize=128)
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(30))  # 832040 (با کش، بسیار سریع‌تر)
print(fibonacci.cache_info())  # CacheInfo(hits=28, misses=31, ...)

# partial - ثابت کردن پارامترها
def multiply(a, b):
    return a * b

double = partial(multiply, 2)  # a = 2 ثابت می‌شود
print(double(5))   # 10
print(double(10))  # 20

# reduce - تجمیع عناصر
numbers = [1, 2, 3, 4, 5]
sum_all = reduce(lambda a, b: a + b, numbers)
print(sum_all)  # 15

product = reduce(lambda a, b: a * b, numbers)
print(product)  # 120

# wraps - حفظ اطلاعات تابع در دکوریتور
def debug(func):
    @wraps(func)  # نام و docstring تابع اصلی حفظ می‌شود
    def wrapper(*args, **kwargs):
        print(f"فراخوانی {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@debug
def say_hello(name):
    """این تابع سلام می‌دهد"""
    return f"سلام {name}"

print(say_hello.__name__)   # say_hello (بدون wraps: wrapper)
print(say_hello.__doc__)    # "این تابع سلام می‌دهد"

# cmp_to_key - تبدیل تابع مقایسه به key (برای sorted)
from functools import cmp_to_key
def compare(a, b):
    return a - b  # عدد منفی یعنی a < b
numbers = [5, 2, 8, 1, 9]
sorted_numbers = sorted(numbers, key=cmp_to_key(compare))
print(sorted_numbers)  # [1, 2, 5, 8, 9]
➜ 832040
➜ 15
➜ 120
💎 نکته طلایی: lru_cache برای توابع سنگین و محاسباتی که بارها با آرگومان‌های یکسان فراخوانی می‌شوند، بسیار مفید است. partial برای ایجاد توابع تخصصی‌تر از توابع عمومی استفاده می‌شود.
🧪 تمرین: یک تابع factorial با lru_cache پیاده‌سازی کنید و سرعت آن را با حالت بدون کش مقایسه کنید.

۱۶.۴ ماژول logging – لاگ‌گیری حرفه‌ای

ماژول logging یک سیستم لاگ‌گیری قدرتمند و انعطاف‌پذیر برای ثبت رویدادها و خطاهای برنامه ارائه می‌دهد.

import logging

# پیکربندی اولیه
logging.basicConfig(
    level=logging.DEBUG,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    datefmt='%Y-%m-%d %H:%M:%S'
)

# سطوح لاگ (از کم‌اهمیت به زیاد)
logging.debug("پیام دیباگ (برای توسعه)")
logging.info("اطلاعات عمومی")
logging.warning("هشدار! ممکن است مشکلی پیش بیاید")
logging.error("خطا رخ داده است")
logging.critical("خطای بحرانی! برنامه متوقف می‌شود")

# نوشتن لاگ در فایل
file_handler = logging.FileHandler("app.log")
file_handler.setLevel(logging.INFO)
formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s')
file_handler.setFormatter(formatter)
logger = logging.getLogger()
logger.addHandler(file_handler)

# لاگ با متغیرها
name = "علی"
age = 25
logger.info(f"کاربر {name} با سن {age} وارد شد")

# لاگ با exception
try:
    1 / 0
except ZeroDivisionError:
    logging.exception("خطا در تقسیم بر صفر")

# پیکربندی پیشرفته با دیکشنری
LOGGING_CONFIG = {
    'version': 1,
    'formatters': {
        'simple': {'format': '%(levelname)s - %(message)s'},
        'detailed': {'format': '%(asctime)s - %(name)s - %(levelname)s - %(message)s'}
    },
    'handlers': {
        'console': {
            'class': 'logging.StreamHandler',
            'level': 'DEBUG',
            'formatter': 'simple'
        },
        'file': {
            'class': 'logging.FileHandler',
            'filename': 'detailed.log',
            'level': 'INFO',
            'formatter': 'detailed'
        }
    },
    'root': {
        'level': 'DEBUG',
        'handlers': ['console', 'file']
    }
}
# logging.config.dictConfig(LOGGING_CONFIG)
➜ 2026-01-15 14:30:00 - root - DEBUG - پیام دیباگ
➜ 2026-01-15 14:30:00 - root - INFO - اطلاعات عمومی
💡 نکته: سطوح لاگ از کم‌اهمیت به زیاد: DEBUG → INFO → WARNING → ERROR → CRITICAL. در production، معمولاً سطح را روی WARNING یا ERROR تنظیم می‌کنند.
🧪 تمرین: یک برنامه بنویسید که از کاربر یک عدد دریافت کند و در صورت خطا، خطا را در فایل لاگ ثبت کند. از logging با سطوح مختلف استفاده کنید.

۱۶.۵ ماژول argparse – رابط خط فرمان حرفه‌ای

ماژول argparse به شما امکان می‌دهد رابط‌های خط فرمان حرفه‌ای با پارامترهای مختلف بسازید.

import argparse

# ایجاد parser
parser = argparse.ArgumentParser(
    description="یک ابزار نمونه با argparse",
    epilog="مثال: python script.py -n علی -a 25"
)

# اضافه کردن آرگومان‌ها
parser.add_argument("-n", "--name", help="نام کاربر", required=True)
parser.add_argument("-a", "--age", type=int, help="سن کاربر", default=18)
parser.add_argument("-v", "--verbose", action="store_true", help="حالت verbose")

# آرگومان‌های موقعیتی
parser.add_argument("file", help="نام فایل ورودی")

# آرگومان با انتخاب محدود
parser.add_argument("--color", choices=["red", "green", "blue"], help="رنگ")

# آرگومان با تعداد متغیر
parser.add_argument("numbers", nargs="*", type=int, help="لیست اعداد")

# گروه‌های متقابل
group = parser.add_mutually_exclusive_group()
group.add_argument("--add", action="store_true", help="افزودن")
group.add_argument("--remove", action="store_true", help="حذف")

# parse کردن آرگومان‌ها
args = parser.parse_args()

# استفاده از آرگومان‌ها
print(f"نام: {args.name}")
print(f"سن: {args.age}")
print(f"فایل: {args.file}")
print(f"رنگ: {args.color}")
print(f"اعداد: {args.numbers}")

if args.verbose:
    print("حالت verbose فعال است")

if args.add:
    print("افزودن")
elif args.remove:
    print("حذف")

# اجرا: python script.py test.txt -n علی -a 25 --color red --add 1 2 3
➜ نام: علی
➜ سن: 25
➜ فایل: test.txt
💎 نکته طلایی: argparse به‌طور خودکار راهنما (help) و پیام‌های خطا تولید می‌کند. با python script.py -h می‌توانید راهنما را مشاهده کنید.
🧪 تمرین: یک اسکریپت خط فرمان با argparse بنویسید که دو عدد را به‌عنوان آرگومان دریافت کند و عملیات (جمع، تفریق، ضرب، تقسیم) را با یک پارامتر انتخاب کند.

۱۶.۶ ماژول subprocess – اجرای دستورات سیستمی

ماژول subprocess به شما امکان می‌دهد فرآیندهای جدید ایجاد کنید، خروجی آن‌ها را دریافت کنید و با آنها ارتباط برقرار کنید.

import subprocess

# اجرای یک دستور و دریافت خروجی
result = subprocess.run(["ls", "-l"], capture_output=True, text=True)
print(result.stdout)  # خروجی استاندارد
print(result.stderr)  # خطاها
print(result.returncode)  # کد بازگشت (۰ = موفق)

# اجرا با shell=True (اجرای مستقیم در شل)
result = subprocess.run("echo Hello World", shell=True, capture_output=True, text=True)
print(result.stdout)  # "Hello World\n"

# اجرای دستور و دریافت خروجی به‌صورت رشته
output = subprocess.check_output(["ls", "-l"], text=True)
print(output)

# اجرا با ورودی
result = subprocess.run(["grep", "python"], input="python is great\njava is ok", text=True, capture_output=True)
print(result.stdout)  # "python is great\n"

# استفاده از PIPE برای ارتباط پیشرفته
process = subprocess.Popen(["python", "-c", "import time; print('start'); time.sleep(2); print('end')"],
                           stdout=subprocess.PIPE, text=True)
for line in process.stdout:
    print(line.strip())

# زمان‌سنجی اجرا
import time
start = time.time()
subprocess.run(["sleep", "2"])  # در Windows: subprocess.run(["timeout", "2"])
print(f"زمان اجرا: {time.time() - start:.2f} ثانیه")
➜ total 0 ...
➜ Hello World
💡 نکته: subprocess.run() روش توصیه‌شده برای اجرای دستورات ساده است. از shell=True با احتیاط استفاده کنید (مخصوصاً با ورودی کاربر).
🧪 تمرین: با استفاده از subprocess، یک برنامه بنویسید که لیست فایل‌های یک دایرکتوری را دریافت کند و تعداد فایل‌های .py را بشمارد.

۱۶.۷ ماژول shutil – عملیات پیشرفته روی فایل‌ها

ماژول shutil (Shell Utilities) عملیات سطح‌بالا روی فایل‌ها و دایرکتوری‌ها را ارائه می‌دهد، مانند کپی کردن، جابه‌جایی، حذف و آرشیو کردن.

📋 copy کپی فایل
📁 copytree کپی دایرکتوری
✂️ move جابه‌جایی
🗑️ rmtree حذف دایرکتوری
📦 make_archive ایجاد آرشیو (ZIP, TAR) 
import shutil
import os

# کپی کردن فایل
shutil.copy("source.txt", "destination.txt")  # محتوا و مجوزها کپی می‌شوند
shutil.copy2("source.txt", "destination2.txt")  # متادیتا هم کپی می‌شود

# کپی کردن دایرکتوری
shutil.copytree("source_folder", "destination_folder")  # کل دایرکتوری کپی می‌شود
shutil.copytree("source", "dest", ignore=shutil.ignore_patterns("*.tmp", "__pycache__"))

# جابه‌جایی (Move/Rename)
shutil.move("old_name.txt", "new_name.txt")  # تغییر نام
shutil.move("file.txt", "folder/file.txt")  # انتقال به پوشه دیگر

# حذف دایرکتوری (غیرخالی)
shutil.rmtree("folder_to_delete")  # کل دایرکتوری حذف می‌شود

# ایجاد آرشیو (ZIP)
shutil.make_archive("backup", "zip", "folder_to_archive")  # backup.zip ایجاد می‌شود

# استخراج آرشیو
shutil.unpack_archive("backup.zip", "extracted_folder")

# دریافت فضای دیسک
total, used, free = shutil.disk_usage("/")
print(f"فضای کل: {total // (1024**3)} GB")
print(f"فضای استفاده‌شده: {used // (1024**3)} GB")
print(f"فضای آزاد: {free // (1024**3)} GB")

# کپی با پیشرفت (ایجاد خودکار دایرکتوری)
shutil.copy("file.txt", "new_folder/file.txt")

# بررسی وجود فایل قبل از کپی
if os.path.exists("source.txt"):
    shutil.copy("source.txt", "backup.txt")
else:
    print("فایل وجود ندارد")
➜ فضای کل: 500 GB
➜ فضای استفاده‌شده: 200 GB
➜ فضای آزاد: 300 GB
💎 نکته طلایی: shutil برای کارهای خودکار مانند بک‌آپ‌گیری، سازماندهی فایل‌ها و جابه‌جایی داده‌ها بسیار مفید است. با shutil.make_archive() می‌توانید به‌راحتی بک‌آپ ZIP ایجاد کنید.
🧪 تمرین: یک برنامه بنویسید که یک پوشه را بک‌آپ بگیرد (با shutil.copytree) و سپس یک آرشیو ZIP از آن ایجاد کند.

⚠️ خطاهای رایج و عیب‌یابی

  • 🔴 اشتباه: فراموش کردن import ماژول مورد نیاز که باعث NameError می‌شود.
    🔧 راه حل: همیشه ماژول‌ها را در ابتدای فایل import کنید.
  • 🔴 اشتباه: استفاده از logging بدون پیکربندی که باعث می‌شود لاگ‌ها در کنسول نمایش داده نشوند.
    🔧 راه حل: با logging.basicConfig() پیکربندی اولیه را انجام دهید.
  • 🔴 اشتباه: فراموش کردن @lru_cache که باعث می‌شود تابع بدون کش اجرا شود.
    🔧 راه حل: دکوریتور را بالای تابع قرار دهید.
  • 🔴 اشتباه: استفاده از subprocess.run() با shell=True و ورودی کاربر که خطر امنیتی دارد.
    🔧 راه حل: از shell=False استفاده کنید و آرگومان‌ها را به‌صورت لیست ارسال کنید.
  • 🔴 اشتباه: استفاده از shutil.rmtree() بدون بررسی وجود دایرکتوری که باعث FileNotFoundError می‌شود.
    🔧 راه حل: قبل از حذف، وجود دایرکتوری را با os.path.exists() بررسی کنید.
