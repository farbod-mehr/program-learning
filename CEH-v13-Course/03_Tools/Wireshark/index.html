📡 چیت‌شیت جامع Wireshark

🔰 مقدمه – Wireshark چیست؟

Wireshark یکی از قدرتمندترین و محبوب‌ترین ابزارهای تحلیل و شنود شبکه (Network Sniffing & Analysis) در جهان است. این ابزار متن‌باز که در سال ۱۹۹۸ توسط Gerald Combs توسعه یافت، به متخصصان امنیت، مدیران شبکه و هکرهای قانونمند امکان می‌دهد تا ترافیک شبکه را در زمان واقعی ضبط، تحلیل و بررسی کنند.

Wireshark به شما امکان می‌دهد تا بسته‌های شبکه را در سطح بایت مشاهده کنید و تمام لایه‌های مدل OSI/TCP/IP را تحلیل نمایید. این ابزار برای عیب‌یابی شبکه، تحلیل حملات، شناسایی بدافزارها و آموزش بسیار مفید است.

💡 کاربردهای اصلی Wireshark:
  • شنود شبکه (Sniffing): ضبط و نمایش تمام بسته‌های عبوری از شبکه.
  • تحلیل ترافیک: بررسی پروتکل‌ها، اندازه بسته‌ها، تأخیر و …
  • عیب‌یابی شبکه: شناسایی مشکلات اتصال، تأخیر و از دست رفتن بسته‌ها.
  • تشخیص حملات: شناسایی حملات ARP Spoofing، DoS، MITM و …
  • تحلیل بدافزار: شناسایی ارتباطات مشکوک بدافزارها با سرورهای C2.
  • آموزش: مشاهده عملکرد پروتکل‌ها به صورت بصری.
  • جرم‌یابی دیجیتال: استخراج شواهد از ترافیک شبکه.
⚠️ هشدار اخلاقی: شنود شبکه‌های بدون مجوز، جرم محسوب می‌شود و حریم خصوصی افراد را نقض می‌کند. فقط در شبکه‌های خود یا با مجوز کتبی استفاده شود.

📥 نصب و راه‌اندازی Wireshark

📌 نصب در Kali Linux (پیش‌فرض):

Wireshark در Kali Linux به صورت پیش‌فرض نصب است.

sudo apt update
sudo apt install wireshark -y

📌 نصب در ویندوز:

دانلود از سایت رسمی: https://www.wireshark.org/download.html

📌 نصب در macOS:

brew install wireshark

📌 اجرای Wireshark:

sudo wireshark
💡 نکته: برای ضبط ترافیک در لینوکس، Wireshark باید با دسترسی root اجرا شود. در غیر این صورت، ممکن است نتوانید بسته‌ها را ضبط کنید.

🖥️ آشنایی با رابط کاربری Wireshark

📌 بخش‌های اصلی:

  • Toolbar (نوار ابزار): دکمه‌های شروع/توقف ضبط، باز کردن فایل، ذخیره و …
  • Packet List Pane: لیست تمام بسته‌های ضبط شده با خلاصه اطلاعات.

  • Packet Bytes Pane: نمایش داده‌های خام بسته به صورت Hex و ASCII.
  • Filter Bar: جعبه متن برای وارد کردن فیلترهای نمایش.
  • Status Bar: اطلاعات آماری مانند تعداد بسته‌ها و …

🎯 فیلترهای ضبط (Capture Filters)

فیلترهای ضبط قبل از شروع ضبط اعمال می‌شوند و تعیین می‌کنند که کدام بسته‌ها ضبط شوند. این فیلترها با زبان BPF (Berkeley Packet Filter) نوشته می‌شوند و برای کاهش حجم فایل ضبط بسیار مفید هستند.

📌 فیلترهای پرکاربرد Capture:

فیلترتوضیح
host 192.168.1.101 ضبط ترافیک یک IP خاص
src host 192.168.1.100 ضبط بسته‌هایی که از یک IP خاص آمده‌اند
dst host 192.168.1.1 ضبط بسته‌هایی که به یک IP خاص می‌روند
port 80 ضبط ترافیک یک پورت خاص
portrange 1-1024 ضبط ترافیک یک محدوده پورت
tcp ضبط فقط ترافیک TCP
udp ضبط فقط ترافیک UDP
icmp ضبط فقط ترافیک ICMP (پینگ)
arp ضبط فقط ترافیک ARP
not port 22 ضبط همه ترافیک به جز پورت ۲۲
host 192.168.1.101 and port 80 ضبط ترافیک HTTP یک IP خاص
src host 10.0.0.1 and dst port 53 ضبط درخواست‌های DNS از یک IP خاص
💡 نکته: فیلترهای ضبط در کادر Capture Filter در بالای صفحه یا در پنجره Capture Options وارد می‌شوند.

🔍 فیلترهای نمایش (Display Filters)

فیلترهای نمایش پس از ضبط اعمال می‌شوند و تعیین می‌کنند که کدام بسته‌ها در لیست نمایش داده شوند. این فیلترها با زبان اختصاصی Wireshark نوشته می‌شوند و بسیار قدرتمند هستند.

📌 فیلترهای پایه:

فیلترتوضیح
ip.addr == 192.168.1.101 نمایش بسته‌های یک IP خاص (مبدأ یا مقصد)
ip.src == 192.168.1.100 نمایش بسته‌هایی با IP مبدأ خاص
ip.dst == 192.168.1.1 نمایش بسته‌هایی با IP مقصد خاص
tcp.port == 80 نمایش ترافیک یک پورت TCP خاص
udp.port == 53 نمایش ترافیک یک پورت UDP خاص
tcp نمایش فقط ترافیک TCP
udp نمایش فقط ترافیک UDP
icmp نمایش فقط ترافیک ICMP
arp نمایش فقط ترافیک ARP
dns نمایش فقط ترافیک DNS
http نمایش فقط ترافیک HTTP
https نمایش فقط ترافیک HTTPS

📌 فیلترهای ترکیبی:

فیلترتوضیح
ip.addr == 192.168.1.101 and tcp.port == 80 ترافیک HTTP یک IP خاص
ip.src == 10.0.0.1 or ip.dst == 10.0.0.1 بسته‌های مرتبط با یک IP
!(arp or icmp) همه چیز به جز ARP و ICMP
tcp.flags.syn == 1 بسته‌های SYN (شروع اتصال)
tcp.flags.reset == 1 بسته‌های RST (قطع اتصال)
tcp.flags.fin == 1 بسته‌های FIN (پایان اتصال)
http.request.method == "GET" درخواست‌های GET HTTP
http.request.method == "POST" درخواست‌های POST HTTP
http.response.code == 404 پاسخ‌های HTTP 404
http contains "password" درخواست‌های HTTP حاوی کلمه password
frame contains "admin" بسته‌هایی که شامل عبارت admin هستند

📌 فیلترهای پیشرفته:

فیلترتوضیح
tcp.stream eq 0 نمایش جریان TCP شماره ۰
tcp.analysis.retransmission بسته‌های ارسال مجدد (Retransmission)
tcp.analysis.duplicate_ack بسته‌های ACK تکراری
tcp.analysis.ack_rtt > 0.5 تأخیر ACK بیشتر از ۵۰۰ میلی‌ثانیه
tcp.window_size < 65535 پنجره TCP کوچک
tcp.len > 0 بسته‌های TCP با داده
udp.length > 1000 بسته‌های UDP با طول بیشتر از ۱۰۰۰ بایت
ip.ttl < 10 بسته‌هایی با TTL کمتر از ۱۰
ip.fragmented بسته‌های تکه‌تکه‌شده IP
dns.qry.name contains "example.com" درخواست‌های DNS برای یک دامنه خاص
ssl.handshake.type == 1 بسته‌های Client Hello در SSL/TLS
💡 نکته: فیلترهای نمایش در کادر Display Filter (نوار سبز رنگ) وارد می‌شوند. اگر فیلتر صحیح باشد، زمینه سبز می‌شود و اگر اشتباه باشد، قرمز می‌شود.

📎 دنبال کردن جریان (Follow Stream)

یکی از قوی‌ترین ویژگی‌های Wireshark، قابلیت دنبال کردن جریان است که به شما امکان می‌دهد تا ارتباط کامل بین کلاینت و سرور را به صورت یکپارچه مشاهده کنید.

📌 نحوه استفاده:

  1. یک بسته از جریان مورد نظر را انتخاب کنید.
  2. از منوی Analyze → Follow و سپس انتخاب نوع جریان (TCP Stream، UDP Stream، TLS Stream، HTTP Stream).
  3. محتوا به صورت کامل نمایش داده می‌شود.

📌 میانبر:

Ctrl+Alt+Shift+T
💡 کاربرد در هک:
  • استخراج رمزهای عبور: در ترافیک HTTP غیرامن، رمزهای عبور به صورت متن واضح قابل مشاهده هستند.
  • بازسازی محتوای وب: مشاهده کامل صفحات وب منتقل‌شده.
  • تحلیل بدافزار: مشاهده ارتباطات بدافزار با سرورهای C2.
  • شناسایی داده‌های حساس: پیدا کردن اطلاعات کارت اعتباری یا اطلاعات شخصی در ترافیک.

🛡️ تشخیص حملات با Wireshark

📌 ۱. تشخیص ARP Spoofing

# فیلتر نمایش
arp.duplicate-address-frame

# یا بررسی دستی
arp.opcode == 2  # پاسخ ARP
# و مشاهده آدرس‌های MAC تکراری

نشانه‌ها: چندین پاسخ ARP با یک IP اما با MAC متفاوت.

📌 ۲. تشخیص SYN Flood (DoS)

# نمایش تعداد SYN در یک بازه زمانی
tcp.flags.syn == 1 and tcp.flags.ack == 0

# تعداد SYN از یک IP خاص
tcp.flags.syn == 1 and ip.src == 192.168.1.100

نشانه‌ها: تعداد زیادی بسته SYN از یک یا چند IP بدون تکمیل Handshake.

📌 ۳. تشخیص حملات MITM

# بررسی SSL/TLS
ssl.handshake.type == 1  # Client Hello

# بررسی تغییر مسیر ICMP
icmp.type == 5  # ICMP Redirect

نشانه‌ها: تغییر مسیر غیرعادی یا گواهی‌های SSL مشکوک.

📌 ۴. تشخیص DNS Spoofing

# پاسخ‌های DNS با آدرس‌های غیرمعمول
dns.flags.response == 1 and dns.a != 0

نشانه‌ها: پاسخ‌های DNS که به آدرس‌های IP غیرمعمول اشاره می‌کنند.

📌 ۵. تشخیص ترافیک بدافزار

# ترافیک به پورت‌های غیراستاندارد
tcp.port >= 49152 and tcp.port <= 65535

# درخواست‌های DNS به دامنه‌های مشکوک
dns.qry.name contains "tor" or dns.qry.name contains "onion"

# ترافیک به IPهای خارجی با الگوی غیرعادی
ip.dst == 8.8.8.8 or ip.dst == 1.1.1.1

نشانه‌ها: ارتباطات غیرعادی به پورت‌های بالا، دامنه‌های مشکوک یا IPهای خارجی.

⚠️ نکته: تشخیص حملات نیاز به دانش و تجربه دارد. همیشه با یک شبکه سالم مقایسه کنید تا الگوهای غیرعادی را شناسایی کنید.

💡 نکته: Wireshark یک ابزار قدرتمند است که با تمرین و تجربه، می‌توانید از آن برای تحلیل عمیق شبکه و تشخیص حملات استفاده کنید.

🔒 نکات امنیتی و حرفه‌ای

  • فقط در شبکه‌های مجاز ضبط کنید: شنود شبکه‌های دیگران بدون مجوز جرم است.
  • از فیلترهای ضبط استفاده کنید: برای کاهش حجم فایل و تمرکز بر ترافیک مورد نظر.
  • ذخیره فایل‌های ضبط با فرمت pcapng: فرمت استاندارد Wireshark با قابلیت‌های بیشتر.
  • استفاده از رنگ‌بندی: برای تشخیص سریع انواع ترافیک، رنگ‌ها را سفارشی کنید.
  • بررسی هشدارها: Wireshark دارای قابلیت تشخیص خودکار برخی حملات و مشکلات است.
  • به‌روزرسانی منظم: همیشه آخرین نسخه Wireshark را برای پشتیبانی از پروتکل‌های جدید نصب کنید.
  • تحلیل با احتیاط: فایل‌های ضبط ممکن است حاوی اطلاعات حساس باشند. از آنها به‌درستی محافظت کنید.
  • استفاده از tcpdump: در سرورهای بدون GUI، از tcpdump برای ضبط و سپس تحلیل با Wireshark استفاده کنید.
⚠️ هشدار اخلاقی: Wireshark ابزاری قدرتمند برای تحلیل شبکه است، اما استفاده از آن برای شنود ارتباطات دیگران بدون مجوز، غیراخلاقی و غیرقانونی است.

📖 واژه‌نامه تخصصی Wireshark

واژهتوضیح کامل
Sniffing فرآیند ضبط و تحلیل بسته‌های شبکه برای جمع‌آوری اطلاعات.
Capture Filter فیلتری که قبل از ضبط اعمال می‌شود و تعیین می‌کند کدام بسته‌ها ضبط شوند.
Display Filter فیلتری که پس از ضبط اعمال می‌شود و تعیین می‌کند کدام بسته‌ها نمایش داده شوند.
BPF Berkeley Packet Filter – زبان فیلتر کردن بسته‌ها در سطح هسته.
Stream یک جریان ارتباطی بین دو دستگاه که شامل تمام بسته‌های مرتبط است.
Follow Stream قابلیت Wireshark برای نمایش کامل یک جریان ارتباطی (TCP/UDP/HTTP).
Pcap فرمت فایل ضبط بسته‌های شبکه (Packet Capture).
Pcapng نسخه جدیدتر فرمت pcap با قابلیت‌های بیشتر.
ARP Spoofing حمله‌ای که در آن مهاجم با ارسال بسته‌های ARP جعلی، ترافیک را به سمت خود هدایت می‌کند.
MITM Man-in-the-Middle – حمله‌ای که در آن مهاجم بین دو طرف ارتباط قرار می‌گیرد.
TCP Handshake فرآیند سه مرحله‌ای برقراری اتصال TCP (SYN, SYN-ACK, ACK).
Wireshark ابزاری برای ضبط و تحلیل بسته‌های شبکه در زمان واقعی.
Tcpdump نسخه خط فرمان Wireshark برای ضبط بسته‌ها در سرورها.
💡 جمع‌بندی چیت‌شیت Wireshark:

Wireshark یکی از قدرتمندترین ابزارهای تحلیل شبکه است که با قابلیت‌های پیشرفته‌ای مانند فیلترهای دقیق، دنبال کردن جریان و تشخیص حملات، به متخصصان امنیت امکان بررسی عمیق ترافیک شبکه را می‌دهد.

📌 توصیه نهایی: با فیلترهای پایه شروع کنید و به تدریج به سراغ فیلترهای پیشرفته و تحلیل حملات بروید. تمرین روی شبکه‌های خود و محیط‌های آزمایشگاهی بهترین راه برای یادگیری است. همچنین از ابزار tcpdump برای ضبط در سرورها و سپس تحلیل با Wireshark استفاده کنید.
