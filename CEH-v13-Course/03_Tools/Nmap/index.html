🔍 چیت‌شیت جامع Nmap

🔰 مقدمه – Nmap چیست؟

Nmap (Network Mapper) یکی از قدرتمندترین و محبوب‌ترین ابزارهای اسکن شبکه در جهان است. این ابزار متن‌باز در سال ۱۹۹۷ توسط Gordon Lyon (معروف به Fyodor) توسعه یافت و امروزه به عنوان ابزار استاندارد برای شناسایی شبکه‌ها، کشف میزبان‌های زنده، شناسایی پورت‌های باز، تشخیص سیستم‌عامل، شناسایی سرویس‌ها و نسخه‌های آنها، و حتی اسکن آسیب‌پذیری استفاده می‌شود.

Nmap در Kali Linux به صورت پیش‌فرض نصب است و یکی از اصلی‌ترین ابزارهای هر هکر قانونمند و متخصص امنیت شبکه محسوب می‌شود.

💡 کاربردهای اصلی Nmap:
  • کشف میزبان‌های زنده (Host Discovery): تشخیص دستگاه‌های فعال در شبکه.
  • اسکن پورت (Port Scanning): شناسایی پورت‌های باز و سرویس‌های در حال اجرا.
  • تشخیص سیستم‌عامل (OS Detection): شناسایی سیستمعامل و نسخه آن.
  • تشخیص نسخه سرویس‌ها (Version Detection): شناسایی نام و نسخه سرویس‌های در حال اجرا.
  • اسکن آسیب‌پذیری با NSE: استفاده از اسکریپت‌های پیشرفته برای شناسایی آسیب‌پذیری‌ها.
  • نقشه‌برداری شبکه (Network Mapping): ترسیم توپولوژی شبکه.

📥 نصب و راه‌اندازی Nmap

📌 نصب در Kali Linux (پیش‌فرض):

Nmap در Kali Linux به صورت پیش‌فرض نصب است. برای اطمینان از آخرین نسخه:

sudo apt update
sudo apt install nmap -y

📌 نصب در ویندوز:

دانلود از سایت رسمی: https://nmap.org/download.html

📌 نصب در macOS:

brew install nmap

📌 بررسی نصب:

nmap --version
💡 نکته: برخی از اسکن‌ها (مانند SYN Scan, OS Detection) نیاز به دسترسی root یا administrator دارند.

🔌 انواع اسکن پورت (Port Scanning Techniques)

گزینهنوع اسکنتوضیحمثال
-sS SYN Scan (Half-Open) اسکن SYN – سریع و مخفی. اتصال TCP کامل نمی‌شود. نیاز به root دارد. sudo nmap -sS 192.168.1.1
-sT TCP Connect Scan اسکن کامل TCP – دقیق و قابل‌اعتماد. بدون نیاز به root. nmap -sT 192.168.1.1
-sU UDP Scan اسکن UDP – کندتر و کم‌اعتمادتر. نیاز به root دارد. sudo nmap -sU 192.168.1.1
-sF FIN Scan اسکن FIN – ارسال بسته FIN. برای دور زدن فایروال‌های ساده. sudo nmap -sF 192.168.1.1
-sN NULL Scan اسکن NULL – ارسال بسته بدون فلگ TCP. sudo nmap -sN 192.168.1.1
-sX Xmas Scan اسکن Xmas – ارسال بسته با فلگ‌های FIN, PSH, URG. sudo nmap -sX 192.168.1.1
-sA ACK Scan اسکن ACK – شناسایی قوانین فایروال (نه برای تشخیص پورت باز). sudo nmap -sA 192.168.1.1
-sW Window Scan اسکن Window – مشابه ACK اما با تحلیل پنجره TCP. sudo nmap -sW 192.168.1.1
-sM Maimon Scan اسکن Maimon – ارسال بسته با فلگ‌های FIN/ACK. sudo nmap -sM 192.168.1.1
-sI Idle Scan (Zombie) اسکن Idle – کاملاً مخفی با استفاده از یک میزبان zombie. sudo nmap -sI 192.168.1.1
⚠️ نکته: اسکن FIN, NULL و Xmas بر اساس استاندارد RFC 793 طراحی شده‌اند و فقط روی سیستم‌های Unix/Linux کار می‌کنند. در ویندوز پاسخ متفاوتی دریافت می‌شود.

🔍 گزینه‌های تشخیص (Detection Options)

گزینهتوضیحمثال
-O تشخیص سیستم‌عامل (OS Detection). نیاز به root دارد. sudo nmap -O 192.168.1.1
-sV تشخیص نسخه سرویس‌ها (Version Detection). nmap -sV 192.168.1.1
-A اسکن تهاجمی (Aggressive) – ترکیب OS Detection، Version Detection، TraceRoute و اسکریپت‌ها. sudo nmap -A 192.168.1.1
-sC یا --script=default اجرای اسکریپت‌های پیش‌فرض NSE. nmap -sC 192.168.1.1
--script= اجرای اسکریپت‌های خاص NSE. nmap --script=vuln 192.168.1.1
--script-args ارسال آرگومان به اسکریپت‌های NSE. nmap --script=http-title --script-args http-title.url=/admin 192.168.1.1
💡 نکته: گزینه -A یک اسکن کامل انجام می‌دهد اما زمان بیشتری می‌برد و ممکن است توسط IDS/IPS شناسایی شود.

⏱️ گزینه‌های Timing و عملکرد (Timing & Performance)

گزینهتوضیحمثال
-T0 تا -T5 T0 (Paranoid): بسیار آهسته (برای دور زدن IDS)
T1 (Sneaky): آهسته
T2 (Polite): نسبتاً آهسته (کمتر از ۱۰ بسته در ثانیه)
T3 (Normal): معمولی (پیش‌فرض)
T4 (Aggressive): سریع
T5 (Insane): بسیار سریع (ممکن است باعث اختلال شود) 		nmap -T4 192.168.1.1
--scan-delay فاصله زمانی بین ارسال بسته‌ها (به ثانیه). nmap --scan-delay 1s 192.168.1.1
--host-timeout حداکثر زمان اسکن یک میزبان. nmap --host-timeout 5m 192.168.1.1
--max-retries تعداد دفعات ارسال مجدد بسته‌ها. nmap --max-retries 2 192.168.1.1
--min-rate / --max-rate سرعت حداقل و حداکثر ارسال بسته (بسته در ثانیه). nmap --min-rate 100 192.168.1.1
--parallelism تعداد اتصالات موازی. nmap --parallelism 10 192.168.1.1
💡 نکته: استفاده از -T5 ممکن است باعث از دست رفتن بسته‌ها یا شناسایی توسط فایروال شود. در محیط‌های واقعی از -T3 یا -T4 استفاده کنید.

🔢 گزینه‌های انتخاب پورت (Port Specification)

گزینهتوضیحمثال
-p اسکن پورت‌های مشخص (با کاما یا خط تیره). nmap -p 22,80,443 192.168.1.1
-p- اسکن تمام پورت‌ها (۱ تا ۶۵۵۳۵). nmap -p- 192.168.1.1
-F اسکن سریع (۱۰۰ پورت معروف). nmap -F 192.168.1.1
--top-ports اسکن N پورت برتر (پیش‌فرض ۱۰۰۰). nmap --top-ports 200 192.168.1.1
-p (محدوده) اسکن یک محدوده پورت. nmap -p 1-1000 192.168.1.1

🛡️ تکنیک‌های دور زدن فایروال و IDS

گزینهتوضیحمثال
-f تکه‌تکه‌سازی بسته‌ها (Fragmentation) برای دور زدن فایروال. sudo nmap -f 192.168.1.1
--mtu تنظیم حداکثر اندازه بسته (MTU) برای دور زدن فایروال. sudo nmap --mtu 16 192.168.1.1
-D استفاده از Decoy IP (آدرس‌های جعلی) برای مخفی کردن منبع اصلی. sudo nmap -D 10.0.0.1,10.0.0.2,10.0.0.3 192.168.1.1
--spoof-mac جعل آدرس MAC برای دور زدن فیلتر MAC. sudo nmap --spoof-mac 00:11:22:33:44:55 192.168.1.1
-g یا --source-port استفاده از پورت منبع خاص (برای شبیه‌سازی ترافیک مجاز). sudo nmap -g 53 192.168.1.1
--data-length افزودن داده تصادفی به بسته‌ها برای تغییر اندازه. sudo nmap --data-length 200 192.168.1.1
--badsum ارسال بسته با Checksum اشتباه برای تست فایروال. sudo nmap --badsum 192.168.1.1
⚠️ هشدار: استفاده از این تکنیک‌ها بدون مجوز جرم است. فقط در محیط‌های آزمایشگاهی با مجوز استفاده شود.

📄 گزینه‌های خروجی (Output Options)

گزینهتوضیحمثال
-oN خروجی معمولی (Normal) – قابل خواندن توسط انسان. nmap -oN scan.txt 192.168.1.1
-oX خروجی XML – قابل پردازش توسط برنامه‌ها. nmap -oX scan.xml 192.168.1.1
-oG خروجی Grepable – قابل پردازش توسط grep. nmap -oG scan.gnmap 192.168.1.1
-oA خروجی همزمان در سه فرمت (Normal, XML, Grepable). nmap -oA scan 192.168.1.1
-v خروجی با جزئیات بیشتر (Verbose). nmap -v 192.168.1.1
-vv خروجی با جزئیات بسیار زیاد. nmap -vv 192.168.1.1
-d حالت Debug برای اشکال‌زدایی. nmap -d 192.168.1.1

📜 اسکریپت‌های NSE (Nmap Scripting Engine)

Nmap دارای بیش از ۶۰۰ اسکریپت است که برای انجام وظایف پیشرفته مانند شناسایی آسیب‌پذیری‌ها، بررسی پیکربندی امنیتی، جمع‌آوری اطلاعات و ... استفاده می‌شوند.

📌 اسکریپت‌های پرکاربرد:

اسکریپت/گروهکاربردمثال
vuln اسکن آسیب‌پذیری‌های شناخته‌شده. nmap --script=vuln 192.168.1.1
smb-vuln-* اسکن آسیب‌پذیری‌های SMB (مانند EternalBlue). nmap --script=smb-vuln-* -p 445 192.168.1.1
http-vuln-* اسکن آسیب‌پذیری‌های وب‌سرور. nmap --script=http-vuln-* -p 80,443 192.168.1.1
ssl-heartbleed بررسی آسیب‌پذیری Heartbleed. nmap --script=ssl-heartbleed -p 443 192.168.1.1
dns-zone-transfer بررسی امکان Zone Transfer DNS. nmap --script=dns-zone-transfer -p 53 192.168.1.1
http-enum شمارش دایرکتوری‌های وب. nmap --script=http-enum -p 80 192.168.1.1
ssh-brute Brute-Force به SSH. nmap --script=ssh-brute -p 22 192.168.1.1
ftp-anon بررسی دسترسی ناشناس به FTP. nmap --script=ftp-anon -p 21 192.168.1.1 
# لیست کردن همه اسکریپت‌های NSE
ls /usr/share/nmap/scripts/

# جستجوی اسکریپت‌های مرتبط با یک سرویس
ls /usr/share/nmap/scripts/ | grep http

# اجرای اسکریپت با آرگومان
nmap --script=http-title --script-args http-title.url=/admin 192.168.1.1
💡 نکته: اسکریپت‌های NSE بسیار قدرتمند هستند اما ممکن است باعث فعال‌سازی هشدارهای امنیتی شوند. با دقت از آنها استفاده کنید.

🧪 مثال‌های ترکیبی Nmap

📌 ۱. اسکن کامل یک سرور:

sudo nmap -A -p- 192.168.1.101

توضیح: اسکن تمام پورت‌ها با تشخیص سیستم‌عامل، نسخه سرویس و TraceRoute.

📌 ۲. اسکن سریع با تشخیص نسخه:

nmap -sV -F 192.168.1.101

توضیح: اسکن سریع (۱۰۰ پورت) با تشخیص نسخه سرویس‌ها.

📌 ۳. اسکن آسیب‌پذیری SMB:

nmap --script=smb-vuln-* -p 445 192.168.1.101

توضیح: بررسی آسیب‌پذیری‌های SMB (از جمله EternalBlue).

📌 ۴. اسکن با دور زدن فایروال:

sudo nmap -f -D 10.0.0.1,10.0.0.2 -T2 --scan-delay 1s 192.168.1.101

توضیح: اسکن با Fragmentation، Decoy IP، سرعت پایین و تأخیر بین بسته‌ها.

📌 ۵. اسکن شبکه کامل:

nmap -sn 192.168.1.0/24   # Ping Sweep
nmap -sS 192.168.1.0/24    # اسکن SYN همه دستگاه‌ها

توضیح: شناسایی دستگاه‌های زنده و سپس اسکن پورت‌های باز.

📌 ۶. اسکن با ذخیره خروجی:

nmap -oA scan_results -p- 192.168.1.101

توضیح: ذخیره خروجی در سه فرمت (Normal, XML, Grepable).

📌 ۷. تشخیص سیستم‌عامل با حدس:

sudo nmap -O --osscan-guess 192.168.1.101

توضیح: تشخیص سیستم‌عامل با استفاده از حدس‌های هوشمند.

📖 واژه‌نامه تخصصی Nmap

واژهتوضیح کامل
SYN Scan اسکن SYN یا Half-Open – یک تکنیک اسکن سریع و مخفی که اتصال TCP را کامل نمی‌کند.
TCP Connect Scan اسکن کامل TCP که Three-Way Handshake را کامل می‌کند و دقیق‌ترین نوع اسکن است.
UDP Scan اسکن پورت‌های UDP که به دلیل بدون اتصال بودن، کندتر و کم‌اعتمادتر است.
FIN Scan اسکن با ارسال بسته FIN – برای دور زدن فایروال‌های ساده استفاده می‌شود.
NULL Scan اسکن با ارسال بسته بدون هیچ فلگ TCP – برای دور زدن فایروال‌های ساده.
Xmas Scan اسکن با ارسال بسته با فلگ‌های FIN, PSH, URG – به دلیل روشن بودن تمام فلگ‌ها.
Idle Scan اسکن Zombie – کاملاً مخفی با استفاده از یک میزبان third-party.
NSE موتور اسکریپت‌نویسی Nmap که امکان اجرای اسکریپت‌های پیشرفته را فراهم می‌کند.
Decoy IP آدرس‌های IP جعلی که برای مخفی کردن منبع اصلی اسکن استفاده می‌شوند.
Fragmentation تکه‌تکه‌سازی بسته‌ها برای دور زدن فایروال و IDS.
OS Fingerprinting تشخیص سیستم‌عامل بر اساس ویژگی‌های پاسخ‌های دریافتی.
Version Detection تشخیص نام و نسخه سرویس‌های در حال اجرا روی پورت‌های باز.
Ping Sweep ارسال پینگ به یک محدوده IP برای شناسایی میزبان‌های زنده.
MTU حداکثر اندازه بسته قابل انتقال – برای تنظیم اندازه بسته‌ها در اسکن.
TTL Time To Live – تعداد هاپ‌های مجاز برای یک بسته در شبکه.
💡 جمع‌بندی چیت‌شیت Nmap:

Nmap یکی از قدرتمندترین ابزارهای اسکن شبکه است که هر هکر قانونمند باید به آن مسلط باشد. با ترکیب گزینه‌های مختلف، می‌توانید اطلاعات بسیار دقیقی از شبکه هدف به دست آورید.

📌 توصیه نهایی: همیشه اسکن را با -T3 یا -T4 شروع کنید و در صورت نیاز از گزینه‌های پیشرفته‌تر استفاده کنید. در محیط‌های واقعی، از اسکن‌های مخرب (مانند -T5) خودداری کنید.
