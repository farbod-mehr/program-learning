🛡️ چیت‌شیت جامع Burp Suite

🔰 مقدمه – Burp Suite چیست؟

Burp Suite یک ابزار قدرتمند و جامع برای تست نفوذ برنامه‌های وب (Web Application Penetration Testing) است که توسط شرکت PortSwigger توسعه داده شده است. این ابزار به عنوان یکی از استانداردهای طلایی در حوزه امنیت وب شناخته می‌شود و توسط هکرهای قانونمند، تحلیلگران امنیتی و تست‌کنندگان نفوذ در سراسر جهان استفاده می‌شود.

Burp Suite به عنوان یک پروکسی بین مرورگر و سرور عمل می‌کند و تمام ترافیک HTTP/HTTPS را ضبط، بررسی و دستکاری می‌کند. این قابلیت به متخصصان امنیت اجازه می‌دهد تا درخواست‌های ارسالی به سرور را تغییر دهند، پاسخ‌ها را تحلیل کنند و آسیب‌پذیری‌های مختلف را شناسایی نمایند.

💡 کاربردهای اصلی Burp Suite:
  • ضبط و دستکاری ترافیک (Proxy): مشاهده و تغییر درخواست‌ها و پاسخ‌های HTTP/HTTPS.
  • اسکن آسیب‌پذیری (Scanner): شناسایی خودکار آسیب‌پذیری‌های رایج مانند SQL Injection, XSS, CSRF.
  • حملات Brute-Force و Fuzzing (Intruder): ارسال خودکار درخواست‌های متعدد با payloadهای مختلف.
  • دستکاری و ارسال مجدد درخواست‌ها (Repeater): تغییر و ارسال مجدد درخواست‌ها برای تست دقیق‌تر.
  • رمزگشایی/رمزنگاری (Decoder): تبدیل داده‌ها به فرمت‌های مختلف (Base64, URL encoding, HTML encoding).
  • مقایسه پاسخ‌ها (Comparer): مقایسه دو پاسخ برای تشخیص تفاوت‌ها.
💡 نکته: Burp Suite در دو نسخه Community (رایگان) و Professional (تجاری) موجود است. نسخه رایگان برای یادگیری و تست‌های اولیه کافی است، اما نسخه Professional امکانات پیشرفته‌تری مانند اسکنر خودکار و Intruder با سرعت بالا را ارائه می‌دهد.

📥 نصب و راه‌اندازی Burp Suite

📌 نصب در Kali Linux:

Burp Suite در Kali Linux به صورت پیش‌فرض نصب است. برای اجرا:

burpsuite

اگر نصب نیست:

sudo apt update
sudo apt install burpsuite -y

📌 نصب در ویندوز:

دانلود از سایت رسمی: https://portswigger.net/burp

📌 راه‌اندازی اولیه:

  1. اجرای Burp Suite و انتخاب Temporary Project (برای تست موقت).
  2. انتخاب Use Burp Defaults برای تنظیمات پیش‌فرض.
  3. رفتن به تب Proxy و مشاهده آدرس و پورت پروکسی (پیش‌فرض: 127.0.0.1:8080).
  4. تنظیم مرورگر برای استفاده از پروکسی 127.0.0.1:8080.
  5. نصب گواهی SSL Burp برای مشاهده ترافیک HTTPS (در مرورگر به http://burp بروید و گواهی را دانلود و نصب کنید).
⚠️ نکته: برای مشاهده ترافیک HTTPS، حتماً گواهی Burp را در مرورگر نصب کنید. در غیر این صورت، خطای SSL مشاهده خواهید کرد.

📑 تب‌های اصلی Burp Suite

Burp Suite دارای تب‌های مختلفی است که هر کدام وظیفه خاصی را بر عهده دارند:

📡 ۱. Proxy – ضبط و دستکاری ترافیک

تب Proxy قلب Burp Suite است. تمام درخواست‌ها و پاسخ‌های HTTP/HTTPS از این تب عبور می‌کنند.

  • Intercept: قابلیت توقف درخواست‌ها برای مشاهده و تغییر قبل از ارسال به سرور.
  • HTTP History: تاریخچه تمام درخواست‌ها و پاسخ‌ها.
  • WebSockets History: تاریخچه ارتباطات WebSocket.
  • Options: تنظیمات پروکسی (پورت، فیلترها، و …).
# فعال‌سازی Intercept
# در تب Proxy روی Intercept is on کلیک کنید

# ارسال درخواست به Repeater
# راست‌کلیک → Send to Repeater

# ارسال درخواست به Intruder
# راست‌کلیک → Send to Intruder

🔄 ۲. Repeater – ارسال مجدد درخواست‌ها

تب Repeater به شما امکان می‌دهد یک درخواست را تغییر داده و بارها ارسال کنید تا پاسخ‌های مختلف را مشاهده کنید.

  • مشاهده و ویرایش درخواست قبل از ارسال.
  • ارسال مجدد با کلیک روی دکمه Send.
  • مشاهده پاسخ در سمت راست.
  • قابلیت تغییر روش HTTP (GET, POST, PUT, DELETE).
💡 نکته: Repeater برای تست دستی آسیب‌پذیری‌ها مانند SQL Injection و XSS بسیار مفید است.

🚀 ۳. Intruder – حملات خودکار

تب Intruder برای انجام حملات خودکار مانند Brute-Force، Fuzzing و Enumeration استفاده می‌شود.

  • Positions: تعیین نقاطی که payloadها در آن قرار می‌گیرند.
  • Payloads: تعیین لیست payloadها (دیکشنری).
  • Attack Types: Sniper, Battering ram, Pitchfork, Cluster bomb.
  • مشاهده نتایج حملات در تب Results.
# مثال: حمله Brute-Force به صفحه ورود
# ۱. درخواست را به Intruder ارسال کنید
# ۲. در Positions، قسمت username و password را highlight کنید
# ۳. روی Add § کلیک کنید
# ۴. در Payloads، یک دیکشنری بارگذاری کنید
# ۵. روی Start Attack کلیک کنید
⚠️ هشدار: حملات Intruder می‌توانند باعث ایجاد ترافیک سنگین و شناسایی توسط سیستم‌های دفاعی شوند. با احتیاط استفاده کنید.

🔍 ۴. Scanner – اسکن خودکار آسیب‌پذیری (فقط Professional)

تب Scanner به‌صورت خودکار برنامه وب را برای آسیب‌پذیری‌های رایج اسکن می‌کند.

  • اسکن فعال و غیرفعال.
  • شناسایی SQL Injection, XSS, CSRF, Path Traversal و …
  • نمایش نتایج با سطح خطر (High, Medium, Low).
  • ارائه پیشنهادات برای رفع آسیب‌پذیری‌ها.
💡 نکته: نسخه Community فاقد قابلیت Scanner است. برای اسکن خودکار از ابزارهای جایگزین مانند OWASP ZAP استفاده کنید.

🔐 ۵. Decoder – رمزگشایی و رمزنگاری

تب Decoder برای تبدیل داده‌ها به فرمت‌های مختلف استفاده می‌شود.

  • Encode: تبدیل به Base64, URL encoding, HTML encoding, Hex.
  • Decode: تبدیل از Base64, URL encoding, HTML encoding, Hex.
  • Hash: محاسبه هش (MD5, SHA-1, SHA-256).
# مثال: رمزگشایی Base64
# ۱. متن Base64 را در Decoder paste کنید
# ۲. Decode as → Base64 را انتخاب کنید

📊 ۶. Comparer – مقایسه پاسخ‌ها

تب Comparer برای مقایسه دو پاسخ یا دو درخواست برای یافتن تفاوت‌ها استفاده می‌شود.

  • مقایسه متن (Text).
  • مقایسه بایت (Bytes).
  • نمایش تفاوت‌ها به صورت رنگی.

🧩 ۷. Extender – افزونه‌ها

تب Extender برای نصب و مدیریت افزونه‌های Burp Suite (BApps) استفاده می‌شود.

  • نصب افزونه‌های متن‌باز از BApp Store.
  • بارگذاری افزونه‌های سفارشی (Python, Ruby, Java).
  • مدیریت و فعال/غیرفعال کردن افزونه‌ها.
💡 نکته: افزونه‌های مفید: ActiveScan++, Logger++, Turbo Intruder, XSS Validator.

🔒 نکات امنیتی و حرفه‌ای

  • همیشه پروکسی را بعد از تست غیرفعال کنید: اگر پروکسی Burp روشن بماند، ممکن است باعث اختلال در اتصال اینترنت شود.
  • از فیلترها استفاده کنید: در HTTP History از فیلترها برای نمایش فقط درخواست‌های مورد نظر استفاده کنید.
  • ذخیره پروژه: برای نگهداری نتایج تست، پروژه را ذخیره کنید.
  • استفاده از گواهی سفارشی: برای دور زدن SSL Pinning، از گواهی Burp در دستگاه موبایل استفاده کنید.
  • تنظیم تایم‌اوت: در Intruder، تایم‌اوت را تنظیم کنید تا از گیر کردن جلوگیری شود.
  • احترام به حریم خصوصی: هرگز داده‌های حساس (رمزها، اطلاعات کارت) را ذخیره نکنید مگر در محیط‌های آزمایشگاهی.
⚠️ هشدار اخلاقی: استفاده از Burp Suite برای تست برنامه‌های وب بدون مجوز، جرم محسوب می‌شود. همیشه قبل از تست، مجوز کتبی دریافت کنید.

📖 واژه‌نامه تخصصی Burp Suite

واژهتوضیح کامل
Proxy یک سرور واسط که درخواست‌های مرورگر را دریافت کرده و به سرور ارسال می‌کند. Burp Suite به عنوان یک پروکسی عمل می‌کند.
Intercept قابلیت توقف درخواست‌ها در پروکسی برای مشاهده و تغییر آنها قبل از ارسال به سرور.
Repeater ابزاری برای تغییر و ارسال مجدد درخواست‌ها به سرور برای مشاهده پاسخ‌های مختلف.
Intruder ابزاری برای انجام حملات خودکار مانند Brute-Force, Fuzzing و Enumeration.
Payload داده‌ای که در حملات Intruder به نقاط مشخص شده تزریق می‌شود (مثل رمز عبور، کد SQL).
Fuzzing ارسال داده‌های تصادفی یا نیمه‌تصادفی به برنامه برای شناسایی آسیب‌پذیری‌ها.
Decoder ابزاری برای رمزگشایی و رمزنگاری داده‌ها به فرمت‌های مختلف (Base64, URL, HTML, Hex).
Comparer ابزاری برای مقایسه دو پاسخ یا دو درخواست و نمایش تفاوت‌ها.
Extender سیستم مدیریت افزونه‌های Burp Suite که امکان نصب افزونه‌های سفارشی را فراهم می‌کند.
BApp فروشگاه افزونه‌های Burp Suite که شامل افزونه‌های متن‌باز و رایگان است.
SSL Pinning مکانیزمی که برنامه‌ها برای جلوگیری از حملات MITM از گواهی‌های خاص استفاده می‌کنند.
Scope محدوده تعیین‌شده برای تست که Burp Suite فقط درخواست‌های مربوط به آن را پردازش می‌کند.
Active Scan اسکن فعال که با ارسال درخواست‌های خاص به سرور، آسیب‌پذیری‌ها را شناسایی می‌کند.
💡 جمع‌بندی چیت‌شیت Burp Suite:

Burp Suite یکی از قدرتمندترین ابزارهای تست نفوذ وب است که با ترکیب Proxy، Repeater، Intruder و سایر امکانات، به متخصصان امنیت امکان شناسایی و بهره‌برداری از آسیب‌پذیری‌های برنامه‌های وب را می‌دهد.

📌 توصیه نهایی: برای تسلط بر Burp Suite، با Proxy و Repeater شروع کنید و سپس به سراغ Intruder و افزونه‌ها بروید. تمرین عملی روی محیط‌های آزمایشگاهی مانند DVWA و OWASP WebGoat بهترین راه برای یادگیری است.
