🔰 مقدمه – Enumeration چیست؟

Enumeration (شمارش) سومین مرحله از چرخه هک قانونمند است که پس از شناسایی (Footprinting) و اسکن (Scanning) انجام می‌شود. در این مرحله، هکر با استفاده از اتصالات فعال به سیستم هدف، اطلاعات دقیق‌تری مانند نام کاربران، گروه‌ها، اشتراک‌های شبکه، سرویس‌های در حال اجرا، و تنظیمات سیستم را جمع‌آوری می‌کند.

تفاوت اصلی Enumeration با اسکن در این است که اسکن به دنبال پورت‌های باز و سرویس‌ها است، در حالی که Enumeration به دنبال جزئیات دقیق درباره آن سرویس‌ها و کاربران است. به عبارت دیگر، اسکن به شما می‌گوید "چه چیزی" در حال اجراست، در حالی که Enumeration به شما می‌گوید "چه کسی" و "با چه جزئیاتی" در حال استفاده از آن است.

💡 نکته کلیدی: Enumeration یکی از حیاتی‌ترین مراحل هک است، زیرا اطلاعات جمع‌آوری شده در این مرحله به طور مستقیم برای نفوذ و دسترسی به سیستم استفاده می‌شوند.

🎯 اهداف Enumeration

Enumeration با اهداف مشخصی انجام می‌شود که در ادامه به مهم‌ترین آنها اشاره می‌کنیم:

  • شناسایی نام کاربران: پیدا کردن نام کاربران سیستم برای حملات Brute-Force و مهندسی اجتماعی.
  • شناسایی گروه‌ها و نقش‌ها: درک ساختار سازمانی و سطوح دسترسی.
  • شناسایی اشتراک‌های شبکه: پیدا کردن پوشه‌ها و منابع اشتراکی که ممکن است اطلاعات حساس داشته باشند.
  • شناسایی سرویس‌های در حال اجرا: دریافت اطلاعات دقیق‌تر از سرویس‌ها مانند نسخه و تنظیمات.
  • شناسایی سیاست‌های امنیتی: درک قوانین و محدودیت‌های سیستم هدف.
  • شناسایی آسیب‌پذیری‌ها: برخی اطلاعات Enumeration می‌توانند آسیب‌پذیری‌های خاصی را نشان دهند.
💡 نتیجه‌گیری: اطلاعات جمع‌آوری شده در این مرحله، نقشه راهی برای نفوذ به سیستم هدف است. هرچه Enumeration دقیق‌تر و کامل‌تر باشد، احتمال موفقیت در مراحل بعدی بیشتر خواهد بود.

💻 NetBIOS Enumeration

NetBIOS (Network Basic Input/Output System) یک پروتکل قدیمی اما همچنان پرکاربرد در شبکه‌های ویندوزی است که برای اشتراک‌گذاری فایل‌ها، چاپگرها و ارتباطات بین برنامه‌ها استفاده می‌شود. NetBIOS Enumeration به هکر اجازه می‌دهد تا اطلاعات زیر را جمع‌آوری کند:

  • نام کامپیوترها (NetBIOS Names)
  • نام کاربران (User Names)
  • گروه‌ها (Groups)
  • اشتراک‌های شبکه (Shares)
  • جلسات فعال (Active Sessions)
  • خدمات در حال اجرا (Services)

📌 ابزارهای NetBIOS Enumeration:

  • nbtstat: ابزار خط فرمان ویندوز برای نمایش اطلاعات NetBIOS.
  • enum4linux: ابزاری قدرتمند در Kali Linux برای Enumeration سیستم‌های ویندوز و SMB.
  • smbclient: ابزاری برای اتصال و کاوش اشتراک‌های SMB.
# استفاده از nbtstat (در ویندوز)
nbtstat -A 192.168.1.101

# استفاده از enum4linux (در Kali Linux)
enum4linux -a 192.168.1.101

# استفاده از smbclient برای مشاهده اشتراک‌ها
smbclient -L //192.168.1.101 -N

# اتصال به اشتراک خاص
smbclient //192.168.1.101/share -N
⚠️ نکته امنیتی: NetBIOS ذاتاً ناامن است و اطلاعات حساسی را افشا می‌کند. بسیاری از سازمان‌ها امروزه NetBIOS را غیرفعال می‌کنند و از پروتکل‌های امن‌تر مانند SMB با احراز هویت قوی استفاده می‌کنند.

📡 SNMP Enumeration

SNMP (Simple Network Management Protocol) یک پروتکل استاندارد برای مدیریت و مانیتورینگ دستگاه‌های شبکه است. SNMP Enumeration به هکر اجازه می‌دهد تا اطلاعات بسیار گسترده‌ای از یک دستگاه جمع‌آوری کند، از جمله:

  • اطلاعات سیستم: نام سیستم، توضیحات، موقعیت، تماس.
  • فرآیندهای در حال اجرا: لیست کامل فرآیندها و خدمات.
  • کاربران: نام کاربران لاگین‌شده.
  • شبکه: رابط‌های شبکه، آدرس‌های IP، جدول مسیریابی.
  • دیسک: اطلاعات دیسک‌ها و فضای ذخیره‌سازی.
  • نرم‌افزار: نرم‌افزارهای نصب‌شده و نسخه‌های آنها.

📌 رشته‌های Community مهم SNMP:

  • public: رشته پیش‌فرض برای دسترسی فقط خواندنی (Read-Only).
  • private: رشته پیش‌فرض برای دسترسی خواندن/نوشتن (Read-Write).
  • manager: گاهی اوقات برای مدیریت استفاده می‌شود.

📌 ابزارهای SNMP Enumeration:

  • snmpwalk: ابزار خط فرمان برای پیمایش درخت MIB.
  • snmpcheck: اسکنر SNMP برای جمع‌آوری اطلاعات.
  • MIB Browser: ابزار گرافیکی برای مرور MIB.
# استفاده از snmpwalk برای جمع‌آوری اطلاعات سیستم
snmpwalk -v 1 -c public 192.168.1.101 system

# جمع‌آوری اطلاعات کاربران
snmpwalk -v 1 -c public 192.168.1.101 .1.3.6.1.4.1.77.1.2.25

# جمع‌آوری اطلاعات فرآیندها
snmpwalk -v 1 -c public 192.168.1.101 hrSWRunTable

# استفاده از snmpcheck
snmpcheck -t 192.168.1.101 -c public
⚠️ هشدار امنیتی: استفاده از رشته‌های Community پیش‌فرض (public/private) یک آسیب‌پذیری امنیتی بزرگ است. سازمان‌ها باید رشته‌های قوی و منحصربه‌فرد برای SNMP تنظیم کنند.

👤 LDAP Enumeration

LDAP (Lightweight Directory Access Protocol) یک پروتکل استاندارد برای دسترسی و مدیریت دایرکتوری‌های اطلاعاتی است. LDAP معمولاً در سازمان‌ها برای مدیریت کاربران، گروه‌ها و منابع استفاده می‌شود. LDAP Enumeration به هکر اجازه می‌دهد تا اطلاعات زیر را جمع‌آوری کند:

  • ساختار دایرکتوری: سازماندهی کاربران و گروه‌ها.
  • نام کاربران و گروه‌ها: لیست کامل کاربران و گروه‌ها.
  • اطلاعات تماس: ایمیل، تلفن، آدرس.
  • سیاست‌های امنیتی: برخی اطلاعات امنیتی ممکن است در LDAP ذخیره شوند.
  • کامپیوترها و دستگاه‌ها: دستگاه‌های متصل به دایرکتوری.

📌 ابزارهای LDAP Enumeration:

  • ldapsearch: ابزار خط فرمان برای جستجو در LDAP.
  • JXplorer: مرورگر گرافیکی LDAP.
  • LDAP Admin: ابزار مدیریت LDAP.
  • Recon-ng: ماژول‌های LDAP در این چارچوب موجود است.
# جستجوی LDAP با ldapsearch
ldapsearch -x -h 192.168.1.101 -b "dc=example,dc=com" -D "cn=admin,dc=example,dc=com" -w password

# جستجوی کاربران
ldapsearch -x -h 192.168.1.101 -b "ou=users,dc=example,dc=com" "(objectClass=person)"

# جستجوی گروه‌ها
ldapsearch -x -h 192.168.1.101 -b "ou=groups,dc=example,dc=com" "(objectClass=group)"
💡 نکته: LDAP معمولاً با احراز هویت پیکربندی می‌شود. در صورتی که احراز هویت ضعیف باشد (مثل رمز پیش‌فرض)، هکر می‌تواند به تمام اطلاعات دسترسی پیدا کند.

📂 SMB Enumeration

SMB (Server Message Block) یک پروتکل شبکه برای اشتراک‌گذاری فایل‌ها، چاپگرها و ارتباطات بین دستگاه‌ها (عمدتاً در محیط‌های ویندوز) است. SMB Enumeration به هکر اجازه می‌دهد تا اطلاعات زیر را جمع‌آوری کند:

  • اشتراک‌های فایل: پوشه‌های مشترک در شبکه.
  • نام کاربران: کاربرانی که به سیستم دسترسی دارند.
  • گروه‌ها: گروه‌های کاربری و سطح دسترسی آنها.
  • سیاست‌های امنیتی: قوانین مرتبط با رمز عبور و احراز هویت.
  • جلسات فعال: کاربرانی که در حال حاضر به سیستم متصل هستند.

📌 ابزارهای SMB Enumeration:

  • enum4linux: ابزار قدرتمند برای Enumeration SMB و NetBIOS.
  • smbclient: کلاینت SMB برای اتصال و کاوش اشتراک‌ها.
  • smbmap: ابزاری برای نقشه‌برداری از اشتراک‌های SMB.
  • Nmap: با اسکریپت‌های NSE برای SMB.
# استفاده از enum4linux برای Enumeration کامل
enum4linux -a 192.168.1.101

# استفاده از smbclient برای مشاهده اشتراک‌ها
smbclient -L //192.168.1.101 -N

# استفاده از smbmap برای نقشه‌برداری
smbmap -H 192.168.1.101 -u guest -p ""

# استفاده از Nmap برای اسکن SMB
nmap --script=smb-* -p 445 192.168.1.101
⚠️ هشدار: SMB دارای آسیب‌پذیری‌های معروفی مانند EternalBlue است که در حملات باج‌افزاری مانند WannaCry استفاده شد. همیشه سیستم‌های SMB را به‌روز نگه دارید.

🗂️ NFS Enumeration

NFS (Network File System) یک پروتکل اشتراک‌گذاری فایل در محیط‌های Unix/Linux است. NFS Enumeration به هکر اجازه می‌دهد تا اشتراک‌های فایل NFS را شناسایی کند.

📌 ابزارهای NFS Enumeration:

  • showmount: نمایش اشتراک‌های NFS.
  • mount: برای اتصال به اشتراک‌های NFS.
  • Nmap: با اسکریپت‌های NSE برای NFS.
# نمایش اشتراک‌های NFS
showmount -e 192.168.1.101

# اتصال به اشتراک NFS
sudo mount -t nfs 192.168.1.101:/export /mnt/nfs

# استفاده از Nmap برای اسکن NFS
nmap --script=nfs-* -p 2049 192.168.1.101
💡 نکته: NFS معمولاً بدون رمزنگاری کار می‌کند و اگر به درستی پیکربندی نشود، می‌تواند اطلاعات حساس را افشا کند.

🌐 DNS Enumeration

DNS Enumeration فرآیند جمع‌آوری اطلاعات از سرورهای DNS است. این اطلاعات می‌تواند شامل زیردامنه‌ها، رکوردهای مختلف DNS و حتی Zone Transfer باشد.

📌 اطلاعات قابل دریافت از DNS:

  • رکوردهای A: آدرس‌های IPv4.
  • رکوردهای AAAA: آدرس‌های IPv6.
  • رکوردهای MX: سرورهای ایمیل.
  • رکوردهای NS: سرورهای نام.
  • رکوردهای TXT: اطلاعات متنی (مثل SPF).
  • زیردامنه‌ها: زیردامنه‌های یک دامنه.
  • Zone Transfer: انتقال کامل منطقه (در صورت پیکربندی اشتباه).

📌 ابزارهای DNS Enumeration:

  • dig: ابزار خط فرمان قدرتمند برای پرس‌وجوی DNS.
  • nslookup: ابزار خط فرمان ساده برای پرس‌وجوی DNS.
  • dnsrecon: ابزار پیشرفته برای Enumeration DNS.
  • dnsenum: ابزار دیگر برای Enumeration DNS با قابلیت جستجوی زیردامنه.
# استفاده از dig
dig example.com A
dig example.com MX
dig example.com NS
dig example.com ANY

# Zone Transfer
dig @ns1.example.com example.com AXFR

# استفاده از dnsrecon
dnsrecon -d example.com

# استفاده از dnsenum
dnsenum example.com
⚠️ هشدار: Zone Transfer یکی از آسیب‌پذیری‌های رایج DNS است. سرورهای DNS باید به گونه‌ای پیکربندی شوند که Zone Transfer را محدود کنند.

📧 Email Enumeration

Email Enumeration فرآیند جمع‌آوری آدرس‌های ایمیل از سرورهای ایمیل است. این کار معمولاً با استفاده از دستورات SMTP مانند VRFY و EXPN انجام می‌شود.

📌 روش‌های Email Enumeration:

  • VRFY (Verify): تأیید وجود یک آدرس ایمیل.
  • EXPN (Expand): نمایش اعضای یک گروه ایمیل.
  • RCPT TO: در مرحله SMTP، می‌توان از آن برای Enumeration استفاده کرد.

📌 ابزارهای Email Enumeration:

  • smtp-user-enum: ابزار تخصصی برای Enumeration کاربران SMTP.
  • theHarvester: جمع‌آوری ایمیل از منابع عمومی.
  • Metasploit: ماژول‌های SMTP Enumeration.
# استفاده از smtp-user-enum
smtp-user-enum -M VRFY -U users.txt -t 192.168.1.101

# استفاده از theHarvester
theharvester -d example.com -l 500 -b google,linkedin

# استفاده از Metasploit برای SMTP Enumeration
msf6 > use auxiliary/scanner/smtp/smtp_enum
💡 نکته: بسیاری از سرورهای SMTP مدرن، VRFY و EXPN را به دلایل امنیتی غیرفعال کرده‌اند. با این حال، برخی سرورها همچنان این دستورات را فعال نگه می‌دارند.

🤖 Enumeration با هوش مصنوعی

CEH v13 به عنوان اولین نسخه‌ای که هوش مصنوعی را در تمام مراحل هک قانونمند ادغام کرده، ابزارها و تکنیک‌های مبتنی بر AI را برای Enumeration نیز معرفی می‌کند.

📌 نقش هوش مصنوعی در Enumeration:

  • اتوماسیون جمع‌آوری اطلاعات: AI می‌تواند به‌صورت خودکار از چندین منبع اطلاعات جمع‌آوری کند.
  • تحلیل هوشمند داده‌ها: AI می‌تواند الگوها و روابط پنهان در داده‌های جمع‌آوری شده را شناسایی کند.
  • پیش‌بینی اطلاعات مفید: AI می‌تواند بر اساس داده‌های موجود، اطلاعات مفید را اولویت‌بندی کند.
  • کاهش خطاهای انسانی: خودکارسازی فرآیندها باعث کاهش خطاهای انسانی می‌شود.

📌 ابزارهای AI-Powered Enumeration در CEH v13:

  • AI-Powered OSINT Tools: ابزارهایی که از هوش مصنوعی برای جمع‌آوری و تحلیل اطلاعات استفاده می‌کنند.
  • AI-Based User Enumeration: شناسایی خودکار کاربران با استفاده از الگوریتم‌های یادگیری ماشین.
  • AI-Driven Data Analysis: تحلیل داده‌های جمع‌آوری شده برای شناسایی آسیب‌پذیری‌های بالقوه.
💡 چرا هوش مصنوعی در Enumeration مهم است؟

Enumeration با AI می‌تواند اطلاعات را بسیار سریع‌تر و دقیق‌تر از روش‌های دستی جمع‌آوری کند و الگوهای پیچیده‌ای را شناسایی کند که ممکن است توسط تحلیلگران انسانی نادیده گرفته شوند.

🛡️ راه‌های مقابله با Enumeration (Countermeasures)

برای جلوگیری از Enumeration، سازمان‌ها باید اقدامات زیر را انجام دهند:

📌 اقدامات کلی:

  • غیرفعال کردن سرویس‌های غیرضروری: سرویس‌هایی مانند NetBIOS و SNMP که نیازی به آنها نیست را غیرفعال کنید.
  • استفاده از فایروال: پورت‌های حساس را با فایروال محدود کنید.
  • به‌روزرسانی سیستم‌ها: همه سیستم‌ها را با آخرین وصله‌های امنیتی به‌روز نگه دارید.
  • استفاده از احراز هویت قوی: از رمزهای عبور قوی و احراز هویت چندعاملی استفاده کنید.
  • آموزش کارکنان: کارکنان را در مورد خطرات Enumeration و مهندسی اجتماعی آموزش دهید.

📌 اقدامات خاص برای هر پروتکل:

  • NetBIOS/SMB: NetBIOS را غیرفعال کنید و از SMB با احراز هویت قوی استفاده کنید.
  • SNMP: رشته‌های Community پیش‌فرض را تغییر دهید و از نسخه SNMPv3 با رمزنگاری استفاده کنید.
  • LDAP: از احراز هویت قوی و رمزنگاری (LDAPS) استفاده کنید.
  • DNS: Zone Transfer را محدود کنید و از DNSSEC استفاده کنید.
  • SMTP: دستورات VRFY و EXPN را غیرفعال کنید.
  • NFS: از NFSv4 با احراز هویت و رمزنگاری استفاده کنید.
⚠️ هشدار: Enumeration معمولاً اولین گام برای نفوذ است. اگر بتوانید Enumeration را متوقف کنید، بسیاری از حملات قبل از شروع خنثی می‌شوند.

🧪 کارگاه عملی – Enumeration در عمل

در این کارگاه، شما یک سناریوی جامع Enumeration را روی یک هدف فرضی پیاده‌سازی می‌کنید. هدف این کارگاه، آشنایی عملی با تکنیک‌ها و ابزارهای Enumeration است.

🎯 هدف کارگاه:

  • انجام NetBIOS Enumeration با enum4linux.
  • انجام SNMP Enumeration با snmpwalk و snmpcheck.
  • انجام SMB Enumeration با smbclient و smbmap.
  • انجام DNS Enumeration با dig و dnsrecon.
  • یادگیری تحلیل و ترکیب اطلاعات جمع‌آوری شده.

🖥️ محیط مورد نیاز:

  • حمله‌کننده: Kali Linux
  • هدف: Metasploitable 2 یا یک سیستم ویندوز آزمایشگاهی
  • ابزارها: enum4linux, snmpwalk, snmpcheck, smbclient, smbmap, dnsrecon, dig

📝 سناریوی گام‌به‌گام:

مرحله ۱: NetBIOS Enumeration با enum4linux

# Enumeration کامل با enum4linux
enum4linux -a 192.168.1.101

تحلیل: نتایج را بررسی کنید. اطلاعاتی مانند نام کاربران، گروه‌ها، اشتراک‌ها و جلسات فعال را شناسایی کنید.

مرحله ۲: SNMP Enumeration با snmpwalk

# جمع‌آوری اطلاعات سیستم
snmpwalk -v 1 -c public 192.168.1.101 system

# جمع‌آوری اطلاعات کاربران
snmpwalk -v 1 -c public 192.168.1.101 .1.3.6.1.4.1.77.1.2.25

# جمع‌آوری اطلاعات فرآیندها
snmpwalk -v 1 -c public 192.168.1.101 hrSWRunTable

تحلیل: اطلاعات سیستم، کاربران و فرآیندهای در حال اجرا را شناسایی کنید.

مرحله ۳: SMB Enumeration با smbclient و smbmap

# مشاهده اشتراک‌ها با smbclient
smbclient -L //192.168.1.101 -N

# نقشه‌برداری با smbmap
smbmap -H 192.168.1.101 -u guest -p ""

تحلیل: اشتراک‌های موجود و دسترسی‌های آنها را بررسی کنید.

مرحله ۴: DNS Enumeration با dig و dnsrecon

# پرس‌وجوی DNS با dig
dig example.com ANY

# Enumeration کامل DNS با dnsrecon
dnsrecon -d example.com

تحلیل: رکوردهای DNS، زیردامنه‌ها و اطلاعات Zone Transfer را شناسایی کنید.

مرحله ۵: جمع‌بندی و مستندسازی

تمام اطلاعات جمع‌آوری شده را در یک گزارش منظم ثبت کنید. این گزارش باید شامل موارد زیر باشد:

  • لیست کاربران و گروه‌های شناسایی شده.
  • اشتراک‌های شبکه و دسترسی‌ها.
  • اطلاعات سیستم از SNMP.
  • زیردامنه‌ها و رکوردهای DNS.
  • تحلیل و جمع‌بندی نقاط ضعف شناسایی شده.
⏳ تکلیف: تمام مراحل بالا را در محیط آزمایشگاهی خود اجرا کنید و یک گزارش کامل از نتایج Enumeration تهیه کنید.

📝 تمرین‌های عملی

این تمرینات به شما کمک می‌کنند تا مهارت‌های Enumeration خود را تقویت کنید.

  • تمرین ۱ – NetBIOS Enumeration:
    با استفاده از enum4linux، یک Enumeration کامل روی یک سیستم ویندوز انجام دهید و نتایج را تحلیل کنید.
  • تمرین ۲ – SNMP Enumeration:
    با استفاده از snmpwalk، اطلاعات سیستم و کاربران یک دستگاه با SNMP فعال را جمع‌آوری کنید.
  • تمرین ۳ – SMB Enumeration:
    با استفاده از smbclient و smbmap، اشتراک‌های SMB یک سیستم را شناسایی و تحلیل کنید.
  • تمرین ۴ – DNS Enumeration:
    با استفاده از dig و dnsrecon، اطلاعات DNS یک دامنه را جمع‌آوری کنید و زیردامنه‌های آن را پیدا کنید.
  • تمرین ۵ – LDAP Enumeration:
    با استفاده از ldapsearch، اطلاعات LDAP یک دایرکتوری را جمع‌آوری کنید.
  • تمرین ۶ – Email Enumeration:
    با استفاده از smtp-user-enum، کاربران ایمیل یک سرور SMTP را شناسایی کنید.
  • تمرین ۷ – ترکیبی:
    یک سناریوی کامل Enumeration را روی یک سیستم هدف پیاده‌سازی کنید و یک گزارش جامع تهیه کنید.

📖 واژه‌نامه تخصصی (Glossary)

در این بخش، تمام واژه‌های تخصصی این ماژول، همراه با ساختار (ریشه یا مخفف)، تعریف ساده، کاربرد در هک، و یک مثال روزمره توضیح داده شده است.

واژه ساختار / مخفف تعریف ساده کاربرد در هک مثال
Enumeration — فرآیند جمع‌آوری اطلاعات دقیق از یک سیستم هدف. شناسایی کاربران، گروه‌ها، اشتراک‌ها و سرویس‌ها. استفاده از enum4linux برای جمع‌آوری اطلاعات یک سرور.
NetBIOS Network Basic Input/Output System پروتکل قدیمی برای اشتراک‌گذاری فایل‌ها و ارتباطات در شبکه‌های ویندوز. شناسایی نام کامپیوترها، کاربران و اشتراک‌ها. دستور nbtstat -A 192.168.1.1
SNMP Simple Network Management Protocol پروتکل مدیریت شبکه برای مانیتورینگ دستگاه‌ها. جمع‌آوری اطلاعات سیستم، کاربران و فرآیندها. snmpwalk -v 1 -c public 192.168.1.1
LDAP Lightweight Directory Access Protocol پروتکل دسترسی به دایرکتوری‌های اطلاعاتی. جمع‌آوری اطلاعات کاربران و گروه‌ها از دایرکتوری. ldapsearch -x -h 192.168.1.1 -b "dc=example,dc=com"
SMB Server Message Block پروتکل اشتراک‌گذاری فایل‌ها در شبکه‌های ویندوز. شناسایی اشتراک‌ها، کاربران و گروه‌ها. smbclient -L //192.168.1.1 -N
NFS Network File System پروتکل اشتراک‌گذاری فایل‌ها در محیط‌های Unix/Linux. شناسایی اشتراک‌های فایل NFS. showmount -e 192.168.1.1
Zone Transfer — انتقال کامل رکوردهای DNS از یک سرور به سرور دیگر. جمع‌آوری تمام رکوردهای DNS یک دامنه. dig @ns1.example.com example.com AXFR
VRFY Verify دستور SMTP برای تأیید وجود یک آدرس ایمیل. تأیید وجود کاربران ایمیل. VRFY user@example.com
EXPN Expand دستور SMTP برای نمایش اعضای یک گروه ایمیل. شناسایی اعضای گروه‌های ایمیل. EXPN group@example.com
MIB Management Information Base پایگاه داده اطلاعات مدیریت در SNMP. مرجع اطلاعات قابل جمع‌آوری از SNMP. پیمایش درخت MIB با snmpwalk.
enum4linux — ابزار قدرتمند برای Enumeration NetBIOS و SMB. جمع‌آوری کامل اطلاعات از سیستم‌های ویندوز و Samba. enum4linux -a 192.168.1.1
snmpwalk — ابزار پیمایش درخت MIB در SNMP. جمع‌آوری اطلاعات سیستم، کاربران و فرآیندها. snmpwalk -v 1 -c public 192.168.1.1
ldapsearch — ابزار جستجو در دایرکتوری‌های LDAP. جمع‌آوری اطلاعات کاربران و گروه‌ها. ldapsearch -x -h 192.168.1.1 -b "dc=example,dc=com"
dnsrecon — ابزار پیشرفته برای Enumeration DNS. جمع‌آوری رکوردهای DNS، زیردامنه‌ها و Zone Transfer. dnsrecon -d example.com
