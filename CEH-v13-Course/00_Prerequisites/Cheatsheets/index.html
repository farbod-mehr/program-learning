🔰 معرفی دوره CEH V13 و اهمیت چیت‌شیت‌ها

CEH (Certified Ethical Hacker) یکی از معتبرترین گواهینامه‌های حوزه امنیت سایبری است که توسط EC-Council ارائه می‌شود. این دوره به شما مهارت‌های لازم برای شناسایی آسیب‌پذیری‌ها، انجام تست نفوذ (Penetration Testing) و دفاع در برابر حملات را می‌آموزد.

چیت‌شیت (Cheat Sheet) به مجموعه‌ای فشرده از دستورات، مفاهیم، نکات کلیدی و جداول مرجع گفته می‌شود که به متخصصان کمک می‌کند تا سریع‌تر و دقیق‌تر کار کنند. در دوره CEH، دو حوزهٔ اصلی شبکه و لینوکس از پایه‌ای‌ترین و پرکاربردترین مباحث هستند.

💡 چرا چیت‌شیت؟
  • دسترسی سریع به دستورات و مفاهیم کلیدی در زمان تست نفوذ
  • جمع‌آوری اطلاعات پراکنده در یک صفحهٔ منظم
  • یادگیری مؤثرتر با مرور مداوم
  • کمک به آمادگی برای آزمون عملی CEH Practical
⚠️ توجه: چیت‌شیت‌ها جایگزین مطالعهٔ عمیق نمی‌شوند، اما ابزاری کارآمد برای مرور سریع و به‌خاطرسپاری هستند.

🌐 چیت‌شیت شبکه (Networking Cheat Sheet)

این چیت‌شیت شامل مفاهیم پایه و پیشرفتهٔ شبکه است که در آزمون CEH و تست نفوذ روزمره به آنها نیاز دارید.

📌 مدل OSI (۷ لایه)

  • لایهٔ کاربرد (Application): ارتباط با نرم‌افزار کاربر (HTTP, FTP, DNS, SMTP)
  • لایهٔ نمایش (Presentation): رمزگذاری، فشرده‌سازی، تبدیل فرمت (SSL/TLS, JPEG)
  • لایهٔ جلسه (Session): مدیریت ارتباط (NetBIOS, RPC)
  • لایهٔ انتقال (Transport): انتقال مطمئن (TCP) یا سریع (UDP)
  • لایهٔ شبکه (Network): مسیریابی و آدرس‌دهی IP (IPv4, IPv6, ICMP)
  • لایهٔ پیوند داده (Data Link): انتقال فریم با آدرس MAC (Ethernet, Wi-Fi)
  • لایهٔ فیزیکی (Physical): انتقال بیت‌ها روی کابل یا امواج

📌 مدل TCP/IP (۴ لایه)

  • کاربرد: معادل لایه‌های ۷،۶،۵ OSI (HTTP, DNS, DHCP)
  • انتقال: TCP و UDP
  • اینترنت: IP, ICMP, ARP
  • دسترسی به شبکه: Ethernet, Wi-Fi, PPP

📌 آدرس‌دهی IPv4 و Subnetting

  • فرمت: ۴ بخش ۰ تا ۲۵۵ (مثل ۱۹۲.۱۶۸.۱.۱)
  • کلاس‌ها (منسوخ): A, B, C, D, E
  • آدرس‌های خصوصی: ۱۰.۰.۰.۰/۸ ، ۱۷۲.۱۶.۰.۰/۱۲ ، ۱۹۲.۱۶۸.۰.۰/۱۶
  • CIDR: نمایش با پیشوند (مثل /24)
  • فرمول میزبان: ۲^(۳۲-پیشوند) - ۲

📌 پورت‌های معروف

  • ۲۰/۲۱: FTP
  • ۲۲: SSH
  • ۲۳: Telnet
  • ۲۵: SMTP
  • ۵۳: DNS
  • ۸۰: HTTP
  • ۴۴۳: HTTPS
  • ۴۴۵: SMB
  • ۳۳۸۹: RDP

📌 تفاوت TCP و UDP

  • TCP: اتصال‌گرا، تأیید دریافت، مرتب‌سازی، کندتر، مناسب برای HTTP/SSH/FTP
  • UDP: بدون اتصال، بدون تأیید، سریع‌تر، مناسب برای DNS/VoIP/بازی

📌 دستورات کلیدی شبکه

  • ip a / ipconfig ← نمایش IP
  • ping ← تست اتصال
  • traceroute / tracert ← نمایش مسیر
  • netstat -tulpn / netstat -ano ← پورت‌های باز
  • nslookup / dig ← پرس‌وجوی DNS
  • arp -a ← جدول ARP
  • route -n ← جدول مسیریابی
💡 کاربرد در هک: با اسکن پورت (Nmap) و شنود (Wireshark) می‌توانید سرویس‌های فعال را شناسایی کرده و آسیب‌پذیری‌های آنها را بررسی کنید.

➡️ مشاهدهٔ چیت‌شیت کامل شبکه (با جداول و تمرینات)

🐧 چیت‌شیت لینوکس (Linux Cheat Sheet)

لینوکس سیستمعامل اصلی در تست نفوذ است. تسلط بر دستورات آن برای هر هکر قانونمند ضروری می‌باشد.

📌 مدیریت فایل‌ها و دایرکتوری‌ها

  • ls -la ← لیست فایل‌ها با جزئیات
  • cd ← تغییر دایرکتوری
  • pwd ← مسیر فعلی
  • cp -r ← کپی (با زیرشاخه‌ها)
  • mv ← جابه‌جایی یا تغییر نام
  • rm -rf ← حذف اجباری (با احتیاط!)
  • mkdir ← ساخت پوشه
  • touch ← ساخت فایل خالی

📌 مجوزها (Permissions)

  • chmod 755 file ← تنظیم مجوز (rwxr-xr-x)
  • chown user:group file ← تغییر مالکیت
  • umask ← پیش‌فرض مجوزها

📌 شبکه در لینوکس

  • ip a ← مشاهده IP
  • ping -c 4 ← تست اتصال
  • ss -tulpn ← پورت‌های باز (جایگزین netstat)
  • tcpdump -i eth0 ← ضبط بسته
  • nmap ← اسکن شبکه

📌 مدیریت فرآیندها

  • ps aux ← لیست همه فرآیندها
  • top / htop ← مانیتورینگ لحظه‌ای
  • kill -9 PID ← پایان دادن اجباری
  • systemctl start/stop/restart service ← مدیریت سرویس‌ها

📌 اسکریپت‌نویسی (Bash)

  • #!/bin/bash ← شبانگ (shebang)
  • var="value" ← تعریف متغیر
  • if [ condition ]; then ... fi ← شرط
  • for i in {1..10}; do ... done ← حلقه
  • chmod +x script.sh && ./script.sh ← اجرا
💡 نکته امنیتی: در لینوکس، دستورات مخرب را با sudo و با آگاهی کامل اجرا کنید. همیشه از محیط‌های ایزوله (مانند VirtualBox) برای تمرین استفاده کنید.

➡️ مشاهدهٔ چیت‌شیت کامل لینوکس (با دستورات پیشرفته و مثال‌ها)

📖 واژه‌نامه تخصصی (Glossary) – معنی، کاربرد، مثال، کارکرد و عملکرد

در این بخش، تمام واژه‌های کلیدی که در این صفحه و چیت‌شیت‌های مرتبط به کار رفته‌اند، به‌صورت کامل و با ذکر معنی، کاربرد، مثال، کارکرد و عملکرد توضیح داده شده‌اند.

واژهتوضیح کامل (معنی، کاربرد، مثال، کارکرد، عملکرد)
CEH معنی: Certified Ethical Hacker – گواهینامهٔ هک قانونمند از EC-Council.
کاربرد: تأیید مهارت‌های فرد در شناسایی آسیب‌پذیری‌ها و تست نفوذ.
مثال: یک متخصص امنیت با مدرک CEH می‌تواند تست نفوذ شبکهٔ سازمان را انجام دهد.
کارکرد: آموزش روش‌های هک اخلاقی برای دفاع در برابر حملات.
عملکرد: دارندهٔ این مدرک قادر به استفاده از ابزارهای هک در محیط‌های قانونی است.
Cheat Sheet (چیت‌شیت) معنی: برگهٔ مرجع فشرده شامل دستورات، مفاهیم و نکات کلیدی.
کاربرد: دسترسی سریع به اطلاعات در حین کار یا امتحان.
مثال: چیت‌شیت شبکه شامل جدول پورت‌ها و دستورات Nmap است.
کارکرد: جمع‌آوری دانش پراکنده در یک صفحهٔ منظم.
عملکرد: افزایش سرعت و دقت در انجام وظایف فنی.
OSI Model معنی: مدل مرجع اتصال سیستم‌های باز – یک مدل ۷ لایه برای استانداردسازی ارتباطات شبکه.
کاربرد: درک و عیب‌یابی لایه‌های مختلف شبکه.
مثال: لایهٔ انتقال (Transport) وظیفهٔ تحویل مطمئن داده را با TCP دارد.
کارکرد: تفکیک وظایف شبکه به لایه‌های مستقل.
عملکرد: هر لایه فقط با لایهٔ مجاور خود ارتباط دارد و تغییر در یک لایه بر دیگران تأثیر نمی‌گذارد.
TCP/IP معنی: مجموعه پروتکل‌های اینترنت شامل ۴ لایه (کاربرد، انتقال، اینترنت، دسترسی به شبکه).
کاربرد: اساس ارتباطات در اینترنت و شبکه‌های مدرن.
مثال: مرورگر وب از HTTP (لایه کاربرد) روی TCP (لایه انتقال) استفاده می‌کند.
کارکرد: ارائهٔ سرویس‌های انتقال داده بین دستگاه‌ها.
عملکرد: داده از لایه کاربرد به سمت لایه دسترسی شبکه حرکت می‌کند و بالعکس.
Subnetting معنی: تقسیم یک شبکهٔ IP بزرگ به چندین شبکهٔ کوچک‌تر (زیرشبکه).
کاربرد: مدیریت بهینهٔ آدرس‌ها، کاهش ترافیک Broadcast و افزایش امنیت.
مثال: تقسیم ۱۹۲.۱۶۸.۱.۰/24 به دو زیرشبکه /25.
کارکرد: با تغییر ماسک زیرشبکه، تعداد میزبان‌ها را کنترل می‌کند.
عملکرد: هر زیرشبکه محدودهٔ IP مستقل خود را دارد و ترافیک بین آنها از طریق روتر عبور می‌کند.
Port معنی: یک شناسه عددی ۱۶ بیتی (۰-۶۵۵۳۵) برای تشخیص سرویس‌های شبکه روی یک دستگاه.
کاربرد: هدایت ترافیک به برنامهٔ مناسب روی سرور.
مثال: پورت ۸۰ برای HTTP و پورت ۴۴۳ برای HTTPS.
کارکرد: سرویس‌ها روی پورت‌های خاص گوش می‌دهند (Listen).
عملکرد: کلاینت با ترکیب IP:Port به سرور متصل می‌شود (مثل ۱۹۲.۱۶۸.۱.۱:۸۰).
TCP معنی: پروتکل کنترل انتقال – یک پروتکل اتصال‌گرا و مطمئن در لایه انتقال.
کاربرد: انتقال داده‌های حساس که نیاز به تأیید و مرتب‌سازی دارند.
مثال: وب‌گردی (HTTP) و ایمیل (SMTP) از TCP استفاده می‌کنند.
کارکرد: برقراری ارتباط با Three-way Handshake (SYN, SYN-ACK, ACK).
عملکرد: تأیید دریافت (ACK)، مرتب‌سازی بسته‌ها، کنترل ازدحام و ارسال مجدد بسته‌های گم‌شده.
UDP معنی: پروتکل دیتاگرام کاربر – یک پروتکل بدون اتصال و سریع در لایه انتقال.
کاربرد: انتقال داده‌هایی که تأخیر برایشان مهم‌تر از اطمینان است (مثل VoIP، بازی).
مثال: DNS و استریم ویدیو از UDP استفاده می‌کنند.
کارکرد: بدون Handshake و بدون تأیید، داده را ارسال می‌کند.
عملکرد: بسته‌ها ممکن است گم شوند یا نامرتب برسند، اما سرعت بالایی دارد.
Linux معنی: یک سیستمعامل متن‌باز و شبه‌یونیکس که هستهٔ آن توسط لینوس توروالدز توسعه یافته است.
کاربرد: سیستمعامل اصلی برای تست نفوذ، سرورها و دستگاه‌های امنیتی.
مثال: توزیع کالی لینوکس (Kali Linux) مخصوص هک قانونمند است.
کارکرد: ارائهٔ محیط خط فرمان قدرتمند و ابزارهای فراوان شبکه.
عملکرد: امکان مدیریت فایل‌ها، فرآیندها، شبکه و اجرای اسکریپت‌های خودکار.
Permission (مجوز) معنی: سطح دسترسی به فایل‌ها و دایرکتوری‌ها در لینوکس (خواندن، نوشتن، اجرا).
کاربرد: کنترل دسترسی کاربران به منابع سیستم.
مثال: chmod 755 file به مالک اجازهٔ کامل و به گروه و دیگران اجازهٔ خواندن و اجرا می‌دهد.
کارکرد: تعیین سطح دسترسی برای مالک، گروه و دیگران.
عملکرد: از دسترسی غیرمجاز به فایل‌های حساس جلوگیری می‌کند.
Process (فرآیند) معنی: یک برنامهٔ در حال اجرا در سیستم‌عامل که دارای PID (شناسهٔ فرآیند) است.
کاربرد: مدیریت و نظارت بر برنامه‌های در حال اجرا.
مثال: مرورگر وب وقتی باز می‌شود، یک فرآیند جدید ایجاد می‌کند.
کارکرد: هر فرآیند منابعی (CPU، حافظه) مصرف می‌کند.
عملکرد: با دستوراتی مثل ps و kill می‌توان آنها را مشاهده یا پایان داد.
Bash Script معنی: یک فایل متنی شامل دستورات Bash که به‌صورت خودکار اجرا می‌شوند.
کاربرد: خودکارسازی کارهای تکراری در لینوکس.
مثال: اسکریپتی که هر روز از فایل‌های مهم بک‌آپ می‌گیرد.
کارکرد: ترکیب دستورات، حلقه‌ها و شرط‌ها برای انجام یک وظیفه.
عملکرد: با ./script.sh اجرا می‌شود و می‌تواند ورودی بگیرد و خروجی تولید کند.
Nmap معنی: یک ابزار متن‌باز برای اسکن شبکه و شناسایی پورت‌ها، سرویس‌ها و سیستم‌عامل.
کاربرد: جمع‌آوری اطلاعات از دستگاه‌های هدف در تست نفوذ.
مثال: nmap -sS 192.168.1.1 اسکن SYN مخفی انجام می‌دهد.
کارکرد: ارسال بسته‌های خاص به پورت‌ها و تحلیل پاسخ‌ها.
عملکرد: می‌تواند نسخهٔ سرویس، سیستم‌عامل و حتی آسیب‌پذیری‌ها را شناسایی کند.
Wireshark معنی: یک ابزار گرافیکی برای ضبط و تحلیل بسته‌های شبکه در زمان واقعی.
کاربرد: عیب‌یابی شبکه، شناسایی ترافیک مشکوک و تحلیل پروتکل‌ها.
مثال: با فیلتر http می‌توان درخواست‌های وب را مشاهده کرد.
کارکرد: بسته‌ها را از رابط شبکه گرفته و در تمام لایه‌ها نمایش می‌دهد.
عملکرد: امکان دنبال کردن جریان TCP، فیلترگذاری و استخراج اطلاعات مفید را فراهم می‌کند.
SSH معنی: پروتکل پوستهٔ امن – یک پروتکل رمزنگاری‌شده برای دسترسی از راه دور به سرورها.
کاربرد: مدیریت ایمن سرورهای لینوکس و انتقال فایل (SFTP).
مثال: ssh user@192.168.1.10 برای اتصال به یک سرور.
کارکرد: ایجاد یک تونل رمزنگاری‌شده بین کلاینت و سرور.
عملکرد: احراز هویت با رمز عبور یا کلید عمومی/خصوصی انجام می‌شود.
NAT معنی: ترجمهٔ آدرس شبکه – تبدیل آدرس‌های خصوصی به عمومی برای ارتباط با اینترنت.
کاربرد: کاهش مصرف آدرس‌های IPv4 و افزایش امنیت شبکه داخلی.
مثال: روتر خانگی آدرس ۱۹۲.۱۶۸.۱.۱۰ را به آدرس عمومی ISP تبدیل می‌کند.
کارکرد: نگاشت آدرس‌ها و پورت‌ها در جدول NAT.
عملکرد: بسته‌های خروجی با IP روتر جایگزین می‌شوند و پاسخ‌ها به دستگاه داخلی هدایت می‌شوند.
💡 نکته: این واژه‌نامه یک مرجع سریع برای تمام اصطلاحات کلیدی دوره CEH است. توصیه می‌شود هنگام مطالعهٔ چیت‌شیت‌ها، به این بخش مراجعه کنید.
📌 جمع‌بندی و گام بعدی:
  • برای تسلط بر شبکه، چیت‌شیت شبکه را مطالعه کنید.
  • برای تسلط بر لینوکس، چیت‌شیت لینوکس را مرور کنید.
  • هر زمان با واژه‌ای ناآشنا مواجه شدید، به واژه‌نامه برگردید.
