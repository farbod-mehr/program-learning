🔰 Kali Linux چیست و چرا برای CEH ضروری است؟

Kali Linux یک توزیع لینوکس مبتنی بر Debian است که به‌طور ویژه برای تست نفوذ (Penetration Testing)، تحلیل امنیتی و هک قانونمند طراحی شده است. این سیستمعامل توسط تیم Offensive Security توسعه داده می‌شود و شامل بیش از ۶۰۰ ابزار امنیتی از جمله Nmap، Wireshark، Metasploit، Aircrack-ng، Burp Suite و بسیاری دیگر است.

چرا در دوره CEH از Kali استفاده می‌کنیم؟

  • یکپارچگی: همهٔ ابزارهای موردنیاز در یک جا جمع شده‌اند.
  • به‌روزرسانی مداوم: جدیدترین نسخه‌های ابزارها به‌سرعت در Kali ارائه می‌شوند.
  • جامعهٔ بزرگ: مستندات گسترده و پشتیبانی قوی.
  • سازگاری: روی ماشین‌های مجازی، فیزیکی و حتی ابر (Cloud) قابل نصب است.
💡 نکته: Kali Linux فقط برای تست نفوذ و آموزش طراحی شده است. از آن در شبکه‌های واقعی بدون مجوز کتبی استفاده نکنید، زیرا این کار غیرقانونی است.

📥 پیش‌نیازهای نصب Kali

قبل از شروع نصب، مطمئن شوید که موارد زیر را دارید:

  • نرم‌افزار ماشین مجازی: VirtualBox (رایگان) یا VMware (تجاری).
  • فایل ISO Kali: از وب‌سایت رسمی Kali آخرین نسخه را دانلود کنید (حداقل ۳.۵ گیگابایت).
  • منابع سخت‌افزاری کافی:
    • رم (RAM): حداقل ۲ گیگابایت (۴ گیگابایت یا بیشتر توصیه می‌شود).
    • فضای دیسک: حداقل ۲۰ گیگابایت خالی.
    • پردازنده: پشتیبانی از مجازی‌سازی (VT-x/AMD-V) در BIOS فعال باشد.
  • اتصال به اینترنت: برای دانلود به‌روزرسانی‌ها و ابزارهای اضافی.
⚠️ هشدار: اگر رم سیستم شما کمتر از ۴ گیگابایت است، ممکن است Kali با کندی اجرا شود. در این صورت، از نسخهٔ Kali Light (بدون محیط گرافیکی سنگین) استفاده کنید.

⚙️ مراحل نصب Kali Linux روی VirtualBox

در این بخش، نصب را به‌صورت گام‌به‌گام و با توضیح چرایی هر تنظیمات پیش می‌بریم.

۱ ایجاد ماشین مجازی جدید
  • VirtualBox را باز کنید و روی New کلیک کنید.
  • نام: Kali CEH (یا هر نام دلخواه).
  • نوع (Type): Linux را انتخاب کنید.
  • ورژن (Version): Debian (64-bit) (چون Kali مبتنی بر Debian است).
  • چرا؟ انتخاب درست نوع و ورژن باعث می‌شود VirtualBox از درایورهای صحیح استفاده کند و عملکرد بهتری داشته باشد.
۲ تخصیص حافظه (RAM)
  • حداقل ۲۰۴۸ مگابایت (۲ گیگ) را انتخاب کنید.
  • توصیه: ۴۰۹۶ مگابایت (۴ گیگ) یا بیشتر، اگر رم فیزیکی شما اجازه می‌دهد.
  • چرا؟ ابزارهای تست نفوذ مثل Metasploit و Wireshark به حافظهٔ نسبتاً بالایی نیاز دارند. کمبود رم باعث کندی شدید می‌شود.
۳ ایجاد هارد دیسک مجازی
  • گزینهٔ Create a virtual hard disk now را انتخاب کنید.
  • نوع فایل: VDI (VirtualBox Disk Image) یا VMDK (سازگار با VMware).
  • فضا: ۲۰ گیگابایت (حداقل). اگر می‌خواهید ابزارهای زیادی نصب کنید، ۳۰ تا ۴۰ گیگ انتخاب کنید.
  • نوع ذخیره‌سازی: Dynamically allocated (فضا به‌مرور افزایش می‌یابد).
  • چرا؟ حالت پویا باعث می‌شود فایل هارد فقط به اندازهٔ واقعی استفاده‌شده رشد کند و در هدررفت فضای هارد فیزیکی صرفه‌جویی شود.
۴ متصل کردن فایل ISO
  • ماشین را انتخاب کنید و روی Settings کلیک کنید.
  • به بخش Storage بروید.
  • زیر Controller: IDE، روی Empty کلیک کنید.
  • در سمت راست، روی آیکون دیسک کلیک کرده و Choose a disk file... را بزنید.
  • فایل ISO دانلودشده را انتخاب کنید.
  • چرا؟ این کار به ماشین مجازی می‌گوید که از این ISO به‌عنوان دیسک بوت استفاده کند.
۵ شروع نصب و پیکربندی اولیه
  • روی Start کلیک کنید.
  • از منوی بوت، Graphical Install را انتخاب کنید (برای نصب با رابط گرافیکی).
  • زبان: English یا Persian (اگر فارسی را انتخاب کنید، متن‌های نصب به فارسی نمایش داده می‌شوند).
  • منطقه (Location): Iran یا United States (برای تنظیم منطقهٔ زمانی).
  • چیدمان صفحه‌کلید (Keyboard): Persian یا English (US).
۶ تنظیمات شبکه و کاربر
  • نام میزبان (Hostname): kali (پیش‌فرض) – این نام در شبکه شناسایی می‌شود.
  • نام دامنه (Domain name): خالی بگذارید (یا local).
  • رمز عبور ریشه (Root password): یک رمز قوی انتخاب کنید (حروف بزرگ/کوچک، اعداد، نمادها).
  • ایجاد کاربر معمولی: یک نام کاربری (مثل ceh) و رمز عبور مجزا وارد کنید.
  • چرا؟ در Kali، حساب ریشه (root) دسترسی کامل دارد. برای کارهای روزمره از کاربر معمولی استفاده کنید و فقط در صورت نیاز با sudo دستورات را اجرا کنید تا از آسیب‌های احتمالی جلوگیری شود.
۷ پارتیشن‌بندی دیسک
  • گزینهٔ Guided – use entire disk را انتخاب کنید.
  • دیسک مقصد (/dev/sda) را انتخاب کنید.
  • طرح پارتیشن‌بندی: All files in one partition (ساده‌ترین گزینه).
  • تغییرات را تأیید کرده و روی Finish partitioning and write changes to disk کلیک کنید.
  • چرا؟ برای یک ماشین مجازی تستی، پارتیشن‌بندی ساده کافی است. اگر نیاز به جداسازی (مثل جدا کردن /home) دارید، می‌توانید از حالت دستی (Manual) استفاده کنید.
۸ نصب GRUB (بوت‌لودر)
  • در پایان نصب، از شما می‌پرسد که GRUB را روی /dev/sda نصب کنید.
  • بله را انتخاب کنید.
  • چرا؟ GRUB به سیستم اجازه می‌دهد که Kali را به‌درستی بوت کند. اگر این مرحله را اشتباه انجام دهید، سیستم پس از ری‌استارت بوت نمی‌شود.
۹ پایان نصب و ری‌استارت
  • پس از اتمام نصب، گزینهٔ Continue را بزنید.
  • ماشین مجازی را ری‌استارت کنید.
  • پس از بوت، با کاربری که ایجاد کردید وارد شوید.
  • تأیید نصب موفق: ترمینال را باز کنید و دستور uname -a را اجرا کنید تا نسخهٔ هسته را ببینید.
💡 نکته طلایی: بعد از اولین ورود، حتماً Snapshot بگیرید! در VirtualBox از منوی Machine → Take Snapshot. این کار به شما اجازه می‌دهد در صورت بروز مشکل، به این نقطهٔ سالم برگردید.

🔧 پیکربندی پس از نصب – به‌روزرسانی و نصب ابزارها

پس از نصب موفق، باید سیستم را به‌روز کرده و ابزارهای ضروری را نصب کنید.

📌 به‌روزرسانی سیستم

sudo apt update          # بروزرسانی لیست مخازن
sudo apt upgrade -y      # ارتقاء بسته‌های نصب‌شده
sudo apt full-upgrade -y # ارتقاء کامل (شامل وابستگی‌ها)
sudo apt autoremove -y   # حذف بسته‌های بی‌استفاده

📌 نصب ابزارهای اضافی

  • ابزارهای شبکه: (معمولاً از قبل نصب‌اند، اما در صورت نیاز:) 
    sudo apt install nmap wireshark tcpdump netcat-openbsd
  • ابزارهای تست نفوذ وب: 
    sudo apt install burpsuite zaproxy
  • ابزارهای بی‌سیم: 
    sudo apt install aircrack-ng reaver kismet
  • ابزارهای استخراج اطلاعات: 
    sudo apt install recon-ng theharvester
💡 نکته: اگر فضای دیسک محدود است، فقط ابزارهایی که واقعاً نیاز دارید را نصب کنید. لیست کامل ابزارهای Kali در وب‌سایت رسمی موجود است.

🌐 تنظیمات شبکه در Kali

برای تست نفوذ، باید شبکه را به‌درستی پیکربندی کنید. در این بخش، تنظیمات شبکه در Kali را بررسی می‌کنیم.

📌 بررسی وضعیت شبکه

ip a                    # مشاهدهٔ تمام رابط‌های شبکه
ping -c 4 google.com    # تست اتصال به اینترنت
ip route                # مشاهدهٔ جدول مسیریابی

📌 تنظیم آدرس IP ثابت (در صورت نیاز)

اگر می‌خواهید Kali همیشه یک IP ثابت داشته باشد (مثلاً برای آزمایشگاه)، فایل /etc/network/interfaces را ویرایش کنید: 

sudo nano /etc/network/interfaces

# اضافه کنید:
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 1.1.1.1

سپس برای اعمال تغییرات:

sudo systemctl restart networking
💡 نکته: در VirtualBox، بهتر است از حالت NAT برای دسترسی به اینترنت و Host-Only یا Bridge برای ارتباط با سایر ماشین‌های مجازی استفاده کنید.

🛠️ عیب‌یابی مشکلات رایج در نصب و اجرای Kali

❌ مشکل ۱: ماشین مجازی پس از نصب بوت نمی‌شود
  • دلیل: ممکن است ISO در Storage متصل مانده باشد و سیستم دوباره وارد مراحل نصب شود.
  • راه‌حل: به Settings → Storage رفته و ISO را از Controller IDE خارج کنید (Remove disk).
❌ مشکل ۲: صفحه‌کلید یا زبان به‌درستی کار نمی‌کند
  • دلیل: انتخاب اشتباه چیدمان صفحه‌کلید در حین نصب.
  • راه‌حل: پس از نصب، دستور sudo dpkg-reconfigure keyboard-configuration را اجرا کرده و تنظیمات را اصلاح کنید.
❌ مشکل ۳: اینترنت در Kali کار نمی‌کند
  • دلیل: تنظیمات شبکه در VirtualBox (مثلاً NAT فعال نیست) یا عدم دریافت IP از DHCP.
  • راه‌حل:
    • بررسی کنید که آداپتور شبکه در VirtualBox روی NAT یا Bridged تنظیم شده باشد.
    • دستور sudo dhclient eth0 را اجرا کنید تا IP جدید دریافت کنید.
❌ مشکل ۴: فضای دیسک تمام شده است
  • دلیل: نصب ابزارهای زیاد یا ذخیرهٔ فایل‌های حجیم.
  • راه‌حل:
    • با df -h فضای مصرفی را بررسی کنید.
    • فایل‌های غیرضروری را با sudo apt clean و sudo apt autoremove حذف کنید.
    • در VirtualBox، می‌توانید اندازهٔ دیسک را افزایش دهید (نیاز به مراحل پیشرفته‌تر دارد).
❌ مشکل ۵: ابزارهای خاص نصب نشده‌اند
  • دلیل: مخزن (Repository) در /etc/apt/sources.list صحیح نیست.
  • راه‌حل: فایل را ویرایش کرده و خطوط زیر را اضافه کنید: 
    deb http://http.kali.org/kali kali-rolling main non-free contrib
    سپس sudo apt update را اجرا کنید.

🛡️ نکات امنیتی برای سخت‌سازی Kali

Kali Linux به‌صورت پیش‌فرض امنیت بالایی ندارد (چون برای تست طراحی شده است). برای استفاده‌ی ایمن‌تر، این نکات را رعایت کنید:

🔐 ۱. غیرفعال کردن حساب ریشه (Root)

پس از نصب، از کاربر معمولی استفاده کنید و فقط با sudo دستورات مدیریتی را اجرا کنید. برای غیرفعال کردن لاگین مستقیم ریشه:

sudo passwd -l root
🔐 ۲. تغییر رمز عبور پیش‌فرض

اگر از Kali به‌صورت پیش‌فرض استفاده می‌کنید، رمز عبور کاربر و ریشه را با passwd تغییر دهید.

🔐 ۳. به‌روزرسانی منظم

همیشه Kali را به‌روز نگه دارید: sudo apt update && sudo apt upgrade -y

🔐 ۴. نصب فایروال (UFW)

اگر Kali را به شبکه متصل می‌کنید، فایروال نصب کنید:

sudo apt install ufw
sudo ufw enable
sudo ufw status
🔐 ۵. استفاده از VPN

برای حفظ حریم خصوصی، ترافیک خود را از طریق VPN یا Tor هدایت کنید. ابزار anonsurf در Kali موجود است.

⚠️ هشدار: Kali یک سیستمعامل قدرتمند است. هرگز بدون مجوز از آن روی شبکه‌های دیگران استفاده نکنید. این کار جرم محسوب می‌شود.

📖 واژه‌نامه تخصصی مرتبط با نصب Kali

واژهتوضیح کامل (معنی، کاربرد، مثال، کارکرد، عملکرد)
Kali Linux معنی: توزیع لینوکس مبتنی بر Debian برای تست نفوذ و امنیت.
کاربرد: اجرای ابزارهای هک و تحلیل امنیتی.
مثال: اسکن شبکه با Nmap در Kali.
کارکرد: ارائهٔ بیش از ۶۰۰ ابزار امنیتی یکپارچه.
عملکرد: پس از نصب، می‌توانید مستقیماً از محیط گرافیکی یا خط فرمان آن استفاده کنید.
VirtualBox معنی: نرم‌افزار ماشین مجازی رایگان برای اجرای سیستمعامل‌های مهمان.
کاربرد: نصب Kali روی سیستم‌عامل فعلی بدون نیاز به پارتیشن‌بندی مجدد.
مثال: ایجاد یک ماشین مجازی برای Kali با ۴ گیگ رم.
کارکرد: شبیه‌سازی سخت‌افزار برای سیستمعامل مهمان.
عملکرد: امکان pause، snapshot و شبکه‌سازی بین ماشین‌های مجازی را فراهم می‌کند.
ISO معنی: یک فایل تصویری از یک دیسک نوری (CD/DVD) که شامل فایل‌های بوت‌شونده است.
کاربرد: نصب سیستمعامل از روی فایل ISO بدون نیاز به دیسک فیزیکی.
مثال: فایل kali-linux-2024.1-installer-amd64.iso.
کارکرد: به ماشین مجازی اجازه می‌دهد از این فایل به‌عنوان دیسک بوت استفاده کند.
عملکرد: هنگام نصب، سیستم از روی ISO بوت شده و مراحل نصب را آغاز می‌کند.
GRUB معنی: GRand Unified Bootloader – یک بوت‌لودر استاندارد در لینوکس.
کاربرد: مدیریت بوت چندگانه (مثل انتخاب بین Kali و ویندوز).
مثال: پس از نصب، GRUB روی /dev/sda نصب می‌شود.
کارکرد: بارگذاری هستهٔ لینوکس در حافظه و شروع سیستمعامل.
عملکرد: اگر GRUB به‌درستی نصب نشود، سیستم بوت نمی‌شود.
Root (ریشه) معنی: حساب کاربری با بالاترین سطح دسترسی در لینوکس (superuser).
کاربرد: اجرای دستورات مدیریتی مانند نصب نرم‌افزار یا تغییر تنظیمات سیستمی.
مثال: sudo apt update (با دسترسی root).
کارکرد: انجام عملیات‌هایی که به مجوزهای ویژه نیاز دارند.
عملکرد: استفادهٔ بی‌رویه از root خطرناک است؛ بهتر است از sudo استفاده کنید.
Snapshot معنی: یک تصویر لحظه‌ای از وضعیت فعلی ماشین مجازی.
کاربرد: بازگشت به یک وضعیت سالم در صورت بروز مشکل.
مثال: قبل از نصب ابزار جدید، از ماشین Snapshot بگیرید.
کارکرد: ذخیرهٔ کامل وضعیت دیسک، رم و تنظیمات.
عملکرد: در VirtualBox از منوی Machine → Take Snapshot.
NAT (Network Address Translation) معنی: حالت شبکه در VirtualBox که ماشین مجازی از طریق میزبان به اینترنت متصل می‌شود.
کاربرد: دسترسی به اینترنت بدون نیاز به تنظیمات پیچیده.
مثال: Kali با حالت NAT می‌تواند به‌راحتی به اینترنت متصل شود.
کارکرد: آدرس IP ماشین مجازی توسط VirtualBox ترجمه می‌شود.
عملکرد: میزبان و ماشین مجازی از شبکهٔ جداگانه‌ای استفاده می‌کنند.
Bridged Adapter معنی: حالت شبکه که ماشین مجازی مستقیماً به شبکهٔ فیزیکی متصل می‌شود.
کاربرد: زمانی که می‌خواهید Kali در شبکه‌ی محلی (LAN) مانند یک دستگاه واقعی دیده شود.
مثال: برای اسکن شبکه‌ی محلی با Nmap از Bridged استفاده کنید.
کارکرد: ماشین مجازی IP خود را از DHCP روتر دریافت می‌کند.
عملکرد: سایر دستگاه‌های شبکه می‌توانند Kali را مستقیماً ببینند.
