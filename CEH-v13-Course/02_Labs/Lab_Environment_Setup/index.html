🖥️ آزمایشگاه: راه‌اندازی محیط تست نفوذ

🔰 مقدمه – چرا محیط آزمایشگاهی مهم است؟

قبل از شروع هرگونه تست نفوذ، باید یک محیط آزمایشگاهی امن و ایزوله داشته باشید. این محیط به شما امکان می‌دهد تا بدون نگرانی از آسیب به سیستم‌های واقعی، تکنیک‌های هک را تمرین کنید.

در این آزمایشگاه، شما یک شبکه مجازی کامل با سه ماشین اصلی راه‌اندازی خواهید کرد:

  • Kali Linux: ماشین حمله‌کننده با تمام ابزارهای تست نفوذ.
  • Metasploitable 2: ماشین هدف آسیب‌پذیر برای تمرین حملات.
  • Windows 10 (اختیاری): برای تمرین حملات به سیستم‌های ویندوزی.
💡 هدف نهایی:

پس از اتمام این آزمایشگاه، شما یک محیط کامل برای انجام تمام تست‌های نفوذ دوره CEH V13 خواهید داشت و می‌توانید هر سناریویی را بدون نگرانی پیاده‌سازی کنید.

📋 نیازمندی‌های سیستم

قبل از شروع، مطمئن شوید که سیستم شما شرایط زیر را دارد:

💾 رم (RAM)
حداقل ۸ گیگابایت (۱۶ گیگابایت توصیه می‌شود)
💿 فضای ذخیره‌سازی
حداقل ۵۰ گیگابایت فضای خالی
⚙️ پردازنده
پشتیبانی از مجازی‌سازی (Intel VT-x یا AMD-V)
🖥️ نرم‌افزار
VirtualBox 7.x یا VMware Workstation/Player

📌 نرم‌افزارهای مورد نیاز:

  • VirtualBox: دانلود (رایگان و متن‌باز)
  • VMware Workstation Player: دانلود (رایگان برای استفاده شخصی)
  • تصاویر ISO:
    • Kali Linux ISO
    • Metasploitable 2
    • Windows 10 ISO (اختیاری)
💡 نکته: اگر سیستم شما محدودیت منابع دارد، می‌توانید فقط Kali و Metasploitable را نصب کنید و از Windows صرف‌نظر کنید.

📥 مرحله ۱: نصب VirtualBox

گام ۱

دانلود و نصب VirtualBox

از سایت رسمی VirtualBox، آخرین نسخه را دانلود و نصب کنید.

# برای سیستم‌های مبتنی بر Debian/Ubuntu می‌توانید از دستور زیر استفاده کنید:
sudo apt update
sudo apt install virtualbox virtualbox-ext-pack -y
⚠️ توجه: پس از نصب، حتماً سیستم را ری‌استارت کنید تا ماژول‌های هسته به‌درستی بارگذاری شوند.
گام ۲

نصب Extension Pack

برای پشتیبانی از USB 3.0، رمزگذاری دیسک و سایر قابلیت‌ها، Extension Pack را نصب کنید.

  • از منوی File → Preferences → Extensions
  • روی دکمه Add کلیک کرده و فایل .vbox-extpack را انتخاب کنید.
گام ۳

تنظیم شبکه مجازی (Host-Only Network)

یک شبکه Host-Only برای ارتباط بین ماشین‌های مجازی ایجاد کنید.

# در VirtualBox:
# File → Host Network Manager → Create
# Name: vboxnet0
# IPv4 Address: 192.168.56.1
# DHCP Server: فعال (برای تخصیص خودکار IP)
💡 نکته: این شبکه به ماشین‌ها اجازه می‌دهد بدون نیاز به اینترنت واقعی، با یکدیگر ارتباط برقرار کنند.

🐧 مرحله ۲: نصب Kali Linux (ماشین حمله‌کننده)

گام ۱

ایجاد ماشین مجازی جدید

  • نام: Kali Linux
  • نوع: Linux
  • ورژن: Debian (64-bit)
  • رم: ۲ تا ۴ گیگابایت (توصیه: ۴ گیگ)
  • هارد دیسک: ۲۰ تا ۴۰ گیگابایت (پویا یا ثابت)
گام ۲

تنظیمات شبکه

  • Adapter 1: NAT (برای دسترسی به اینترنت)
  • Adapter 2: Host-Only (vboxnet0) – برای ارتباط با Metasploitable
💡 نکته: دو آداپتور به ماشین امکان می‌دهد همزمان به اینترنت و شبکه داخلی دسترسی داشته باشد.
گام ۳

نصب Kali Linux

  1. ISO را در DVD-ROM قرار دهید و ماشین را روشن کنید.
  2. گزینه Graphical Install را انتخاب کنید.
  3. زبان و منطقه را انتخاب کنید (Persian / Iran یا English).
  4. نام میزبان: kali
  5. نام کاربری: kali و رمز عبور قوی انتخاب کنید.
  6. پارتیشن‌بندی: Guided – use entire disk
  7. نصب GRUB روی /dev/sda
  8. پس از اتمام، سیستم را ری‌استارت کنید.
# پس از ورود به Kali، سیستم را به‌روزرسانی کنید:
sudo apt update && sudo apt upgrade -y

# نصب ابزارهای اضافی (در صورت نیاز):
sudo apt install kali-linux-headless -y
گام ۴

بررسی شبکه در Kali

# نمایش تنظیمات شبکه
ip a

# تست اتصال به اینترنت (NAT)
ping -c 4 google.com

# تست ارتباط با شبکه Host-Only (بعد از نصب Metasploitable)
ping -c 4 192.168.56.101

🎯 مرحله ۳: نصب Metasploitable 2 (ماشین هدف)

گام ۱

دانلود و راه‌اندازی

  • فایل Metasploitable 2 را از اینترنت دانلود کنید (فایل .zip یا .ova).
  • در VirtualBox، از منوی File → Import Appliance استفاده کنید.
  • فایل .ova را انتخاب کرده و روی Import کلیک کنید.
  • تنظیمات پیش‌فرض را تأیید کنید.
گام ۲

تنظیمات شبکه Metasploitable

  • Adapter 1: Host-Only (vboxnet0) – ارتباط با Kali
  • Adapter 2: NAT (اختیاری – برای دسترسی به اینترنت)
⚠️ هشدار: هرگز Metasploitable را با آداپتور Bridged یا NAT به اینترنت متصل نکنید! این دستگاه به‌عمد آسیب‌پذیر است و می‌تواند توسط هکرهای دیگر هدف قرار گیرد.
گام ۳

ورود و بررسی Metasploitable

  • نام کاربری: msfadmin
  • رمز عبور: msfadmin
  • پس از ورود، آدرس IP را بررسی کنید:
ifconfig
# یا
ip a

# آدرس IP معمولاً 192.168.56.101 است
💡 نکته: اگر IP متفاوتی دریافت کردید، آن را یادداشت کنید. در تمام آزمایشگاه‌ها از این IP به عنوان هدف استفاده خواهید کرد.

🪟 مرحله ۴: نصب Windows 10 (اختیاری – برای تمرین حملات ویندوزی)

اختیاری

ایجاد ماشین Windows 10

  • نام: Windows 10
  • نوع: Windows
  • ورژن: Windows 10 (64-bit)
  • رم: ۴ تا ۸ گیگابایت
  • هارد دیسک: ۵۰ گیگابایت
اختیاری

تنظیمات شبکه

  • Adapter 1: Host-Only (vboxnet0)
  • Adapter 2: NAT (برای به‌روزرسانی و دسترسی به اینترنت)
اختیاری

غیرفعال کردن Windows Defender و فایروال

برای تمرین تست نفوذ، بهتر است امنیت ویندوز را به‌طور موقت غیرفعال کنید:

  • Windows Security → Virus & threat protection → Manage settings → Real-time protection (غیرفعال)
  • Windows Defender Firewall → Turn Windows Defender Firewall on or off → غیرفعال
⚠️ هشدار: این تنظیمات فقط برای محیط آزمایشگاهی است. هرگز در سیستم‌های واقعی امنیت را غیرفعال نکنید.

🔗 مرحله ۵: تست ارتباط بین ماشین‌ها

گام ۱

از Kali به Metasploitable پینگ کنید

ping -c 4 192.168.56.101

خروجی مورد انتظار: ۴ بسته ارسال و دریافت شده با زمان پاسخ.

گام ۲

اسکن سریع با Nmap از Kali

nmap -sV -p- 192.168.56.101

خروجی مورد انتظار: لیست پورت‌های باز شامل 21 (FTP), 22 (SSH), 80 (HTTP), 443 (HTTPS), 3306 (MySQL) و …

گام ۳

تست ارتباط با ویندوز (در صورت نصب)

ping -c 4 192.168.56.102   # آدرس IP ویندوز را بررسی کنید
✅ موفقیت!

اگر همه پینگ‌ها موفقیت‌آمیز بود، محیط آزمایشگاهی شما به درستی پیکربندی شده است. اکنون می‌توانید به سراغ آزمایشگاه هک سیستم بروید.

🛠️ ابزارهای ضروری در Kali

Kali Linux شامل بیش از ۶۰۰ ابزار تست نفوذ است. در اینجا مهم‌ترین ابزارهایی که در طول دوره استفاده خواهید کرد، معرفی می‌شوند:

  • Nmap: اسکن شبکه و شناسایی پورت‌ها
  • Metasploit: چارچوب بهره‌برداری از آسیب‌پذیری‌ها
  • Burp Suite: تست نفوذ برنامه‌های وب
  • Wireshark: تحلیل و شنود ترافیک شبکه
  • Hydra: حملات Brute-Force
  • SQLmap: تشخیص و بهره‌برداری SQL Injection
  • John the Ripper: کرک پسورد
  • Aircrack-ng: هک شبکه‌های بی‌سیم
  • Ettercap: حملات MITM و ARP Spoofing
💡 نکته: برای یادگیری هر ابزار، به بخش چیت‌شیت ابزارها مراجعه کنید.

🔧 عیب‌یابی مشکلات رایج

❌ مشکل: Kali و Metasploitable نمی‌توانند یکدیگر را پینگ کنند

  • مطمئن شوید هر دو ماشین از آداپتور Host-Only استفاده می‌کنند.
  • در VirtualBox، Host Network Manager را بررسی کنید و مطمئن شوید vboxnet0 فعال است.
  • در Kali، آدرس IP را با ip a و در Metasploitable با ifconfig بررسی کنید.
  • در Metasploitable، فایروال را غیرفعال کنید: sudo ufw disable

❌ مشکل: Kali اینترنت ندارد

  • مطمئن شوید که آداپتور اول (NAT) به درستی تنظیم شده است.
  • در Kali، دستور sudo dhclient eth0 را اجرا کنید.
  • فایل /etc/network/interfaces را بررسی کنید.

❌ مشکل: Metasploitable راه‌اندازی نمی‌شود

  • مطمئن شوید VirtualBox Extension Pack نصب است.
  • از نسخه صحیح VirtualBox استفاده کنید (حداقل ۶.x).
  • در صورت خطا، ماشین را با تنظیمات پیش‌فرض دوباره ایمپورت کنید.

❌ مشکل: ابزار در Kali یافت نمی‌شود

  • ابزار را نصب کنید: sudo apt install [tool-name] -y
  • اگر ابزار در مخازن نیست، از مخزن اضافی استفاده کنید.

✅ چک‌لیست نهایی

قبل از شروع آزمایشگاه‌های بعدی، مطمئن شوید که تمام موارد زیر را انجام داده‌اید:

  • VirtualBox یا VMware نصب شده است.
  • شبکه Host-Only (vboxnet0) پیکربندی شده است.
  • Kali Linux نصب و به‌روزرسانی شده است.
  • Metasploitable 2 ایمپورت و پیکربندی شده است.
  • ارتباط بین Kali و Metasploitable با پینگ تست شده است.
  • ابزارهای اصلی در Kali موجود هستند (Nmap, Metasploit, Burp Suite, Wireshark).
  • یک پوشه برای ذخیره نتایج آزمایشگاه‌ها ایجاد شده است.
