اهداف آموزشی

پس از پایان این فصل، شما قادر خواهید بود:

  • متغیرها را در پایتون تعریف و مقداردهی کنید
  • انواع داده‌ی اصلی (int, float, str, bool, None) را بشناسید
  • نوع داده‌ی یک متغیر را با ()type تشخیص دهید
  • تبدیل نوع (Type Casting) را با ()int, ()float, ()str انجام دهید
  • از ()input برای دریافت ورودی کاربر استفاده کنید
  • از f-strings برای فرمت‌دهی خروجی استفاده کنید
  • تفاوت بین متغیرهای قابل تغییر (Mutable) و غیرقابل تغییر (Immutable) را درک کنید

مقدمه و انگیزه‌بخشی

در فصل قبل با پایتون و نحوه‌ی نصب و اجرای آن آشنا شدید. حالا وقت آن است که با قلب تپنده‌ی هر برنامه یعنی متغیرها و انواع داده آشنا شوید.

متغیرها مانند جعبه‌هایی هستند که اطلاعات را در خود ذخیره می‌کنند. هر جعبه یک نوع داده مشخص دارد که مشخص می‌کند چه نوع اطلاعاتی می‌تواند در آن ذخیره شود.

در این فصل با همه‌ی انواع داده‌ی اصلی پایتون آشنا می‌شوید: اعداد صحیح و اعشاری، رشته‌ها، مقادیر بولی و مقدار خاص None. همچنین یاد می‌گیرید که چگونه با ()input از کاربر ورودی بگیرید و با ()print و f-strings خروجی‌های زیبا و خوانا تولید کنید.

تسلط بر متغیرها و انواع داده، پایه‌ی تمام مباحث بعدی است. اگر این مفاهیم را به خوبی درک کنید، یادگیری بقیه‌ی پایتون برای شما بسیار آسان‌تر خواهد شد.

۲.۱ متغیرها در پایتون و قوانین نام‌گذاری

در پایتون برای تعریف متغیر، فقط کافی است یک نام انتخاب کنید و به آن مقدار بدهید. نیازی به اعلام نوع داده نیست (زبان Dynamically Typed).

قوانین نام‌گذاری:

  • با حرف یا _ شروع شود (نه عدد)
  • فقط شامل حروف، اعداد و _ باشد
  • به حروف بزرگ و کوچک حساس است (Age و age متفاوتند)
  • از کلمات کلیدی پایتون (مثل if, for, class) استفاده نشود

کنوانسیون نام‌گذاری: از snake_case استفاده کنید (مثل user_age).

# تعریف متغیرها
name = "علی"
age = 25
height = 1.78
is_student = True

# چاپ متغیرها
print(name)      # "علی"
print(age)       # 25
print(height)    # 1.78
print(is_student) # True

# تغییر مقدار متغیر
age = 26
print(age)       # 26

# تعریف چند متغیر در یک خط
x, y, z = 10, 20, 30
print(x, y, z)   # 10 20 30

# مقدار یکسان برای چند متغیر
a = b = c = 0
print(a, b, c)   # 0 0 0
نکته در پایتون، متغیرها به صورت پویا (Dynamic) نوع‌دهی می‌شوند. یعنی یک متغیر می‌تواند در طول برنامه نوع خود را تغییر دهد، اما این کار معمولاً توصیه نمی‌شود.
✏ تمرین سه متغیر با نام‌های birth_year، first_name، salary تعریف کنید و مقادیر مناسب به آن‌ها بدهید. سپس آن‌ها را با ()print نمایش دهید.

۲.۳ تشخیص نوع داده با ()type

تابع ()type نوع داده‌ی یک متغیر را برمی‌گرداند. این تابع برای دیباگ و درک بهتر کد بسیار مفید است.

# تشخیص نوع داده
print(type(10))      # 
print(type(3.14))    # 
print(type("سلام"))  # 
print(type(True))    # 
print(type(None))    # 

# تشخیص نوع متغیرها
x = 42
y = 3.14
z = "Python"
print(type(x))  # 
print(type(y))  # 
print(type(z))  # 

# استفاده در شرط‌ها
value = 10
if type(value) == int:
    print("این یک عدد صحیح است")
✏ تمرین یک متغیر data = "123" تعریف کنید. با ()type نوع آن را ببینید. سپس آن را با ()int به عدد تبدیل کنید و دوباره نوع آن را بررسی کنید.

۲.۴ تبدیل نوع (Type Casting)

در پایتون می‌توانید با استفاده از توابع زیر، نوع داده‌ی یک متغیر را تغییر دهید:

  • ()int ← تبدیل به عدد صحیح
  • ()float ← تبدیل به عدد اعشاری
  • ()str ← تبدیل به رشته
  • ()bool ← تبدیل به مقدار بولی
# تبدیل به int
print(int(3.14))     # 3
print(int("123"))    # 123
print(int(True))     # 1
print(int(False))    # 0

# تبدیل به float
print(float(5))      # 5.0
print(float("3.14")) # 3.14
print(float(True))   # 1.0

# تبدیل به str
print(str(123))      # "123"
print(str(3.14))     # "3.14"
print(str(True))     # "True"

# تبدیل به bool
print(bool(0))       # False
print(bool(1))       # True
print(bool(""))      # False (رشته خالی)
print(bool("سلام"))  # True (رشته غیرخالی)
print(bool(None))    # False

# نکته: تبدیل رشته‌ی غیرعددی به int
# int("abc")  # ValueError
نکته در پایتون، هر متغیر را می‌توان به نوع دیگری تبدیل کرد، اما اگر تبدیل معنی‌دار نباشد (مثل تبدیل "abc" به عدد)، خطای ValueError رخ می‌دهد.
✏ تمرین یک رشته‌ی عددی مثل "42.5" را به float تبدیل کنید، سپس به int و در نهایت به str تبدیل کنید و هر مرحله را چاپ کنید.

۲.۵ دریافت ورودی با ()input

تابع ()input از کاربر ورودی می‌گیرد و آن را به صورت رشته برمی‌گرداند. برای دریافت اعداد، باید آن‌ها را با ()int یا ()float تبدیل کنید.

# دریافت نام
name = input("نام خود را وارد کنید: ")
print("سلام", name)

# دریافت عدد و تبدیل به int
age = int(input("سن خود را وارد کنید: "))
print("شما", age, "ساله هستید")

# دریافت عدد اعشاری
height = float(input("قد خود را به متر وارد کنید: "))
print("قد شما", height, "متر")

# محاسبه با ورودی
num1 = int(input("عدد اول: "))
num2 = int(input("عدد دوم: "))
print("مجموع:", num1 + num2)
نکته فراموش نکنید که ورودی ()input همیشه رشته است. اگر بخواهید محاسبات ریاضی انجام دهید، حتماً آن را به int یا float تبدیل کنید.

۲.۶ فرمت‌دهی خروجی با f-strings

f-strings (رشته‌های f) یک روش مدرن و ساده برای فرمت‌دهی رشته‌ها در پایتون هستند. با قرار دادن f قبل از رشته و استفاده از {} برای متغیرها، می‌توانید خروجی‌های زیبا و خوانا تولید کنید.

name = "علی"
age = 25
height = 1.78

# f-string ساده
print(f"نام: {name}, سن: {age}")

# محاسبه درون f-string
print(f"آینده {age + 1} ساله می‌شوید")

# فرمت‌دهی اعداد
pi = 3.14159265
print(f"pi با ۲ رقم اعشار: {pi:.2f}")   # 3.14
print(f"pi با ۴ رقم اعشار: {pi:.4f}")   # 3.1416

# فرمت‌دهی با فاصله
score = 95
print(f"امتیاز: {score:>5}")  # چپ‌چین با ۵ فاصله

# استفاده از متغیرها درون f-string
price = 19900
discount = 0.15
final_price = price * (1 - discount)
print(f"قیمت با {discount * 100:.0f}% تخفیف: {final_price:,.0f} تومان")
# خروجی: قیمت با ۱۵% تخفیف: ۱۶,۹۱۵ تومان
نکته طلایی f-strings از Python 3.6 به بعد در دسترس هستند و بهترین روش برای فرمت‌دهی رشته‌ها محسوب می‌شوند. اگر از نسخه‌های قدیمی‌تر استفاده می‌کنید، از ()format استفاده کنید.
✏ تمرین برنامه‌ای بنویسید که نام، سن و شهر کاربر را دریافت کند و با f-string یک پیام خوش‌آمدگویی کامل نمایش دهد.

۲.۷ متغیرهای قابل تغییر (Mutable) و غیرقابل تغییر (Immutable)

در پایتون، برخی از انواع داده غیرقابل تغییر (Immutable) هستند و برخی قابل تغییر (Mutable):

  • Immutable (غیرقابل تغییر): int, float, str, bool, tuple
  • Mutable (قابل تغییر): list, dict, set
# Immutable: رشته‌ها
text = "سلام"
print(id(text))  # آدرس حافظه
text = text + " دنیا"  # رشته‌ی جدید ایجاد می‌شود
print(id(text))  # آدرس حافظه تغییر کرده است

# Immutable: اعداد
x = 10
print(id(x))
x = x + 5  # عدد جدید ایجاد می‌شود
print(id(x))  # آدرس تغییر کرده است

# Mutable: لیست‌ها (در فصل بعد)
my_list = [1, 2, 3]
print(id(my_list))
my_list.append(4)  # لیست تغییر می‌کند
print(id(my_list))  # آدرس ثابت می‌ماند
نکته طلایی درک تفاوت بین انواع Immutable و Mutable برای جلوگیری از باگ‌های عجیب در برنامه‌های پیچیده بسیار مهم است. مخصوصاً وقتی که متغیرها را به توابع ارسال می‌کنید.
✏ تمرین یک رشته تعریف کنید و آن را تغییر دهید. با ()id آدرس حافظه را قبل و بعد از تغییر بررسی کنید. سپس یک لیست (با []) تعریف کنید و با ()append به آن عنصر اضافه کنید و دوباره آدرس را بررسی کنید.

جمع‌بندی و خلاصه

نکات طلایی متغیرها با نام snake_case تعریف می‌شوند. انواع داده‌ی اصلی: int, float, str, bool, None. ()type نوع داده‌ی متغیر را تشخیص می‌دهد. ()int, ()float, ()str برای تبدیل نوع استفاده می‌شوند. ()input ورودی را به صورت رشته دریافت می‌کند. f-strings بهترین روش برای فرمت‌دهی خروجی است. int, float, str → Immutable (غیرقابل تغییر). list, dict, set → Mutable (قابل تغییر).

# تعریف متغیر
name = "علی"
age = 25
height = 1.78

# تشخیص نوع
type(name)  # 

# تبدیل نوع
int("123")    # 123
float("3.14") # 3.14
str(123)      # "123"

# ورودی
name = input("نام: ")
age = int(input("سن: "))

# f-string
print(f"نام: {name}, سن: {age}")

واژه‌نامه تخصصی

  • Variable (متغیر): نامی برای ذخیره‌سازی یک مقدار.
  • int: عدد صحیح (مثل ۱۰، ۵-).
  • float: عدد اعشاری (مثل ۳.۱۴).
  • str: رشته (متن) — با ' یا " مشخص می‌شود.
  • bool: مقدار بولی (True یا False).
  • None: مقدار خالی یا عدم وجود مقدار.
  • Type Casting: تبدیل یک نوع داده به نوع دیگر.
  • f-string: روش مدرن برای فرمت‌دهی رشته‌ها.
  • Mutable: قابل تغییر (لیست‌ها، دیکشنری‌ها).
  • Immutable: غیرقابل تغییر (اعداد، رشته‌ها، تاپل‌ها).

شرح: یک برنامه‌ی خط فرمان بسازید که مانند یک ماشین حساب عمل کند و شامل موارد زیر باشد:

  • از کاربر دو عدد (با ()input) دریافت کند.
  • یک عملگر (+, -, *, /) را از کاربر دریافت کند.
  • بر اساس عملگر، عملیات ریاضی را انجام دهد و نتیجه را با f-string نمایش دهد.
  • در صورت تقسیم بر صفر، پیام «تقسیم بر صفر مجاز نیست» را نمایش دهد (با شرط).
  • با ()type نوع داده‌ی ورودی‌ها را در کنسول چاپ کند.
  • از f-strings برای نمایش نتایج با ۲ رقم اعشار استفاده کند.
  • یک پیام خوش‌آمدگویی با نام کاربر (دریافت شده از ()input) نمایش دهد.

کد خود را در VS Code بنویسید و با python3 اجرا کنید.

چالش بیشتر پشتیبانی از عملگرهای توان (**) و باقی‌مانده (%). اجازه‌ی ادامه‌ی محاسبه با نتیجه‌ی قبلی (مثل یک ماشین حساب واقعی). ذخیره‌ی تاریخچه‌ی عملیات در یک لیست (با نمایش در انتها).
